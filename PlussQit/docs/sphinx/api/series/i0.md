# Series::i0

[Back to Series API Reference](../../series_api_reference)

## Signature

```cpp
Series Series::i0() const
Series& Series::i0_()
Series& Series::i0_() const
```

## What It Does

Computes the modified Bessel function of the first kind, order zero, `I0`,
elementwise:

```
I0(x) = sum_{k>=0} (x/2)^(2k) / (k!)^2
```

`I0` is the normalizing constant of the von Mises distribution — the circular
analogue of a Gaussian — so `i0()` shows up whenever a density or likelihood is
defined over angles. It is also the shape factor of a Kaiser window and appears
in the amplitude statistics of narrowband noise (the Rician distribution).

Behaviour:

- `I0(0) = 1`, its minimum.
- `I0` is even: `I0(-x) = I0(x)`.
- It grows very fast — roughly `e^|x| / sqrt(2 pi |x|)` for large `|x|` — so
  `i0()` overflows `float64` for `|x|` past about `713`.
- It is smooth and strictly positive everywhere; there are no poles or
  branch points.

`i0()` is out-of-place; `i0_()` overwrites the current storage.

## Parameters

None.

## Returns

`Series` or `Series&`
    A `Series` with the same shape as `self`, each element replaced by `I0(x)`.
    `i0_()` returns a reference to the mutated series.

An integral input is promoted to `float64`.

## Gradient

`i0()` is differentiable everywhere. Its derivative is the order-one modified
Bessel function `I1`:

```
d/dx I0(x) = I1(x)
```

`I1` is odd and `I1(0) = 0`, so a tracked `i0()` has zero slope at the origin
and a slope that grows with `|x|` away from it. The backward pass evaluates
`I1` directly.

## In-Place Form

`i0_()` is the in-place sibling of [`i0()`](i0.md): it computes the same
result and writes it back into `self` directly — mutating it (and any other
handle sharing the same storage) instead of allocating a new `Series` — then
returns a reference to `self`.

Despite being declared `const` at the call site — a quirk of how this method's wrapper is generated, not a promise that `self` is left unchanged — `i0_()` genuinely mutates the series it's called on.

```cpp
auto x = pluss::make_series({0.0, 1.0});

auto& ref = x.i0_();
std::cout << "x=" << x << "\n";
std::cout << std::boolalpha << "same object: " << (&ref == &x);
```

### Output

```text
x=pluss::Series(shape=[2], strides=[1], dtype=float64, platform=cpu, numel=2, contiguous=true)
data=[1, 1.2660658]
same object: true
```

## Examples

Example 1. `I0` rises from `1` at the origin.

```cpp
pluss::series::print(
    std::cout,
    pluss::make_series({0.0, 1.0, 2.0, 3.0}).i0()
) << "\n";
```

### Output

```text
Series(shape=[4], strides=[1], dtype=float64, platform=cpu, numel=4, contiguous=true)
data=[1.0000, 1.2661, 2.2796, 4.8808]
```

Example 2. `I0` is even.

```cpp
pluss::series::print(std::cout,
                     pluss::make_series({-3.0, -1.0, 1.0, 3.0}).i0());
```

### Output

```text
Series(shape=[4], strides=[1], dtype=float64, platform=cpu, numel=4, contiguous=true)
data=[4.8808, 1.2661, 1.2661, 4.8808]
```

Example 3. The backward pass is `I1(x)`. Although the forward function is
even, its derivative must be odd: equal-magnitude negative and positive inputs
produce opposite sensitivities.

```cpp
auto x = pluss::make_series({-2.0, -1.0, 0.0, 1.0, 2.0});
x.tracks_slope_(true);
x.i0().sum().reverse();

pluss::series::print(std::cout, x.sensitivity());
```

### Output

```text
Series(shape=[5], strides=[1], dtype=float64, platform=cpu, numel=5, contiguous=true)
data=[-1.5906, -0.5652, 0.0000, 0.5652, 1.5906]
```

Example 4. Integral inputs are promoted to `float64`.

```cpp
pluss::series::print(std::cout, pluss::make_series({0, 1, 2}).i0());
```

### Output

```text
Series(shape=[3], strides=[1], dtype=float64, platform=cpu, numel=3, contiguous=true)
data=[1.0000, 1.2661, 2.2796]
```

Example 5. `i0_()` overwrites the current storage in place.

```cpp
auto a = pluss::make_series({0.0, 1.0, 2.0});
a.i0_();

pluss::series::print(std::cout, a);
```

### Output

```text
Series(shape=[3], strides=[1], dtype=float64, platform=cpu, numel=3, contiguous=true)
data=[1.0000, 1.2661, 2.2796]
```

## Gotchas And Failure Modes

- `I0` grows exponentially. For `|x|` past roughly `713` the result overflows
  to `+inf`. When you only need a ratio or a log — a von Mises log-likelihood,
  for instance — rescale before calling rather than dividing two large `I0`
  values.
- This is the *modified* Bessel function `I0`, not the oscillatory `J0`. `I0`
  is monotone on `[0, inf)` and never negative.
- The gradient is `I1`, not `I0` itself.
- Integral inputs promote to `float64`.
- `i0_()` requires floating storage. An integral receiver cannot represent the
  non-integral result, so use the out-of-place `i0()` to obtain `float64`.

## Summary

`i0()` is the order-zero modified Bessel function `I0`:

- `I0(0) = 1`, even, strictly positive, no singularities
- grows like `e^|x| / sqrt(2 pi |x|)`; overflows for `|x|` past ~713
- differentiable everywhere with backward `I1(x)`
- `i0_()` is the in-place form

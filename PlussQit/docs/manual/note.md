# Note by example

Each page here solves a real text task end to end with `Note`: complete programs that print their results, with the output copied from the run. The reference pages say what each method does; these pages show how to combine methods to clean, parse and read text.

1. **Cleaning text and protecting data.** Tidy names, validate addresses, mask personal data, repair web-scraped text and build safe slugs and file names.
2. **Parsing, counting and reading text.** Pull fields out of a log with regular expressions, select the failing requests, tokenise reviews to count what people talk about, and outline a Markdown document and check its links.
3. **Comparing and matching text.** Diff two versions of a file and find near-duplicate listings with a visible threshold.
4. **Documents: generating and checking.** A mail merge with defaults and a LaTeX manuscript check for undefined references and missing citations.

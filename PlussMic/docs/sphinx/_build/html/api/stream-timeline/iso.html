StreamTimelineAccessor::iso¶

Back to StreamTimelineAccessor API Reference

Signature¶

Stream StreamTimelineAccessor::iso() const

What It Does¶

Renders the bound stream’s timestamp as a fixed ISO-8601-with-offset text representation, replacing it with a Note (text) stream. Equivalent to fmt("%Y-%m-%dT%H:%M:%S.%f%z").

Important

StreamTimelineAccessor requires the bound stream to be Timeline- or TimeIndex-kind Same precondition as every method on this accessor — see StreamTimelineAccessor::isnat’s own important callout for the full explanation and the exact throw message.

Parameters¶

None

Returns¶

Stream A new Note stream holding each row as "YYYY-MM-DDTHH:MM:SS.fffffffff+HH:MM".

Examples¶

Example 1. Render a timestamp as ISO-8601 text.

auto stream = pluss::kindle::Stream(pluss::make_timeline({"2024-01-31T09:15:30Z"}));
auto out = stream.tl().iso();
std::cout << out.as_note().at(0);

Output¶

2024-01-31T09:15:30.000000000+00:00

Notes¶

  • Always includes the full 9-digit nanosecond fraction and a signed %z offset — use fmt() with your own pattern for a more compact string.

  • Changes the stream’s kind from Timeline/TimeIndex to Note.

  • See the important callout above.

See Also¶

  • Stream::tl: the entry point this accessor is reached from.

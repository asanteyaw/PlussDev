StreamTimelineAccessor::epoch¶

Back to StreamTimelineAccessor API Reference

Signature¶

Stream StreamTimelineAccessor::epoch(pluss::table::TimeUnit unit = pluss::table::TimeUnit::Nanos) const

What It Does¶

Extracts the bound stream’s timestamp as a Unix epoch value in unit, replacing it with an Int64 Series stream.

Important

StreamTimelineAccessor requires the bound stream to be Timeline- or TimeIndex-kind Same precondition as every method on this accessor — see StreamTimelineAccessor::isnat’s own important callout for the full explanation and the exact throw message.

Important

The default unit is Nanos, not Seconds A bare epoch() call reports nanoseconds since the Unix epoch, not seconds — easy to assume otherwise, since seconds is the more familiar epoch unit in casual use. Pass TimeUnit::Seconds explicitly for the more commonly expected scale.

Parameters¶

unit (pluss::table::TimeUnit, defaults to pluss::table::TimeUnit::Nanos) One of the fixed-duration units: Nanos, Micros, Millis, Seconds, or Days. Passing a span-only unit (Weeks, Months, Years, BusinessDays) throws.

Returns¶

Stream A new Int64 Series stream of epoch counts in unit.

Examples¶

Example 1. Default call reports nanoseconds — see the important callout above.

auto stream = pluss::kindle::Stream(pluss::make_timeline({"2024-01-31T09:15:30Z"}));
auto out = stream.tl().epoch();
std::cout << out.as_series().to_vec<std::int64_t>()[0];

Output¶

1706692530000000000

Example 2. Pass TimeUnit::Seconds explicitly for the more commonly expected scale.

auto stream = pluss::kindle::Stream(pluss::make_timeline({"2024-01-31T09:15:30Z", "2024-02-29T23:45:00Z"}));
auto out = stream.tl().epoch(pluss::table::TimeUnit::Seconds);
auto v = out.as_series().to_vec<std::int64_t>();
std::cout << v[0] << " " << v[1];

Output¶

1706692530 1709250300

Example 3 (edge case). A span-only unit throws.

auto stream = pluss::kindle::Stream(pluss::make_timeline({"2024-01-31T09:15:30Z"}));
try {
  auto out = stream.tl().epoch(pluss::table::TimeUnit::Weeks);
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n'));
}

Output¶

Thread::tl().epoch: unit is span-only; use Thread::tl().span

Notes¶

  • See the important callouts above — the default unit is Nanos.

  • Only fixed-duration units are accepted; passing Weeks, Months, Years, or BusinessDays throws. The throw message references Thread::tl().span, a suggestion that comes from the shared underlying engine — Stream’s tl() accessor has no span() method of its own.

See Also¶

  • Stream::tl: the entry point this accessor is reached from.

  • CatalogTimelineAccessor::epoch: the whole-catalog equivalent.

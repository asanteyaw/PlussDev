StreamTimelineAccessor::month_end¶

Back to StreamTimelineAccessor API Reference

Signature¶

Stream StreamTimelineAccessor::month_end() const

What It Does¶

Flags whether the bound stream’s timestamp falls on the last day of its calendar month, replacing it with a Bool Series stream.

Important

StreamTimelineAccessor requires the bound stream to be Timeline-kind Same precondition as every method on this accessor — see StreamTimelineAccessor::isnat’s own important callout for the full explanation and the exact throw message.

Parameters¶

None

Returns¶

Stream A new Bool Series stream: true where the row’s day-of-month is that month’s last valid day, false otherwise.

Examples¶

Example 1. Both sample timestamps are the last day of their respective month.

auto stream = pluss::kindle::Stream(pluss::make_timeline({"2024-01-31T09:15:30Z", "2024-02-29T23:45:00Z"}));
auto out = stream.tl().month_end();
std::cout << out;

Output¶

========================================================================================================================
kindle::Stream  kind=Series  dtype=Series[bool]  records=2
label=no  mask=yes  meta=0
------------------------------------------------------------------------------------------------------------------------
label        | value                                                                                                    
------------------------------------------------------------------------------------------------------------------------
0            | true                                                                                                     
1            | true                                                                                                     
========================================================================================================================

"2024-01-31" is January’s last day; "2024-02-29" is February’s last day in this leap year — see leap(), since the correct “last day” for February depends on whether the year is a leap year.

Notes¶

  • Correctly accounts for each month’s actual length, including leap-year February — see the important callout on leap().

  • Only checks the date component; the time-of-day portion doesn’t affect the result.

  • Reads local calendar fields relative to whatever timezone the stream currently carries ("UTC" unless changed via tz()/ localize()).

  • See the important callout above.

See Also¶

  • StreamTimelineAccessor::leap: where leap-year status actually changes February’s last valid day.

  • Stream::tl: the entry point this accessor is reached from.

StreamTimelineAccessor::week¶

Back to StreamTimelineAccessor API Reference

Signature¶

Stream StreamTimelineAccessor::week() const

What It Does¶

Extracts the ISO week-of-year (1-53) of the bound stream’s timestamp, replacing it with an Int32 Series stream.

Important

StreamTimelineAccessor requires the bound stream to be Timeline- or TimeIndex-kind Same precondition as every method on this accessor — see StreamTimelineAccessor::isnat’s own important callout for the full explanation and the exact throw message.

Parameters¶

None

Returns¶

Stream A new Int32 Series stream of ISO week numbers.

Examples¶

Example 1. Extract the ISO week from a January and a February timestamp.

auto stream = pluss::kindle::Stream(pluss::make_timeline({"2024-01-31T09:15:30Z", "2024-02-29T23:45:00Z"}));
auto out = stream.tl().week();
std::cout << out;

Output¶

========================================================================================================================
kindle::Stream  kind=Series  dtype=Series[int32]  records=2
label=no  mask=yes  meta=0
------------------------------------------------------------------------------------------------------------------------
label        | value                                                                                                    
------------------------------------------------------------------------------------------------------------------------
0            | 5                                                                                                        
1            | 9                                                                                                        
========================================================================================================================

Notes¶

  • Uses ISO week numbering — weeks start on Monday, and week 1 is the week containing the year’s first Thursday, so early-January dates can land in the previous year’s final week under ISO rules.

  • Reads local calendar fields relative to whatever timezone the stream currently carries ("UTC" unless changed via tz()/ localize()).

  • See the important callout above.

StreamTimelineAccessor::fmt¶

Back to StreamTimelineAccessor API Reference

Signature¶

Stream StreamTimelineAccessor::fmt(std::string_view pattern) const

What It Does¶

Renders the bound stream’s timestamp as custom text built from pattern, replacing it with a Note (text) stream.

Important

StreamTimelineAccessor requires the bound stream to be Timeline-kind Same precondition as every method on this accessor — see StreamTimelineAccessor::isnat’s own important callout for the full explanation and the exact throw message.

Parameters¶

pattern (std::string_view) A strftime-style format string. Recognized tokens: %Y (4-digit year), %m/%d (2-digit month/day), %H/%M/%S (2-digit hour/minute/second), %f (9-digit zero-padded nanoseconds), %z (UTC offset as +HH:MM/-HH:MM, never a bare Z), %a/%A (abbreviated/full weekday name), %b/%B (abbreviated/full month name), and %% (a literal %). Cannot be empty.

Returns¶

Stream A new Note stream holding each row’s text rendered per pattern.

Examples¶

Example 1. Format two timestamps with a custom day/month-name/year pattern.

auto stream = pluss::kindle::Stream(pluss::make_timeline({"2024-01-31T09:15:30Z", "2024-02-29T23:45:00Z"}));
auto out = stream.tl().fmt("%d %b %Y");
std::cout << out;

Output¶

========================================================================================================================
kindle::Stream  kind=Note  dtype=Note  records=2
label=no  mask=yes  meta=0
------------------------------------------------------------------------------------------------------------------------
label        | value                                                                                                    
------------------------------------------------------------------------------------------------------------------------
0            | 31 Jan 2024                                                                                              
1            | 29 Feb 2024                                                                                              
========================================================================================================================

Notes¶

  • pattern cannot be empty — an empty pattern throws.

  • %f always emits all 9 nanosecond digits, zero-padded; %z always renders as a signed HH:MM offset, never a bare "Z".

  • Changes the stream’s kind from Timeline to Note.

  • See the important callout above.

See Also¶

  • StreamTimelineAccessor::iso: a fixed ISO-8601-with-offset pattern, equivalent to fmt("%Y-%m-%dT%H:%M:%S.%f%z").

  • StreamTimelineAccessor::weekday_name / month_name(): dedicated shorthands for the full-name tokens.

  • Stream::tl: the entry point this accessor is reached from.

  • CatalogTimelineAccessor::fmt: the whole-catalog equivalent.

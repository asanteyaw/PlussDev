ThreadPlotAccessor::bar¶

Back to ThreadPlotAccessor API Reference

Signatures¶

ThreadPlotAccessor::bar() const -> pluss::pl::Studio
ThreadPlotAccessor::bar(const Thread& x) const -> pluss::pl::Studio
ThreadPlotAccessor::bar(const BarPlotOptions& options) const -> pluss::pl::Studio
ThreadPlotAccessor::bar(const Thread& x, const BarPlotOptions& options) const -> pluss::pl::Studio

What It Does¶

Draws one bar per row for the bound thread’s values, against an optional companion x thread — the single-series specialization of DataFramePlotAccessor::bar. Same shape and naming rules as line().

Parameters¶

x (const Thread&, optional) Same as line()’s x.

options (BarPlotOptions) The identical struct documented on DataFramePlotAccessor::bar (ci_enabled, ci_level, horizontal). ci_enabled = true still aggregates rows sharing the same x position into a mean-plus-confidence-interval bar, exactly as on the 2D accessor — useful when x has repeated values.

Returns¶

pluss::pl::Studio A figure with one pane containing a single bar trace of the bound thread’s values.

Examples¶

Example 1. No companion thread: falls back to a plain case index.

using namespace pluss::table;

auto amount = Thread(pluss::make_series({320.0, 180.0, 240.0}));
amount = amount.name("amount");

auto chart = amount.plot().bar();
chart.show();

Example 2. An explicit companion thread as the category axis.

auto city = Thread(pluss::make_note({"Accra", "Tema", "Kumasi"}));
city = city.name("city");

auto chart = amount.plot().bar(city);
chart.show();

Example 3. ci_enabled = true — rows sharing the same x value aggregate into a mean bar with a confidence-interval whisker.

auto repeated_amount = Thread(pluss::make_series({300.0, 320.0, 340.0, 175.0, 185.0}));
repeated_amount = repeated_amount.name("amount");

auto repeated_city = Thread(pluss::make_note({"Accra", "Accra", "Accra", "Tema", "Tema"}));
repeated_city = repeated_city.name("city");

BarPlotOptions options;
options.ci_enabled = true;
options.ci_level = 0.90;

auto chart = repeated_amount.plot().bar(repeated_city, options);
chart.show();

"Accra"’s three rows aggregate into one bar at the mean of 300, 320, 340 = 320, with a 90% confidence-interval whisker.

Notes¶

  • Shares every mechanic described on line()’s page.

  • ci_enabled = true behaves identically to DataFramePlotAccessor::bar’s — see that page for the full aggregation rule.

  • Returns a pluss::pl::Studio — see line() for how to view or save the result.

See Also¶

  • DataFramePlotAccessor::bar: the method this delegates to.

  • ThreadPlotAccessor::box / violin: distribution-shape summaries, an alternative to ci_enabled’s mean-and-interval view.

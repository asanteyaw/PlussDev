ThreadPlotAccessor::act¶

Back to ThreadPlotAccessor API Reference

Signature¶

ThreadPlotAccessor::act(const ActPlotOptions& options = {}) const -> pluss::pl::Studio

What It Does¶

Draws an autocorrelation plot for the bound thread’s values — the single-series specialization of DataFramePlotAccessor::act, which on the 2D accessor requires naming a feature; here the bound thread is always the one and only feature autocorrelated.

Note

At least three data points are required Same as the 2D accessor: a thread with fewer than three rows throws "flash::acfplot requires at least three points".

Parameters¶

options (ActPlotOptions) The identical struct documented on DataFramePlotAccessor::act (max_lag, show_confidence_band, confidence_level, trace_width).

Returns¶

pluss::pl::Studio A figure with one pane containing one autocorrelation spike per lag, a zero reference line, and (when enabled) two confidence-band reference lines.

Examples¶

Example 1. Default options.

using namespace pluss::table;

std::vector<double> wave;
for (int i = 0; i < 60; ++i) {
  wave.push_back(std::sin(static_cast<double>(i) * 0.5) + 0.1 * (i % 3));
}

auto signal = Thread(pluss::make_series(wave));
signal = signal.name("signal");

auto chart = signal.plot().act();
chart.show();

Example 2. An explicit ActPlotOptions, narrowing max_lag and using a stricter confidence_level.

ActPlotOptions options;
options.max_lag = 12;
options.confidence_level = 0.99;

auto chart = signal.plot().act(options);
chart.show();

Notes¶

  • The bound thread is always the single autocorrelated feature — there is no feature-name argument the way the 2D accessor’s act() has.

  • Lag 0 is never shown; spikes start at lag 1.

  • max_lag is clamped to [1, n - 1], never throwing for an over-large request.

  • Returns a pluss::pl::Studio — see line() for how to view or save the result.

See Also¶

  • DataFramePlotAccessor::act: the method this delegates to.

  • ThreadPlotAccessor::lag: a single lag’s scatter plot, rather than every lag’s correlation.

  • ThreadPlotAccessor::bootstrap: another single-feature diagnostic, based on resampling rather than lags.

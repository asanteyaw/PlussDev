ThreadPlotAccessor::bootstrap¶

Back to ThreadPlotAccessor API Reference

Signature¶

ThreadPlotAccessor::bootstrap(const BootstrapPlotOptions& options = {}) const -> pluss::pl::Studio

What It Does¶

Draws a bootstrap sampling-distribution plot for the bound thread’s values — the single-series specialization of DataFramePlotAccessor::bootstrap, which on the 2D accessor requires naming a feature; here the bound thread is always the one and only feature bootstrapped.

Note

At least two data points are required Same as the 2D accessor: a thread with fewer than two rows throws "flash::bootstrapplot requires at least two points".

Parameters¶

options (BootstrapPlotOptions) The identical struct documented on DataFramePlotAccessor::bootstrap (samples, sample_size, seed, bins, statistic, trace_width).

Returns¶

pluss::pl::Studio A figure with one pane containing a histogram of the resampled statistic and a vertical reference line at the statistic computed on the full, original data.

Examples¶

Example 1. Default options: bootstrap the mean, 300 resamples.

using namespace pluss::table;

auto score = Thread(pluss::make_series({71.0, 85.0, 90.0, 63.0, 78.0, 82.0, 95.0, 68.0}));
score = score.name("score");

auto chart = score.plot().bootstrap();
chart.show();

Example 2. Bootstrapping the standard deviation, with more resamples and a fixed seed for reproducibility.

BootstrapPlotOptions options;
options.statistic = BootstrapStatistic::Std;
options.samples = 2000;
options.seed = 42;

auto chart = score.plot().bootstrap(options);
chart.show();

Notes¶

  • The bound thread is always the single bootstrapped feature — there is no feature-name argument the way the 2D accessor’s bootstrap() has.

  • samples is floored to 8; bins is floored to 4.

  • seed makes the resampling fully deterministic and reproducible across runs.

  • Returns a pluss::pl::Studio — see line() for how to view or save the result.

See Also¶

  • DataFramePlotAccessor::bootstrap: the method this delegates to.

  • ThreadPlotAccessor::act / lag: the other two single-feature diagnostic plots on this accessor.

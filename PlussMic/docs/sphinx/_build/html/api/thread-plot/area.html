ThreadPlotAccessor::area¶

Back to ThreadPlotAccessor API Reference

Signatures¶

ThreadPlotAccessor::area() const -> pluss::pl::Studio
ThreadPlotAccessor::area(const Thread& x) const -> pluss::pl::Studio
ThreadPlotAccessor::area(const AreaPlotOptions& options) const -> pluss::pl::Studio
ThreadPlotAccessor::area(const Thread& x, const AreaPlotOptions& options) const -> pluss::pl::Studio

What It Does¶

Identical in shape to line(), but the trace is filled down to the baseline instead of drawn as a bare line — the single-series specialization of DataFramePlotAccessor::area. See line() for the full naming and row-label inheritance rules shared by every method on this accessor.

Parameters¶

x (const Thread&, optional) Same as line()’s x.

options (AreaPlotOptions) The identical struct documented on DataFramePlotAccessor::area (alpha, line_width) — note alpha defaults lower here (0.88) than line()’s 1.0.

Returns¶

pluss::pl::Studio A figure with one pane containing a single filled area trace of the bound thread’s values.

Examples¶

Example 1. No companion thread: falls back to a plain case index.

using namespace pluss::table;

auto amount = Thread(pluss::make_series({100.0, 120.0, 90.0, 150.0}));
amount = amount.name("amount");

auto chart = amount.plot().area();
chart.show();

Example 2. An explicit companion thread as the x-axis.

auto month = Thread(pluss::make_note({"Jan", "Feb", "Mar", "Apr"}));
month = month.name("month");

auto chart = amount.plot().area(month);
chart.show();

Example 3. An explicit AreaPlotOptions, raising opacity toward fully opaque.

AreaPlotOptions options;
options.alpha = 1.0;
options.line_width = 2.0;

auto chart = amount.plot().area(month, options);
chart.show();

Notes¶

  • Shares every mechanic described on line()’s page except the filled trace shape and AreaPlotOptions’s lower default alpha.

  • Returns a pluss::pl::Studio — see line() for how to view or save the result.

See Also¶

  • DataFramePlotAccessor::area: the method this delegates to.

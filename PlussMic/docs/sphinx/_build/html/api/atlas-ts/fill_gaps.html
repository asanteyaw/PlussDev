AtlasTsAccessor::fill_gaps¶

Back to AtlasTsAccessor API Reference

Signature¶

AtlasTsAccessor::fill_gaps(pluss::subsp::stats::ts::GapFillMode mode = pluss::subsp::stats::ts::GapFillMode::Forward, std::optional<double> constant = std::nullopt) const -> Atlas

What It Does¶

Fills missing (NULL) values in every bound feature, in every frame of the stack, according to mode — the same transform DataFrameTsAccessor::fill_gaps applies to a single frame, broadcast across the whole Atlas via Atlas::map_frames(). Forward/Backward carry the nearest neighbor within that frame; Zero/Constant fill every gap unconditionally.

Parameters¶

mode (GapFillMode, default Forward) Forward, Backward, Zero, or Constant — see DataFrameTsAccessor::fill_gaps for the full behavior of each.

constant (std::optional<double>, default std::nullopt) The fill value for GapFillMode::Constant. Required (and only meaningful) when mode == Constant.

Returns¶

Atlas A new atlas, same depth and depth labels as the source, with each frame’s bound feature’s gaps filled according to mode.

Examples¶

Example 1. Forward-fill a gapped feature stacked across two frames.

using namespace pluss::table;

auto nan = std::numeric_limits<double>::quiet_NaN();
auto q1 = DataFrame({{"load", Thread(pluss::make_series({10.0, nan, nan, 30.0}))}});
auto q2 = DataFrame({{"load", Thread(pluss::make_series({12.0, nan, 14.0, nan}))}});
auto atlas = Atlas({q1, q2});

auto out = atlas.ts().fill_gaps();
std::cout << out.frame(0) << "\n" << out.frame(1);

Output¶

===========
     | load
-----------
0    | 10  
1    | 10  
2    | 10  
3    | 30  
-----------
[4 cs x 1 feat]
===========
     | load
-----------
0    | 12  
1    | 12  
2    | 14  
3    | 14  
-----------
[4 cs x 1 feat]

Each frame’s gaps are carried forward using only that frame’s own values — frame(1)’s row 3 carries forward 14 from frame(1)’s own row 2, never a value from frame(0).

Important

A NaN literal is used here, not std::nullopt, to build the gapped Series pluss::make_series({10.0, std::nullopt, ...}) — the pattern shown in several other already-published pages — currently fails to compile in this build (a confirmed library issue: DataReader has no std::optional<double> element-type support). The example above works around it by using std::numeric_limits<double>::quiet_NaN() directly, which the display layer already renders identically to a genuine null cell.

Notes¶

  • Forward/Backward gaps with no qualifying neighbor within that frame (leading nulls under Forward, trailing nulls under Backward) remain NULL.

  • Constant requires constant to be supplied; calling it without one throws.

  • Each frame’s gap-filling is independent — a gap in one frame is never filled from another frame’s values.

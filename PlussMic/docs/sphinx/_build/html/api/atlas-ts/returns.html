AtlasTsAccessor::returns¶

Back to AtlasTsAccessor API Reference

Signature¶

AtlasTsAccessor::returns(std::int64_t periods = 1) const -> Atlas

What It Does¶

Computes the fractional period-over-period change of every bound feature in every frame of the stack: out[i] = x[i] / base[i] - 1, where base is x shifted by periods within that same frame — the same transform DataFrameTsAccessor::returns applies to a single frame, broadcast across the whole Atlas via Atlas::map_frames(). A cell is NULL wherever x[i] or base[i] is missing, base[i] is 0, or either value is non-finite.

Parameters¶

periods (std::int64_t, default 1) The shift distance used to build the comparison base, within each frame independently. Positive shifts compare each row against an earlier one (a lag); negative shifts compare against a later one (a lead). Must not be 0, or the call throws.

Returns¶

Atlas A new atlas, same depth and depth labels as the source, with each frame’s bound feature replaced by its period-over-period fractional return.

Examples¶

Example 1. Compute the one-period return of a numeric feature stacked across two frames.

using namespace pluss::table;

auto q1 = DataFrame({{"load", Thread(pluss::make_series({10.0, 20.0, 15.0, 30.0}))}});
auto q2 = DataFrame({{"load", Thread(pluss::make_series({12.0, 18.0, 14.0, 28.0}))}});
auto atlas = Atlas({q1, q2});

auto out = atlas.ts().returns();
std::cout << out.frame(0) << "\n" << out.frame(1);

Output¶

============
     | load 
------------
0    |  nan 
1    |  1   
2    | -0.25
3    |  1   
------------
[4 cs x 1 feat]
====================
     | load         
--------------------
0    |  nan         
1    |  0.5         
2    | -0.2222222222
3    |  1           
--------------------
[4 cs x 1 feat]

Each frame computes its own returns independently — frame(1)’s first return is 18 / 12 - 1 = 0.5, unrelated to frame(0)’s values.

Notes¶

  • returns() operates independently, feature by feature and frame by frame — no frame’s computation ever crosses into another’s data.

  • A base value of exactly 0 always produces NULL, regardless of x[i].

  • Atlas::ts() auto-binds the numeric Series features on each frame, same as DataFrame::ts() does for a single frame.

  • AtlasTsAccessor::log_returns: the logarithmic counterpart.

  • AtlasTsAccessor::diff: the absolute (non-fractional) period-over-period change.

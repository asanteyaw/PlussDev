Axel::size¶

Back to Axel API Reference

Signature¶

std::int64_t Axel::size() const

What It Does¶

Returns the number of Registry frames stacked in this Axel. Byte-identical to depth() — size()’s body is a single return depth();.

Parameters¶

None

Returns¶

std::int64_t The number of registries — the same value depth() returns.

Examples¶

Example 1. size() and depth() agree on a three-frame Axel.

auto axel = pluss::bundle::Axel({
    pluss::bundle::Registry({{"ids", pluss::bundle::Slot({pluss::make_series(1)})}}),
    pluss::bundle::Registry({{"ids", pluss::bundle::Slot({pluss::make_series(2)})}}),
    pluss::bundle::Registry({{"ids", pluss::bundle::Slot({pluss::make_series(3)})}}),
});
std::cout << axel.size() << " " << axel.depth();

Output¶

3 3

Notes¶

  • size() exists as a name-parity convenience with Registry::size() and Slot::size(), but for Axel, “size” means the depth axis (how many registries), not a row or value count — there is no separate concept of Axel row count, since each registry frame can have its own independent row shape.

  • Requires defined() — an undefined handle throws "Axel: undefined handle" (via the underlying depth() call).

See Also¶

  • Axel::depth: the canonical name for this same value.

  • Axel::empty: shorthand for size() == 0.

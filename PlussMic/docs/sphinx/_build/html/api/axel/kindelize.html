Axel::kindelize¶

Back to Axel API Reference

Signature¶

pluss::kindle::Archive Axel::kindelize() const

What It Does¶

Converts this Axel to its kindle::Archive representation. A depth-stacked bridge from the scribble model into the Kindle model.

Parameters¶

None

Returns¶

pluss::kindle::Archive One archive catalog per registry, in axel depth order.

Examples¶

Example 1. kindelize() preserves depth.

auto axel = pluss::scribble::Axel({
    pluss::scribble::Registry({{"ids", pluss::scribble::Slot({pluss::make_series(1)})}}),
    pluss::scribble::Registry({{"ids", pluss::scribble::Slot({pluss::make_series(2)})}}),
});
auto archive = axel.kindelize();
std::cout << archive.depth();

Output¶

2

Notes¶

  • Requires defined() — an undefined handle throws "Axel: undefined handle".

See Also¶

  • Archive::scribbelize: the reverse bridge from Kindle back into the scribble model.

Axel::empty¶

Back to Axel API Reference

Signature¶

bool Axel::empty() const

What It Does¶

Reports whether this Axel has zero depth (no registry frames at all). Equivalent to depth() == 0.

Parameters¶

None

Returns¶

bool true if the axel has no registry frames; false otherwise.

Examples¶

Example 1. A three-frame Axel is not empty; one built from an empty registry vector is.

auto axel = pluss::scribble::Axel({
    pluss::scribble::Registry({{"ids", pluss::scribble::Slot({pluss::make_series(1)})}}),
});
auto empty_axel = pluss::scribble::Axel(std::vector<pluss::scribble::Registry>{});
std::cout << std::boolalpha << axel.empty() << " " << empty_axel.empty();

Output¶

false true

Notes¶

  • empty() is about depth (registry-frame count), not about whether any individual registry inside has rows or fields — a one-frame Axel wrapping a registry with zero rows is still not empty().

  • An Axel with zero depth is still defined() (see defined()’s Example 1) — empty() and defined() answer different questions.

  • Requires defined() — an undefined handle throws "Axel: undefined handle" (via the underlying depth() call).

See Also¶

  • Axel::depth / size(): the underlying count empty() compares against zero.

  • Axel::defined: whether the handle is bound to storage at all, independent of depth.

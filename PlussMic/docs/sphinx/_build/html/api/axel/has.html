Axel::has¶

Back to Axel API Reference

Signature¶

bool Axel::has(std::string_view field) const

What It Does¶

Checks whether field exists in any registry frame across the depth stack.

Important

“any”, not “every” has() returns true as soon as one frame contains field — it does not mean every frame does. Axel does not require every frame to share an identical schema, so a true result here doesn’t guarantee fields({field}) will succeed on the whole Axel (that call requires the field to exist in every frame it’s applied to and throws otherwise).

Parameters¶

field (std::string_view) The field name to look for.

Returns¶

bool true if at least one frame has a field named field; false if no frame does.

Examples¶

Example 1. Two frames with disjoint schemas — has() is true for a field that only exists in one of them.

auto r0 = pluss::scribble::Registry({{"ids", pluss::scribble::Slot({pluss::make_series(1)})}});
auto r1 = pluss::scribble::Registry({{"city", pluss::scribble::Slot({pluss::make_note("Accra")})}});
auto axel = pluss::scribble::Axel({r0, r1});

std::cout << std::boolalpha << axel.has("ids") << " " << axel.has("city") << " " << axel.has("zzz");

Output¶

true true false

"ids" only exists in frame 0 and "city" only in frame 1, but both report true — has() only needs a single matching frame.

Notes¶

  • See the important callout above — don’t treat a true result as “every frame has this field.”

  • Never throws, regardless of the answer — same contract as Registry::has().

  • Requires defined() — an undefined handle throws "Axel: undefined handle".

See Also¶

  • Axel::fields: the operation that actually requires a field to exist in every frame it touches.

  • Registry::has: the single-frame equivalent this method loops over internally.

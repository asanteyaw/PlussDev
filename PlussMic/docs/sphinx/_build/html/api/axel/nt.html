Axel::nt¶

Back to Axel API Reference

Signature¶

AxelNoteAccessor Axel::nt() const

What It Does¶

Returns an AxelNoteAccessor bound to this Axel, for applying text (Note-kind) operations across every field of every registry frame in the depth stack.

```{important} Scope with fields() first Like cast() and tl(), nt() itself takes no field names — it applies to every field of every frame. Chain axel.fields({"..."}).nt() to scope the effect to one field.


## Parameters

`None`

## Returns

`AxelNoteAccessor`
    An accessor exposing the full `Note` text-processing method set
    (`strip()`, `upper()`, `has()`, `count()`, `replace()`, ...) — see
    the [`AxelNoteAccessor` reference](../../axel_note_accessor_api_reference).

## Examples

Example 1. Uppercase the `"city"` field across every frame.

```cpp
auto r0 = pluss::scribble::Registry({{"city", pluss::scribble::Slot({pluss::make_note("Accra"), pluss::make_note("Tema")})}});
auto r1 = pluss::scribble::Registry({{"city", pluss::scribble::Slot({pluss::make_note("Kumasi"), pluss::make_note("Takoradi")})}});
auto axel = pluss::scribble::Axel({r0, r1});

auto out = axel.fields({"city"}).nt().upper();
std::cout << std::get<pluss::Note>(out.registry(0).fields("city").at(0)).at(0);

Output¶

ACCRA

Notes¶

  • Every field the accessor touches must be Note-kind in every frame it’s applied to — a non-Note field throws whatever the underlying Registry::nt() call throws for that frame.

  • Requires defined() — an undefined handle throws "Axel: undefined handle".

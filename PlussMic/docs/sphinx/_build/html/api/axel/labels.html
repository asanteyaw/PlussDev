Axel::labels¶

Back to Axel API Reference

Signature¶

const std::optional<Slot>& Axel::labels() const

What It Does¶

Returns the optional depth-axis label Slot — one label value per registry frame — if this Axel was constructed with one.

Parameters¶

None

Returns¶

const std::optional<Slot>& An engaged optional holding the label Slot (size equal to depth()) if labels were provided at construction; std::nullopt otherwise.

Examples¶

Example 1. An Axel built without a second constructor argument has no labels; one built with a matching-size Slot does.

auto r0 = pluss::scribble::Registry({{"ids", pluss::scribble::Slot({pluss::make_series(1)})}});
auto r1 = pluss::scribble::Registry({{"ids", pluss::scribble::Slot({pluss::make_series(2)})}});

auto unlabeled = pluss::scribble::Axel({r0, r1});
std::cout << "unlabeled: " << std::boolalpha << unlabeled.labels().has_value() << "\n";

auto labeled = pluss::scribble::Axel({r0, r1}, pluss::scribble::Slot({pluss::make_note("q1"), pluss::make_note("q2")}));
std::cout << "labeled: " << labeled.labels().has_value() << " first=" << std::get<pluss::Note>(labeled.labels()->at(0)).at(0);

Output¶

unlabeled: false
labeled: true first=q1

Example 2. A labels Slot whose size doesn’t match depth() throws at construction time, before labels() is ever called.

auto r0 = pluss::scribble::Registry({{"ids", pluss::scribble::Slot({pluss::make_series(1)})}});
auto r1 = pluss::scribble::Registry({{"ids", pluss::scribble::Slot({pluss::make_series(2)})}});
try {
  auto bad = pluss::scribble::Axel({r0, r1}, pluss::scribble::Slot({pluss::make_note("only-one")}));
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n'));
}

Output¶

Axel: labels size must match depth

Notes¶

  • The label Slot’s size must equal depth() — this is enforced once, at construction, not on every labels() call. An undefined label Slot passed as the second constructor argument also throws ("Axel: labels slot undefined").

  • Labels can hold any Slot-representable value per frame (Note, Series, Timeline, TimeIndex) — the two examples above use Note (text) labels, but nothing restricts labels to text.

  • Axel::slice, head(), tail() all slice the label Slot alongside the registries, keeping labels aligned with their frames. concat_depth() is the one operation where labels can silently disappear — see its Notes.

  • Requires defined() — an undefined handle throws "Axel: undefined handle".

See Also¶

  • Axel::slice: one place labels are kept in sync automatically when frames are selected.

  • Axel::concat_depth: where an asymmetric label presence between two axels causes the result to lose labels entirely.

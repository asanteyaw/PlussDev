Axel::isnull¶

Back to Axel API Reference

Signature¶

Axel Axel::isnull() const

What It Does¶

Returns a new axel where every field’s values, in every registry frame, are replaced by a boolean flag for whether each value is null — applies Registry::isnull() to every frame via map(), which in turn applies Slot::isnull() to every field. Works uniformly across every field regardless of its own value kind — the result is always Series[bool]-valued.

Parameters¶

None

Returns¶

Axel A new axel with every field’s values replaced by boolean null-flags.

Examples¶

Example 1. A field with one null value among numeric values reports Series[bool] per value.

auto r0 = pluss::bundle::Registry({{"id", pluss::bundle::Slot({pluss::make_series(1), pluss::bundle::Slot::Value{std::monostate{}}, pluss::make_series(3)})}});
auto axel = pluss::bundle::Axel({r0});

auto out = axel.isnull();
std::cout << out.registry(0).fields("id").to_json();

Output¶

{
  "_type": "Slot",
  "defined": true,
  "size": 3,
  "values": [
    "Series[bool]",
    "Series[bool]",
    "Series[bool]"
  ]
}

Notes¶

  • Unlike fillnull(), isnull() never throws on a field whose kind doesn’t match a fill payload — it works identically on every kind.

  • Never mutates the receiver — always returns a new Axel.

See Also¶

  • Axel::notnull: the logical complement.

  • Axel::invalid: a related but distinct check — invalid (not-a-value) rather than strictly null.

  • Axel::dropnull: removes null values instead of flagging them.

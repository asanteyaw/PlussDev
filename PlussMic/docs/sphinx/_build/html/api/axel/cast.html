Axel::cast¶

Back to Axel API Reference

Signature¶

AxelCastAccessor Axel::cast() const
AxelCastAccessor Axel::cast(const pluss::table::ThreadCastOptions& options) const

What It Does¶

Returns an AxelCastAccessor bound to this Axel, for reinterpreting every field’s Slot values as a specific target kind (Series, Note, Timeline, or TimeIndex) across the whole depth stack.

```{important} Scope with fields() first, not with cast()’s own parameters cast() itself takes no field names — it always acts on every field of every frame. To cast only one field, chain axel.fields({"..."}).cast() instead, exactly like Axel::nt and Axel::tl.


## Parameters

**options** (`const pluss::table::ThreadCastOptions&`, optional)
    Cast behavior options (e.g. parse formats) forwarded to each
    frame's underlying `Registry::cast(options)` call. Omit for
    defaults.

## Returns

`AxelCastAccessor`
    An accessor exposing `series()`, `note()`, `timeline()`, and
    `timeindex()` — see the
    [`AxelCastAccessor` reference](../../axel_cast_accessor_api_reference).

## Examples

Example 1. Cast the `"ids"` field of every frame to `Note` (text).

```cpp
auto r0 = pluss::scribble::Registry({{"ids", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2)})}});
auto r1 = pluss::scribble::Registry({{"ids", pluss::scribble::Slot({pluss::make_series(3), pluss::make_series(4)})}});
auto axel = pluss::scribble::Axel({r0, r1});

auto out = axel.fields({"ids"}).cast().note();
std::cout << std::get<pluss::Note>(out.registry(0).fields("ids").at(0)).at(0);

Output¶

1

Notes¶

  • cast() with no field scope applies to every field of every frame — scope it first with fields() to affect only specific fields, the same idiom used for nt() and tl().

  • Requires defined() — an undefined handle throws "Axel: undefined handle".

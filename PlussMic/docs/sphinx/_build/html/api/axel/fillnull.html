Axel::fillnull¶

Back to Axel API Reference

Signatures¶

Axel Axel::fillnull(double value) const
Axel Axel::fillnull(std::string_view value) const
Axel Axel::fillnull(const char* value) const
Axel Axel::fillnull(const pluss::Timeline& value) const

What It Does¶

Returns a new axel with null values replaced by value, applying Registry::fillnull(value) to every frame via map() — one overload per fill-value kind (double for numeric fields, std::string_view/const char* for text fields, Timeline for datetime fields).

Note

No Duration overload here Unlike Registry::fillnull, Axel::fillnull does not have a pluss::Duration overload. Fill a Duration field by narrowing with fields() first and calling Slot::fillnull on it directly.

Important

Every field in every frame is filled, and every field’s kind must match Because fillnull() applies unconditionally to every field of every frame via nested map() calls, calling fillnull(double value) on an axel where any frame has a non-numeric field throws — even if that field has zero null values. The same gotcha documented on Registry::fillnull applies here, just across every frame instead of one registry. There is no way to scope fillnull() to specific fields at the Axel level — for a mixed-kind axel, narrow with fields() first.

Parameters¶

value (double / std::string_view / const char* / const pluss::Timeline&) The replacement for null values, in the kind matching the overload selected.

Returns¶

Axel A new axel with every field’s null values, in every frame, replaced by value.

Examples¶

Example 1. On an axel where every field is numeric, fillnull(double) succeeds and fills the null.

auto r0 = pluss::scribble::Registry({{"id", pluss::scribble::Slot({pluss::make_series(1), pluss::scribble::Slot::Value{std::monostate{}}, pluss::make_series(3)})}});
auto axel = pluss::scribble::Axel({r0});

auto out = axel.fillnull(99.0);
std::cout << out.registry(0).fields("id").to_json();

Output¶

{
  "_type": "Slot",
  "defined": true,
  "size": 3,
  "values": [
    "Series[int64]",
    "Series[float64]",
    "Series[int64]"
  ]
}

Notes¶

  • See the important callout above — this is the same surprising behavior documented for Registry::fillnull(), extended across every frame: a throw can come from a field with no nulls at all, just because its kind doesn’t match the overload chosen.

  • Filling a null in an integer Series field with a double promotes that value’s numeric entry to Series[float64] — see Example 1.

  • Never mutates the receiver — always returns a new Axel.

See Also¶

  • Axel::dropnull: removes null values instead of filling them, and never throws over kind mismatches.

  • Axel::isnull: identify which values are null before deciding how to fill them.

  • Axel::fields: scope a fill to a single field on a mixed-kind axel.

  • Registry::fillnull: the single-frame operation this method broadcasts across the depth stack.

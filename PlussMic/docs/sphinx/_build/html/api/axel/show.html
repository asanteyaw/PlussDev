Axel::show¶

Back to Axel API Reference

Signature¶

void Axel::show(std::ostream& os) const

What It Does¶

Writes the exact same summary string to_string() produces to os. operator<< for Axel calls this method internally, so os << axel and axel.show(os) are equivalent.

Parameters¶

os (std::ostream&) The stream to write the summary to.

Returns¶

void

Examples¶

Example 1. show()’s output matches to_string()’s return value exactly.

auto axel = pluss::bundle::Axel({
    pluss::bundle::Registry({{"ids", pluss::bundle::Slot({pluss::make_series(1)})}}),
});
std::ostringstream oss;
axel.show(oss);
std::cout << std::boolalpha << (oss.str() == axel.to_string());

Output¶

true

Notes¶

  • show() is to_string()’s content routed to a stream — see to_string() for the format, including its depth-6 truncation behavior and the important asymmetry with to_json().

  • std::ostream& operator<<(std::ostream&, const Axel&) calls show() internally, so std::cout << axel is equivalent to axel.show(std::cout).

See Also¶

  • Axel::to_string: the string this method streams.

  • Axel::to_json: the alternative, unabridged dump.

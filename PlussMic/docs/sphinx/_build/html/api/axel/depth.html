Axel::depth¶

Back to Axel API Reference

Signature¶

std::int64_t Axel::depth() const

What It Does¶

Returns the number of Registry frames stacked in this Axel — the size of the depth axis.

Parameters¶

None

Returns¶

std::int64_t The number of registries.

Examples¶

Example 1. A three-frame Axel reports a depth of 3.

auto axel = pluss::scribble::Axel({
    pluss::scribble::Registry({{"ids", pluss::scribble::Slot({pluss::make_series(1)})}}),
    pluss::scribble::Registry({{"ids", pluss::scribble::Slot({pluss::make_series(2)})}}),
    pluss::scribble::Registry({{"ids", pluss::scribble::Slot({pluss::make_series(3)})}}),
});
std::cout << axel.depth();

Output¶

3

Example 2. An undefined handle throws.

pluss::scribble::Axel undef;
try {
  undef.depth();
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n'));
}

Output¶

Axel: undefined handle

Notes¶

  • Axel::size is a byte-identical alias for depth().

  • Requires defined() — an undefined handle throws "Axel: undefined handle".

See Also¶

  • Axel::size: the exact same value under a second name.

  • Axel::empty: shorthand for depth() == 0.

  • Axel::registry: fetch a single frame by index within [0, depth()).

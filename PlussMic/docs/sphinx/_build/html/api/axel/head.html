Axel::head¶

Back to Axel API Reference

Signature¶

Axel Axel::head(std::int64_t n) const

What It Does¶

Returns the first n registry frames (depth-wise), clamped to [0, depth()]. Equivalent to slice(0, n) after clamping.

Parameters¶

n (std::int64_t) The number of leading frames to keep. Values greater than depth() are clamped down to depth(); negative values are clamped up to 0.

Returns¶

Axel A new axel holding the first (clamped) n frames. If labels() is engaged, the label Slot is sliced alongside the frames.

Examples¶

Example 1. Keep the first two frames of a five-frame Axel.

auto axel = pluss::bundle::Axel({
    pluss::bundle::Registry({{"ids", pluss::bundle::Slot({pluss::make_series(0)})}}),
    pluss::bundle::Registry({{"ids", pluss::bundle::Slot({pluss::make_series(1)})}}),
    pluss::bundle::Registry({{"ids", pluss::bundle::Slot({pluss::make_series(2)})}}),
    pluss::bundle::Registry({{"ids", pluss::bundle::Slot({pluss::make_series(3)})}}),
    pluss::bundle::Registry({{"ids", pluss::bundle::Slot({pluss::make_series(4)})}}),
});
auto out = axel.head(2);
std::cout << "depth=" << out.depth() << " last_id="
          << std::get<pluss::Series>(out.registry(out.depth() - 1).fields("ids").at(0)).to_vec<std::int64_t>()[0];

Output¶

depth=2 last_id=1

Example 2. Asking for more frames than exist clamps to depth() instead of throwing.

auto axel = pluss::bundle::Axel({
    pluss::bundle::Registry({{"ids", pluss::bundle::Slot({pluss::make_series(0)})}}),
    pluss::bundle::Registry({{"ids", pluss::bundle::Slot({pluss::make_series(1)})}}),
});
auto out = axel.head(100);
std::cout << out.depth();

Output¶

2

Notes¶

  • n is silently clamped, never throws for an out-of-range value.

  • Requires defined() — an undefined handle throws "Axel: undefined handle" (via the underlying slice() call).

See Also¶

  • Axel::tail: the same clamped-count idiom, from the end.

  • Axel::slice: the general-purpose range selector head() delegates to.

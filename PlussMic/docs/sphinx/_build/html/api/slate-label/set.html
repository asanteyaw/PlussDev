SlateLabelAccessor::set¶

Back to SlateLabelAccessor API Reference

Signature¶

SlateLabelAccessor::set(const Slate& labels) const -> Slate

What It Does¶

Replaces the bound slate’s case labels with labels, used as-is — a direct forward to Slate::caselbl(labels). The slate’s own values are completely unchanged; only the companion case-label sequence shown alongside them (and used by sort(), slice(), pos(), and similar) is replaced.

Parameters¶

labels (const Slate&)

The replacement case labels. Must be the same length as the bound slate.

Returns¶

Slate A new slate, holding the same values as *this, with labels as its case labels.

Examples¶

Example 1. Attach text labels to a numeric slate.

using namespace pluss::table;

auto sales = Slate(pluss::make_series({100.0, 200.0, 150.0, 90.0}));
auto tagged = sales.label().set(
    Slate(pluss::make_note({"east", "west", "east", "north"})));
std::cout << tagged;

Output¶

east   100
west   200
east   150
north  90

ptype: Series

The values are exactly sales’s own — only the leftmost display column (the case labels) changed.

Notes¶

  • The slate’s own values and kind are never touched — only the case-label companion sequence changes.

  • Identical to calling Slate::caselbl(labels) directly.

  • Unlike DataFrameLabelAccessor::set, there is no feature-promotion overload here — a bare Slate has no named features to promote, so this is the only form.

See Also¶

  • SlateLabelAccessor::reset: the inverse — clears case labels back to the default integer range.

  • SlateLabelAccessor::range: explicitly reset to the default range labels.

  • SlateLabelAccessor::values: read the current case labels back out.

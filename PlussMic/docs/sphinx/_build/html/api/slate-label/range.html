SlateLabelAccessor::range¶

Back to SlateLabelAccessor API Reference

Signature¶

SlateLabelAccessor::range() const -> Slate

What It Does¶

Replaces the bound thread’s case labels with an explicit default integer range (0, 1, 2, ...) — a direct forward to Slate::rangelbl(). Visually identical to a thread that never had case labels set at all, but — unlike reset() — has() reports true afterward, since range() actively attaches a labels thread rather than clearing one.

Parameters¶

None

Returns¶

Slate A new thread, holding the same values as *this, with an explicit default integer range as its case labels.

Examples¶

Example 1. Reset custom labels back to a plain range, and confirm has() still reports true.

using namespace pluss::table;

auto tagged = Slate(pluss::make_series({100.0, 200.0, 150.0}))
                  .label().set(Slate(pluss::make_note({"a", "b", "c"})));
std::cout << tagged;

auto ranged = tagged.label().range();
std::cout << ranged;
std::cout << ranged.label().has();

Output (before)¶

a  100
b  200
c  150

ptype: Series

Output (after range())¶

0  100
1  200
2  150

ptype: Series

Output (has())¶

true

The display now looks like a thread with no case labels at all, but has() still reports true — range() actively attached a labels thread, it didn’t clear one. Contrast with reset(), which produces the same display but leaves has() false.

Notes¶

  • Produces the same visible 0, 1, 2, ... display as a never-labeled thread, but has() reports true afterward — see reset() for the version that leaves has() false.

  • Identical to calling Slate::rangelbl() directly.

See Also¶

  • SlateLabelAccessor::reset: visually identical result, but clears case labels entirely rather than attaching a range.

  • SlateLabelAccessor::set: attach arbitrary case labels instead of the default range.

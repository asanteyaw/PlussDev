CatalogTimeSeriesAccessor::diff¶

Back to CatalogTimeSeriesAccessor API Reference

Signature¶

Catalog CatalogTimeSeriesAccessor::diff(std::int64_t periods = 1) const

What It Does¶

Computes the absolute period-over-period change of every bound key: out[i] = x[i] - base[i], where base is x shifted by periods (a lag when periods > 0, a lead when periods < 0). A position is NULL wherever x[i] or base[i] is missing. periods = 0 produces an all-zero result rather than throwing.

Important

CatalogTimeSeriesAccessor requires every bound key to be numeric Series-kind Every method on this accessor routes through Stream::ts() for each bound key. If any bound key isn’t a numeric Series (Note, Timeline, TimeIndex, or a non-numeric Series), the call throws. Since Catalog::ts() binds every key of the catalog by default, project down to just the numeric keys first with Catalog::keys(names) or Catalog::keyaxis().series() before calling .ts().

Parameters¶

periods (std::int64_t, default 1) The shift distance used to build the comparison base. Positive shifts compare each position against an earlier one (a lag); negative shifts compare against a later one (a lead).

Returns¶

Catalog A new catalog with every bound key replaced by its period-over-period absolute difference.

Examples¶

Example 1. Compute the one-period difference of a numeric key.

using namespace pluss::kindle::literals;

auto ct = pluss::kindle::Catalog({
    "metric"_k = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 15.0, 30.0})),
});
auto out = ct.ts().diff(1);
std::cout << out;

Output¶

========================================================================================================================
kindle::Catalog  keys=1
keys: [metric]
------------------------------------------------------------------------------------------------------------------------
key                      | kind         | dtype            | cs      | preview                                          
------------------------------------------------------------------------------------------------------------------------
metric                   | Series       | Series[float64]  | 4       | [nan, 10, -5, 15]                                
========================================================================================================================

Position 0 has no prior position, so it’s nan. Position 1 is 20 - 10 = 10; position 2 is 15 - 20 = -5; position 3 is 30 - 15 = 15.

Example 2. periods = 0 produces an all-zero result rather than throwing.

using namespace pluss::kindle::literals;

auto ct = pluss::kindle::Catalog({
    "metric"_k = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 15.0, 30.0})),
});
auto out = ct.ts().diff(0);
std::cout << out;

Output¶

========================================================================================================================
kindle::Catalog  keys=1
keys: [metric]
------------------------------------------------------------------------------------------------------------------------
key                      | kind         | dtype            | cs      | preview                                          
------------------------------------------------------------------------------------------------------------------------
metric                   | Series       | Series[float64]  | 4       | [0, 0, 0, 0]                                     
========================================================================================================================

Unlike a hand-rolled shift-based approach, diff() handles periods = 0 explicitly by returning an all-zero identity comparison rather than a key of NULLs.

Example 3 (edge case). A non-numeric key throws — see the important callout above.

using namespace pluss::kindle::literals;

auto ct = pluss::kindle::Catalog({
    "name"_k = pluss::kindle::Stream(pluss::make_note({"a", "b"})),
});
try {
  auto out = ct.ts().diff(1);
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n'));
}

Output¶

TimeSeriesAccessor::diff: source must be Series

Notes¶

  • Unlike a hand-rolled shift-based approach you might build by hand, diff() handles periods = 0 explicitly by returning all zeros (an identity comparison) rather than a key of NULLs.

  • A pre-existing missing entry in a bound key is honored — it produces NULL in every difference that would otherwise reference it, not just the NULLs the shift itself introduces at the vacated end.

  • See the important callout above.

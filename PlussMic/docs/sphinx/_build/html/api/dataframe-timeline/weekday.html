DataFrameTimelineAccessor::weekday¶

Back to DataFrameTimelineAccessor API Reference

Signature¶

DataFrameTimelineAccessor::weekday() const -> DataFrame

What It Does¶

Replaces every selected Timeline/TimeIndex feature with its day-of-week, as a numeric Series — same feature name, same row order. Encoding is 0 = Monday through 6 = Sunday.

Parameters¶

None

Returns¶

DataFrame A new frame with each selected time feature replaced by its Int64 day-of-week (0-6, Monday-first).

Examples¶

Example 1. Extract the day-of-week from every row of a Timeline feature.

using namespace pluss::table;

auto events = DataFrame(
    {{"ts", Thread(pluss::make_timeline({
          "2024-01-31T09:15:30Z",
          "2024-02-29T23:45:00Z",
          "2024-07-06T14:00:00Z",
          "2023-03-01T00:00:00Z",
      }))}});
std::cout << events;

auto out = events.tl().weekday();
std::cout << out;

Output (before)¶

==========================
     | ts                 
--------------------------
0    | 2024-01-31 09:15:30
1    | 2024-02-29 23:45:00
2    | 2024-07-06 14:00:00
3    | 2023-03-01 00:00:00
--------------------------
[4 cs x 1 feat]

Output (after)¶

===========
     | ts  
-----------
0    | 2   
1    | 3   
2    | 5   
3    | 2   
-----------
[4 cs x 1 feat]

"2024-01-31" and "2023-03-01" are both Wednesdays (2); "2024-02-29" is a Thursday (3); "2024-07-06" is a Saturday (5).

Notes¶

  • The encoding is Monday 0 through Sunday 6 — not the C/Python tm_wday-style Sunday-first convention some other libraries use.

  • DataFrame::tl() requires every feature on the calling frame to already be Timeline/TimeIndex-kind — narrow with features() first if needed.

  • A NaT row (or one already null on the underlying Thread) displays as "NULL".

See Also¶

  • DataFrameTimelineAccessor::weekday_name: the same information as a text name instead of a number.

  • DataFrameTimelineAccessor::weekend: whether the day falls on Saturday/Sunday.

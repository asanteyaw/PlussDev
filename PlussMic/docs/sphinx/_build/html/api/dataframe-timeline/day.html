DataFrameTimelineAccessor::day¶

Back to DataFrameTimelineAccessor API Reference

Signature¶

DataFrameTimelineAccessor::day() const -> DataFrame

What It Does¶

Replaces every selected Timeline/TimeIndex feature with its day-of-month (1-31), as a numeric Series — same feature name, same row order.

Parameters¶

None

Returns¶

DataFrame A new frame with each selected time feature replaced by its Int64 day-of-month.

Examples¶

Example 1. Extract the day-of-month from every row of a Timeline feature.

using namespace pluss::table;

auto events = DataFrame(
    {{"ts", Thread(pluss::make_timeline({
          "2024-01-31T09:15:30Z",
          "2024-02-29T23:45:00Z",
          "2024-07-06T14:00:00Z",
          "2023-03-01T00:00:00Z",
      }))}});
std::cout << events;

auto out = events.tl().day();
std::cout << out;

Output (before)¶

==========================
     | ts                 
--------------------------
0    | 2024-01-31 09:15:30
1    | 2024-02-29 23:45:00
2    | 2024-07-06 14:00:00
3    | 2023-03-01 00:00:00
--------------------------
[4 cs x 1 feat]

Output (after)¶

===========
     | ts  
-----------
0    | 31  
1    | 29  
2    | 6   
3    | 1   
-----------
[4 cs x 1 feat]

The "ts" column keeps its name but is now Int64, holding each row’s day-of-month.

Notes¶

  • DataFrame::tl() requires every feature on the calling frame to already be Timeline/TimeIndex-kind — narrow with features() first if the source frame has other kinds mixed in.

  • A NaT row (or one already null on the underlying Thread) displays as "NULL".

  • Reads the local calendar day relative to the Timeline’s current timezone.

See Also¶

  • DataFrameTimelineAccessor::year, DataFrameTimelineAccessor::month: the other calendar-date components.

  • DataFrameTimelineAccessor::month_start, DataFrameTimelineAccessor::month_end: whether this day is its month’s first/last.

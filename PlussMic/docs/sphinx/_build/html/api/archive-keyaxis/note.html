ArchiveKeyAxisAccessor::note¶

Back to ArchiveKeyAxisAccessor API Reference

Signature¶

Archive ArchiveKeyAxisAccessor::note() const

What It Does¶

Returns a new archive where every catalog in the stack has been narrowed to only its Note-kind keys — each catalog filtered independently, by delegating to that catalog’s own CatalogKeyAxisAccessor::note.

Important

Each catalog is filtered independently — no cross-catalog key uniformity required Same rule as like(): note() never validates keys across catalogs. If one catalog has two Note-kind keys and another has none, the result simply has an empty catalog at that depth position — no throw.

Parameters¶

None

Returns¶

Archive A new archive of the same depth, with each catalog narrowed to its own Note-kind keys.

Examples¶

Example 1. Narrow a catalog with a mix of Series and Note keys down to just the Note-kind one.

using namespace pluss::kindle::literals;

auto c0 = pluss::kindle::Catalog({
    "n"_k = pluss::kindle::Stream(pluss::make_series({1.0})),
    "s"_k = pluss::kindle::Stream(pluss::make_note({"x"})),
});
auto archive = pluss::kindle::Archive({c0});

auto out = archive.keyaxis().note();
std::cout << out.catalog(0);

Notes¶

  • See the important callout above.

  • A catalog with zero Note-kind keys becomes a valid, defined, empty catalog in the result.

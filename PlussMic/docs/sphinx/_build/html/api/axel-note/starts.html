AxelNoteAccessor::starts¶

Back to AxelNoteAccessor API Reference

Signature¶

Axel AxelNoteAccessor::starts(std::string_view prefix) const

What It Does¶

Checks whether each bound field’s text starts with prefix, in every registry frame, replacing each Note field with a Bool Series field. Applies RegistryNoteAccessor::starts to every frame via Axel::map.

Parameters¶

prefix (std::string_view) The literal text to check for at the start of each value. Always a literal comparison — there is no regex or case-insensitive mode, unlike has().

Returns¶

Axel A new axel with every bound field, in every frame, replaced by a Bool Series field; every unbound field unchanged.

Examples¶

Example 1. Check which city names start with "Ac".

auto r0 = pluss::scribble::Registry({{"city", pluss::scribble::Slot({pluss::make_note("Accra"), pluss::make_note("Tema")})}});
auto axel = pluss::scribble::Axel({r0});

auto out = axel.fields({"city"}).nt().starts("Ac");
auto city = out.registry(0).fields("city");
std::cout << std::boolalpha
          << std::get<pluss::Series>(city.at(0)).to_vec<bool>()[0] << " "
          << std::get<pluss::Series>(city.at(1)).to_vec<bool>()[0];

Output¶

true false

Notes¶

  • Always a literal, case-sensitive comparison — there’s no TextOptions overload here, unlike has() or count().

  • Changes each bound field’s kind from Note to Series (Bool).

  • Requires every bound field, in every frame, to be Note-kind — a non-Note field throws "Slot::nt: slot kind must be Note".

See Also¶

  • AxelNoteAccessor::ends: the mirror check at the end of the text instead of the beginning.

  • AxelNoteAccessor::has: a general substring/pattern search anywhere in the text, with case-insensitive and regex options.

  • Axel::nt: the entry point this accessor is reached from.

DataFrameCaseStudyAccessor::pick¶

Back to DataFrameCaseStudyAccessor API Reference

Signature¶

DataFrame DataFrameCaseStudyAccessor::pick(const DataFrame::CasePick& pick) const

What It Does¶

Selects rows from a named, possibly multi-level case axis. Unlike labels(), which searches the rendered case-axis key, pick() can constrain one named level, several named levels, or the complete ordered key. All supplied constraints are combined with logical AND. At least one row must match.

Parameters¶

pick (const DataFrame::CasePick&) The constraint to apply, using exactly one selector form (see CasePick Options below). An empty CasePick (no selector form populated) is an error.

CasePick Options¶

Field

Meaning

Default

label

One case-level name to match

empty

value

Value paired with label

empty

names

Several case-level names

empty

values

Values paired positionally with names

empty

key

Full key in the frame’s case-level order

empty

drop

Remove matched level(s) from the result axis

false

Use exactly one selector form: label/value, names/values, or key. names and values must have equal lengths; key must contain exactly one value per case level. Unknown levels, mixed selector forms, and a selector that matches no rows are errors. Missing case-level values compare through the public "NULL" spelling.

Returns¶

DataFrame A new frame containing every case that satisfies every supplied constraint. If drop is set, the matched level(s) are removed from the result’s case axis; otherwise every original level is retained.

Examples¶

Example 1. Match one named level; every row sharing that level’s value is kept.

using namespace pluss::table;
auto frame = DataFrame({
    {"region", Slate(pluss::make_note({"West", "West", "East"}))},
    {"account", Slate(pluss::make_note({"101", "102", "201"}))},
    {"sales", Slate(pluss::make_series({3, 5, 8}))},
}).label().set({"region", "account"});

auto west = frame.case_study().pick(
    DataFrame::CasePick{.label = "region", .value = "West"});
std::cout << west;

Output¶

================
         | sales
----------------
West101 | 3    
West102 | 5    
----------------
[2 cs x 1 feat]

Example 2. A full key, in the frame’s case-level order, matches exactly one row.

auto exact = frame.case_study().pick(
    DataFrame::CasePick{.key = {"East", "201"}});
std::cout << exact;

Output¶

================
         | sales
----------------
East201 | 8    
----------------
[1 cs x 1 feat]

Example 3. drop = true removes the matched level(s) from the result’s case axis.

auto stripped = frame.case_study().pick(DataFrame::CasePick{
    .names = {"region", "account"},
    .values = {"West", "101"},
    .drop = true,
});
std::cout << stripped;

Output¶

============
     | sales
------------
0    | 3    
------------
[1 cs x 1 feat]

Example 4. Several named constraints are paired positionally and combined with logical AND.

auto west_102 = frame.case_study().pick(DataFrame::CasePick{
    .names = {"region", "account"},
    .values = {"West", "102"},
});
std::cout << west_102;

Output¶

================
         | sales
----------------
West102 | 5    
----------------
[1 cs x 1 feat]

Example 5. drop removes only the level(s) used by the selector — the unused level survives as the result’s (now single-level) case axis.

auto west_without_region = frame.case_study().pick(DataFrame::CasePick{
    .label = "region",
    .value = "West",
    .drop = true,
});
std::cout << west_without_region;

Output¶

============
     | sales
------------
101  | 3    
102  | 5    
------------
[2 cs x 1 feat]

Example 6. Each named level requires exactly one paired value; a length mismatch fails before any row is examined.

try {
  (void)frame.case_study().pick(DataFrame::CasePick{
      .names = {"region", "account"},
      .values = {"West"},
  });
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

DataFrame::case_study: names/values length mismatch

Example 7. A full key must cover every case level, in order.

try {
  (void)frame.case_study().pick(
      DataFrame::CasePick{.key = {"West"}});
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

DataFrame::case_study: full key length must match case-label count

Notes¶

  • pick() is the right terminal once case levels have been created with label().set({...names...}); use labels() for a flat (single-string) case axis instead.

  • Use exactly one of the three selector forms per call — mixing label/value with names/values, for example, is not a supported combination.

  • A selector that matches no rows is an error, the same as an unknown key on labels() — pick() never returns an unexpected zero-case frame.

See Also¶

  • DataFrameCaseStudyAccessor::labels: select by the rendered case-axis key as a single string, rather than by named level.

  • DataFrame::labels: create the structured, multi-level case axis that pick() operates on, via label().set({...names...}).

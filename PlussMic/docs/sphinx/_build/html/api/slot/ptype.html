Slot::ptype¶

Back to Slot API Reference

Signature¶

std::string Slot::ptype() const

What It Does¶

Returns the slot’s value type as a string: the value type name shared by every value ("Series", "Note", "Timeline", "TimeIndex"), "Mixed" if values differ in type, or "Empty" for a zero-value slot.

Parameters¶

None

Returns¶

std::string The shared value type name, "Mixed", or "Empty".

Examples¶

Example 1. A homogeneous Series slot reports "Series".

auto slot = pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2)});
std::cout << slot.ptype();

Output¶

Series

Example 2. A homogeneous Note slot reports "Note".

auto slot = pluss::scribble::Slot({pluss::make_note("a"), pluss::make_note("bb")});
std::cout << slot.ptype();

Output¶

Note

Example 3. Mixing value types reports "Mixed".

auto slot = pluss::scribble::Slot({pluss::make_series(1), pluss::make_note("x")});
std::cout << slot.ptype();

Output¶

Mixed

Notes¶

  • A string counterpart to kind(), which returns the SlotKind enum instead — ptype() is more convenient for logging or display, kind() for branching in code.

  • Requires the slot to be defined — an undefined Slot throws "Slot: undefined handle".

See Also¶

  • Slot::kind: the enum form of this same classification.

  • Slot::type_counts: a full per-value type tally.

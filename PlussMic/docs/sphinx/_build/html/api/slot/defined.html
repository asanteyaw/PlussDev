Slot::defined¶

Back to Slot API Reference

Signature¶

bool Slot::defined() const noexcept

What It Does¶

Reports whether the Slot handle owns a concrete, usable payload. A default-constructed Slot is undefined; every other constructor produces a defined one.

Important

Almost every other method requires defined() to be true Calling size(), values(), at(), or nearly any other method on an undefined Slot throws "Slot: undefined handle". defined() (and its sibling unique()) are the two exceptions — both are noexcept and safe to call on any Slot, defined or not.

Parameters¶

None

Returns¶

bool true if the slot owns a payload; false for a default-constructed Slot.

Examples¶

Example 1. A slot built from values is defined.

auto slot = pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2)});
std::cout << std::boolalpha << slot.defined();

Output¶

true

Example 2. A default-constructed slot is not.

pluss::scribble::Slot slot;
std::cout << std::boolalpha << slot.defined();

Output¶

false

Notes¶

  • See the important callout above — this is the one check safe to make before calling anything else on a Slot that might be undefined.

  • noexcept — never throws, regardless of state.

See Also¶

  • Slot::unique: the other noexcept state check, reporting reference-count uniqueness rather than payload presence.

  • Slot::empty: a defined slot can still be empty (zero values) — a different condition from being undefined.

Slot::head¶

Back to Slot API Reference

Signature¶

Slot Slot::head(std::int64_t n) const

What It Does¶

Returns a new slot holding the first n values.

Parameters¶

n (std::int64_t) The number of leading values to keep. Clamped to [0, size()] — never throws for an out-of-range n.

Returns¶

Slot A new slot with at most n values.

Examples¶

Example 1. Take the first two values.

auto slot = pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)});
auto out = slot.head(2);
std::cout << "size=" << out.size() << " vals="
          << std::get<pluss::Series>(out.at(0)).to_vec<std::int64_t>()[0] << ","
          << std::get<pluss::Series>(out.at(1)).to_vec<std::int64_t>()[0];

Output¶

size=2 vals=1,2

Example 2. Requesting more than size() clamps rather than throwing.

auto slot = pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)});
auto out = slot.head(100);
std::cout << out.size();

Output¶

3

Notes¶

  • Clamps to [0, size()] — never throws for an out-of-range n, unlike slice()/take().

  • Implemented as slice(0, clamped_n).

  • Requires the slot to be defined — an undefined Slot throws "Slot: undefined handle".

See Also¶

  • Slot::tail: the mirror operation, keeping the last n values.

  • Slot::slice: the general positional-range operation head() is built on.

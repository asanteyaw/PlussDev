Slot::show¶

Back to Slot API Reference

Signature¶

void Slot::show(std::ostream& os) const

What It Does¶

Writes the same rendering to_string()/ to_json() produce to os, instead of returning it as a string. What operator<< calls internally.

Parameters¶

os (std::ostream&) The destination stream.

Returns¶

void

Examples¶

Example 1. Write to a caller-provided stream.

auto slot = pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2)});
std::ostringstream oss;
slot.show(oss);
std::cout << std::boolalpha << (oss.str() == slot.to_string());

Output¶

true

Notes¶

  • Byte-identical output to to_string()/ to_json() — just written to a stream instead of returned.

  • operator<<(std::ostream&, const Slot&) is implemented as a call to show().

See Also¶

  • Slot::to_string / Slot::to_json: the string-returning equivalents.

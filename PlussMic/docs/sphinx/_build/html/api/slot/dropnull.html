Slot::dropnull¶

Back to Slot API Reference

Signature¶

Slot Slot::dropnull() const

What It Does¶

Returns a new slot with every null (std::monostate) value removed, shortening the slot.

Parameters¶

None

Returns¶

Slot A new slot, holding only the non-null values, in their original order.

Examples¶

Example 1. Drop the null in the middle of a slot.

auto slot = pluss::scribble::Slot({pluss::make_series(1), pluss::scribble::Slot::Value{std::monostate{}}, pluss::make_series(3)});
auto out = slot.dropnull();
std::cout << "size=" << out.size() << " vals="
          << std::get<pluss::Series>(out.at(0)).to_vec<std::int64_t>()[0] << ","
          << std::get<pluss::Series>(out.at(1)).to_vec<std::int64_t>()[0];

Output¶

size=2 vals=1,3

Notes¶

  • Unlike fillnull(), dropnull() has no kind-matching requirement on the rest of the slot — it works on any slot regardless of what non-null values it holds.

  • Requires the slot to be defined — an undefined Slot throws "Slot: undefined handle".

See Also¶

  • Slot::isnull: identify nulls without removing them.

  • Slot::fillnull: replace nulls instead of dropping them, keeping the slot’s original length.

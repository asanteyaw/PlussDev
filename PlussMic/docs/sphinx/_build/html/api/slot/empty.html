Slot::empty¶

Back to Slot API Reference

Signature¶

bool Slot::empty() const

What It Does¶

Reports whether the slot holds zero values. Shorthand for size() == 0.

Parameters¶

None

Returns¶

bool true if the slot has no values; false otherwise.

Examples¶

Example 1. A slot with values is not empty.

auto slot = pluss::scribble::Slot({pluss::make_series(1)});
std::cout << std::boolalpha << slot.empty();

Output¶

false

Example 2. A zero-value (but defined) slot is empty.

auto slot = pluss::scribble::Slot(std::vector<pluss::scribble::Slot::Value>{});
std::cout << std::boolalpha << slot.empty();

Output¶

true

Notes¶

  • Requires the slot to be defined — an undefined Slot throws "Slot: undefined handle" (via size(), which empty() calls).

  • Different from defined(): a slot can be defined and empty at the same time (zero values, but still a valid handle).

See Also¶

  • Slot::size: the count empty() checks against zero.

  • Slot::defined: checks handle validity, not value count.

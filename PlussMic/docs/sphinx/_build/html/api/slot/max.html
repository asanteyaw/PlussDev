Slot::max¶

Back to Slot API Reference

Signature¶

Slot Slot::max() const

What It Does¶

Returns a new, single-value slot holding the maximum of the slot’s values.

Parameters¶

None

Returns¶

Slot A new Series slot with exactly one value: the maximum.

Examples¶

Example 1. Find the maximum of three values.

auto slot = pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)});
auto out = slot.max();
std::cout << std::get<pluss::Series>(out.at(0)).to_vec<std::int64_t>()[0];

Output¶

3

Notes¶

  • Always collapses to exactly one value.

  • Bridges through kindelize() internally — requires the slot to be stream-compatible (a single, homogeneous numeric kind).

  • Requires the slot to be defined — an undefined Slot throws "Slot: undefined handle".

See Also¶

  • Slot::min: the mirror reduction.

  • Slot::sum, Slot::mean: the other reductions.

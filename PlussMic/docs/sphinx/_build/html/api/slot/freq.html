Slot::freq¶

Back to Slot API Reference

Signature¶

Slot Slot::freq(pluss::kindle::FreqOptions options = {}) const

What It Does¶

Returns a new slot where each value is replaced by its frequency count — how many times each distinct value occurs, sorted by descending frequency.

Parameters¶

options (pluss::kindle::FreqOptions, optional) {std::int64_t top = 0, bool dropnull = true} — top limits the result to the top most frequent values (0 means no limit); dropnull controls whether nulls are excluded before counting.

Returns¶

Slot A new Series[int64] slot holding one count per distinct value, most frequent first.

Examples¶

Example 1. A repeated value’s count sorts before the singleton’s.

auto slot = pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(1), pluss::make_series(2)});
auto out = slot.freq();
std::cout << std::get<pluss::Series>(out.at(0)).to_vec<std::int64_t>()[0] << " "
          << std::get<pluss::Series>(out.at(1)).to_vec<std::int64_t>()[0];

Output¶

2 1

Example 2. Limit to the single most frequent value’s count via top.

auto slot = pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(1), pluss::make_series(2)});
pluss::kindle::FreqOptions options;
options.top = 1;
auto out = slot.freq(options);
std::cout << "size=" << out.size() << " val=" << std::get<pluss::Series>(out.at(0)).to_vec<std::int64_t>()[0];

Output¶

size=1 val=2

Notes¶

  • Returns the counts, not the distinct values themselves — pair with distinct() if both are needed, in the same descending-frequency order.

  • Bridges through kindelize() internally — requires the slot to be stream-compatible.

  • Requires the slot to be defined — an undefined Slot throws "Slot: undefined handle".

See Also¶

  • Slot::distinct: the distinct values these counts correspond to.

  • Slot::ndistinct: the total distinct-value count.

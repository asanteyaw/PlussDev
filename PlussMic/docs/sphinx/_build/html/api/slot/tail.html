Slot::tail¶

Back to Slot API Reference

Signature¶

Slot Slot::tail(std::int64_t n) const

What It Does¶

Returns a new slot holding the last n values.

Parameters¶

n (std::int64_t) The number of trailing values to keep. Clamped to [0, size()] — never throws for an out-of-range n.

Returns¶

Slot A new slot with at most n values.

Examples¶

Example 1. Take the last two values.

auto slot = pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)});
auto out = slot.tail(2);
std::cout << "size=" << out.size() << " vals="
          << std::get<pluss::Series>(out.at(0)).to_vec<std::int64_t>()[0] << ","
          << std::get<pluss::Series>(out.at(1)).to_vec<std::int64_t>()[0];

Output¶

size=2 vals=2,3

Notes¶

  • Clamps to [0, size()] — never throws for an out-of-range n.

  • Implemented as slice(size() - clamped_n, size()).

  • Requires the slot to be defined — an undefined Slot throws "Slot: undefined handle".

See Also¶

  • Slot::head: the mirror operation, keeping the first n values.

  • Slot::slice: the general positional-range operation tail() is built on.

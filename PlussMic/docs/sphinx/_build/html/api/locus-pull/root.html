LocusPull::root¶

Back to LocusPull API Reference

Signature¶

LocusPull::root() const noexcept -> const std::string&

What It Does¶

Reports the catalog that owns the pull’s output grain – the table name passed to Locus::pull(root). It does not execute anything and never changes after construction; there is no way to retarget an existing LocusPull at a different root.

Parameters¶

None.

Returns¶

A reference to the root table’s name, valid for the LocusPull’s own lifetime.

Examples¶

Example 1. root() is set at construction and stays stable as specs are added.

auto root_plan = data.pull("customers");
std::cout << "root=" << root_plan.root() << " specs=" << root_plan.specs().size() << "\n";
root_plan.take("id").sum("events.spend", "spent");
std::cout << "root=" << root_plan.root() << " specs=" << root_plan.specs().size() << "\n";

Output¶

root=customers specs=0
root=customers specs=2

root() reads "customers" both before and after two specs are added – adding fields changes specs(), never root().

DataFrameContingencyTableBuilder::rowshare¶

Back to DataFrame contingency accessor API Reference

Signature¶

DataFrameContingencyTableBuilder::rowshare() const -> DataFrame

What It Does¶

Materializes the contingency table as row-normalized proportions.

Each cell is count(cell) / count(this row-key tuple across all columns).

Parameters¶

None

Returns¶

DataFrame A contingency table where each numeric row expresses the within-row distribution across the crossed column groups.

Examples¶

Example 1. Normalize each row by its own row total.

using namespace pluss::table;

auto df = DataFrame({
    {"city", Thread(pluss::make_note({"A", "A", "B", "B", "B"}))},
    {"channel", Thread(pluss::make_note({"Cash", "Card", "Cash", "Cash", "Card"}))},
});

auto out = df.contingency("city", "channel").rowshare();
std::cout << out;

Output¶

=======================================
     | city  Card          Cash
---------------------------------------
0    | A     0.5           0.5
1    | B     0.3333333333  0.6666666667
---------------------------------------
[2 cs x 3 feat]

The "B" row has 3 total observations, so its "Cash" cell is 2 / 3.

Notes¶

  • Each non-empty numeric row sums to 1.

  • This is still a cell-wise contingency materialization. It is not a DataFrame row reduction over existing numeric features.

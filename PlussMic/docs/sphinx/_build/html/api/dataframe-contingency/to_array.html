ContingencyTable::to_array¶

Back to ContingencyTable API Reference

Signature¶

ContingencyTable::to_array() const -> pluss::Series

What It Does¶

Returns the retained contingency tensor as an N-dimensional pluss::Series.

Use this when you want the actual dense N-dimensional payload rather than a 2D rendered DataFrame.

Returns¶

pluss::Series The dense retained tensor in current value space.

When To Use It¶

Use to_array() when:

  • you want tensor-style downstream work rather than a table render

  • you care about axis order and rank

  • you want counts as int64 or normalized values as floating point directly

Examples¶

Example 1. Inspect the dense count tensor’s rank, shape, and flattened cell values.

using namespace pluss::table;

auto df = DataFrame({
    {"city", Thread(pluss::make_note({"A", "A", "B", "B", "B"}))},
    {"channel", Thread(pluss::make_note({"Cash", "Card", "Cash", "Cash", "Card"}))},
});

auto array = df.contingency("city", "channel")
               .to_array()
               .to(pluss::codem::Platform::CPU)
               .contiguous();
std::cout << array.dim() << "\n";
std::cout << array.sizes()[0] << " " << array.sizes()[1] << "\n";

const auto* raw = reinterpret_cast<const std::int64_t*>(array.raw_data());
for (std::int64_t i = 0; i < array.numel(); ++i) {
  std::cout << raw[i] << " ";
}
std::cout << "\n";

Output¶

2
2 2
1 1 1 2

Example 2. to_array() respects the current value interpretation, so shares come back as floating-point tensors.

auto array = df.contingency("city", "channel")
               .share()
               .to_array()
               .to(pluss::codem::Platform::CPU)
               .contiguous();

const auto* raw = reinterpret_cast<const double*>(array.raw_data());
for (std::int64_t i = 0; i < array.numel(); ++i) {
  std::cout << raw[i] << " ";
}
std::cout << "\n";

Output¶

0.2 0.2 0.2 0.4

Notes¶

  • The array axis order is exactly dims().

  • freq() returns integral count tensors; share() and condition(...) return floating-point tensors.

  • to_array() exports the current retained object exactly as it stands after any slicing or marginalization.

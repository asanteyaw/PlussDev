Archive::cast¶

Back to Archive API Reference

Signatures¶

Archive::cast() const -> ArchiveCastAccessor
Archive::cast(const pluss::table::ThreadCastOptions& options) const -> ArchiveCastAccessor
Archive::cast(pluss::table::ThreadCastTarget target, const pluss::table::ThreadCastOptions& options = {}) const -> Archive

What It Does¶

Archive casting follows the same two-surface pattern as catalog casting:

  • accessor-first: archive.cast().series() / .note() / .timeline() / .timeindex()

  • direct root overload: archive.cast(target, options)

Both cast every stream in every catalog to the same target payload kind by delegating to each catalog’s own Catalog::cast(), applied uniformly regardless of each stream’s current kind.

Important

Preferred surface Prefer the accessor form in new code: archive.cast().timeline() reads better than passing an explicit target enum at the root. The direct root overload still exists and returns the same result.

Important

Applies to every stream in every catalog uniformly Same behavior as Catalog::cast(), just archive-wide: cast() doesn’t skip streams that are already the target kind, or streams for which the target doesn’t make obvious sense — it calls cast() on all of them, in every catalog. If you only want to cast specific streams, use Archive::keys(names) followed by .cast() on the selection instead.

Parameters¶

options (const pluss::table::ThreadCastOptions&, optional) For the accessor overloads, stores conversion policy on the accessor before you pick the terminal target.

target (pluss::table::ThreadCastTarget) For the direct root overload, the payload kind to cast every stream to — Series, Note, Timeline, or TimeIndex.

options (const pluss::table::ThreadCastOptions&, optional) For the direct root overload, conversion policy — series_dtype picks the numeric dtype for a Series target; invalid chooses parse-failure behavior. See Thread::cast for the full breakdown.

Returns¶

ArchiveCastAccessor / Archive The no-target overloads return an accessor; the target overload returns the fully cast archive directly.

Examples¶

Example 1. Cast every Note-kind stream of numeric-looking text to Series, across every catalog.

using namespace pluss::kindle::literals;

auto c0 = pluss::kindle::Catalog({
    "id"_k    = pluss::kindle::Stream(pluss::make_note({"1", "2", "3"})),
    "score"_k = pluss::kindle::Stream(pluss::make_note({"1.5", "2.5"})),
});
auto archive = pluss::kindle::Archive({c0});

auto out = archive.cast().series();
std::cout << out.catalog(0);

Notes¶

  • Applies to every stream in every catalog, unconditionally — see the important callout above.

  • Archive::cast(target, options) and Archive::cast(options).series() are equivalent in result; they differ only in surface style.

  • Requires a defined archive; throws "Archive: undefined handle" otherwise.

  • Follows the same per-target conversion rules as Catalog::cast/Thread::cast.

See Also¶

  • Archive::astype: the shorthand for cast(Series, {.series_dtype = dtype}).

  • Catalog::cast: the single-catalog delegate this method applies to every catalog.

  • Archive::keys: scope a cast to specific streams instead of the whole archive.

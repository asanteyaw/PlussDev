Archive::astype¶

Back to Archive API Reference

Signature¶

Archive::astype(pluss::codem::ScalarType dtype) const -> Archive

What It Does¶

Shorthand for cast(ThreadCastTarget::Series, {.series_dtype = dtype}) — casts every stream in every catalog to Series, at the requested numeric dtype, in one call. Delegates to each catalog’s own Catalog::astype().

Parameters¶

dtype (pluss::codem::ScalarType) The numeric scalar dtype to cast every stream to (e.g. Int64, Float64).

Returns¶

Archive A new archive, same depth and depth labels as the receiver, with every stream in every catalog cast to Series at dtype.

Examples¶

Example 1. Cast every stream to Series[int64].

using namespace pluss::kindle::literals;

auto c0 = pluss::kindle::Catalog({ "id"_k = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0})) });
auto archive = pluss::kindle::Archive({c0});

auto out = archive.astype(pluss::codem::ScalarType::Int64);
std::cout << out.catalog(0);

Output¶

========================================================================================================================
kindle::Catalog  keys=1
keys: [id]
------------------------------------------------------------------------------------------------------------------------
key                      | kind         | dtype            | cs      | preview                                          
------------------------------------------------------------------------------------------------------------------------
id                       | Series       | Series[int64]    | 3       | [1, 2, 3]                                        
========================================================================================================================

Notes¶

  • Applies to every stream in every catalog, unconditionally — same reach as cast().

  • Requires a defined archive; throws "Archive: undefined handle" otherwise.

See Also¶

  • Archive::cast: the more general form this method is shorthand for.

  • Catalog::astype: the single-catalog delegate this method applies to every catalog.

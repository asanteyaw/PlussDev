Archive::dropnull¶

Back to Archive API Reference

Signature¶

Archive::dropnull() const -> Archive

What It Does¶

Removes rows with any NULL cell from every catalog in the archive — delegating to each catalog’s own Catalog::dropnull() independently. Because it runs per-catalog, a ragged archive’s catalogs can end up with different record counts after this call (each catalog may lose a different number of rows).

Parameters¶

None

Returns¶

Archive A new archive, same depth and depth labels as the receiver, with NULL-containing rows removed from every catalog independently.

Examples¶

Example 1. Drop the row containing a NULL.

using namespace pluss::kindle::literals;

auto mask = pluss::make_series(std::vector<bool>{true, false, true});
auto c0 = pluss::kindle::Catalog({
    "id"_k = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0}), mask),
    "city"_k = pluss::kindle::Stream(pluss::make_note({"Accra", "Tema", "Kumasi"})),
});
auto archive = pluss::kindle::Archive({c0});

auto out = archive.dropnull();
std::cout << out.catalog(0);

Output¶

========================================================================================================================
kindle::Catalog  keys=2
keys: [id, city]
------------------------------------------------------------------------------------------------------------------------
key                      | kind         | dtype            | cs      | preview                                          
------------------------------------------------------------------------------------------------------------------------
id                       | Series       | Series[float64]  | 2       | [1, 3]                                           
city                     | Note         | Note             | 2       | [Accra, Kumasi]                                  
========================================================================================================================

Notes¶

  • Runs per-catalog independently — catalogs with different NULL patterns can end up with different record counts, making the archive newly ragged even if it wasn’t before.

  • Requires a defined archive; throws "Archive: undefined handle" otherwise.

  • Depth labels are preserved on the result.

See Also¶

  • Archive::fillnull / Archive::ffill / Archive::bfill: fill NULL cells instead of removing their rows.

  • Catalog::dropnull: the single-catalog delegate this method applies to every catalog.

Archive::show¶

Back to Archive API Reference

Signature¶

Archive::show(std::ostream& os) const -> void

What It Does¶

Writes the archive’s boxed-table summary to os — the same rendering operator<< writes, and the same content to_string() returns as a string, plus a trailing newline to_string() omits.

Parameters¶

os (std::ostream&) The destination stream to write to (e.g. std::cout, an std::ostringstream).

Returns¶

void Writes to os as a side effect; produces no return value.

Examples¶

Example 1. Write directly to std::cout.

using namespace pluss::kindle::literals;

auto c0 = pluss::kindle::Catalog({ "id"_k = pluss::kindle::Stream(pluss::make_series({1.0, 2.0})) });
auto archive = pluss::kindle::Archive({c0}, pluss::kindle::Stream(pluss::make_note({"jan"})));

archive.show(std::cout);

Output¶

========================================================================================================================
kindle::Archive  depth=1
depth_labels=yes
------------------------------------------------------------------------------------------------------------------------
frame  | label                  | keys     | min_cs | max_cs | keys                                                     
------------------------------------------------------------------------------------------------------------------------
0      | jan                    | 1        | 2      | 2      | [id]                                                     
========================================================================================================================

Example 2. show() and operator<< produce byte-identical output.

using namespace pluss::kindle::literals;

auto c0 = pluss::kindle::Catalog({ "id"_k = pluss::kindle::Stream(pluss::make_series({1.0, 2.0})) });
auto archive = pluss::kindle::Archive({c0});

std::ostringstream via_show;
archive.show(via_show);

std::ostringstream via_operator;
via_operator << archive;

std::cout << "equal: " << (via_show.str() == via_operator.str());

Output¶

equal: 1

Notes¶

  • Byte-identical to operator<<’s output — see Example 2.

  • One byte longer than to_string(): the trailing newline show() appends that to_string() omits.

  • This is a summary view — one row per catalog — not the full per-catalog table rendering.

See Also¶

  • Archive::to_string: the same rendering, returned as a string (minus the trailing newline) instead of written to a stream.

  • Catalog::show: the per-catalog equivalent.

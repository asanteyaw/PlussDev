Archive::ndistinct¶

Back to Archive API Reference

Signature¶

Archive::ndistinct(DistinctOptions options = {}) const -> Archive

struct DistinctOptions {
  bool dropnull{true};
};

What It Does¶

Returns a new archive where every catalog is replaced by its own Catalog::ndistinct() result — each stream reduced to a single count of its distinct values, per catalog. options.dropnull (default true) controls whether NULL counts as one of the distinct values.

Parameters¶

options (DistinctOptions, optional) dropnull (default true) excludes NULL from the distinct count; set false to include it.

Returns¶

Archive A new archive, same depth and depth labels as the receiver, with every stream in every catalog reduced to a one-element Series[int64] holding its distinct-value count.

Examples¶

Example 1. Count of distinct values in a text stream.

using namespace pluss::kindle::literals;

auto c0 = pluss::kindle::Catalog({
    "region"_k = pluss::kindle::Stream(pluss::make_note({"east", "west", "east", "north"})),
});
auto archive = pluss::kindle::Archive({c0});

auto out = archive.ndistinct();
std::cout << out.catalog(0);

Output¶

========================================================================================================================
kindle::Catalog  keys=1
keys: [region]
------------------------------------------------------------------------------------------------------------------------
key                      | kind         | dtype            | cs      | preview                                          
------------------------------------------------------------------------------------------------------------------------
region                   | Series       | Series[int64]    | 1       | [3]                                              
========================================================================================================================

Notes¶

  • Each stream, in every catalog, is reduced independently to a one-element result.

  • Requires a defined archive; throws "Archive: undefined handle" otherwise.

See Also¶

  • Archive::distinct: the distinct values themselves, instead of just the count.

  • Archive::freq: distinct values paired with their occurrence counts.

  • Catalog::ndistinct: the single-catalog delegate this method applies to every catalog.

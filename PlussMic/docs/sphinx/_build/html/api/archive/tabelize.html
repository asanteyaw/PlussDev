Archive::tabelize¶

Back to Archive API Reference

Signature¶

Archive::tabelize(const TabelizePolicy& policy = {}) const -> pluss::table::Atlas

What It Does¶

Converts the whole archive into a pluss::table::Atlas — the depth-stacked table-stack analog of Archive, the same way a single Catalog::tabelize() produces one DataFrame. Each catalog becomes one DataFrame in the resulting Atlas, in the same depth order, using the same TabelizePolicy (align/align_by/fill/dtype/ collision) documented on Catalog::tabelize, applied independently per catalog.

Parameters¶

policy (const TabelizePolicy&, optional) The same alignment policy Catalog::tabelize() accepts — see that page for the full breakdown of each field.

Returns¶

pluss::table::Atlas A depth-stacked Atlas, one DataFrame per catalog, in the archive’s depth order.

Examples¶

Example 1. Convert a two-catalog archive to an Atlas.

using namespace pluss::kindle::literals;

auto c0 = pluss::kindle::Catalog({
    "id"_k = pluss::kindle::Stream(pluss::make_series({1.0, 2.0})),
    "city"_k = pluss::kindle::Stream(pluss::make_note({"Accra", "Tema"})),
});
auto c1 = pluss::kindle::Catalog({
    "id"_k = pluss::kindle::Stream(pluss::make_series({3.0, 4.0})),
    "city"_k = pluss::kindle::Stream(pluss::make_note({"Ho", "Sunyani"})),
});
auto archive = pluss::kindle::Archive({c0, c1}, pluss::kindle::Stream(pluss::make_note({"jan", "feb"})));

auto atlas = archive.tabelize();
std::cout << "atlas depth: " << atlas.depth() << "\n";
std::cout << atlas.dloc(0);

Output¶

atlas depth: 2
==================
     | id    city 
------------------
0    | 1     Accra
1    | 2     Tema 
------------------
[2 cs x 2 feat]

Notes¶

  • One DataFrame per catalog, same depth order as the receiver; Atlas exposes its own depth()/dloc()-style access, matching Archive::depth/ Archive::dloc’s own API shape.

  • Each catalog is tabelized independently with the same policy — a ragged archive produces DataFrames with different shapes, one per catalog.

  • Requires a defined archive; throws "Archive: undefined handle" otherwise.

See Also¶

  • Archive::to_table: a thin wrapper over this method that can also print the result.

  • Catalog::tabelize: the single-catalog delegate this method applies to every catalog, and the full TabelizePolicy field reference.

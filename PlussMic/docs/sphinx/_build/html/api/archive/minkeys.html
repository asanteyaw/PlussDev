Archive::minkeys¶

Back to Archive API Reference

Signature¶

Archive::minkeys() const -> std::int64_t

What It Does¶

Returns the smallest key count among the archive’s catalogs — the ragged-tolerant counterpart to nkeys(), which throws if catalogs disagree. Never throws for a key-count mismatch; on a uniform archive, minkeys() == maxkeys() == nkeys().

Parameters¶

None

Returns¶

std::int64_t The smallest key count found across every catalog in the archive.

Examples¶

Example 1. A ragged archive: one catalog has 1 key, the other has 2.

using namespace pluss::kindle::literals;

auto c0 = pluss::kindle::Catalog({
    "id"_k = pluss::kindle::Stream(pluss::make_series({1.0, 2.0})),
});
auto c1 = pluss::kindle::Catalog({
    "id"_k = pluss::kindle::Stream(pluss::make_series({3.0, 4.0})),
    "city"_k = pluss::kindle::Stream(pluss::make_note({"Ho", "Koforidua"})),
});
auto ragged = pluss::kindle::Archive({c0, c1});

std::cout << ragged.minkeys();

Output¶

1

Example 2. On a uniform archive, minkeys() agrees with nkeys().

using namespace pluss::kindle::literals;

auto c0 = pluss::kindle::Catalog({ "id"_k = pluss::kindle::Stream(pluss::make_series({1.0})) });
auto c1 = pluss::kindle::Catalog({ "id"_k = pluss::kindle::Stream(pluss::make_series({2.0})) });
auto archive = pluss::kindle::Archive({c0, c1});

std::cout << "minkeys: " << archive.minkeys() << "  nkeys: " << archive.nkeys();

Output¶

minkeys: 1  nkeys: 1

Notes¶

  • Never throws for a key-count mismatch, unlike nkeys().

  • Requires a defined archive; throws "Archive: undefined handle" otherwise.

See Also¶

  • Archive::maxkeys: the mirror — the largest key count instead of the smallest.

  • Archive::nkeys: the uniform-only equivalent, which throws instead of tolerating a ragged archive.

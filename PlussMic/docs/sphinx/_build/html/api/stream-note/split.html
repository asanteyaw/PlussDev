StreamNoteAccessor::split¶

Back to StreamNoteAccessor API Reference

Signatures¶

pluss::table::DataFrame StreamNoteAccessor::split(std::string_view delimiter, std::int64_t limit = -1, std::string prefix = "part") const

pluss::table::DataFrame StreamNoteAccessor::split(std::string_view pattern, const pluss::table::TextOptions& options) const

What It Does¶

Splits the bound stream’s text on delimiter (literal) or pattern (regex, via options), returning the pieces as columns of a pluss::table::DataFrame — one row per record, one column per split position.

Important

Returns a DataFrame, not a Stream Same escape from the kindle model as findall() — see that page’s own important callout.

Parameters¶

delimiter (std::string_view, first overload) The literal text to split on.

limit (std::int64_t, first overload, default -1) Maximum number of splits; -1 means unlimited.

prefix (std::string, first overload, default "part") The prefix used to name each output column ("part_0", "part_1", …).

pattern (std::string_view, second overload) A regex pattern to split on, instead of a literal delimiter.

options (const pluss::table::TextOptions&, second overload) options.case_sensitive (default true): ignore case when false.

Returns¶

pluss::table::DataFrame One row per record; one {prefix}_N column per split position, up to the maximum number of pieces found in any single record.

Examples¶

Example 1. Split comma-separated text into columns.

auto stream = pluss::kindle::Stream(pluss::make_note({"a,b,c"}));
auto out = stream.nt().split(",");
std::cout << out;

Output¶

=============================
     | part_0  part_1  part_2
-----------------------------
0    | a       b       c     
-----------------------------
[1 cs x 3 feat]

Notes¶

  • See the important callout above.

  • The default column prefix is "part" — pass a different prefix to rename the output columns.

  • A record with fewer pieces than the maximum leaves the extra columns null for that row.

See Also¶

  • StreamNoteAccessor::partition: a related split, keeping the delimiter itself as its own column and stopping at the first match.

  • StreamNoteAccessor::findall: the other DataFrame-returning extraction method.

  • Stream::nt: the entry point this accessor is reached from.

  • CatalogNoteAccessor::split: the whole-catalog equivalent.

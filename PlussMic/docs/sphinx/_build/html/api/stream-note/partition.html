StreamNoteAccessor::partition¶

Back to StreamNoteAccessor API Reference

Signature¶

pluss::table::DataFrame StreamNoteAccessor::partition(std::string_view separator, std::string prefix = "part") const

What It Does¶

Splits the bound stream’s text into exactly three pieces at the first occurrence of separator: the text before it, the separator itself, and the text after it — returned as three columns of a pluss::table::DataFrame.

Important

Returns a DataFrame, not a Stream Same escape from the kindle model as findall() — see that page’s own important callout.

Parameters¶

separator (std::string_view) The literal text to partition on.

prefix (std::string, default "part") The prefix used to name each of the three output columns.

Returns¶

pluss::table::DataFrame One row per record, with exactly three columns: {prefix}_0 (before), {prefix}_1 (the separator itself), {prefix}_2 (after).

Examples¶

Example 1. Partition a key=value string around "=".

auto stream = pluss::kindle::Stream(pluss::make_note({"key=value"}));
auto out = stream.nt().partition("=");
std::cout << out;

Output¶

=============================
     | part_0  part_1  part_2
-----------------------------
0    | key     =       value 
-----------------------------
[1 cs x 3 feat]

The middle column, part_1, holds the separator itself ("="), not an empty placeholder — distinguishing partition() from a plain two-piece split.

Notes¶

  • See the important callout above.

  • Always exactly three columns, unlike split()’s variable column count — partition() only ever splits at the first occurrence.

  • The middle column always holds the separator text itself.

See Also¶

  • StreamNoteAccessor::split: splits at every occurrence, with a variable number of output columns.

  • Stream::nt: the entry point this accessor is reached from.

  • CatalogNoteAccessor::partition: the whole-catalog equivalent.

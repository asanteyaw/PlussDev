StreamNoteAccessor::indicate¶

Back to StreamNoteAccessor API Reference

Signature¶

pluss::table::DataFrame StreamNoteAccessor::indicate(std::string_view delimiter = "|", std::string prefix = "") const

What It Does¶

Multi-label-binarizes the bound stream’s text: splits each value on delimiter, then builds one Bool column per distinct token seen anywhere in the stream, returning a pluss::table::DataFrame — like findall(), this method leaves the kindle model. Each column is named after the token itself (with prefix prepended, if given), and each row’s column is true if that row’s value contains that token.

Important

Returns a DataFrame, not a Stream Same escape from the kindle model as findall()/ split()/partition() — see findall()’s own important callout.

Parameters¶

delimiter (std::string_view, defaults to "|") The literal text used to split each value into tokens before binarizing.

prefix (std::string, default empty) Optional prefix prepended to each generated column’s name.

Returns¶

pluss::table::DataFrame One row per record. One Bool column per distinct token seen across every row.

Examples¶

Example 1. "a|b" and "c", split on the default "|", produce three columns — one per distinct token (a, b, c) — each true exactly where that row’s value contained the token.

auto stream = pluss::kindle::Stream(pluss::make_note({"a|b", "c"}));
auto out = stream.nt().indicate("|");
std::cout << out;

Output¶

==========================
     | a      b      c    
--------------------------
0    | true   true   false
1    | false  false  true 
--------------------------
[2 cs x 3 feat]

Notes¶

  • See the important callout above.

  • Column order follows the order distinct tokens are first encountered, not necessarily alphabetical — treat column presence/absence as the contract, not column position.

  • The default delimiter is "|", matching a common multi-value-tag convention; pass any other literal delimiter for differently-formatted tag text.

StreamNoteAccessor::findall¶

Back to StreamNoteAccessor API Reference

Signatures¶

pluss::table::DataFrame StreamNoteAccessor::findall(std::string_view pattern) const

pluss::table::DataFrame StreamNoteAccessor::findall(std::string_view pattern, const pluss::table::TextOptions& options) const

What It Does¶

Finds every regex match of pattern in the bound stream’s text and returns them as columns of a pluss::table::DataFrame — one row per record, one column per match position found across all records.

Important

Returns a DataFrame, not a Stream Unlike every other method on this accessor, findall() leaves the kindle model entirely — its result is a pluss::table::DataFrame, not a Stream. split(), partition(), and indicate() share this same escape hatch.

Parameters¶

pattern (std::string_view) An ECMAScript-flavor regular expression.

options (const pluss::table::TextOptions&, two-argument overload) options.case_sensitive (default true): ignore case when false.

Returns¶

pluss::table::DataFrame One row per record; one match_N column per match position, up to the maximum number of matches found in any single record.

Examples¶

Example 1. Extract every run of digits from a string.

auto stream = pluss::kindle::Stream(pluss::make_note({"a1 b2 c3"}));
auto out = stream.nt().findall("[0-9]+");
std::cout << out;

Output¶

================================
     | match_0  match_1  match_2
--------------------------------
0    | 1        2        3      
--------------------------------
[1 cs x 3 feat]

Notes¶

  • See the important callout above.

  • Columns are named match_0, match_1, … in order of appearance.

  • A record with fewer matches than the maximum leaves the extra columns null for that row.

See Also¶

  • StreamNoteAccessor::split / partition(): the other methods on this accessor that leave the kindle model for a DataFrame result.

  • StreamNoteAccessor::count: counts matches instead of extracting their text.

  • Stream::nt: the entry point this accessor is reached from.

  • CatalogNoteAccessor::findall: the whole-catalog equivalent.

StreamLabelAccessor::has¶

Back to StreamLabelAccessor API Reference

Signature¶

bool StreamLabelAccessor::has() const

What It Does¶

Reports whether the bound stream has an explicitly set row label — true only after a prior set(...), false both before any label is set and after a reset().

Important

has() is the accurate existence check — values() is not values() always returns a usable Stream, synthesizing a positional range when unlabeled — it never signals “no label” through its return type. has() is the method that actually distinguishes “a real label was set” from “nothing was set, here’s a fallback.”

Parameters¶

None

Returns¶

bool true if a label was explicitly set (and not since reset), false otherwise.

Examples¶

Example 1. has() toggles across the set/reset lifecycle.

using pluss::table::Thread;

auto stream = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0}));
std::cout << "initial: " << std::boolalpha << stream.lbl().has() << "\n";

auto labeled = stream.lbl().set(Thread(pluss::make_note({"a", "b", "c"})));
std::cout << "after set: " << std::boolalpha << labeled.lbl().has() << "\n";

auto back = labeled.lbl().reset();
std::cout << "after reset: " << std::boolalpha << back.lbl().has();

Output¶

initial: false
after set: true
after reset: false

Notes¶

  • See the important callout above.

  • Every method on this accessor returns a new Stream (the accessor never mutates in place), so has() must be re-checked on the result of set()/reset(), not on the original stream.

See Also¶

  • StreamLabelAccessor::values: the method whose always-succeeds behavior makes has() necessary as a separate existence check.

  • StreamLabelAccessor::set / reset(): the methods that actually change what has() reports.

  • Stream::has_label: the plain getter-pair equivalent, reached outside this accessor.

  • Stream::lbl: the entry point this accessor is reached from.

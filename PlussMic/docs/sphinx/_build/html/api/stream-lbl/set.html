StreamLabelAccessor::set¶

Back to StreamLabelAccessor API Reference

Signatures¶

Stream StreamLabelAccessor::set(const Stream& labels) const
Stream StreamLabelAccessor::set(const pluss::table::Slate& labels) const

What It Does¶

Attaches labels as the bound stream’s row labels, returning a new stream. Both overloads accept the same length-matching label data — as a Stream or a pluss::table::Slate — and are otherwise interchangeable.

Important

make_note(…) is ambiguous here — wrap it explicitly pluss::make_note(...) (and other make_* helpers) implicitly convert to both Stream and pluss::table::Slate — passing one directly to set() fails to compile with an ambiguous-overload error. Wrap it explicitly in whichever type you mean: set(pluss::table::Slate(pluss::make_note({...}))) or set(pluss::kindle::Stream(pluss::make_note({...}))). A pre-built Stream or Slate value (not a bare make_note(...) call) resolves cleanly with no wrapping needed.

Parameters¶

labels (const Stream& or const pluss::table::Slate&) The new row labels. Must be the same length as the bound stream.

Returns¶

Stream A new stream with labels attached as its row labels; every other aspect of the stream (values, mask) is unchanged.

Examples¶

Example 1. Attach Note-kind labels via the Slate overload.

using pluss::table::Slate;

auto stream = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0}));
auto labeled = stream.lbl().set(Slate(pluss::make_note({"a", "b", "c"})));
std::cout << labeled;

Example 2. The Stream overload is equivalent — pass an already-built Stream of labels directly.

auto stream = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0}));
auto label_stream = pluss::kindle::Stream(pluss::make_note({"x", "y", "z"}));
auto labeled = stream.lbl().set(label_stream);
std::cout << labeled;

Notes¶

  • See the important callout above.

  • After set(), has() reports true — the label is now genuine, not a values() synthesized fallback.

  • labels must match the bound stream’s length; a mismatch throws.

See Also¶

  • StreamLabelAccessor::reset: the inverse operation, clearing the label back to unset.

  • StreamLabelAccessor::has: confirms a label was genuinely set.

  • Stream::with_label: a narrower set-only surface reached outside this accessor, equivalent in effect.

  • Stream::lbl: the entry point this accessor is reached from.

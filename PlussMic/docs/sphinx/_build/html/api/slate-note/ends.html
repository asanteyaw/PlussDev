SlateNoteAccessor::ends¶

Back to SlateNoteAccessor API Reference

Signature¶

SlateNoteAccessor::ends(std::string_view suffix) const -> Slate

What It Does¶

Checks the bound slate’s cells for a literal, case-sensitive suffix match, replacing each cell with a Bool — true where the cell’s text ends with suffix, false where it doesn’t. A direct forward to Slate::ends(); the mirror image of starts(). Requires the bound slate to be Note-kind.

Parameters¶

suffix (std::string_view)

The literal text to check for at the end of each cell. An empty suffix matches every non-null cell.

Returns¶

Slate A new Bool-typed Series slate, same length as the bound slate, holding the elementwise suffix check.

Examples¶

Example 1. Check a filenames slate for a literal, case-sensitive suffix.

using namespace pluss::table;

auto files = Slate(pluss::make_note({"report.pdf", "notes.PDF", "summary.docx"}));
auto out = files.nt().ends(".pdf");
std::cout << out;

Output¶

0  true
1  false
2  false

ptype: Series

Row 1 ("notes.PDF") doesn’t match — the uppercase ".PDF" extension doesn’t match lowercase ".pdf" under a case-sensitive comparison.

Example 2. Case-insensitive suffix matching by normalizing first.

auto out2 = files.nt().lower().nt().ends(".pdf");
std::cout << out2;

Output¶

0  true
1  true
2  false

ptype: Series

Lowercasing first folds "notes.PDF" down to "notes.pdf", so row 1 now matches too — ends() itself never gained a case-insensitivity option.

Example 3. A non-Note slate throws — the same message Slate::ends() produces directly.

auto numbers = Slate(pluss::make_series({1.0, 2.0, 3.0}));
try {
  auto bad = numbers.nt().ends("1");
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n')) << "\n";
}

Output¶

Slate::ends: expected Note payload

Notes¶

  • SlateNoteAccessor::ends() is a one-line forward to Slate::ends() — identical behavior and throws.

  • Case-sensitive, literal comparison only — no regex mode.

  • Changes the payload kind from Note to Series (Bool).

  • A null cell on input stays null on output.

See Also¶

  • Slate::ends: the direct, non-accessor form this method forwards to.

  • SlateNoteAccessor::starts: the same check anchored at the start instead of the end.

  • SlateNoteAccessor::lower / SlateNoteAccessor::casefold: normalize case ahead of a case-insensitive suffix check.

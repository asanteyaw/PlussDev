DataFrameSortBuilder::nulls_first¶

Back to DataFrameSortBuilder API Reference

Signature¶

DataFrameSortBuilder DataFrameSortBuilder::nulls_first() const

What It Does¶

Moves missing values to the front of the result for the active key — the most recently added key via by(...)/then(...).

Important

nulls_first() mutates only the active key Same scoping rule as asc()/desc() — this changes only the most recently added key’s null placement, not every key in the plan.

Parameters¶

None

Returns¶

DataFrameSortBuilder A new builder with the active key’s null placement set to front.

Examples¶

Example 1. A missing "sales" value sorts first instead of the default last.

using namespace pluss::table;

auto df = DataFrame({
    {"sales", Thread(pluss::make_series({120.0, 100.0, 90.0}),
                     pluss::make_series(std::vector<bool>{true, false, true}))},
});

auto default_out = df.sort().by("sales").yield();
std::cout << "default (nulls_last):\n" << default_out;

auto out = df.sort().by("sales").nulls_first().yield();
std::cout << "nulls_first:\n" << out;

Output¶

default (nulls_last):
============
     | sales
------------
2    | 90   
0    | 120  
1    | NULL 
------------
[3 cs x 1 feat]
nulls_first:
============
     | sales
------------
1    | NULL 
2    | 90   
0    | 120  
------------
[3 cs x 1 feat]

The missing row (1) moves from last to first; the two real values (90, 120) keep their relative ascending order in both cases.

Notes¶

  • See the important callout above.

  • Requires an active key to exist — call .by(...)/.then(...) first.

  • Overrides whatever nulls_last default DataFrame::sort(ascending, nulls_last) set, for this key only.

See Also¶

  • DataFrameSortBuilder::nulls_last: the opposite placement, and the builder’s own default.

  • DataFrameSortBuilder::by: supplies the key this method mutates.

  • DataFrame::sort: the entry point this builder is reached from, whose nulls_last parameter sets every key’s default.

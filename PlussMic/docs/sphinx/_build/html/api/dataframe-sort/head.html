DataFrameSortBuilder::head¶

Back to DataFrameSortBuilder API Reference

Signature¶

DataFrame DataFrameSortBuilder::head(std::int64_t n) const

What It Does¶

Executes the plan and returns only the top-ranked n rows — a “top-N” shorthand for yield().slice(0, n) that (per the underlying implementation) can avoid materializing the full sorted frame just to discard most of it.

Important

A terminal method — unknown-feature validation fires here Same as yield()/order()/tail() — calling head() is what actually executes the plan. See by()’s own edge-case example.

Parameters¶

n (std::int64_t) How many top-ranked rows to return. Must be non-negative.

Returns¶

DataFrame The first n rows under the planned ordering.

Examples¶

Example 1. The two highest-sales rows.

using namespace pluss::table;

auto df = DataFrame({
    {"city",  Thread(pluss::make_note({"Tema", "Accra", "Accra", "Tema"}))},
    {"sales", Thread(pluss::make_series({120.0, 100.0, 90.0, 200.0}))},
});

auto top2 = df.sort().by("sales").desc().head(2);
std::cout << top2;

Output¶

==================
     | city  sales
------------------
3    | Tema  200  
0    | Tema  120  
------------------
[2 cs x 2 feat]

Notes¶

  • See the important callout above.

  • n must be non-negative.

  • Uses the same planned ordering yield() would produce — the top rows under that plan, not simply the first n rows of the unsorted frame.

See Also¶

  • DataFrameSortBuilder::tail: the bottom-ranked counterpart.

  • DataFrameSortBuilder::yield: the full sorted frame, with no row limit.

  • DataFrame::sort: the entry point this builder is reached from.

DataFrameSortBuilder::order¶

Back to DataFrameSortBuilder API Reference

Signature¶

Thread DataFrameSortBuilder::order() const

What It Does¶

Executes the plan and materializes it as a Thread of Int64 row positions — the reusable permutation artifact, rather than the sorted frame itself. Feeding this into DataFrame::take (on the same frame, or any other frame/thread that shares its row alignment) reproduces the sorted order.

Important

A terminal method — this is where unknown-feature validation actually fires Like yield()/head()/tail(), calling order() is what actually executes the plan — an unknown feature name supplied to an earlier .by(...)/.then(...) call only throws here. See by()’s own edge-case example.

Parameters¶

None

Returns¶

Thread An Int64 Series-kind thread of row positions, in sorted order.

Examples¶

Example 1. Materialize the permutation, then apply it via take() — useful when several aligned objects need the exact same ordering.

using namespace pluss::table;

auto df = DataFrame({
    {"city",  Thread(pluss::make_note({"Tema", "Accra", "Accra", "Tema"}))},
    {"sales", Thread(pluss::make_series({120.0, 100.0, 90.0, 200.0}))},
});

auto ord = df.sort().by("sales").desc().order();
std::cout << ord;

auto taken = df.take(ord);
std::cout << "take(order()):\n" << taken;

Output¶

0  3
1  0
2  1
3  2

ptype: Series
take(order()):
===================
     | city   sales
-------------------
3    | Tema   200  
0    | Tema   120  
1    | Accra  100  
2    | Accra  90   
-------------------
[4 cs x 2 feat]

df.take(ord) reproduces exactly what df.sort().by("sales").desc().yield() would have returned directly — order() is useful specifically when the same permutation needs to be applied to more than one object.

Notes¶

  • See the important callout above.

  • The result’s own case labels are the source positions in sorted order — the same convention take() itself follows.

See Also¶

  • DataFrameSortBuilder::yield: executes and returns the sorted frame directly, when you don’t need the raw permutation.

  • DataFrame::take: the row-selection primitive this permutation feeds into.

  • DataFrame::sort: the entry point this builder is reached from.

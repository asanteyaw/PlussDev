DataFrameSortBuilder::yield¶

Back to DataFrameSortBuilder API Reference

Signature¶

DataFrame DataFrameSortBuilder::yield() const

What It Does¶

Executes the sort plan and returns the fully sorted DataFrame — the terminal that corresponds most directly to DataFrame::arrange(...)’s direct execute-now form, reached instead through the reusable builder.

Important

A terminal method — unknown-feature validation fires here Same as order()/head()/tail() — calling yield() is what actually executes the plan and validates every feature name supplied to .by(...)/.then(...). See by()’s own edge-case example.

Parameters¶

None

Returns¶

DataFrame A new frame with rows reordered by the planned key(s).

Examples¶

Example 1. Build a multi-key plan, then materialize it with yield().

using namespace pluss::table;

auto df = DataFrame({
    {"city",  Thread(pluss::make_note({"Tema", "Accra", "Accra", "Tema"}))},
    {"sales", Thread(pluss::make_series({120.0, 100.0, 90.0, 200.0}))},
});

auto out = df.sort().by("city").then("sales").desc().yield();
std::cout << out;

Output¶

===================
     | city   sales
-------------------
1    | Accra  100  
2    | Accra  90   
3    | Tema   200  
0    | Tema   120  
-------------------
[4 cs x 2 feat]

Notes¶

  • See the important callout above.

  • Equivalent in result to calling order() followed by take() yourself — yield() is the direct one-call path when you don’t need the raw permutation for anything else.

See Also¶

  • DataFrameSortBuilder::order: materializes the permutation instead of applying it directly.

  • DataFrameSortBuilder::head / tail(): execute the plan and keep only the top/bottom n rows.

  • DataFrame::arrange: the direct execute-now sorter this method corresponds to.

  • DataFrame::sort: the entry point this builder is reached from.

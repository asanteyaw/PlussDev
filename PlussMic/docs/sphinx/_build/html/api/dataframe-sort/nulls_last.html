DataFrameSortBuilder::nulls_last¶

Back to DataFrameSortBuilder API Reference

Signature¶

DataFrameSortBuilder DataFrameSortBuilder::nulls_last() const

What It Does¶

Moves missing values to the end of the result for the active key — the most recently added key via by(...)/then(...). This is also the builder’s own default (nulls_last = true on DataFrame::sort(...) unless overridden).

Important

nulls_last() mutates only the active key Same scoping rule as asc()/desc() — this changes only the most recently added key’s null placement, not every key in the plan.

Parameters¶

None

Returns¶

DataFrameSortBuilder A new builder with the active key’s null placement set to end.

Examples¶

Example 1. Explicit nulls_last() reproduces the builder’s default placement — a missing "sales" value sorts after every real value.

using namespace pluss::table;

auto df = DataFrame({
    {"sales", Thread(pluss::make_series({120.0, 100.0, 90.0}),
                     pluss::make_series(std::vector<bool>{true, false, true}))},
});

auto out = df.sort().by("sales").nulls_last().yield();
std::cout << out;

Output¶

============
     | sales
------------
2    | 90   
0    | 120  
1    | NULL 
------------
[3 cs x 1 feat]

Notes¶

  • See the important callout above.

  • Requires an active key to exist — call .by(...)/.then(...) first.

  • Mainly useful to reverse a prior .nulls_first() on the active key, or when a builder-level nulls_last = false default needs overriding back for this specific key.

See Also¶

  • DataFrameSortBuilder::nulls_first: the opposite placement.

  • DataFrameSortBuilder::by: supplies the key this method mutates.

  • DataFrame::sort: the entry point this builder is reached from, whose nulls_last parameter sets every key’s default.

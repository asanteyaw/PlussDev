RegistryNoteAccessor::normalize¶

Back to RegistryNoteAccessor API Reference

Signature¶

Registry RegistryNoteAccessor::normalize(pluss::table::UnicodeForm form = pluss::table::UnicodeForm::NFC) const

What It Does¶

Applies Unicode normalization to every bound field’s text, returning a new registry with those fields replaced.

enum class UnicodeForm : std::uint8_t {
  NFC = 0,
  NFD = 1,
  NFKC = 2,
  NFKD = 3,
};

Normalization matters when the same visual character can be represented by different underlying byte sequences (for example, a precomposed accented letter versus the base letter plus a combining accent mark) — two values that look identical on screen can compare as unequal or hash differently until they’re normalized to the same form.

Parameters¶

form (pluss::table::UnicodeForm, defaults to pluss::table::UnicodeForm::NFC) Which of the four standard Unicode normalization forms to apply: NFC (canonical composition, the default), NFD (canonical decomposition), NFKC (compatibility composition), or NFKD (compatibility decomposition).

Returns¶

Registry A new registry with every bound field’s text normalized; every unbound field unchanged.

Examples¶

Example 1. Default call normalizes to NFC.

auto rg = pluss::scribble::Registry({
    {"txt", pluss::scribble::Slot({pluss::make_note("cafe")})},
});

auto out = rg.fields({"txt"}).nt().normalize();
std::cout << std::get<pluss::Note>(out.fields("txt").at(0)).at(0);

Output¶

cafe

Example 2. Passing a form explicitly.

auto rg = pluss::scribble::Registry({
    {"txt", pluss::scribble::Slot({pluss::make_note("cafe")})},
});

auto out = rg.fields({"txt"}).nt().normalize(pluss::table::UnicodeForm::NFD);
std::cout << std::get<pluss::Note>(out.fields("txt").at(0)).at(0);

Output¶

cafe

Plain ASCII text like "cafe" has no composed/decomposed distinction to make, so every form round-trips it unchanged — the visible difference shows up on text containing combining marks or compatibility characters.

Notes¶

  • Defaults to NFC, the most common form for storage and comparison.

  • Requires every bound field to be Note-kind — a non-Note field throws "Slot::nt: slot kind must be Note".

  • Bound via Registry::nt(), which binds every field of the registry unless you project first with fields(keys).

See Also¶

  • RegistryNoteAccessor::casefold: another transform aimed at making text comparable, applied to case rather than composition.

  • RegistryNoteAccessor::encode: the other byte/text-level transform on this accessor.

  • Registry::nt: the entry point this accessor is reached from.

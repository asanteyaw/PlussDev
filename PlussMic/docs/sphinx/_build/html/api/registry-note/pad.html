RegistryNoteAccessor::pad¶

Back to RegistryNoteAccessor API Reference

Signature¶

Registry RegistryNoteAccessor::pad(std::int64_t width,
                                   pluss::table::TextAlign align = pluss::table::TextAlign::Left,
                                   char fill = ' ') const

What It Does¶

Pads every bound field’s text out to at least width characters, using fill and the alignment given by align. Returns a new registry with those fields replaced.

enum class TextAlign : std::uint8_t {
  Left = 0,
  Right = 1,
  Center = 2,
};

align describes where the original text ends up, not where the padding goes: Left keeps the text flush left and adds padding on the right; Right keeps the text flush right and adds padding on the left; Center splits the padding between both sides.

Parameters¶

width (std::int64_t) The minimum total length of the result. Values already at or beyond this length are returned unchanged.

align (pluss::table::TextAlign, defaults to pluss::table::TextAlign::Left) Where the original text sits relative to the added padding.

fill (char, defaults to ' ') The character used to pad.

Returns¶

Registry A new registry with every bound field’s text padded to width; every unbound field unchanged.

Examples¶

Example 1. Default call: left-align, pad with spaces on the right.

auto rg = pluss::bundle::Registry({
    {"code", pluss::bundle::Slot({pluss::make_note("7")})},
});

auto out = rg.fields({"code"}).nt().pad(4);
std::cout << "'" << std::get<pluss::Note>(out.fields("code").at(0)).at(0) << "'";

Output¶

'7   '

Example 2. Right-align with a '0' fill — a common way to zero-pad numeric codes stored as text.

auto rg = pluss::bundle::Registry({
    {"code", pluss::bundle::Slot({pluss::make_note("7")})},
});

auto out = rg.fields({"code"}).nt().pad(4, pluss::table::TextAlign::Right, '0');
std::cout << std::get<pluss::Note>(out.fields("code").at(0)).at(0);

Output¶

0007

Example 3. Center alignment splits the padding across both sides.

auto rg = pluss::bundle::Registry({
    {"code", pluss::bundle::Slot({pluss::make_note("7")})},
});

auto out = rg.fields({"code"}).nt().pad(5, pluss::table::TextAlign::Center);
std::cout << "'" << std::get<pluss::Note>(out.fields("code").at(0)).at(0) << "'";

Output¶

'  7  '

Notes¶

  • Values already at or beyond width characters pass through unchanged — this is a minimum-width pad, not a fixed-width truncate.

  • align describes where the original text lands, not where the padding goes — see the description above.

  • Requires every bound field to be Note-kind — a non-Note field throws "Slot::nt: slot kind must be Note".

See Also¶

  • RegistryNoteAccessor::strip / lstrip() / rstrip(): the inverse operation family, removing characters from the edges instead of adding them.

  • Registry::nt: the entry point this accessor is reached from.

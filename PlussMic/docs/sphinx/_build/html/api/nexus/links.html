What It Does¶

A family of exact aliases: the zero-argument links() calls relationships(); the single-Relationship and initializer_list<Relationship> overloads of links/links_ call add_relationship/add_relationship_/add_relationships/add_relationships_ respectively. All behave identically to their canonical counterparts — same validation, same throws, same non-mutating/mutating split. links exists purely as a shorter, more conversational spelling for the same four calls.

Parameters¶

See relationships() (zero-argument overload) and add_relationship() (the four add overloads) for the full parameter documentation — identical here.

Returns¶

Identical to relationships() and add_relationship().

Examples¶

Example 1. links() and relationships() always agree; links(rel) behaves exactly like add_relationship(rel).

using namespace pluss::table;

auto customers = DataFrame({
    {"customer_id", Thread(pluss::make_series({1.0, 2.0, 3.0}))},
    {"name",        Thread(pluss::make_note({"Ada", "Ben", "Cy"}))},
});
auto orders = DataFrame({
    {"order_id",    Thread(pluss::make_series({101.0, 102.0}))},
    {"customer_id", Thread(pluss::make_series({1.0, 2.0}))},
});

auto biz = Nexus({
    {"customers", customers},
    {"orders", orders},
});

std::cout << (biz.links().size() == biz.relationships().size()) << "\n";

Relationship rel;
rel.name = "orders_to_customers";
rel.left_table = "orders";
rel.right_table = "customers";
rel.keys = {{"customer_id", "customer_id"}};

auto linked = biz.links(rel);
std::cout << linked.nrelationships();

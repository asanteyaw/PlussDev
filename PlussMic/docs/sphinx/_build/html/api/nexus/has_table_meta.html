Nexus::has_table_meta¶

Back to Nexus API Reference

Signature¶

Nexus::has_table_meta(std::string_view key) const -> bool

What It Does¶

Reports whether a table currently has TableMeta declared — grain, primary/candidate keys, a time field, and so on. This is the safe way to check before relying on declared metadata: several auditing methods (grain_audit(), the default-key overloads of validate_keys()/detect_duplicates()) require metadata to already be declared and throw otherwise.

Note

Checks presence, not readiness has_table_meta() only reports whether a TableMeta value has been attached at all — even a TableMeta{} with every field left at its default counts as “has metadata”. It does not check whether the declared metadata is actually useful (for example, whether a primary key was ever set). If you need “does this table have a usable primary key declared”, read the primary_key field off table_meta()’s result yourself.

Parameters¶

key (std::string_view) The table name to check. Unlike most other lookups on this class, an unknown key does not throw here — it simply returns false.

Returns¶

bool true if the table has TableMeta declared (via set_table_meta() or meta()), false if it doesn’t — including for a key that doesn’t exist in the workspace at all.

Examples¶

Example 1. No metadata declared yet.

using namespace pluss::table;
using namespace pluss::bundle;

auto customers = DataFrame({
    {"customer_id", Slate(pluss::make_series({1.0, 2.0, 3.0}))},
    {"name",        Slate(pluss::make_note({"Ada", "Ben", "Cy"}))},
});

auto biz = Nexus({{"customers", customers}});

std::cout << std::boolalpha << biz.has_table_meta("customers");

Output¶

false

Example 2. After declaring metadata, has_table_meta() reports true on the returned workspace — but the original, un-tagged workspace is unaffected.

TableMeta meta;
meta.grain = "one row per customer";
meta.primary_key = {"customer_id"};

auto tagged = biz.set_table_meta("customers", meta);

std::cout << std::boolalpha << biz.has_table_meta("customers") << " " << tagged.has_table_meta("customers");

Output¶

false true

Example 3. An unknown key returns false rather than throwing.

std::cout << std::boolalpha << biz.has_table_meta("missing");

Output¶

false

Notes¶

  • Reports presence only, not “readiness” — see the note above.

  • An unknown table key returns false; it does not throw.

  • Non-mutating; simply inspects the workspace’s current state.

See Also¶

  • Nexus::table_meta: read the declared metadata itself.

  • Nexus::set_table_meta: attach metadata to a table.

  • Nexus::grain_audit: one of several methods that requires declared metadata and throws when it’s missing.

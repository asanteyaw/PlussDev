Nexus::audit¶

Back to Nexus API Reference

Signature¶

Nexus::audit() const -> DataFrame
Nexus::audit(std::string_view name) const -> DataFrame

What It Does¶

audit() now has two roles:

  • audit() with no arguments returns the workspace-wide integrity table — the same combined table/relationship diagnostics returned by scan()

  • audit(name) remains the shorter alias for relationship_audit(name)

That split makes audit() the natural trust entry point for Nexus: one call to inspect the whole workspace, or one named call to zoom into a single declared relationship.

Parameters¶

For audit(): none.

For audit(name): see relationship_audit() — identical here.

Returns¶

For audit(): the same combined diagnostics frame as scan().

For audit(name): identical to relationship_audit().

Examples¶

Example 1. audit() with no arguments returns the workspace command-center audit.

using namespace pluss::table;
using namespace pluss::bundle;

auto customers = DataFrame({
    {"customer_id", Slate(pluss::make_series({1.0, 2.0}))},
    {"name",        Slate(pluss::make_note({"Ada", "Ben"}))},
});
auto orders = DataFrame({
    {"order_id",    Slate(pluss::make_series({101.0, 102.0}))},
    {"customer_id", Slate(pluss::make_series({1.0, 2.0}))},
});

auto biz = Nexus({
    {"customers", customers},
    {"orders", orders},
});

Relationship rel;
rel.name = "orders_to_customers";
rel.left_table = "orders";
rel.right_table = "customers";
rel.keys = {{"customer_id", "customer_id"}};

auto linked = biz.add_relationship(rel);

std::cout << linked.audit().features("kind");

Output¶

0  table
1  table
2  relationship
Name: kind, ptype: Note

Example 2. audit(name) still aliases the one-relationship summary.

std::cout << linked.audit("orders_to_customers").features("valid");

Output¶

0  true
Name: valid, ptype: Series

Notes¶

  • audit() is now the short workspace-integrity entry point; it is not relationship-only anymore.

  • audit(name) is still purely a naming alternative for relationship_audit(name).

See Also¶

  • Nexus::scan: the canonical workspace-level audit table returned by audit().

  • Nexus::relationship_audit: the canonical name this aliases.

Nexus::audit¶

Back to Nexus API Reference

Signature¶

Nexus::audit(std::string_view name) const -> DataFrame

What It Does¶

An exact alias for relationship_audit() — audit calls straight through with no behavioral difference. audit is the shorter, more conversational spelling.

Parameters¶

See relationship_audit() — identical here.

Returns¶

Identical to relationship_audit().

Examples¶

Example 1. audit() and relationship_audit() return identical results.

using namespace pluss::table;

auto customers = DataFrame({
    {"customer_id", Thread(pluss::make_series({1.0, 2.0}))},
    {"name",        Thread(pluss::make_note({"Ada", "Ben"}))},
});
auto orders = DataFrame({
    {"order_id",    Thread(pluss::make_series({101.0, 102.0}))},
    {"customer_id", Thread(pluss::make_series({1.0, 2.0}))},
});

auto biz = Nexus({
    {"customers", customers},
    {"orders", orders},
});

Relationship rel;
rel.name = "orders_to_customers";
rel.left_table = "orders";
rel.right_table = "customers";
rel.keys = {{"customer_id", "customer_id"}};

auto linked = biz.add_relationship(rel);

std::cout << linked.audit("orders_to_customers").features("valid");

Output¶

0  true
Name: valid, ptype: Series

Notes¶

  • Purely a naming alternative — see relationship_audit() for the full documentation, including every returned column.

See Also¶

  • Nexus::relationship_audit: the canonical name this aliases.

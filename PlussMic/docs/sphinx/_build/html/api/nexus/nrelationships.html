Nexus::nrelationships¶

Back to Nexus API Reference

Signature¶

Nexus::nrelationships() const -> std::int64_t

What It Does¶

Returns how many relationships are declared in the workspace — relationships().size(), returned as std::int64_t to match this class’s other count-style methods (ntables(), size()) rather than std::vector’s own size_type.

Parameters¶

None

Returns¶

std::int64_t The number of declared relationships. 0 for a workspace with none.

Examples¶

Example 1. Counting relationships before and after declaring one.

using namespace pluss::table;

auto customers = DataFrame({
    {"customer_id", Thread(pluss::make_series({1.0, 2.0, 3.0}))},
    {"name",        Thread(pluss::make_note({"Ada", "Ben", "Cy"}))},
});
auto orders = DataFrame({
    {"order_id",    Thread(pluss::make_series({101.0, 102.0}))},
    {"customer_id", Thread(pluss::make_series({1.0, 2.0}))},
});

auto biz = Nexus({
    {"customers", customers},
    {"orders", orders},
});

Relationship rel;
rel.name = "orders_to_customers";
rel.left_table = "orders";
rel.right_table = "customers";
rel.keys = {{"customer_id", "customer_id"}};

auto linked = biz.add_relationship(rel);

std::cout << biz.nrelationships() << " " << linked.nrelationships();

Output¶

0 1

Notes¶

  • Equivalent to relationships().size(), returned as std::int64_t.

  • biz itself never changes — add_relationship() is non-mutating, so its relationship count stays 0 while the returned linked workspace’s count becomes 1.

See Also¶

  • Nexus::relationships: the declarations themselves.

  • Nexus::add_relationship: declare a new relationship.

  • Nexus::ntables: the analogous count for tables instead of relationships.

Nexus::fingerprint¶

Back to Nexus API Reference

Signature¶

Nexus::fingerprint() const -> std::string

What It Does¶

Computes a deterministic hash summarizing the whole workspace’s content — every table’s name, shape, feature names, dtypes, and declared TableMeta; every declared Relationship; and every saved view’s JoinPlan — as a 16-character lowercase hex string (a 64-bit FNV-1a hash). Two workspaces with identical content produce identical fingerprints; any difference anywhere in that content changes the result.

Note

A content fingerprint, not a cryptographic one This hashes structural and declared-metadata content (shapes, names, dtypes, TableMeta, relationships, saved views) — it is not a hash of the tables’ actual cell values, and it is not collision-resistant against adversarial input the way a cryptographic hash would be. Use it to detect accidental drift between two workspace snapshots, not as a security primitive.

Parameters¶

None

Returns¶

std::string A 16-character lowercase hex digest.

Examples¶

Example 1. The same workspace fingerprints identically every time; changing it changes the result.

using namespace pluss::table;
using namespace pluss::bundle;

auto customers = DataFrame({
    {"customer_id", Thread(pluss::make_series({1.0, 2.0, 3.0}))},
    {"name",        Thread(pluss::make_note({"Ada", "Ben", "Cy"}))},
});

auto biz = Nexus({{"customers", customers}});

auto fp1 = biz.fingerprint();
auto fp2 = biz.fingerprint();
std::cout << (fp1 == fp2) << " " << fp1.size() << "\n";

auto changed = biz.inject("extra", DataFrame({{"x", Thread(pluss::make_series({1.0}))}}));
std::cout << (fp1 == changed.fingerprint());

Output¶

1 16
0

Notes¶

  • Deterministic given the same content — does not depend on insertion order artifacts beyond what’s already captured in keys()’ own order, and sorts saved-view names internally before hashing them so view-declaration order doesn’t affect the result.

  • Not a hash of the underlying cell data — see the note above.

  • Embedded (truncated) into each row of schema()’s own fingerprint column.

See Also¶

  • Nexus::schema: includes a per-table fingerprint derived the same way.

  • Nexus::save: persists the workspace whose content this method summarizes.

Nexus::duplicates¶

What It Does¶

An exact alias for detect_duplicates() — both overloads call straight through with no behavioral difference. duplicates is the shorter, more conversational spelling.

Parameters¶

See detect_duplicates() — identical here.

Returns¶

Identical to detect_duplicates().

Examples¶

Example 1. duplicates() and detect_duplicates() return identical results.

using namespace pluss::table;
using namespace pluss::bundle;

auto customers = DataFrame({
    {"customer_id", Slate(pluss::make_series({1.0, 2.0, 3.0, 3.0}))},
    {"name",        Slate(pluss::make_note({"Ada", "Ben", "Cy", "Cy2"}))},
});

auto biz = Nexus({{"customers", customers}});

auto dups = biz.duplicates("customers", {"customer_id"});
std::cout << dups.ncases();

Output¶

2

Example 2. The named-container forms alias through identically too — see detect_duplicates()’s own Example 3 for why a std::vector<std::string_view> and a std::vector<std::string> reach different overloads (RangeView vs. the templated form) but produce the same result.

std::vector<std::string_view> as_view = {"customer_id"};
std::cout << biz.duplicates("customers", as_view).ncases();

Output¶

2

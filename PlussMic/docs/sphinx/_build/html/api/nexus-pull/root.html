NexusPull::root¶

Back to NexusPull API Reference

Signature¶

NexusPull::root() const noexcept -> const std::string&

What It Does¶

Reports the anchor table this builder was created against — the same root string passed to Nexus::pull(root) when the builder was constructed. Every field the builder pulls, however many hops away it lives, comes back at this table’s row grain.

Parameters¶

None.

Returns¶

const std::string& The root table’s name, unchanged for the builder’s whole lifetime — there is no way to re-anchor an existing NexusPull to a different root; start a new one via nx.pull(other_root) instead.

Examples¶

Example 1. Inspect the anchor before deciding what to pull.

using namespace pluss::table;
using namespace pluss::bundle;

// nx: the customers/regions/events workspace from Nexus::pull's own page.
auto builder = nx.pull("customers").take("customer_id");
std::cout << builder.root();

Output¶

customers

Notes¶

  • root() is unaffected by which fields have been requested so far — it reflects only how the builder was constructed, not its accumulated .specs().

  • Useful mainly in generic code that builds a NexusPull from elsewhere and needs to know, without re-threading the original table name, what row grain the eventual .collect() result will have.

See Also¶

  • NexusPull::specs: inspect the accumulated field requests themselves.

  • Nexus::pull: where root comes from, and what “row grain” means for a pull.

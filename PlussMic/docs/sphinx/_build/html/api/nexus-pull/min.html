NexusPull::min¶

Back to NexusPull API Reference

Signature¶

NexusPull::min(std::string_view source, std::string_view alias = {}) -> NexusPull&

What It Does¶

Adds a min aggregate directly on this NexusPull, with no scoping step — source must already be a fully qualified "table.feature" path (e.g. "events.spend", meaning table "events", feature "spend"). This is the key difference from NexusPullAgg::min: calling .min(...) through a scope opened by .agg("events") auto-prefixes a bare feature name with "events.", but calling .min(...) directly on NexusPull has no scope to inherit a table name from, so the table must be spelled out in source every time.

Internally, this builds a PullSpec via the free nexus::min(source, alias) factory (in namespace pluss::bundle::nexus) and appends it with add() — the same mechanism NexusPullAgg::min uses once it has prefixed source itself. Reach for this unscoped form for a single reducer on a related table; reach for .agg(table) when stacking several reducers on the same table.

Parameters¶

source (std::string_view) The feature to take the minimum of. Typically "table.feature" for a related table (e.g. "events.spend"); a bare root feature name is accepted syntactically but rarely useful, per Nexus::pull’s restriction against aggregate fields targeting root itself.

alias (std::string_view, default empty) The output column name. When omitted, the default alias is <table>_<feature>_min (dots replaced by underscores) — see NexusPull::sum for the auto-alias pattern in detail.

Returns¶

NexusPull& A reference to the same builder, so calls chain in place.

Examples¶

Example 1. A single unscoped min, with an explicit alias.

using namespace pluss::table;
using namespace pluss::bundle;

auto pulled = nx.pull("customers")
    .take("customer_id")
    .min("events.spend", "min_spend")
    .collect();

std::cout << pulled.to_string();

Output¶

     | customer_id  min_spend
-------------------------------
0    | 1            5
1    | 2            2
2    | 3            NULL
-------------------------------
[3 cs x 2 feat]

Customer 3 has no events rows — min over an empty group is NULL, not a sentinel like 0 or +inf.

Example 2. Omitting alias falls back to the default <table>_<feature>_min naming.

auto pulled = nx.pull("customers")
    .take("customer_id")
    .min("events.spend")
    .collect();

std::cout << pulled.features();

Output¶

customer_id events_spend_min

Notes¶

  • min on an empty group is NULL — the same rule as sum/mean/median/max/std/var, and unlike count/ndistinct, which produce 0.

  • min on a text/date feature compares by that feature’s own ordering, the same as DataFrame’s own grouped min.

  • source is used verbatim — there is no table-name prefixing here, unlike NexusPullAgg::min.

See Also¶

  • NexusPullAgg::min: the scoped equivalent, for when you want several reducers on the same related table without repeating its name.

  • NexusPull::max: the complementary reducer.

  • NexusPull::agg: opens the scoped sub-builder.

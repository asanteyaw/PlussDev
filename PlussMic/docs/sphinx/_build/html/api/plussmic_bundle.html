PlussMic bundle¶

The bundle model is the multi-table workspace surface.

  • Use Nexus for a named workbench of related DataFrame tables, declared relationships, join plans, and workspace audits.

  • Use NexusTraverse for the fluent join-graph builder returned by Nexus::from(...).

  • Use NexusQuery for SQL-style workspace SELECT queries returned by Nexus::query().

  • Use NexusPull for the fluent root-grain feature-table builder returned by Nexus::pull(root).

ThreadTimelineAccessor::period¶

Back to ThreadTimelineAccessor API Reference

Signature¶

ThreadTimelineAccessor::period(std::string_view freq) const -> Thread

What It Does¶

Truncates every row of the bound thread to the start of its enclosing freq period — same length, still Timeline/TimeIndex-kind.

Parameters¶

freq (std::string_view)

One of "y"/"yr"/"year"/"years"/"annual" (truncate to January 1st, 00:00:00 of the row’s year), "mo"/"mth"/"month"/"months" (truncate to the 1st of the row’s month, 00:00:00), "d"/"day"/"days" (floor to local midnight), "h"/"hr"/"hour"/"hours" (floor to the hour), "t"/"min"/"minute"/"minutes" (floor to the minute), or "s"/"sec"/"second"/"seconds" (floor to the second) — case-insensitive. Cannot be empty.

Returns¶

Thread A new Timeline/TimeIndex-kind thread, same length as the bound thread, truncated to the start of its freq period.

Examples¶

Example 1. Truncate every row to its month start.

using namespace pluss::table;

auto events = Thread(pluss::make_timeline({
    "2024-01-31T09:15:30Z",
    "2024-02-29T23:45:00Z",
    "2024-07-06T14:00:00Z",
}));
auto out = events.tl().period("months");
std::cout << out;

Output¶

0  2024-01-01
1  2024-02-01
2  2024-07-01

ptype: Timeline

Example 2. Truncate the same rows to their year start instead.

auto out2 = events.tl().period("years");
std::cout << out2;

Output¶

0  2024-01-01
1  2024-01-01
2  2024-01-01

ptype: Timeline

All three rows collapse to 2024-01-01, regardless of their original month or day — period("years") only cares which year a row falls in.

Example 3. Truncate to the day — identical to floor("D") under a different name.

auto single = Thread(pluss::make_timeline({"2024-06-01T14:05:00Z"}));
auto out3 = single.tl().period("days");
std::cout << out3;

Output¶

0  2024-06-01

ptype: Timeline

"hours", "minutes", and "seconds" delegate the same way, to floor("H")/floor("min")/floor("S") respectively.

Example 4. An unrecognized frequency string throws.

try {
  auto bad = single.tl().period("week");
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n')) << "\n";
}

Output¶

Timeline::to_period: unsupported frequency

Notes¶

  • Unlike shift(), period() doesn’t move by a count of periods — it always snaps down to the start of the row’s own current period; combine with shift() for “start of the next month.”

  • "day"/"hour"/"minute"/"second" truncation is equivalent to floor() with the corresponding unit; "year"/"month" go further than floor() supports (floor() has no calendar-unit option).

  • freq cannot be empty, and an unrecognized string throws.

  • .tl() requires the bound thread to already be Timeline/TimeIndex-kind — the accessor’s constructor throws otherwise.

  • A NaT row stays NaT (displays as "NULL").

See Also¶

  • ThreadTimelineAccessor::shift: move by a count of calendar or fixed periods instead of truncating to the current one.

  • ThreadTimelineAccessor::floor: the sub-day-unit equivalent this method delegates to for day/hour/minute/second.

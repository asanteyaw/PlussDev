ThreadTimelineAccessor::weekend¶

Back to ThreadTimelineAccessor API Reference

Signature¶

ThreadTimelineAccessor::weekend() const -> Thread

What It Does¶

Replaces the bound thread with a boolean Series flagging whether each row falls on Saturday or Sunday.

Parameters¶

None

Returns¶

Thread A new Bool-typed Series thread, same length as the bound thread: true on Saturday/Sunday, false otherwise.

Examples¶

Example 1. Flag weekend rows.

using namespace pluss::table;

auto events = Thread(pluss::make_timeline({
    "2024-01-31T09:15:30Z",
    "2024-07-06T14:00:00Z",
    "2023-03-01T00:00:00Z",
}));
auto out = events.tl().weekend();
std::cout << out;

Output¶

0  false
1  true
2  false

ptype: Series

Only "2024-07-06" (a Saturday) is a weekend row.

Notes¶

  • true covers Saturday and Sunday only — there’s no way to include Friday or exclude one of the two via this method; build a custom mask from weekday() if a different day set is needed.

  • .tl() requires the bound thread to already be Timeline/TimeIndex-kind — the accessor’s constructor throws otherwise.

  • A NaT row (or one already null on the underlying thread) displays as "NULL", not false.

See Also¶

  • ThreadTimelineAccessor::weekday: the underlying day-of-week number weekend() is derived from.

AxelFieldAxisAccessor::match¶

Back to AxelFieldAxisAccessor API Reference

Signature¶

Axel AxelFieldAxisAccessor::match(std::string_view pattern) const

What It Does¶

Returns a new axel where every registry frame is narrowed to only the fields whose name matches pattern as an ECMAScript regular expression (std::regex_search, so the pattern needs to match somewhere in the name, not the whole name — anchor with ^/$ if you need a full match). Applies RegistryFieldAxisAccessor::match to every frame via Axel::map.

Parameters¶

pattern (std::string_view) An ECMAScript-flavor regular expression to search each field name against.

Returns¶

Axel A new axel with every frame narrowed to fields whose name matches pattern.

Examples¶

Example 1. Select every field name ending in _id, in every frame.

auto r0 = pluss::bundle::Registry({
    {"id", pluss::bundle::Slot({pluss::make_series(1), pluss::make_series(2)})},
    {"user_id", pluss::bundle::Slot({pluss::make_series(3), pluss::make_series(4)})},
    {"city", pluss::bundle::Slot({pluss::make_note("Accra"), pluss::make_note("Tema")})},
});
auto axel = pluss::bundle::Axel({r0, r0});

auto out = axel.fieldaxis().match("^.*_id$");
for (const auto& key : out.registry(0).fields()) std::cout << key << " ";

Output¶

user_id

Example 2. An invalid regex pattern throws — the same message Registry::fieldaxis().match() would throw for that frame.

auto r0 = pluss::bundle::Registry({{"id", pluss::bundle::Slot({pluss::make_series(1)})}});
auto axel = pluss::bundle::Axel({r0});

try {
  axel.fieldaxis().match("(unterminated");
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n'));
}

Output¶

Registry::fieldaxis().match: invalid regex '(unterminated': The expression contained mismatched ( and ).

Notes¶

  • Uses std::regex_search, not std::regex_match — the pattern needs to appear somewhere in the name unless you anchor it with ^/$.

  • An invalid regex throws immediately on the first frame it’s applied to, wrapping the underlying std::regex_error message — the thrown message still reads "Registry::fieldaxis().match: ..." since it propagates unchanged from the per-frame call.

See Also¶

  • AxelFieldAxisAccessor::like: the simpler, plain-substring counterpart.

  • AxelFieldAxisAccessor::prefix / suffix(): anchored substring searches, without needing regex syntax.

  • RegistryFieldAxisAccessor::match: the single-frame operation this method broadcasts.

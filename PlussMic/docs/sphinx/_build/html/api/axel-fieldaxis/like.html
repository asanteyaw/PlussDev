AxelFieldAxisAccessor::like¶

Back to AxelFieldAxisAccessor API Reference

Signature¶

Axel AxelFieldAxisAccessor::like(std::string_view needle, bool case_sensitive = false) const

What It Does¶

Returns a new axel where every registry frame is narrowed to only the fields whose name contains needle as a substring — applies RegistryFieldAxisAccessor::like to every frame independently via Axel::map. Matching is case-insensitive by default.

Parameters¶

needle (std::string_view) The substring to search for within each field name.

case_sensitive (bool, optional, defaults to false) Whether the substring search is case-sensitive.

Returns¶

Axel A new axel with every frame narrowed to fields whose name contains needle.

Examples¶

Example 1. A case-insensitive search matches both id and user_id in every frame.

auto r0 = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2)})},
    {"user_id", pluss::scribble::Slot({pluss::make_series(3), pluss::make_series(4)})},
    {"city", pluss::scribble::Slot({pluss::make_note("Accra"), pluss::make_note("Tema")})},
});
auto axel = pluss::scribble::Axel({r0, r0});

auto out = axel.fieldaxis().like("ID");
for (const auto& key : out.registry(0).fields()) std::cout << key << " ";

Output¶

id user_id

Example 2. A case-sensitive search against the same axel matches nothing, since no field name literally contains "ID" in that case.

auto r0 = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2)})},
    {"user_id", pluss::scribble::Slot({pluss::make_series(3), pluss::make_series(4)})},
});
auto axel = pluss::scribble::Axel({r0});

auto out = axel.fieldaxis().like("ID", true);
std::cout << "nfields=" << out.registry(0).nfields();

Output¶

nfields=0

Notes¶

  • Matches against field names, not field values.

  • Applied independently per frame — a frame with no matching fields ends up with zero fields (still a valid, defined, empty registry), not a throw; different frames can end up with different resulting field sets if their schemas differ.

See Also¶

  • AxelFieldAxisAccessor::match: the regex-based counterpart, for more precise patterns than a plain substring.

  • AxelFieldAxisAccessor::prefix / suffix(): anchored variants of this same substring search.

  • RegistryFieldAxisAccessor::like: the single-frame operation this method broadcasts.

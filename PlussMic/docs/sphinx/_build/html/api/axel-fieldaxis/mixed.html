AxelFieldAxisAccessor::mixed¶

Back to AxelFieldAxisAccessor API Reference

Signature¶

Axel AxelFieldAxisAccessor::mixed() const

What It Does¶

Named shorthand for kind(SlotKind::Mixed) — returns a new axel where every registry frame is narrowed to only its heterogeneous (Mixed-kind) fields — fields whose values span more than one value kind.

Parameters¶

None

Returns¶

Axel A new axel with every frame narrowed to its Mixed-kind fields.

Examples¶

Example 1. Keep only the field mixing Series and Note values in every frame.

auto r0 = pluss::bundle::Registry({
    {"mixed", pluss::bundle::Slot({pluss::make_series(1), pluss::make_note("x")})},
    {"id", pluss::bundle::Slot({pluss::make_series(1)})},
});
auto axel = pluss::bundle::Axel({r0});

auto out = axel.fieldaxis().mixed();
for (const auto& key : out.registry(0).fields()) std::cout << key << " ";

Output¶

mixed

Notes¶

  • Equivalent to kind(SlotKind::Mixed) — see kind() for the general form and Slot::kind for exactly when a slot is classified Mixed.

  • Applied independently per frame — different frames can end up with different resulting field sets if their schemas differ.

See Also¶

  • AxelFieldAxisAccessor::kind: the general form this method is a fixed shorthand for.

  • AxelFieldAxisAccessor::nulls / empty: the shorthands for the remaining kind categories.

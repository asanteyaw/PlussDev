DataFrameLabelAccessor::has¶

Back to DataFrameLabelAccessor API Reference

DataFrameLabelAccessor::has(const char* value) const -> Thread
DataFrameLabelAccessor::has(const Thread& values) const -> Thread

What It Does¶

Two unrelated questions share this name:

  • has() (no arguments) answers a structural question: does this frame have structured (named, multi-level-capable) case labels at all — i.e., were they built via a route like set(feature_name) rather than left as the default integer index or a raw axis from set(const Thread&)?

  • has(value) / has(values) answer an elementwise membership question: for each row, does its case label equal value (single-value overloads), or match any of values (the Thread overload, an “is one of” test)?

Parameters¶

value (double / std::string_view / const char*)

A single value to test each case label against, elementwise.

values (const Thread&)

A collection of values; each row is true if its case label matches any of them.

Returns¶

bool (No-argument overload) Whether the frame’s case labels are structured.

Thread (Value-taking overloads) A boolean thread, one entry per row, displayed against the case labels, display_name "has".

Examples¶

Example 1. Check structure before and after promoting a feature to case labels.

using namespace pluss::table;

auto orders = DataFrame(
    {{"region", Thread(pluss::make_note({"east", "west", "east", "north"}))},
     {"sales",  Thread(pluss::make_series({100.0, 200.0, 150.0, 90.0}))}});

std::cout << orders.label().has();

auto labeled = orders.label().set("region");
std::cout << labeled.label().has();

Output¶

false
true

orders still has the default integer case index — no structure yet. labeled was built by promoting "region" via set(), which always creates a one-level case_axis_, so has() becomes true.

Example 2. Elementwise membership against a single value, and against several.

auto eq_east = labeled.label().has("east");
std::cout << eq_east;

auto in_set = labeled.label().has(Thread(pluss::make_note({"west", "north"})));
std::cout << in_set;

Output (has(“east”))¶

 east  true
 west  false
 east  true
north  false
Name: has, ptype: Series

Output (has([west, north]))¶

 east  false
 west  true
 east  false
north  true
Name: has, ptype: Series

Example 3. Elementwise membership on a numeric (Series) case-label axis, using the double overload.

using namespace pluss::table;

auto readings = DataFrame(
    {{"sales", Thread(pluss::make_series({100.0, 200.0, 150.0, 90.0}))}},
    Thread(pluss::make_series({10.0, 20.0, 10.0, 30.0})));
std::cout << readings;

auto eq_ten = readings.label().has(10.0);
std::cout << eq_ten;

Output (readings)¶

============
     | sales
------------
10   | 100  
20   | 200  
10   | 150  
30   | 90   
------------
[4 cs x 1 feat]

Output (has(10.0))¶

10  true
20  false
10  true
30  false
Name: has, ptype: Series

Same mechanics as has("east") in Example 2, just matched by numeric equality instead of string equality.

Notes¶

  • The no-argument overload is purely structural — it says nothing about whether any particular value is present.

  • has(values) is an elementwise “is one of” test across the whole values collection, not a single membership question about the frame as a whole.

See Also¶

  • DataFrameLabelAccessor::pos, DataFrameLabelAccessor::find: locate where a value occurs, rather than just whether it does.

DataFrameLabelAccessor::symdiff¶

Signature¶

DataFrameLabelAccessor::symdiff(const Thread& other) const -> Thread

What It Does¶

Treats the case labels and other as two sets of values, and returns the labels present in exactly one of the two (the symmetric difference) — deduplicated, in this accessor’s first-occurrence order followed by other’s.

Parameters¶

other (const Thread&)

The values to compare against.

Returns¶

Thread The distinct values found in exactly one of the two sides, display_name "symdiff".

Examples¶

Example 1. Symmetric difference between case labels with a repeat and another set.

using namespace pluss::table;

auto orders = DataFrame(
    {{"region", Thread(pluss::make_note({"east", "west", "east", "north"}))},
     {"sales",  Thread(pluss::make_series({100.0, 200.0, 150.0, 90.0}))}});
auto labeled = orders.label().set("region");

auto other = Thread(pluss::make_note({"west", "south"}));
auto out = labeled.label().symdiff(other);
std::cout << out;

Output¶

0  east
1  north
2  south
Name: symdiff, ptype: Note

"west" is shared by both sides, so it’s excluded; "east" and "north" are only on the left, "south" only on the right — all three make it into the result, left-side values first.

Notes¶

  • Unlike diff(), symdiff() is symmetric: swapping the operands produces the same set of values (order may differ).

  • Duplicates on either side are collapsed; the result never repeats a value.

See Also¶

  • DataFrameLabelAccessor::diff: the one-sided (“mine minus yours”) set difference.

  • DataFrameLabelAccessor::unite, DataFrameLabelAccessor::intersect: the other set-algebra operations over case-label values.

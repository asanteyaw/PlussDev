DataFrameLabelAccessor::pos¶

Back to DataFrameLabelAccessor API Reference

Signatures¶

DataFrameLabelAccessor::pos(double value) const -> Thread
DataFrameLabelAccessor::pos(std::string_view value) const -> Thread
DataFrameLabelAccessor::pos(const char* value) const -> Thread

What It Does¶

Returns every position where the case label equals value. Throws if value never occurs. Unlike find(), which returns only the first match for each of several targets, pos() returns all matches for a single target.

Parameters¶

value (double / std::string_view / const char*)

The value to locate every occurrence of.

Returns¶

Thread Int64 positions where the case label equals value, one entry per match, display_name "pos", plain default integer index.

Examples¶

Example 1. Locate every occurrence of a repeated case-label value.

using namespace pluss::table;

auto orders = DataFrame(
    {{"region", Thread(pluss::make_note({"east", "west", "east", "north"}))},
     {"sales",  Thread(pluss::make_series({100.0, 200.0, 150.0, 90.0}))}});
auto labeled = orders.label().set("region");

auto out = labeled.label().pos("east");
std::cout << out;

Output¶

0  0
1  2
Name: pos, ptype: Series

"east" occurs at rows 0 and 2 — both are returned, in ascending order. The plain 0/1 on the left are just pos()’s own default index (the “1st match”, “2nd match”), not the matched positions themselves — those are the values on the right.

Example 2. Locate a value on a numeric (Series) case-label axis, using the double overload.

using namespace pluss::table;

auto readings = DataFrame(
    {{"sales", Thread(pluss::make_series({100.0, 200.0, 150.0, 90.0}))}},
    Thread(pluss::make_series({10.0, 20.0, 10.0, 30.0})));
std::cout << readings;

auto out = readings.label().pos(10.0);
std::cout << out;

Output (readings)¶

============
     | sales
------------
10   | 100  
20   | 200  
10   | 150  
30   | 90   
------------
[4 cs x 1 feat]

Output (pos(10.0))¶

0  0
1  2
Name: pos, ptype: Series

10.0 occurs at rows 0 and 2, the same shape of result as the Note-kind case above, just matched by numeric equality instead of string equality.

Example 3. Look up a value that doesn’t occur, to see the call throw.

using namespace pluss::table;

auto orders = DataFrame(
    {{"region", Thread(pluss::make_note({"east", "west", "east", "north"}))},
     {"sales",  Thread(pluss::make_series({100.0, 200.0, 150.0, 90.0}))}});
auto labeled = orders.label().set("region");

try {
  auto out = labeled.label().pos("south");
} catch (const std::exception& e) {
  std::cout << "threw\n";
}

Output¶

threw

"south" never appears among the case labels, so the call throws instead of returning an empty Thread — check has("south") first if the value’s presence isn’t already guaranteed.

Notes¶

  • Throws if value doesn’t occur at all — check has(value) first if absence is possible.

  • Returns every match, unlike find()’s first-match-only lookup.

See Also¶

  • DataFrameLabelAccessor::find: first-match lookup for several target values at once, instead of every match for one value.

  • DataFrameLabelAccessor::has: a membership check that never throws, as a safe precondition.

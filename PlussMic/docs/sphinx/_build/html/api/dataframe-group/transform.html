DataFrameGrouped::transform¶

Back to DataFrameGroupBuilder API Reference

Signatures¶

DataFrameGrouped::transform(pluss::msharp::RangeView::Of<DataFrame::GroupSpec> specs) const -> DataFrame
DataFrameGrouped::transform(std::initializer_list<DataFrame::GroupSpec> specs) const -> DataFrame

What It Does¶

Computes grouped reductions, then broadcasts the result back to every row in the original group instead of collapsing to one row per group.

This is the grouped “decorate each row with a group statistic” surface. Common uses:

  • add region mean amount to every row in that region

  • add per-customer transaction count to each transaction

  • add within-group max/min/spread signals before later row-wise logic

Parameters¶

specs (RangeView<GroupSpec> / initializer_list<GroupSpec>)

One or more grouped reduction specs, using the same GroupSpec contract as agg().

Returns¶

DataFrame A frame with the same case count and case labels as the source, containing only the broadcasted grouped output features.

Examples¶

Example 1. Attach per-city mean amount to every original row.

using namespace pluss::table;

auto sales = DataFrame({
    {"city", Thread(pluss::make_note({"Accra", "Accra", "Tema", "Tema"}))},
    {"amount", Thread(pluss::make_series({100.0, 80.0, 50.0, 40.0}))},
});

auto city_mean = sales.group()
                      .by({"city"})
                      .transform({
                          {"amount_mean", "amount", DataFrame::GroupOp::Mean},
                      });
std::cout << city_mean;

Output¶

==================
     | amount_mean
------------------
0    | 90         
1    | 90         
2    | 45         
3    | 45         
------------------
[4 cs x 1 feat]

Rows 0 and 1 (both "Accra") receive the same broadcasted amount_mean ((100 + 80) / 2 = 90); rows 2 and 3 ("Tema") receive the other one ((50 + 40) / 2 = 45). The row order and row count exactly match sales — only the key column (city) and the original amount column are gone.

Example 2. Broadcast several grouped signals at once.

auto stats = sales.group()
                  .by({"city"})
                  .transform({
                      {"amount_mean", "amount", DataFrame::GroupOp::Mean},
                      {"amount_max", "amount", DataFrame::GroupOp::Max},
                      {"n", "", DataFrame::GroupOp::Count},
                  });
std::cout << stats;

Output¶

====================================
     | amount_mean  amount_max  n   
------------------------------------
0    | 90           100         2   
1    | 90           100         2   
2    | 45           50          2   
3    | 45           50          2   
------------------------------------
[4 cs x 3 feat]

That produces a row-aligned grouped feature block you can join back mentally with the source row space without doing an explicit merge. n counts rows per group (2 for each city here), broadcast just like the numeric aggregates.

Notes¶

  • transform(...) returns only the broadcasted grouped features, not the key columns and not the original source columns.

  • Case order is preserved exactly. This is what makes it suitable for downstream row-wise feature engineering.

  • Like agg(...), non-count operations require a source feature.

See Also¶

  • DataFrameGrouped::agg: one row per group instead of row-space broadcast.

  • DataFrame::join: if you want to combine the broadcasted result explicitly with another frame afterwards.

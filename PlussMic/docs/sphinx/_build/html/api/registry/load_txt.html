Registry::load_txt¶

Back to Registry API Reference

Signatures¶

static Registry Registry::load_txt(std::string_view filepath)
static Registry Registry::load_txt(std::string_view filepath, const pluss::loader::Config& config)

What It Does¶

A static factory method — loads a delimited text file (tab-separated by default, with the same auto-detecting parser load_csv() uses under the hood) into a new Registry, one field (slot) per column, with per-column dtype inference.

Parameters¶

filepath (std::string_view) The text file to read.

config (const pluss::loader::Config&, optional) A generic configuration bundle, translated into the underlying CSV-style reader options — see load_csv()’s important callout for the recognized "ncases" row-limit key.

Returns¶

Registry A new registry with one field per column.

Examples¶

Example 1. Load a tab-separated text file.

auto rg = pluss::bundle::Registry::load_txt("cities.txt");
std::cout << rg;

Output¶

{
  "_type": "Registry",
  "defined": true,
  "nfields": 3,
  "fields": {
    "id": {
      "size": 3,
      "types": {
        "Series": 3
      }
    },
    "city": {
      "size": 3,
      "types": {
        "Note": 3
      }
    },
    "population": {
      "size": 3,
      "types": {
        "Series": 3
      }
    }
  }
}

Notes¶

  • Shares its parsing engine with load_csv(), just with a text-file-style default separator rather than comma.

  • Column dtype is inferred per-column from its values.

  • load()("txt", filepath) (or "text") is equivalent to this method’s no-config overload.

See Also¶

  • Registry::load_csv: the comma-delimited counterpart, sharing the same underlying parser.

  • Catalog::load_txt: the equivalent loader on the kindle model.

  • Registry::save_txt: the write-side counterpart.

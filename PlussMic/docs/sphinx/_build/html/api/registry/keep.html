Registry::keep¶

Back to Registry API Reference

Signature¶

Registry Registry::keep(std::string_view key, const std::function<bool(const Slot::Value&)>& predicate) const

What It Does¶

Returns a new registry with one named field’s Slot filtered down to only the values for which predicate returns true — every other field is left untouched. Built on Slot::filter().

Parameters¶

key (std::string_view) The field to filter. Throws if it doesn’t exist.

predicate (const std::function<bool(const Slot::Value&)>&) A callback taking each of the field’s values in turn; values for which it returns false are dropped.

Returns¶

Registry A new registry with the named field’s Slot filtered; every other field unchanged.

Examples¶

Example 1. Keep only the odd values in id.

auto rg = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)})},
    {"city", pluss::scribble::Slot({pluss::make_note("Accra"), pluss::make_note("Tema"), pluss::make_note("Kumasi")})},
});

auto out = rg.keep("id", [](const pluss::scribble::Slot::Value& v) {
  return std::get<pluss::Series>(v).host<std::int64_t>()[0] % 2 == 1;
});

auto ids = out.fields("id");
std::cout << "[";
for (std::int64_t i = 0; i < ids.size(); ++i) {
  if (i) std::cout << ", ";
  std::cout << std::get<pluss::Series>(ids.at(i)).host<std::int64_t>()[0];
}
std::cout << "] nfields=" << out.nfields();

Output¶

[1, 3] nfields=2

Example 2. Filtering an unknown field throws.

auto rg = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1)})},
});

try {
  auto out = rg.keep("zzz", [](const pluss::scribble::Slot::Value&) { return true; });
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Registry::keep: unknown key 'zzz'

Notes¶

  • Scoped to exactly one field — the other fields’ sizes are unaffected, so filtering can make the result ragged relative to those other fields.

  • Throws "Registry::keep: unknown key '<name>'" for a missing field, and "Registry::keep: predicate is empty" for a null predicate.

  • Never mutates the receiver — use keep_() for the in-place form.

See Also¶

  • Registry::keep_: the in-place counterpart.

  • Registry::morph: transform a field’s values in place, rather than filtering them out.

  • Registry::isnull / Registry::dropnull: the null-specific filtering shorthands, applied across every field.

  • Catalog::filter: the closest equivalent on the kindle model, filtering rows rather than one field’s values.

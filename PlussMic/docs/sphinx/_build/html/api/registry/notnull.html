Registry::notnull¶

Back to Registry API Reference

Signature¶

Registry Registry::notnull() const

What It Does¶

The logical complement of isnull() — returns a new registry where every field’s values are replaced by a boolean flag for whether each value is not null, applying Slot::notnull() to every field via map(). Works uniformly across every field regardless of its own value kind.

Parameters¶

None

Returns¶

Registry A new registry with every field’s values replaced by boolean not-null flags, one per original value.

Examples¶

Example 1. A field with one null value among numeric values.

auto rg = pluss::bundle::Registry({
    {"id", pluss::bundle::Slot({pluss::make_series(1), pluss::bundle::Slot::Value{std::monostate{}}, pluss::make_series(3)})},
});

auto out = rg.notnull();
std::cout << out.fields("id").to_json();

Output¶

{
  "_type": "Slot",
  "defined": true,
  "size": 3,
  "values": [
    "Series[bool]",
    "Series[bool]",
    "Series[bool]"
  ]
}

Notes¶

  • notnull() is exactly isnull() with every flag inverted.

  • Never throws on a mismatched field kind — unlike fillnull().

  • Full per-value semantics documented on Slot::notnull.

  • Never mutates the receiver — always returns a new Registry.

See Also¶

  • Registry::isnull: the logical complement.

  • Registry::invalid: a related but distinct check.

  • Catalog::notnull: the equivalent operation on the kindle model.

Registry::tl¶

Back to Registry API Reference

Signature¶

RegistryTimelineAccessor Registry::tl() const

What It Does¶

The entry point into datetime (Timeline/TimeIndex) operations — tl() binds every field of the current registry and hands back a RegistryTimelineAccessor, documented in full on its own pages (see RegistryTimelineAccessor API Reference): calendar field extraction (year(), month(), weekday(), …), formatting (fmt(), iso()), rounding (floor(), ceil(), round()), timezone handling (tz(), localize(), utc()), and more.

Important

tl() always binds every field — scope it by projecting first Same pattern as cast() and nt(): tl() takes no key argument and always operates on every field. To scope datetime operations to one field, project first: rg.fields({"created_at"}).tl().year().

Parameters¶

None

Returns¶

RegistryTimelineAccessor A binder for the current registry’s fields — call one of its methods to run a datetime operation across every bound field.

Examples¶

Example 1. Extract the calendar year from a projected Timeline field.

auto rg = pluss::scribble::Registry({
    {"created_at", pluss::scribble::Slot({pluss::make_timeline("2024-03-15"), pluss::make_timeline("2023-07-04")})},
});

auto out = rg.fields({"created_at"}).tl().year();
auto years = out.fields("created_at");
std::cout << std::get<pluss::Series>(years.at(0)).to_vec<std::int64_t>()[0] << " ";
std::cout << std::get<pluss::Series>(years.at(1)).to_vec<std::int64_t>()[0];

Output¶

2024 2023

Notes¶

  • tl() alone does no work — it only binds the registry’s fields; call one of the accessor’s methods to actually operate on datetime values.

  • See the important callout above for scoping to specific fields.

  • The full accessor surface, including verified examples, is documented separately — see RegistryTimelineAccessor API Reference.

See Also¶

  • Registry::fields: project down to specific fields before running datetime operations, per the important callout above.

  • Registry::cast / Registry::nt: the sibling entry points for type casting and text operations.

  • Catalog::tl: the equivalent entry point on the kindle model.

Registry::get¶

Back to Registry API Reference

Signature¶

std::optional<Slot> Registry::get(std::string_view key) const

What It Does¶

Fetches a field’s Slot by name, returning std::nullopt instead of throwing when the name doesn’t exist. This is the safe way to test for a field’s presence and retrieve it in one call — use has() if you only need the presence check, or fields(key) if you’re confident the field exists and want the Slot directly (throwing otherwise).

Parameters¶

key (std::string_view) The field name to look up.

Returns¶

std::optional<Slot> The field’s Slot if key exists; std::nullopt otherwise. Requires a defined registry; throws on an undefined one.

Examples¶

Example 1. An existing key returns an engaged optional.

auto rg = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)})},
    {"city", pluss::scribble::Slot({pluss::make_note("Accra"), pluss::make_note("Tema"), pluss::make_note("Kumasi")})},
});

auto slot = rg.get("city");
std::cout << std::boolalpha << slot.has_value();

Output¶

true

Example 2. A missing key returns std::nullopt — no throw.

auto rg = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)})},
});

auto slot = rg.get("zzz");
std::cout << std::boolalpha << slot.has_value();

Output¶

false

Notes¶

  • Never throws on a missing key — unlike fields(key), which throws.

  • Key comparison is exact and case-sensitive, same as has().

  • Requires a defined registry — throws "Registry: undefined handle" on an undefined one.

See Also¶

  • Registry::has: a pure presence check, without fetching the Slot.

  • Registry::fields: fetch the Slot directly (single-key overload), throwing if the field is missing.

  • Catalog::get: the equivalent lookup on the kindle model.

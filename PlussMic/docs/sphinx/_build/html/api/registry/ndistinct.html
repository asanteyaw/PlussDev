Registry::ndistinct¶

Back to Registry API Reference

Signature¶

Registry Registry::ndistinct(pluss::kindle::DistinctOptions options = {}) const

What It Does¶

Returns a new registry where each field is collapsed to a single value: the count of that field’s distinct values, applying Slot::ndistinct(options) to every field independently via map().

Parameters¶

options (pluss::kindle::DistinctOptions, optional) {bool dropnull = true} — whether null values are dropped before counting distinct values. Defaults to dropping them.

Returns¶

Registry A new registry where each field’s Slot has exactly one value: the distinct count.

Examples¶

Example 1. A field with one repeated value among three has two distinct values.

auto rg = pluss::bundle::Registry({
    {"id", pluss::bundle::Slot({pluss::make_series(1), pluss::make_series(1), pluss::make_series(2)})},
});

auto out = rg.ndistinct();
auto ids = out.fields("id");
std::cout << "[";
for (std::int64_t i = 0; i < ids.size(); ++i) {
  if (i) std::cout << ", ";
  std::cout << std::get<pluss::Series>(ids.at(i)).to_vec<std::int64_t>()[0];
}
std::cout << "]";

Output¶

[2]

Notes¶

  • Unlike most Registry transforms, this always collapses every field to size() == 1 — a registry that was ragged before ndistinct() becomes aligned (nstate() == 1) afterward.

  • Full semantics documented on Slot::ndistinct.

  • Never mutates the receiver — always returns a new Registry.

See Also¶

  • Registry::distinct: the actual distinct values, rather than just their count.

  • Registry::freq: per-value frequency counts.

  • Catalog::ndistinct: the equivalent operation on the kindle model.

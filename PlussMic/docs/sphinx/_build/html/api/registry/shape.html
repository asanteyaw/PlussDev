Registry::shape¶

Back to Registry API Reference

Signature¶

std::pair<std::int64_t, std::int64_t> Registry::shape() const

What It Does¶

Returns a (state, fields) pair summarizing the registry’s overall size in one call — the first element is the longest field’s length (found by scanning every slot’s size()), the second is nfields(). Because it takes the maximum rather than requiring agreement, shape() never throws on a ragged registry (one whose fields don’t all share the same length) — unlike Registry’s stream-conversion methods, which require every field to individually be stream-compatible but say nothing about fields matching each other’s length.

Parameters¶

None

Returns¶

std::pair<std::int64_t, std::int64_t> (maxstate(), nfields()).

Examples¶

Example 1. A registry whose fields all share the same length.

auto rg = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)})},
    {"city", pluss::scribble::Slot({pluss::make_note("Accra"), pluss::make_note("Tema"), pluss::make_note("Kumasi")})},
});

auto [state, fields] = rg.shape();
std::cout << "(" << state << ", " << fields << ")";

Output¶

(3, 2)

Example 2. A ragged registry (fields of different lengths) reports the longest field’s length as the row count, rather than throwing.

auto ragged = pluss::scribble::Registry({
    {"a", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)})},
    {"b", pluss::scribble::Slot({pluss::make_series(10), pluss::make_series(20)})},
});

auto [state, fields] = ragged.shape();
std::cout << "(" << state << ", " << fields << ")";

Output¶

(3, 2)

Notes¶

  • The pair order is (state, fields).

  • Never throws on a ragged registry — see Example 2. Registry does not require fields to share a common length the way Catalog’s streams often do.

  • An explicitly empty registry reports (0, 0).

See Also¶

  • Registry::nfields / Registry::sizes: field count and per-field lengths.

  • Catalog::shape: the equivalent summary on the kindle model.

Registry::load_json¶

Back to Registry API Reference

Signatures¶

static Registry Registry::load_json(std::string_view filepath)
static Registry Registry::load_json(std::string_view filepath, const pluss::loader::Config& config)

What It Does¶

A static factory method — loads a JSON file (an array of flat objects) into a new Registry, one field (slot) per distinct key across the objects, with per-column dtype inference — the same underlying inference load_csv() uses, applied to the JSON values instead of parsed CSV text.

Parameters¶

filepath (std::string_view) The JSON file to read. Expected shape: a top-level array of flat (non-nested) objects.

config (const pluss::loader::Config&, optional) A generic configuration bundle, translated into the underlying reader options.

Returns¶

Registry A new registry with one field per distinct key found across the JSON objects.

Examples¶

Example 1. Load a JSON array of objects.

auto rg = pluss::bundle::Registry::load_json("cities.json");
std::cout << rg;

Output¶

{
  "_type": "Registry",
  "defined": true,
  "nfields": 3,
  "fields": {
    "id": {
      "size": 3,
      "types": {
        "Series": 3
      }
    },
    "city": {
      "size": 3,
      "types": {
        "Note": 3
      }
    },
    "population": {
      "size": 3,
      "types": {
        "Series": 3
      }
    }
  }
}

Notes¶

  • Expects a flat array-of-objects JSON shape.

  • Column dtype is inferred per-column from its values.

  • load()("json", filepath) is equivalent to this method’s no-config overload.

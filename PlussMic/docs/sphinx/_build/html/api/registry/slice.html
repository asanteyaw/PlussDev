Registry::slice¶

Back to Registry API Reference

Signature¶

Registry Registry::slice(std::int64_t start, std::int64_t stop) const

What It Does¶

Returns a new registry keeping the positional range [start, stop) of every field, applying Slot::slice(start, stop) independently to each field. Supports Python-style negative indices (counting from the end) and never throws for an out-of-range start/stop — both are clamped to each field’s own valid range.

Important

Each field’s range is normalized against its own length, independently Because negative indices and clamping are resolved per field against that field’s own size(), the same slice(start, stop) call can select a different-looking positional window on differently-sized fields in a ragged registry.

Parameters¶

start (std::int64_t) The inclusive start position. Negative values count from the end of each field.

stop (std::int64_t) The exclusive stop position. Negative values count from the end of each field.

Returns¶

Registry A new registry with each field’s Slot restricted to [start, stop).

Examples¶

Example 1. A plain forward slice.

auto rg = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3), pluss::make_series(4)})},
    {"city", pluss::scribble::Slot({pluss::make_note("Accra"), pluss::make_note("Tema"), pluss::make_note("Kumasi"), pluss::make_note("Ho")})},
});

auto out = rg.slice(1, 3);
auto ids = out.fields("id");
std::cout << "[";
for (std::int64_t i = 0; i < ids.size(); ++i) {
  if (i) std::cout << ", ";
  std::cout << std::get<pluss::Series>(ids.at(i)).to_vec<std::int64_t>()[0];
}
std::cout << "]";

Output¶

[2, 3]

Example 2. Negative indices count from the end, Python-style.

auto rg = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3), pluss::make_series(4)})},
});

auto out = rg.slice(-2, -1);
auto ids = out.fields("id");
std::cout << "[";
for (std::int64_t i = 0; i < ids.size(); ++i) {
  if (i) std::cout << ", ";
  std::cout << std::get<pluss::Series>(ids.at(i)).to_vec<std::int64_t>()[0];
}
std::cout << "]";

Output¶

[3]

Notes¶

  • Applies Slot::slice() independently per field — see the important callout above for the ragged-registry consequence.

  • start/stop are each clamped to [0, size] per field after resolving negative indices; an inverted or fully out-of-range request yields an empty result for that field rather than throwing.

  • head(), tail(), and cloc() are all expressible in terms of slice().

See Also¶

  • Registry::head / Registry::tail: fixed-endpoint specializations of this method.

  • Registry::cloc: a thin wrapper — cloc(row) is slice(row, row+1), cloc(start, stop) is slice(start, stop) directly.

  • Catalog::slice: the equivalent operation on the kindle model.

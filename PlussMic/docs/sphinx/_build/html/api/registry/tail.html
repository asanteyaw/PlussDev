Registry::tail¶

Back to Registry API Reference

Signature¶

Registry Registry::tail(std::int64_t n) const

What It Does¶

Returns a new registry keeping only the last n values of every field, applying Slot::tail(n) independently to each field — the mirror image of head().

Important

Each field is clipped to its own length, independently Same caveat as head(): Registry fields are not required to share a common length. tail(n) never throws for n larger than a field’s own size — that field’s Slot::tail() clamps internally, so a shorter field just returns everything it has, taken from its own end.

Parameters¶

n (std::int64_t) The number of trailing values to keep per field. Values less than 0 are clamped to 0.

Returns¶

Registry A new registry with each field’s Slot truncated to its own last n values (or fewer, if the field itself is shorter).

Examples¶

Example 1. Keep the last two rows of a uniform registry.

auto rg = pluss::bundle::Registry({
    {"id", pluss::bundle::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3), pluss::make_series(4)})},
    {"city", pluss::bundle::Slot({pluss::make_note("Accra"), pluss::make_note("Tema"), pluss::make_note("Kumasi"), pluss::make_note("Ho")})},
});

auto out = rg.tail(2);
auto ids = out.fields("id");
std::cout << "[";
for (std::int64_t i = 0; i < ids.size(); ++i) {
  if (i) std::cout << ", ";
  std::cout << std::get<pluss::Series>(ids.at(i)).to_vec<std::int64_t>()[0];
}
std::cout << "]";

Output¶

[3, 4]

Notes¶

  • Applies Slot::tail() independently per field — a ragged registry can end up with fields of different sizes, same as head().

  • n < 0 is clamped to 0, returning an all-fields-empty registry rather than throwing.

  • Requires a defined registry — throws "Registry: undefined handle" on an undefined one.

See Also¶

  • Registry::head: the mirror-image, first-n-values selection.

  • Registry::slice: an arbitrary [start, stop) window, of which tail(n) is a specialization (slice(size() - n, size()) per field).

  • Catalog::tail: the equivalent operation on the kindle model.

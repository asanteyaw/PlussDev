Registry::is_stream_compatible¶

Back to Registry API Reference

Signature¶

bool Registry::is_stream_compatible() const

What It Does¶

Reports whether every field (slot) in the registry holds a single, uniform value kind — the non-throwing boolean form of ensure_stream_compatible(). A true result means to_kindle() and every save_* method except save_json() will succeed on this registry; a false result means they’ll throw.

Parameters¶

None

Returns¶

bool true if every field is stream-compatible; false if any single field holds genuinely mixed value kinds.

Examples¶

Example 1. A registry where every field holds one uniform kind.

auto rg = pluss::bundle::Registry({
    {"id", pluss::bundle::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)})},
    {"city", pluss::bundle::Slot({pluss::make_note("Accra"), pluss::make_note("Tema"), pluss::make_note("Kumasi")})},
});

std::cout << std::boolalpha << rg.is_stream_compatible();

Output¶

true

Example 2. A field with genuinely mixed value kinds makes the whole registry report false.

auto mixed = pluss::bundle::Registry({
    {"id", pluss::bundle::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)})},
    {"mixed", pluss::bundle::Slot({pluss::make_series(10), pluss::make_note("hello"), pluss::make_series(3.5)})},
});

std::cout << std::boolalpha << mixed.is_stream_compatible();

Output¶

false

Notes¶

  • true here is a precondition for to_kindle(), save_csv(), save_txt(), save_excel(), and save_parquet() to succeed without throwing.

  • save_json() is the one method that tolerates false — it falls back to to_json()’s per-value output instead of throwing.

  • Requires a defined registry — throws "Registry: undefined handle" on an undefined one.

See Also¶

  • Registry::ensure_stream_compatible: the throwing form of this same check, with a customizable error-message prefix.

  • Registry::to_kindle: the conversion this check guards.

  • Registry::save_json: the one saver that branches on this check instead of throwing when it’s false.

  • Slot::is_stream_compatible: the per-slot check this method combines across every field.

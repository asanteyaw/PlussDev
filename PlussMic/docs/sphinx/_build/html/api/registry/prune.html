Registry::prune¶

Back to Registry API Reference

Signature¶

Registry Registry::prune() const

What It Does¶

Returns a new registry with every field whose Slot has zero values removed — Slot::size() == 0, not “all values are null.” A field with three null values is not empty by this definition; a field built from an explicitly empty value list is.

Important

Emptiness here means zero values, not all-null values This is a different question from isnull()/dropnull(), which look at whether individual values are null. prune() looks only at each field’s size() — a field holding three null values still has size() == 3 and survives prune() untouched; only a field with size() == 0 is removed.

Parameters¶

None

Returns¶

Registry A new registry with every zero-length field removed; every other field is preserved in its original order.

Examples¶

Example 1. A field built from an explicitly empty value list is dropped; every other field survives.

auto rg = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2)})},
    {"empty_field", pluss::scribble::Slot(std::vector<pluss::scribble::Slot::Value>{})},
});

auto out = rg.prune();
for (const auto& key : out.fields()) std::cout << key << " ";

Output¶

id

Notes¶

  • Checks Slot::size() == 0, not value-nullness — see the important callout above.

  • Preserves the original order of every surviving field.

  • Never mutates the receiver — use prune_() for the in-place form.

  • Requires a defined registry — throws "Registry: undefined handle" on an undefined one.

See Also¶

  • Registry::prune_: the in-place counterpart.

  • Registry::dropnull: the value-level counterpart — drops null values within fields, rather than zero-length fields entirely.

  • Registry::drop: removes fields by explicit name, rather than by emptiness.

  • Registry::sizes: the per-field value counts this method filters on.

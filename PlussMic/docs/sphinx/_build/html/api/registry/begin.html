Registry::begin¶

Back to Registry API Reference

Signature¶

Registry::const_iterator Registry::begin() const

What It Does¶

Returns an iterator over the registry’s field names — begin()/end() are what make Registry usable in a range-for loop and with standard algorithms. const_iterator is std::vector<std::string>::const_iterator.

Important

Iterates field names, not values or Slots A range-for over a Registry yields const std::string& field names, one per field — the same sequence fields()’s no-arg overload returns. It does not yield Slots, and it does not iterate row values within any field.

Parameters¶

None

Returns¶

Registry::const_iterator An iterator to the first field name; equal to end() for an empty registry.

Examples¶

Example 1. Iterate a registry’s field names with a range-for loop.

auto rg = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2)})},
    {"city", pluss::scribble::Slot({pluss::make_note("Accra"), pluss::make_note("Tema")})},
});

for (const auto& name : rg) std::cout << name << " ";

Output¶

id city

Notes¶

  • See the important callout above — this iterates field names, matching fields()’s no-arg overload, not field values.

  • Requires a defined registry — throws "Registry: undefined handle" on an undefined one (via the underlying keys() accessor).

See Also¶

  • Registry::end: the matching end iterator.

  • Registry::fields: the no-arg overload returns the same field names as a std::vector<std::string>, without needing manual iteration.

  • Catalog::begin: the equivalent iterator on the kindle model.

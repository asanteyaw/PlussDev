Registry::push¶

Back to Registry API Reference

Signatures¶

Registry Registry::push(std::string_view key, const Slot::Value& value) const
Registry Registry::push(const Slot::Value& value) const

What It Does¶

Appends one value to the end of a field’s Slot. The single-key overload appends to just that one named field; the value-only overload appends the same value to every field.

Parameters¶

key (std::string_view) The field to append to (single-key overload). Throws if it doesn’t exist.

value (const Slot::Value&) The value to append.

Returns¶

Registry A new registry with the value appended — either to the named field only, or to every field.

Examples¶

Example 1. Append to a single named field.

auto rg = pluss::bundle::Registry({
    {"id", pluss::bundle::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)})},
    {"city", pluss::bundle::Slot({pluss::make_note("Accra"), pluss::make_note("Tema"), pluss::make_note("Kumasi")})},
});

auto out = rg.push("id", pluss::make_series(4));
auto ids = out.fields("id");
std::cout << "[";
for (std::int64_t i = 0; i < ids.size(); ++i) {
  if (i) std::cout << ", ";
  std::cout << std::get<pluss::Series>(ids.at(i)).to_vec<std::int64_t>()[0];
}
std::cout << "]";

Output¶

[1, 2, 3, 4]

Example 2. Appending to an unknown field name throws.

auto rg = pluss::bundle::Registry({
    {"id", pluss::bundle::Slot({pluss::make_series(1)})},
});

try {
  auto out = rg.push("zzz", pluss::make_series(4));
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Registry::push: unknown key 'zzz'

Example 3. The value-only overload appends the same value to every field.

auto rg = pluss::bundle::Registry({
    {"a", pluss::bundle::Slot({pluss::make_series(1), pluss::make_series(2)})},
    {"b", pluss::bundle::Slot({pluss::make_series(10), pluss::make_series(20)})},
});

auto out = rg.push(pluss::make_series(99));
auto a = out.fields("a");
auto b = out.fields("b");
std::cout << std::get<pluss::Series>(a.at(2)).to_vec<std::int64_t>()[0] << " ";
std::cout << std::get<pluss::Series>(b.at(2)).to_vec<std::int64_t>()[0];

Output¶

99 99

Notes¶

  • The single-key overload throws "Registry::push: unknown key '<name>'" for a missing field — contrast with set(), which upserts instead.

  • The value-only overload is built on map(), so it inherits the same “runs on every field, regardless of kind” behavior — appending a value of an incompatible kind to any field can throw.

  • Never mutates the receiver — use push_() for the in-place form.

See Also¶

  • Registry::push_: the in-place counterpart.

  • Registry::concat: append a whole Slot’s worth of values at once, rather than a single value.

  • Registry::set: replace a field’s entire Slot, rather than appending to it.

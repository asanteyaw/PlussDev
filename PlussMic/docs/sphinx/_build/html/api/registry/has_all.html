Registry::has_all¶

Back to Registry API Reference

Signatures¶

bool Registry::has_all(std::span<const std::string_view> keys) const
bool Registry::has_all(std::initializer_list<std::string_view> keys) const
template <pluss::detail::StringViewNameRange NameRange>
bool Registry::has_all(const NameRange& keys) const

What It Does¶

Checks whether every name in keys exists as a field — the AND-combined form of has() over multiple names at once.

Parameters¶

keys (std::span<const std::string_view> / std::initializer_list<std::string_view> / any string-view name range) The field names to check.

Returns¶

bool true if every name in keys is a field; false if any single one is missing (including when keys is empty, which vacuously returns true).

Examples¶

Example 1. All requested names exist.

auto rg = pluss::bundle::Registry({
    {"id", pluss::bundle::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)})},
    {"city", pluss::bundle::Slot({pluss::make_note("Accra"), pluss::make_note("Tema"), pluss::make_note("Kumasi")})},
});

std::vector<std::string_view> keys{"id", "city"};
std::cout << std::boolalpha << rg.has_all(keys);

Output¶

true

Example 2. One missing name is enough to fail the check.

auto rg = pluss::bundle::Registry({
    {"id", pluss::bundle::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)})},
    {"city", pluss::bundle::Slot({pluss::make_note("Accra"), pluss::make_note("Tema"), pluss::make_note("Kumasi")})},
});

std::vector<std::string_view> keys{"id", "zzz"};
std::cout << std::boolalpha << rg.has_all(keys);

Output¶

false

Notes¶

  • An empty keys collection returns true (vacuous truth) — same convention as has_all checks elsewhere in the library.

  • Key comparison is exact and case-sensitive, same as has().

  • Requires a defined registry — throws "Registry: undefined handle" on an undefined one.

See Also¶

  • Registry::has: the single-key form this method combines with AND.

  • Registry::has_any: the OR-combined counterpart.

  • Registry::fields: fetch multiple fields directly (multi-key overload), throwing if any is missing.

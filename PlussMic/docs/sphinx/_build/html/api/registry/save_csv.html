Registry::save_csv¶

Back to Registry API Reference

Signatures¶

void Registry::save_csv(std::string_view filepath) const
void Registry::save_csv(std::string_view filepath, const pluss::loader::Config& config) const

What It Does¶

Writes the registry to a CSV file. Internally, save_csv() (and every save_* method except save_json()) first converts the registry to a Catalog via kindelize(), then aligns it into a DataFrame via tabelize(), then writes that DataFrame to CSV.

Important

Every field must be stream-compatible Because the conversion goes through kindelize(), every field (slot) must hold values of a single, uniform kind — the same requirement kindelize() itself enforces. A registry with a genuinely mixed-type field (e.g. one row Series, the next Note) throws before anything is written. save_json() is the one exception — it falls back to to_json()’s per-value output for mixed fields instead of throwing.

Parameters¶

filepath (std::string_view) The destination file path.

config (const pluss::loader::Config&, optional) A generic configuration scribble, translated into the underlying CSV writer options.

Returns¶

void Writes the file as a side effect; produces no return value.

Examples¶

Example 1. Save a registry to CSV and read the file back to confirm its contents.

auto rg = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)})},
    {"city", pluss::scribble::Slot({pluss::make_note("Accra"), pluss::make_note("Tema"), pluss::make_note("Kumasi")})},
});

rg.save_csv("cities.csv");

std::ifstream saved("cities.csv");
std::cout << saved.rdbuf();

Output¶

id,city
1,Accra
2,Tema
3,Kumasi

Example 2. A field with genuinely mixed value kinds throws — the underlying kindelize() conversion cannot represent it as a uniform Stream.

auto mixed = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)})},
    {"mixed", pluss::scribble::Slot({pluss::make_series(10), pluss::make_note("hello"), pluss::make_series(3.5)})},
});

try {
  mixed.save_csv("bad.csv");
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Registry::kindelize: slot 'mixed': slot is not stream-compatible (kind=Mixed)

Important

The throw message says “kindelize”, not “save_csv” Every save_* method except save_json() routes through kindelize() internally, so the stream-compatibility check reports the error under the name "Registry::kindelize" regardless of which save_* method was actually called.

Notes¶

  • Requires every field to be stream-compatible — see the important callout above.

  • Column order in the file follows the registry’s own field order.

  • save_as()("csv", filepath) is equivalent to this method’s no-config overload.

Registry::clear_¶

Back to Registry API Reference

Signature¶

Registry& Registry::clear_()

What It Does¶

The in-place counterpart to clear() — removes every field from this registry directly. The registry remains defined afterward, just empty.

Parameters¶

None

Returns¶

Registry& A reference to this registry, now holding zero fields.

Examples¶

Example 1. Clear a registry in place.

auto rg = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1)})},
});

rg.clear_();
std::cout << std::boolalpha << rg.defined() << " nfields=" << rg.nfields();

Output¶

true nfields=0

Notes¶

  • Same defined-but-empty result as clear() — see that page’s important callout.

  • Requires a defined registry — throws "Registry: undefined handle" on an undefined one.

  • Mutates the registry it’s called on and returns *this by reference.

See Also¶

  • Registry::clear: the non-mutating counterpart.

  • Registry::prune_: removes only zero-length fields, rather than every field unconditionally.

Registry::push_¶

Back to Registry API Reference

Signatures¶

Registry& Registry::push_(std::string_view key, const Slot::Value& value)
Registry& Registry::push_(const Slot::Value& value)

What It Does¶

The in-place counterpart to push() — appends one value to a field’s Slot directly. The single-key overload appends to just that field; the value-only overload appends to every field.

Parameters¶

key (std::string_view) The field to append to (single-key overload). Throws if it doesn’t exist.

value (const Slot::Value&) The value to append.

Returns¶

Registry& A reference to this registry, now holding the appended value(s).

Examples¶

Example 1. Append to a single named field in place.

auto rg = pluss::bundle::Registry({
    {"id", pluss::bundle::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)})},
});

rg.push_("id", pluss::make_series(4));
auto ids = rg.fields("id");
std::cout << "[";
for (std::int64_t i = 0; i < ids.size(); ++i) {
  if (i) std::cout << ", ";
  std::cout << std::get<pluss::Series>(ids.at(i)).to_vec<std::int64_t>()[0];
}
std::cout << "]";

Output¶

[1, 2, 3, 4]

Notes¶

  • Same throw and every-field behavior as push() — see that page’s notes.

  • Mutates the registry it’s called on and returns *this by reference.

See Also¶

  • Registry::push: the non-mutating counterpart.

  • Registry::concat_: append a whole Slot’s worth of values in place, rather than a single value.

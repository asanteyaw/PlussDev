Registry::save_excel¶

Back to Registry API Reference

Signatures¶

void Registry::save_excel(std::string_view filepath) const
void Registry::save_excel(std::string_view filepath, const pluss::loader::Config& config) const

What It Does¶

Writes the registry to an .xlsx workbook, following the same kindelize() → tabelize() → format-specific writer path as save_csv().

Important

Excel support is an optional build feature (requires libzip) save_excel() (and load_excel()) require the library to have been built with libzip available. In a build without it, save_excel() throws "save_excel: Excel support not built (libzip not available)" — this is a build-configuration issue, not something fixable by changing your call.

Parameters¶

filepath (std::string_view) The destination .xlsx file path.

config (const pluss::loader::Config&, optional) A generic configuration bundle, translated into the underlying Excel writer options.

Returns¶

void Writes the file as a side effect; produces no return value.

Examples¶

Example 1. Attempting to save to .xlsx in a build without Excel support throws — this is the exact message this documentation environment produces, since it was built without libzip.

auto rg = pluss::bundle::Registry({
    {"id", pluss::bundle::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)})},
    {"city", pluss::bundle::Slot({pluss::make_note("Accra"), pluss::make_note("Tema"), pluss::make_note("Kumasi")})},
});

try {
  rg.save_excel("cities.xlsx");
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

save_excel: Excel support not built (libzip not available)

Notes¶

  • Requires libzip at build time and every field to be stream-compatible — see the important callout above. Only the throw example above could actually be verified in this documentation environment; the intended call shape otherwise matches save_csv().

  • save_as()("excel", filepath) (or "xlsx") is equivalent to this method’s no-config overload.

See Also¶

  • Registry::load_excel: the read-side counterpart, with the same libzip requirement.

  • Registry::save_csv: the equivalent saver with no optional build dependency.

  • Catalog::save_excel: the equivalent saver on the kindle model.

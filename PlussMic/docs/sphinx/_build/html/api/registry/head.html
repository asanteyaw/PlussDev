Registry::head¶

Back to Registry API Reference

Signature¶

Registry Registry::head(std::int64_t n) const

What It Does¶

Returns a new registry keeping only the first n values of every field, applying Slot::head(n) independently to each field.

Important

Each field is clipped to its own length, independently Registry fields are not required to share a common length (see shape()’s ragged-registry example). head(n) never throws for n larger than a field’s own size — that field’s Slot::head() simply clamps to its own length internally, so a shorter field just returns everything it has. On a ragged registry, head(n) can leave fields with different sizes than each other.

Parameters¶

n (std::int64_t) The number of leading values to keep per field. Values less than 0 are clamped to 0.

Returns¶

Registry A new registry with each field’s Slot truncated to its own first n values (or fewer, if the field itself is shorter).

Examples¶

Example 1. Keep the first two rows of a uniform registry.

auto rg = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3), pluss::make_series(4)})},
    {"city", pluss::scribble::Slot({pluss::make_note("Accra"), pluss::make_note("Tema"), pluss::make_note("Kumasi"), pluss::make_note("Ho")})},
});

auto out = rg.head(2);
auto ids = out.fields("id");
std::cout << "[";
for (std::int64_t i = 0; i < ids.size(); ++i) {
  if (i) std::cout << ", ";
  std::cout << std::get<pluss::Series>(ids.at(i)).to_vec<std::int64_t>()[0];
}
std::cout << "]";

Output¶

[1, 2]

Example 2. On a ragged registry, n exceeding a field’s own length leaves that field shorter than the others, rather than throwing.

auto ragged = pluss::scribble::Registry({
    {"a", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)})},
    {"b", pluss::scribble::Slot({pluss::make_series(10), pluss::make_series(20)})},
});

auto out = ragged.head(5);
auto sizes = out.sizes();
std::cout << "a: " << sizes["a"] << ", b: " << sizes["b"];

Output¶

a: 3, b: 2

Notes¶

  • Applies Slot::head() independently per field — see the important callout above for the ragged-registry consequence.

  • n < 0 is clamped to 0, returning an all-fields-empty registry rather than throwing.

  • Requires a defined registry — throws "Registry: undefined handle" on an undefined one.

See Also¶

  • Registry::tail: the mirror-image, last-n-values selection.

  • Registry::slice: an arbitrary [start, stop) window, of which head(n) is a specialization (slice(0, n)).

  • Catalog::head: the equivalent operation on the kindle model, where streams are typically expected to share a common length.

Registry::map_¶

Back to Registry API Reference

Signature¶

Registry& Registry::map_(const std::function<Slot(const Slot&)>& fn)

What It Does¶

The in-place counterpart to map() — runs fn over every field’s Slot and rewrites this registry directly.

Important

Whole-registry transform fn runs on every field regardless of value kind, so a callback written only for one kind can throw on a field of a different kind. To scope a Slot -> Slot transform to one field, fetch it via fields(key), call fn on it, and reinsert with set_(): rg.set_("population", fn(rg.fields("population"))).

Parameters¶

fn (const std::function<Slot(const Slot&)>&) A callback taking each field’s Slot in turn and returning its replacement. Must return a defined Slot for every field.

Returns¶

Registry& A reference to this registry, now holding every field transformed by fn.

Examples¶

Example 1. Add 5 to every value in a registry, in place.

auto rg = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2)})},
});

rg.map_([](const pluss::scribble::Slot& s) {
  return s.transform([](const pluss::scribble::Slot::Value& v) -> pluss::scribble::Slot::Value {
    return pluss::make_series(std::get<pluss::Series>(v).to_vec<std::int64_t>()[0] + 5);
  });
});

auto ids = rg.fields("id");
std::cout << "[";
for (std::int64_t i = 0; i < ids.size(); ++i) {
  if (i) std::cout << ", ";
  std::cout << std::get<pluss::Series>(ids.at(i)).to_vec<std::int64_t>()[0];
}
std::cout << "]";

Notes¶

  • Performs a full-registry reassignment under the hood, not a field-by-field mutation of the existing slots.

  • Mutates the registry it’s called on and returns *this by reference.

See Also¶

  • Registry::map: the non-mutating counterpart this method wraps.

  • Registry::fields / Registry::set_: fetch-transform-reinsert for scoping a Slot -> Slot transform to one named field in place.

  • Registry::morph_: a value-level (not whole-Slot) in-place transform, scoped to one field.

  • Catalog::map: the closest equivalent on the kindle model.

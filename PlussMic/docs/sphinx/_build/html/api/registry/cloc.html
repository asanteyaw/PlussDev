Registry::cloc¶

Back to Registry API Reference

Signatures¶

Registry Registry::cloc(std::int64_t row) const
Registry Registry::cloc(std::int64_t start, std::int64_t stop) const

What It Does¶

A thin, positional-selection wrapper over slice():

  • cloc(row) — selects a single row across every field, equivalent to slice(row, row + 1).

  • cloc(start, stop) — selects a range across every field, equivalent to slice(start, stop) directly.

Both overloads inherit slice()’s per-field, independent-length behavior — see slice()’s important callout for how this plays out on a ragged registry.

Parameters¶

row (std::int64_t) The single positional row to select (single-row overload). Negative values count from the end of each field.

start / stop (std::int64_t) The [start, stop) positional range to select (range overload). Negative values count from the end of each field.

Returns¶

Registry A new registry with each field’s Slot restricted to the selected row or range.

Examples¶

Example 1. Select a single row by position.

auto rg = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3), pluss::make_series(4)})},
});

auto out = rg.cloc(1);
auto ids = out.fields("id");
std::cout << "[";
for (std::int64_t i = 0; i < ids.size(); ++i) {
  if (i) std::cout << ", ";
  std::cout << std::get<pluss::Series>(ids.at(i)).to_vec<std::int64_t>()[0];
}
std::cout << "]";

Output¶

[2]

Example 2. Select a range by position — identical to slice(start, stop).

auto rg = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3), pluss::make_series(4)})},
});

auto out = rg.cloc(0, 2);
auto ids = out.fields("id");
std::cout << "[";
for (std::int64_t i = 0; i < ids.size(); ++i) {
  if (i) std::cout << ", ";
  std::cout << std::get<pluss::Series>(ids.at(i)).to_vec<std::int64_t>()[0];
}
std::cout << "]";

Output¶

Notes¶

  • cloc(row) is literally implemented as slice(row, row + 1) — there is no behavioral difference beyond call-site convenience for the single-row case.

  • Both overloads share slice()’s per-field independent clamping and negative-index support.

See Also¶

  • Registry::slice: the method both cloc() overloads delegate to.

  • Registry::head / Registry::tail: other slice()-based positional selections.

  • Registry::take: arbitrary (not-necessarily-contiguous) positional selection, for when a single row or contiguous range isn’t enough.

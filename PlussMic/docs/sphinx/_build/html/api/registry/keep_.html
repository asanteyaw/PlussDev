Registry::keep_¶

Back to Registry API Reference

Signature¶

Registry& Registry::keep_(std::string_view key, const std::function<bool(const Slot::Value&)>& predicate)

What It Does¶

The in-place counterpart to keep() — filters one named field’s Slot down to only the values for which predicate returns true, directly on this registry.

Parameters¶

key (std::string_view) The field to filter. Throws if it doesn’t exist.

predicate (const std::function<bool(const Slot::Value&)>&) A callback taking each of the field’s values in turn; values for which it returns false are dropped.

Returns¶

Registry& A reference to this registry, now holding the filtered field.

Examples¶

Example 1. Keep only the odd values in id, in place.

auto rg = pluss::bundle::Registry({
    {"id", pluss::bundle::Slot({pluss::make_series(1), pluss::make_series(2), pluss::make_series(3)})},
});

rg.keep_("id", [](const pluss::bundle::Slot::Value& v) {
  return std::get<pluss::Series>(v).to_vec<std::int64_t>()[0] % 2 == 1;
});

auto ids = rg.fields("id");
std::cout << "[";
for (std::int64_t i = 0; i < ids.size(); ++i) {
  if (i) std::cout << ", ";
  std::cout << std::get<pluss::Series>(ids.at(i)).to_vec<std::int64_t>()[0];
}
std::cout << "]";

Output¶

[1, 3]

Notes¶

  • Same throw conditions as keep().

  • Mutates the registry it’s called on and returns *this by reference.

See Also¶

  • Registry::keep: the non-mutating counterpart.

  • Registry::morph_: transform a field’s values in place, rather than filtering them out.

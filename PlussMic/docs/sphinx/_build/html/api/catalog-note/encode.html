CatalogNoteAccessor::encode¶

Back to CatalogNoteAccessor API Reference

Signature¶

Catalog CatalogNoteAccessor::encode(std::string_view encoding = "base64") const

What It Does¶

Encodes every bound key’s text bytes using the named encoding, returning a new catalog with those keys’ Note values replaced by their encoded text form.

Important

CatalogNoteAccessor requires every bound key to be Note-kind Same precondition as every method on this accessor — see CatalogNoteAccessor::strip’s own important callout for the full explanation and the exact throw message.

Parameters¶

encoding (std::string_view, defaults to "base64") The name of the encoding scheme to apply. "base64" and "hex" are the two schemes exercised in the examples below.

Returns¶

Catalog A new catalog with every bound key’s text replaced by its encoded form.

Examples¶

Example 1. Default call: base64-encode a text key.

using namespace pluss::kindle::literals;

auto ct = pluss::kindle::Catalog({
    "secret"_k = pluss::kindle::Stream(pluss::make_note({"hi"})),
});
auto out = ct.nt().encode();
std::cout << out;

Output¶

========================================================================================================================
kindle::Catalog  keys=1
keys: [secret]
------------------------------------------------------------------------------------------------------------------------
key                      | kind         | dtype            | cs      | preview                                          
------------------------------------------------------------------------------------------------------------------------
secret                   | Note         | Note             | 1       | [aGk=]                                           
========================================================================================================================

Notes¶

  • See the important callout above.

  • The default encoding is "base64" — pass "hex" (or any other supported scheme) explicitly to change it.

See Also¶

  • Catalog::nt: the entry point this accessor is reached from.

  • RegistryNoteAccessor::encode: the scribble-model equivalent, which also verifies the "hex" scheme’s exact output.

CatalogNoteAccessor::starts¶

Back to CatalogNoteAccessor API Reference

Signature¶

Catalog CatalogNoteAccessor::starts(std::string_view prefix) const

What It Does¶

Tests whether every bound key’s text starts with prefix (a literal string, not a pattern), replacing each Note-kind key with a Bool Series-kind key of results.

Important

CatalogNoteAccessor requires every bound key to be Note-kind Same precondition as every method on this accessor — see CatalogNoteAccessor::strip’s own important callout for the full explanation and the exact throw message.

Parameters¶

prefix (std::string_view) The literal text to test for at the start of each value — always literal, never a regex pattern.

Returns¶

Catalog A new catalog with every bound key replaced by a Bool Series of per-value prefix-match results.

Examples¶

Example 1.

using namespace pluss::kindle::literals;

auto ct = pluss::kindle::Catalog({
    "city"_k = pluss::kindle::Stream(pluss::make_note({"Accra", "Kumasi"})),
});
auto out = ct.nt().starts("Ac");
std::cout << out;

Output¶

========================================================================================================================
kindle::Catalog  keys=1
keys: [city]
------------------------------------------------------------------------------------------------------------------------
key                      | kind         | dtype            | cs      | preview                                          
------------------------------------------------------------------------------------------------------------------------
city                     | Series       | Series[bool]     | 2       | [true, false]                                    
========================================================================================================================

Notes¶

  • See the important callout above.

  • Changes each bound key’s kind from Note to Series (Bool).

  • prefix is always literal text — unlike has()/count(), there is no TextOptions overload to switch to regex matching.

  • Case-sensitive; there is no built-in case-insensitive option for this method.

See Also¶

  • CatalogNoteAccessor::ends: the suffix-matching counterpart.

  • CatalogNoteAccessor::has: a substring (anywhere-in-value) test instead of a start-anchored one, with optional regex/case-insensitive matching.

  • Catalog::nt: the entry point this accessor is reached from.

  • RegistryNoteAccessor::starts: the scribble-model equivalent.

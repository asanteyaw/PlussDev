CatalogNoteAccessor::pad¶

Back to CatalogNoteAccessor API Reference

Signature¶

Catalog CatalogNoteAccessor::pad(
    std::int64_t width,
    pluss::table::TextAlign align = pluss::table::TextAlign::Left,
    char fill = ' ') const

What It Does¶

Pads every bound key’s text up to width characters with fill, aligning the original text according to align, and returns a new catalog with those keys replaced. Values already at or beyond width are left unchanged.

Important

CatalogNoteAccessor requires every bound key to be Note-kind Same precondition as every method on this accessor — see CatalogNoteAccessor::strip’s own important callout for the full explanation and the exact throw message.

Parameters¶

width (std::int64_t) The target character width. Values already at least this long are left unchanged.

align (pluss::table::TextAlign, defaults to Left) Where the original text lands within the padded field: Left (text at the start, fill on the right — the default), Right (fill on the left), or Center.

fill (char, defaults to ' ') The character used to pad.

Examples¶

Example 1. Default align = Left: shorter values get right-padded with spaces up to width.

using namespace pluss::kindle::literals;

auto ct = pluss::kindle::Catalog({
    "code"_k = pluss::kindle::Stream(pluss::make_note({"1", "22"})),
});
auto out = ct.nt().pad(4);
std::cout << out;

Output¶

========================================================================================================================
kindle::Catalog  keys=1
keys: [code]
------------------------------------------------------------------------------------------------------------------------
key                      | kind         | dtype            | cs      | preview                                          
------------------------------------------------------------------------------------------------------------------------
code                     | Note         | Note             | 2       | [1   , 22  ]                                     
========================================================================================================================

Returns¶

Catalog A new catalog with every bound key’s text padded to width.

Notes¶

  • See the important callout above.

  • Values already at or beyond width characters are returned unchanged — pad() never truncates.

  • fill defaults to a space; pass any other single character (e.g. '0') for zero-padding-style output.

See Also¶

  • CatalogNoteAccessor::chars: extracts a character range instead of padding.

  • Catalog::nt: the entry point this accessor is reached from.

  • RegistryNoteAccessor::pad: the scribble-model equivalent.

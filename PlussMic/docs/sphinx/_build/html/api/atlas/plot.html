Atlas::plot¶

Back to Atlas API Reference

Signatures¶

Atlas::plot() const -> AtlasPlotAccessor
Atlas::plot(const AtlasPlotOptions& options) const -> AtlasPlotAccessor

What It Does¶

The entry point into the atlas-level plotting accessor — depth-stack-aware charts (per-frame line/scatter/etc. via frames(), 3D surface/wireframe/point-cloud views across depth via surface()/wireframe()/cloud3(), and depth-axis-specific chart types), returning pluss::pl::Studio figures (or a DataFramePlotAccessor for a single selected frame via frames(index)), the same figure/export mechanics documented on DataFramePlotAccessor. Every method on the returned AtlasPlotAccessor has its own page, with real rendered charts, under AtlasPlotAccessor API Reference.

Parameters¶

options (const AtlasPlotOptions&, optional) A bundle of per-chart-type option structs (figure, frames, depth_axis, surface, wireframe, cloud3, depth, depth_compare, depth_facet, depth_rolling, triplot) — each field configures the corresponding method on the returned accessor.

Returns¶

AtlasPlotAccessor A binder for the current atlas — call one of its methods to build a specific chart.

Examples¶

Example 1. plot() binds without rendering; frames(index) narrows to a single frame’s own DataFramePlotAccessor for the familiar 2D chart methods.

auto f0 = pluss::table::DataFrame({
    {"sales", pluss::table::Thread(pluss::make_series({1.0, 2.0}))},
});
auto atlas = pluss::table::Atlas({f0});

auto frame_plot = atlas.plot().frames(0);

Notes¶

  • plot() alone does no work — it only binds the atlas; call one of the returned accessor’s methods to actually build a chart.

  • Every method except triplot() respects options.depth_axis, selecting and ordering which frames participate — triplot() always pools every frame’s rows together instead.

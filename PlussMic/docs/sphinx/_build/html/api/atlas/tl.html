Atlas::tl¶

Back to Atlas API Reference

Signature¶

Atlas::tl() const -> AtlasTimelineAccessor

What It Does¶

The entry point into the calendar/timestamp-operations accessor, applied across every frame in the atlas — extracting year, month, day, weekday, timezone conversion, flooring/ceiling to a unit, and more, one method per operation. tl() binds the current atlas and hands back an AtlasTimelineAccessor, documented in full on its own pages (see AtlasTimelineAccessor API Reference).

Important

tl() itself never validates — the per-feature check happens lazily, per frame Unlike DataFrame::tl() (which throws immediately if any feature on the frame isn’t Timeline/TimeIndex-kind), Atlas::tl() never throws — it just binds. The validation happens later, independently per frame, the first time you actually call a method on the returned accessor (e.g. .year()). If any frame in the atlas has a non-timeline feature at that point, that frame’s own DataFrame::tl() throws the same message DataFrame::tl documents (pointing at df.features({"date"}).tl() as the fix) — but only when an accessor method is actually invoked, not at tl()’s own call site.

Parameters¶

None

Returns¶

AtlasTimelineAccessor A binder for the current atlas — call one of its methods to actually perform a calendar/timestamp operation across every frame.

Examples¶

Example 1. tl() binds without validating; the check happens when a method is called.

auto f0 = pluss::table::DataFrame({
    {"ts", pluss::table::Thread(pluss::make_timeline({"2024-01-01T00:00:00Z"}))},
});
auto atlas = pluss::table::Atlas({f0});

auto out = atlas.tl().year();
std::cout << out.dloc(0);

Output¶

===========
     | ts  
-----------
0    | 2024
-----------
[1 cs x 1 feat]

Notes¶

  • tl() alone does no validation — see the important callout above. Narrow to timeline feature(s) first with features() if the atlas has other feature kinds present.

  • The full accessor surface is documented separately — see AtlasTimelineAccessor API Reference.

See Also¶

  • DataFrame::tl: the single-frame delegate, whose eager validation this method’s lazy, per-frame validation ultimately relies on.

  • Atlas::features: narrow to timeline feature(s) before calling tl().

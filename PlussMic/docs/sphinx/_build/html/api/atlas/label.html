Atlas::label¶

Back to Atlas API Reference

Signature¶

Atlas::label() const -> AtlasLabelAccessor

What It Does¶

The entry point into the atlas’s depth labels — an optional per-frame label axis, set via the constructor’s axis0_labels parameter or via label().set(...). label() binds the current atlas and hands back an AtlasLabelAccessor, documented in full on its own pages (see AtlasLabelAccessor API Reference): has(), values(), set(), range(), reset(), sort(), align(), plus set-algebra and lookup helpers (unite(), intersect(), diff(), symdiff(), find(), pos(), slice()).

Parameters¶

None

Returns¶

AtlasLabelAccessor A binder for the current atlas — call one of its methods to inspect, set, reorder, or query its depth labels.

Examples¶

Example 1. Check and read back the depth labels via the accessor.

auto f0 = pluss::table::DataFrame({
    {"id", pluss::table::Thread(pluss::make_series({1.0}))},
});
auto atlas = pluss::table::Atlas({f0}, pluss::table::Thread(pluss::make_note({"jan"})));

std::cout << "has(): " << atlas.label().has() << "\n";
std::cout << atlas.label().values();

Output¶

has(): 1
0  jan
ptype: Note

Notes¶

  • label() alone does no work — it only binds the atlas; call one of its methods to actually inspect, set, reorder, or query.

  • The full accessor surface is documented separately — see AtlasLabelAccessor API Reference.

See Also¶

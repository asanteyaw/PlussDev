Atlas::axis0_labels¶

Back to Atlas API Reference

Signature¶

Atlas::axis0_labels() const -> const std::optional<Slate>&

What It Does¶

Returns the labels attached to the depth axis — the name given to each stacked frame’s position, the same role a DataFrame’s case labels play for rows. Unlike case labels, depth labels are optional: an Atlas constructed without an explicit label Slate has axis0_labels() return an empty std::optional, and every depth-label-aware method (loc(), sort_depth(), align_depth()) either requires labels to be set first or falls back to plain integer positions. This is the raw accessor; label() wraps it with a friendlier get/set/sort/align surface.

Parameters¶

None

Returns¶

const std::optional<Slate>& The depth-axis labels, if any were set; an empty std::optional otherwise.

Examples¶

Example 1. An atlas constructed with explicit depth labels.

using namespace pluss::table;

auto q1 = DataFrame({{"sales", Slate(pluss::make_series({100.0, 120.0}))}});
auto q2 = DataFrame({{"sales", Slate(pluss::make_series({110.0, 90.0}))}});
auto atlas = Atlas({q1, q2}, Slate(pluss::make_note({"2024Q1", "2024Q2"})));

std::cout << atlas.axis0_labels().has_value() << "\n";
std::cout << *atlas.axis0_labels();

Output¶

1
0    2024Q1
1    2024Q2

Example 2. An atlas constructed without labels has none — axis0_labels() reports an empty std::optional, not a default integer range.

using namespace pluss::table;

auto q1 = DataFrame({{"sales", Slate(pluss::make_series({100.0, 120.0}))}});
auto q2 = DataFrame({{"sales", Slate(pluss::make_series({110.0, 90.0}))}});
auto atlas = Atlas({q1, q2});

std::cout << atlas.axis0_labels().has_value();

Output¶

0

Notes¶

  • Requires a defined Atlas; throws "Atlas: undefined handle" on a default-constructed Atlas().

  • The absence of labels is a distinct state from labels being 0, 1, 2, ... — dereference the returned std::optional only after checking has_value(), or use label().values(), which fills in default integer labels automatically when none are set.

  • When present, depth labels must have exactly depth() entries — enforced at construction time.

See Also¶

  • Atlas::label: the friendlier accessor built on top of this raw optional — values() defaults to integer labels instead of throwing or requiring a manual has_value() check.

  • Atlas::relabel_depth: replace the depth labels with a new Slate.

  • Atlas::sort_depth / Atlas::align_depth: reorder the stack using these labels.

Atlas::squeeze¶

Back to Atlas API Reference

Signature¶

Atlas::squeeze() const -> DataFrame

What It Does¶

Collapses a depth-1 atlas back into its single DataFrame — the inverse of wrapping a lone frame in Atlas({frame}). Requires the atlas to have exactly one frame; throws otherwise.

Important

Requires depth() == 1 — throws for any other depth squeeze() only works on a single-frame atlas; it throws "Atlas::squeeze requires depth == 1" for a depth of 0 or 2+. Use dloc(i)/frame(i) to pull out one specific frame from a multi-frame atlas instead — squeeze() is specifically for the “this atlas only ever had one frame” case.

Parameters¶

None

Returns¶

DataFrame The atlas’s single frame.

Examples¶

Example 1. Squeeze a depth-1 atlas back to a plain DataFrame.

auto f0 = pluss::table::DataFrame({
    {"id", pluss::table::Slate(pluss::make_series({1.0, 2.0}))},
    {"city", pluss::table::Slate(pluss::make_note({"Accra", "Tema"}))},
});
auto atlas = pluss::table::Atlas({f0});

std::cout << atlas.squeeze();

Output¶

==================
     | id    city 
------------------
0    | 1     Accra
1    | 2     Tema 
------------------
[2 cs x 2 feat]

Example 2. Calling squeeze() on a multi-frame atlas throws.

auto f0 = pluss::table::DataFrame({
    {"id", pluss::table::Slate(pluss::make_series({1.0}))},
});
auto f1 = pluss::table::DataFrame({
    {"id", pluss::table::Slate(pluss::make_series({2.0}))},
});
auto atlas = pluss::table::Atlas({f0, f1});

try {
  atlas.squeeze();
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Atlas::squeeze requires depth == 1

Notes¶

  • Requires exactly one frame — see the important callout above.

  • Depth labels (if any) are not carried over — the return type is a plain DataFrame, which has no depth-label concept.

See Also¶

  • Atlas::frame / Atlas::dloc: pull out one specific frame from a multi-frame atlas by index, instead of requiring exactly one.

  • Atlas::aggregate_over_frames: collapse a multi-frame atlas to one DataFrame via a reducer, instead of requiring the atlas already has depth 1.

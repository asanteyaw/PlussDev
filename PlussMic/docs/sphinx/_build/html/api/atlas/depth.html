Atlas::depth¶

Back to Atlas API Reference

Signature¶

Atlas::depth() const -> std::int64_t

What It Does¶

Returns the number of frames stacked in the atlas — the third axis of the cube, beyond a single frame’s own cases (rows) and features (columns). An Atlas is a strict cube: every one of its depth() frames shares the same ncases(), the same nfeatures(), and the same column names, kinds, and dtypes (enforced at construction time — mismatched frames throw immediately rather than being silently stored). depth() is that third dimension’s size, the same way ncases() and nfeatures() report the other two.

Parameters¶

None

Returns¶

std::int64_t The number of frames in the stack. 0 for an atlas built from an empty frame vector.

Examples¶

Example 1. Three quarters stacked into one atlas.

using namespace pluss::table;

auto q1 = DataFrame({{"sales", Thread(pluss::make_series({100.0, 120.0}))}});
auto q2 = DataFrame({{"sales", Thread(pluss::make_series({110.0, 90.0}))}});
auto q3 = DataFrame({{"sales", Thread(pluss::make_series({130.0, 140.0}))}});
auto atlas = Atlas({q1, q2, q3});

std::cout << atlas.depth();

Output¶

3

Example 2. depth() throws on an undefined atlas — unlike empty(), which treats an undefined atlas as trivially empty instead.

using namespace pluss::table;

Atlas undefined_atlas;
try {
  auto d = undefined_atlas.depth();
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Atlas: undefined handle

Notes¶

  • Requires a defined Atlas (defined()); throws "Atlas: undefined handle" on a default-constructed Atlas().

  • Every frame in the stack has identical ncases()/nfeatures()/column schema by construction — depth() is purely the count of how many such frames are stacked, not a measurement of any single frame’s size.

See Also¶

  • Atlas::ncases / Atlas::nfeatures: the other two axes of the cube — every frame’s shared row count and column count.

  • Atlas::frame / Atlas::dloc: retrieve one frame by its position along this axis.

  • Atlas::empty: a depth() == 0 check that’s also safe on an undefined Atlas.

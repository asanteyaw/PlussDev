Atlas::to_string¶

Back to Atlas API Reference

Signature¶

Atlas::to_string(const display::DisplayOptions& options = {}) const -> std::string

What It Does¶

Renders the atlas’s boxed-table summary as a std::string — one section per frame, each prefixed with frame[i] (and its depth label, if set), followed by that frame’s own table rendering. Same rendering operator<< and show(std::ostream&) write to a stream, minus the trailing newline those two append.

Parameters¶

options (const display::DisplayOptions&, optional) Rendering options shared with the rest of the display layer.

Returns¶

std::string The rendered atlas summary, without a trailing newline.

Examples¶

Example 1. Render an atlas to a string.

auto f0 = pluss::table::DataFrame({
    {"id", pluss::table::Thread(pluss::make_series({1.0, 2.0}))},
});
auto atlas = pluss::table::Atlas({f0}, pluss::table::Thread(pluss::make_note({"jan"})));

std::cout << atlas.to_string();

Output¶

Atlas(depth=1, rows=2, cols=1)
frame[0] case=jan
===========
     | id  
-----------
0    | 1   
1    | 2   
-----------
[2 cs x 1 feat]

Example 2. to_string() is one byte shorter than the equivalent show(std::ostream&) capture — the missing trailing newline, same pattern as Archive::to_string.

auto f0 = pluss::table::DataFrame({
    {"id", pluss::table::Thread(pluss::make_series({1.0, 2.0}))},
});
auto atlas = pluss::table::Atlas({f0}, pluss::table::Thread(pluss::make_note({"jan"})));

auto str = atlas.to_string();
std::ostringstream oss;
atlas.show(oss);

std::cout << "to_string length: " << str.size() << "\n";
std::cout << "show length: " << oss.str().size();

Output¶

to_string length: 136
show length: 137

Notes¶

  • This is a summary view — one section per frame — not a single flat table; each frame’s own content is rendered separately.

  • One byte shorter than show(std::ostream&)/operator<<’s output — see Example 2.

See Also¶

  • Atlas::show: the same rendering, written to a stream instead of returned as a string — see that page for an important callout about the no-argument overload.

  • Archive::to_string: the depth-stacked-catalog analog of this method.

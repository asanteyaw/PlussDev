Atlas::slice_frames¶

Back to Atlas API Reference

Signature¶

Atlas::slice_frames(std::int64_t start, std::int64_t stop) const -> Atlas

What It Does¶

Returns a new atlas containing the contiguous half-open depth range [start, stop) — the Atlas analog of Archive::slice_depth. Supports Python-style negative indices for both start and stop, and clamps out-of-range bounds rather than throwing.

Parameters¶

start (std::int64_t) Inclusive starting depth-index. Negative values count from the end.

stop (std::int64_t) Exclusive ending depth-index. Negative values count from the end.

Returns¶

Atlas A new atlas containing frames [start, stop).

Examples¶

Example 1. Slice a middle range of frames.

std::vector<pluss::table::DataFrame> frames;
for (int i = 0; i < 5; ++i) {
  frames.push_back(pluss::table::DataFrame({
      {"id", pluss::table::Slate(pluss::make_series({double(i)}))},
  }));
}
auto atlas = pluss::table::Atlas(frames);

auto out = atlas.slice_frames(1, 4);
std::cout << "depth: " << out.depth() << "\n";
std::cout << out.dloc(0);

Output¶

depth: 3
===========
     | id  
-----------
0    | 1   
-----------
[1 cs x 1 feat]

Example 2. Negative start/stop count from the end, same convention as dloc()’s negative indexing.

std::vector<pluss::table::DataFrame> frames;
for (int i = 0; i < 5; ++i) {
  frames.push_back(pluss::table::DataFrame({
      {"id", pluss::table::Slate(pluss::make_series({double(i)}))},
  }));
}
auto atlas = pluss::table::Atlas(frames);

auto out = atlas.slice_frames(-3, -1);
std::cout << "depth: " << out.depth() << "\n";
std::cout << out.dloc(0);

Output¶

depth: 2
===========
     | id  
-----------
0    | 2   
-----------
[1 cs x 1 feat]

slice_frames(-3, -1) on a 5-frame atlas is equivalent to slice_frames(2, 4) — depths 2 and 3.

Notes¶

  • stop is exclusive.

  • Both start and stop support negative indexing, and both clamp into range rather than throwing on an out-of-bounds value.

  • Returns a new Atlas; the receiver is unmodified.

See Also¶

  • Atlas::head / Atlas::tail: fixed-count selections from either end, instead of an arbitrary range.

  • Atlas::dloc: the single-frame equivalent with the same negative-indexing convention.

  • Archive::slice_depth: the depth-stacked-catalog analog of this method.

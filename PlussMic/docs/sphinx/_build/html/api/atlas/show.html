Atlas::show¶

Back to Atlas API Reference

Signatures¶

Atlas::show(const display::DisplayOptions& options = {}) const -> void
Atlas::show(std::ostream& os, const display::DisplayOptions& options = {}) const -> void

What It Does¶

Writes the atlas’s boxed-table summary — the same rendering to_string() returns as a string, plus a trailing newline to_string() omits. The std::ostream& overload writes to the given stream; the no-argument overload is meant to write to std::cout directly.

Important

The no-argument overload is confirmed to hang outside an interactive terminal Atlas::show() (no std::ostream& argument) has been directly verified to hang indefinitely when run non-interactively. The std::ostream& overload does not exhibit this hang — it prints immediately and returns, verified directly. Until the no-argument overload is fixed, always call show(std::cout, options) explicitly rather than show(options)/show().

Parameters¶

os (std::ostream&, two-argument overload) The destination stream to write to (e.g. std::cout, an std::ostringstream). Prefer this overload — see the important callout above.

options (const display::DisplayOptions&, optional) Rendering options shared with the rest of the display layer.

Returns¶

void Writes as a side effect; produces no return value.

Examples¶

Example 1. Write explicitly to std::cout via the std::ostream& overload — the safe form, per the important callout above.

auto f0 = pluss::table::DataFrame({
    {"id", pluss::table::Thread(pluss::make_series({1.0, 2.0}))},
});
auto atlas = pluss::table::Atlas({f0}, pluss::table::Thread(pluss::make_note({"jan"})));

atlas.show(std::cout);

Output¶

Atlas(depth=1, rows=2, cols=1)
frame[0] case=jan
===========
     | id  
-----------
0    | 1   
1    | 2   
-----------
[2 cs x 1 feat]

Example 2. Capture into an std::ostringstream; confirm it’s one byte longer than to_string() (the trailing newline).

auto f0 = pluss::table::DataFrame({
    {"id", pluss::table::Thread(pluss::make_series({1.0, 2.0}))},
});
auto atlas = pluss::table::Atlas({f0});

std::ostringstream oss;
atlas.show(oss);

std::cout << "longer than to_string() by: "
          << (oss.str().size() - atlas.to_string().size()) << " byte(s)";

Output¶

longer than to_string() by: 1 byte(s)

Notes¶

  • See the important callout above before ever calling the no-argument overload — use show(std::cout, options) instead.

  • One byte longer than to_string(): the trailing newline this method appends.

See Also¶

  • Atlas::to_string: the same rendering, returned as a string (minus the trailing newline) instead of written to a stream.

  • Archive::show: the depth-stacked-catalog analog of this method (single std::ostream& overload only, no no-argument hang).

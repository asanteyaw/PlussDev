SlotCastAccessor::timeline¶

Back to SlotCastAccessor API Reference

Signature¶

Slot SlotCastAccessor::timeline() const

What It Does¶

Casts every value in the bound slot to Timeline-kind and returns a new slot. This behaves identically regardless of how many values the slot holds — including exactly one — see Example 2.

Parameters¶

None

Returns¶

Slot A new slot, every value cast to Timeline-kind.

Examples¶

Example 1. Cast a two-value Note slot of date-looking text to Timeline.

auto slot = pluss::scribble::Slot({pluss::make_note("2024-01-01"), pluss::make_note("2024-01-02")});
auto out = slot.cast().timeline();
std::cout << out.to_json();

Output¶

{
  "_type": "Slot",
  "defined": true,
  "size": 2,
  "values": [
    "Timeline[numel=1]",
    "Timeline[numel=1]"
  ]
}

Example 2. A single-value slot converts the same way a multi-value one does.

auto single = pluss::scribble::Slot({pluss::make_note("2024-01-01")});
auto out = single.cast().timeline();
std::cout << out.to_json();

Output¶

{
  "_type": "Slot",
  "defined": true,
  "size": 1,
  "values": [
    "Timeline[numel=1]"
  ]
}

Example 3. On a two-or-more-value slot, unparseable text throws the intended, documented error.

auto slot = pluss::scribble::Slot({pluss::make_note("Accra"), pluss::make_note("Tema")});
try {
  auto out = slot.cast().timeline();
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n'));
}

Output¶

moment: failed to parse datetime

Example 4. A single-value slot with unparseable text throws the same intended error, not an internal crash.

auto single_bad = pluss::scribble::Slot({pluss::make_note("Accra")});
try {
  auto out = single_bad.cast().timeline();
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n'));
}

Output¶

moment: failed to parse datetime

Notes¶

  • Unparseable text throws "moment: failed to parse datetime" regardless of slot size — contrast series()’s silent-null behavior for the same kind of input.

  • Bound via Slot::cast().

See Also¶

  • SlotCastAccessor::series: the numeric cast target, with a different (silent-null) failure mode.

  • Slot::cast: the entry point this accessor is reached from.

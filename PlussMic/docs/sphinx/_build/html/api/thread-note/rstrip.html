ThreadNoteAccessor::rstrip¶

Back to ThreadNoteAccessor API Reference

Signatures¶

ThreadNoteAccessor::rstrip() const -> Thread
ThreadNoteAccessor::rstrip(std::string_view chars) const -> Thread

What It Does¶

The right-only half of strip(): trims characters from the end of the bound thread’s cells, leaving the leading edge untouched. A direct forward to Thread::rstrip(). Same two policies as strip() (whitespace by default, character-set membership with chars).

Parameters¶

chars (std::string_view, chars-overload only)

The set of characters to strip from each cell’s right edge only.

Returns¶

Thread A new Note-kind thread, same length as the bound thread, with each cell’s trailing text trimmed.

Examples¶

Example 1. Strip a trailing marker character, leaving the leading end untouched.

using namespace pluss::table;

auto ids = Thread(pluss::make_note({"#203930", "##7788", "4455##"}));
auto out = ids.nt().rstrip("#");
std::cout << out;

Output¶

0  #203930
1  ##7788
2  4455

ptype: Note

Rows 0 and 1’s leading # characters are untouched — only trailing # characters are peeled off.

Notes¶

  • ThreadNoteAccessor::rstrip() is a one-line forward to Thread::rstrip() — identical behavior and throws.

  • See strip() for the full explanation of the default-whitespace vs. chars-set-membership policies, and the non-Note throw.

See Also¶

  • Thread::rstrip: the direct, non-accessor form this method forwards to.

  • ThreadNoteAccessor::lstrip: the mirror image, trimming the leading end only.

  • ThreadNoteAccessor::strip: both ends at once.

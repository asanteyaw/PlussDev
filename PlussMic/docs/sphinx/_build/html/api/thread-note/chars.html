ThreadNoteAccessor::chars¶

Back to ThreadNoteAccessor API Reference

Signature¶

ThreadNoteAccessor::chars(std::int64_t start,
                          std::optional<std::int64_t> stop = std::nullopt,
                          std::int64_t step = 1) const -> Thread

What It Does¶

Slices the bound thread’s text the same way Python slices a string — chars(start, stop, step) mirrors s[start:stop:step] exactly, including negative indices (counted from the end) and a negative step (walking the string backwards). A direct forward to Thread::chars(). Requires the bound thread to be Note-kind. Each cell is split into individual characters (Unicode codepoints, the same unit length() counts), the slice is applied per-cell using that cell’s own length, and the selected characters are rejoined into the output string.

Because the slice bounds are evaluated per-cell using each cell’s own length, cells of different lengths in the same thread can each keep a different number of characters from the same (start, stop, step) call.

Parameters¶

start (std::int64_t)

Index of the first character to include. Negative values count from the end of the cell (-1 is the last character). Out-of-range values are clamped, never throw.

stop (std::optional<std::int64_t>, default std::nullopt)

Index one past the last character to include (exclusive), or the point to stop just before when walking backwards. When omitted, defaults to “the end of the string” if step > 0, or “all the way to the start” if step < 0.

step (std::int64_t, default 1)

Stride between characters. 1 takes every character in order; 2 takes every other character; a negative step walks backwards. Must not be 0.

Returns¶

Thread A new Note-kind thread, same length as the bound thread, holding the sliced text.

Examples¶

Example 1. A plain forward range: chars(0, 5) keeps the first five characters of each cell (or fewer, if the cell is shorter).

using namespace pluss::table;

auto words = Thread(pluss::make_note({"hello world", "Accra", "ab", "x"}),
    pluss::make_series(std::vector<bool>{true, true, true, false}));
auto out1 = words.nt().chars(0, 5);
std::cout << out1;

Output¶

0  hello
1  Accra
2  ab
3  NULL

ptype: Note

Row 0’s first five characters are "hello". Row 1 ("Accra", exactly five characters) comes back unchanged. Row 2 ("ab", only two characters) is also unchanged — stop is clamped to the cell’s own length rather than padding or erroring. Row 3 is invalid and stays NULL.

Example 2. A negative step reverses each cell — the idiomatic way to reverse a string with this method, exactly like Python’s s[::-1].

auto out2 = words.nt().chars(-1, std::nullopt, -1);
std::cout << out2;

Output¶

0  dlrow olleh
1  arccA
2  ba
3  NULL

ptype: Note

Example 3. step = 0 throws — there’s no sensible stride of zero.

try {
  auto bad = words.nt().chars(0, std::nullopt, 0);
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Thread::chars: step cannot be zero

Example 4. A non-Note thread throws — the same message Thread::chars() produces directly.

auto numbers = Thread(pluss::make_series({1.0, 2.0, 3.0}));
try {
  auto bad = numbers.nt().chars(0, 2);
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n')) << "\n";
}

Output¶

Thread::chars: expected Note payload

Notes¶

  • ThreadNoteAccessor::chars() is a one-line forward to Thread::chars() — identical behavior and throws.

  • Slices by Unicode codepoint, the same unit length() counts.

  • Out-of-range start/stop values are clamped rather than throwing — only step == 0 throws.

  • A null cell on input stays null on output.

See Also¶

ThreadNoteAccessor::length¶

Back to ThreadNoteAccessor API Reference

Signature¶

ThreadNoteAccessor::length() const -> Thread

What It Does¶

Replaces the bound thread with its character count, as an Int64 Series-kind thread — a direct forward to Thread::length(). Requires the bound thread to be Note-kind.

Important

Counts Unicode codepoints, not bytes length() counts characters (Unicode codepoints), not raw UTF-8 storage bytes. For plain ASCII text the two are identical — but any character outside the ASCII range is encoded as more than one byte in UTF-8 while still counting as exactly one character.

Parameters¶

None

Returns¶

Thread A new Series-kind (Int64) thread, same length as the bound thread, holding each cell’s character count.

Examples¶

Example 1. Character count of a plain ASCII text thread.

using namespace pluss::table;

auto cities = Thread(pluss::make_note({"Accra", "Tema", "Kumasi"}));
auto out = cities.nt().length();
std::cout << out;

Output¶

0  5
1  4
2  6

ptype: Series

Example 2. A non-Note thread throws — the same message Thread::length() produces directly.

auto numbers = Thread(pluss::make_series({1.0, 2.0, 3.0}));
try {
  auto bad = numbers.nt().length();
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n')) << "\n";
}

Output¶

Thread::length: expected Note payload

Notes¶

  • ThreadNoteAccessor::length() is a one-line forward to Thread::length() — identical behavior and throws.

  • Changes the payload kind from Note to Series (Int64).

  • Counts Unicode codepoints, not raw UTF-8 storage bytes.

  • A null cell on input stays null on output.

See Also¶

  • Thread::length: the direct, non-accessor form this method forwards to.

  • ThreadNoteAccessor::pad: uses the same character-count notion of “width.”

  • ThreadNoteAccessor::chars: slice out a character range instead of counting.

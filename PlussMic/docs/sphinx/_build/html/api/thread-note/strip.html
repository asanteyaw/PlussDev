ThreadNoteAccessor::strip¶

Back to ThreadNoteAccessor API Reference

Signatures¶

ThreadNoteAccessor::strip() const -> Thread
ThreadNoteAccessor::strip(std::string_view chars) const -> Thread

What It Does¶

Trims characters from both ends of the bound thread’s cells — a direct forward to Thread::strip(). Requires the bound thread to be Note-kind. Two distinct trimming policies:

  • No-argument overload: trims the classic ASCII whitespace set (space, tab, newline, carriage return, form feed, vertical tab) from both ends.

  • chars overload: trims by character-set membership, not by matching chars as a literal prefix/suffix substring — every leading/trailing character that appears anywhere in chars is removed, one at a time, until a character not in the set is reached.

Parameters¶

chars (std::string_view, chars-overload only)

The set of characters to strip from each cell’s edges. Order doesn’t matter.

Returns¶

Thread A new Note-kind thread, same length as the bound thread, with each cell’s text trimmed.

Examples¶

Example 1. The default overload trims ASCII whitespace from both ends.

using namespace pluss::table;

auto skus = Thread(pluss::make_note({"  SKU-1001\n", "\tSKU-1002", "SKU-1003   "}));
auto out = skus.nt().strip();
std::cout << out;

Output¶

0  SKU-1001
1  SKU-1002
2  SKU-1003

ptype: Note

Example 2. The chars overload strips by character-set membership, not by matching a literal substring.

auto codes = Thread(pluss::make_note({"[[[SKU-1001]]]", "((SKU-1002))", "SKU-1003"}));
auto out2 = codes.nt().strip("[]()");
std::cout << out2;

Output¶

0  SKU-1001
1  SKU-1002
2  SKU-1003

ptype: Note

"[[[SKU-1001]]]" has no "[]()" substring anywhere in it, yet every edge character still gets stripped, one character at a time, stopping the instant a character outside the chars set is reached.

Example 3. A non-Note thread throws — the same message Thread::strip() produces directly.

auto numbers = Thread(pluss::make_series({1.0, 2.0, 3.0}));
try {
  auto bad = numbers.nt().strip();
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n')) << "\n";
}

Output¶

Thread::strip is only valid for Note payload

Notes¶

  • ThreadNoteAccessor::strip() is a one-line forward to Thread::strip() — identical behavior and throws.

  • The chars overload’s set-membership semantics apply to lstrip() and rstrip() identically — one-sided versions of everything shown here.

  • A null cell on input stays null on output.

See Also¶

  • Thread::strip: the direct, non-accessor form this method forwards to.

  • ThreadNoteAccessor::lstrip / ThreadNoteAccessor::rstrip: the one-sided equivalents.

  • ThreadNoteAccessor::pad: the inverse operation — add characters instead of removing them.

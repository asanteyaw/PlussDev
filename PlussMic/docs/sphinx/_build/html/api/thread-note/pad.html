ThreadNoteAccessor::pad¶

Back to ThreadNoteAccessor API Reference

Signature¶

ThreadNoteAccessor::pad(std::int64_t width,
                        TextAlign align = TextAlign::Left,
                        char fill = ' ') const -> Thread

What It Does¶

Grows every cell of the bound thread up to a target character width by adding fill characters, positioning the original text according to align — a direct forward to Thread::pad(). Requires the bound thread to be Note-kind.

enum class TextAlign { Left = 0, Right = 1, Center = 2 };

  • TextAlign::Left (the default): fill characters are added on the right.

  • TextAlign::Right: fill characters are added on the left — the classic zero-padding-a-code use case ("7" → "0007").

  • TextAlign::Center: fill is split between both sides, extra character on the right for an odd amount.

pad() only ever grows a cell — a cell already at or beyond width comes back unchanged, never truncated.

Parameters¶

width (std::int64_t)

The target character width, measured in Unicode codepoints. Must be >= 0.

align (TextAlign, default TextAlign::Left)

Where the fill characters go.

fill (char, default ' ')

The single character used to pad. A char, not a std::string_view — no multi-byte UTF-8 fill sequences.

Returns¶

Thread A new Note-kind thread, same length as the bound thread, holding the padded (or unchanged) text.

Examples¶

Example 1. Zero-padding numeric-looking codes to a fixed width via the accessor.

using namespace pluss::table;

auto ids = Thread(pluss::make_note({"7", "42", "103"}));
auto out = ids.nt().pad(4, TextAlign::Right, '0');
std::cout << out;

Output¶

0  0007
1  0042
2  0103

ptype: Note

Example 2. TextAlign::Center splits fill between both sides, extra character on the right.

auto codes = Thread(pluss::make_note({"A", "BB", "CCCC"}));
auto out2 = codes.nt().pad(6, TextAlign::Center, '.');
std::cout << out2;

Output¶

0  ..A...
1  ..BB..
2  .CCCC.

ptype: Note

Example 3. A negative width throws — the same message Thread::pad() produces directly.

try {
  auto bad = codes.nt().pad(-1);
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Thread::pad: width must be >= 0

Notes¶

  • ThreadNoteAccessor::pad() is a one-line forward to Thread::pad() — identical behavior and throws.

  • pad() only grows; a cell already at or beyond width is returned unchanged, never truncated.

  • width is measured in Unicode codepoints, the same unit length() counts.

  • Center’s extra fill character (when the amount needed is odd) always goes on the right.

  • A null cell on input stays null on output.

See Also¶

  • Thread::pad: the direct, non-accessor form this method forwards to.

  • ThreadNoteAccessor::chars: the complementary shrink/slice operation.

  • ThreadNoteAccessor::strip: removes characters instead of adding them.

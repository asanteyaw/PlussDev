CatalogTimelineAccessor::weekday¶

Back to CatalogTimelineAccessor API Reference

Signature¶

Catalog CatalogTimelineAccessor::weekday() const

What It Does¶

Extracts the weekday number (0 = Monday through 6 = Sunday) of each bound key’s timestamp, replacing each Timeline- or TimeIndex-kind key with an Int32 Series key.

Important

CatalogTimelineAccessor requires every bound key to be Timeline- or TimeIndex-kind Same precondition as every method on this accessor — see CatalogTimelineAccessor::isnat’s own important callout for the full explanation and the exact throw message.

Parameters¶

None

Returns¶

Catalog A new catalog with every bound key replaced by an Int32 Series key of weekday numbers.

Examples¶

Example 1. Extract the weekday number from a Wednesday and a Thursday.

using namespace pluss::kindle::literals;

auto ct = pluss::kindle::Catalog({
    "ts"_k = pluss::kindle::Stream(pluss::make_timeline({"2024-01-31T09:15:30Z", "2024-02-29T23:45:00Z"})),
});
auto out = ct.tl().weekday();
std::cout << out;

Output¶

========================================================================================================================
kindle::Catalog  keys=1
keys: [ts]
------------------------------------------------------------------------------------------------------------------------
key                      | kind         | dtype            | cs      | preview                                          
------------------------------------------------------------------------------------------------------------------------
ts                       | Series       | Series[int32]    | 2       | [2, 3]                                           
========================================================================================================================

"2024-01-31" is a Wednesday (2), "2024-02-29" is a Thursday (3) — see weekday_name() for the same information spelled out.

Notes¶

  • 0 is Monday, 6 is Sunday (ISO weekday numbering).

  • Reads local calendar fields relative to whatever timezone the key’s Timeline currently carries ("UTC" unless changed via tz()/ localize()).

  • See the important callout above.

See Also¶

  • CatalogTimelineAccessor::weekday_name: the same information as a full English name instead of a number.

  • CatalogTimelineAccessor::weekend: whether the weekday falls on a weekend.

  • CatalogTimelineAccessor::week: the ISO week-of-year this weekday belongs to.

  • Catalog::tl: the entry point this accessor is reached from.

  • RegistryTimelineAccessor::weekday: the scribble-model equivalent.

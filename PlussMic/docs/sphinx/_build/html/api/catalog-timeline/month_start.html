CatalogTimelineAccessor::month_start¶

Back to CatalogTimelineAccessor API Reference

Signature¶

Catalog CatalogTimelineAccessor::month_start() const

What It Does¶

Flags whether each bound key’s timestamp falls on the first day of its calendar month, replacing each Timeline-kind key with a Bool Series key.

Important

CatalogTimelineAccessor requires every bound key to be Timeline-kind Same precondition as every method on this accessor — see CatalogTimelineAccessor::isnat’s own important callout for the full explanation and the exact throw message.

Parameters¶

None

Returns¶

Catalog A new catalog with every bound key replaced by a Bool Series key: true where the row’s day-of-month is 1, false otherwise.

Examples¶

Example 1. Neither sample timestamp falls on the 1st of its month.

using namespace pluss::kindle::literals;

auto ct = pluss::kindle::Catalog({
    "ts"_k = pluss::kindle::Stream(pluss::make_timeline({"2024-01-31T09:15:30Z", "2024-02-29T23:45:00Z"})),
});
auto out = ct.tl().month_start();
std::cout << out;

Output¶

========================================================================================================================
kindle::Catalog  keys=1
keys: [ts]
------------------------------------------------------------------------------------------------------------------------
key                      | kind         | dtype            | cs      | preview                                          
------------------------------------------------------------------------------------------------------------------------
ts                       | Series       | Series[bool]     | 2       | [false, false]                                   
========================================================================================================================

Both sample dates are the last day of their month, not the first — see month_end(), which flags true for exactly these rows.

Notes¶

  • Only checks the day-of-month component (day() == 1); the time-of-day portion doesn’t affect the result.

  • Reads local calendar fields relative to whatever timezone the key’s Timeline currently carries ("UTC" unless changed via tz()/ localize()).

  • See the important callout above.

  • Catalog::tl: the entry point this accessor is reached from.

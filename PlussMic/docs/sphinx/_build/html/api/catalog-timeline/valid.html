CatalogTimelineAccessor::valid¶

Back to CatalogTimelineAccessor API Reference

Signature¶

Catalog CatalogTimelineAccessor::valid() const

What It Does¶

Flags whether each bound key’s timestamp is a real, present timestamp (not NaT), replacing each Timeline- or TimeIndex-kind key with a Bool Series key. Exactly the logical inverse of isnat().

Important

CatalogTimelineAccessor requires every bound key to be Timeline- or TimeIndex-kind Same precondition as every method on this accessor — see CatalogTimelineAccessor::isnat’s own important callout for the full explanation and the exact throw message.

Parameters¶

None

Returns¶

Catalog A new catalog with every bound key replaced by a Bool Series key: true where the value is a real timestamp, false where it’s NaT.

Examples¶

Example 1. Flag a valid timestamp alongside a NaT one.

using namespace pluss::kindle::literals;

auto ct = pluss::kindle::Catalog({
    "ts"_k = pluss::kindle::Stream(pluss::make_timeline({"", "2024-01-01T00:00:00Z"})),
});
auto out = ct.tl().valid();
std::cout << out;

Output¶

========================================================================================================================
kindle::Catalog  keys=1
keys: [ts]
------------------------------------------------------------------------------------------------------------------------
key                      | kind         | dtype            | cs      | preview                                          
------------------------------------------------------------------------------------------------------------------------
ts                       | Series       | Series[bool]     | 2       | [false, true]                                    
========================================================================================================================

Notes¶

  • Exactly !isnat(), provided for readability at call sites that want to filter for present timestamps rather than for missing ones.

  • See the important callout above.

  • Bound via Catalog::tl(), which binds every key of the catalog unless you project first with Catalog::keys(names).

What It Does¶

Lays out every pairwise combination of the selected keys as its own small scatter (or regression) panel in an N×N mosaic, with each diagonal cell showing that one key’s own distribution (histogram or density) instead of a self-vs-self scatter. Off-diagonal cells reuse the exact same pairwise-alignment machinery as scatter()’s numeric-pair branch and corr_heatmap().

Parameters¶

keys (RangeView<std::string_view> or std::initializer_list<std::string_view>, defaults to {}) Same resolution as line(): an empty range selects every plottable key. At least two resolved keys are required — "Catalog::plot().scatter_matrix: need at least two plottable streams" if fewer.

triangle (pluss::table::ScatterMatrixTriangle, an alias for pluss::pl::flash::PairPlotTriangle) Shorthand for CatalogScatterMatrixPlotOptions{}.matrix.pair.triangle = triangle — Full (default, every cell), Lower, or Upper.

options (CatalogScatterMatrixPlotOptions) ```cpp struct CatalogPairAlignOptions { PairAlign align{PairAlign::PairwiseInner}; PairAlignBy align_by{PairAlignBy::Auto}; };

struct PairPlotOptions {                    // pluss::pl::flash
  PairPlotTriangle triangle{PairPlotTriangle::Full};   // Full | Lower | Upper
  PairPlotKind kind{PairPlotKind::Scatter};            // Scatter | Reg
  PairPlotDiagKind diag_kind{PairPlotDiagKind::Histogram}; // Histogram | Density
  bool corner{false};
  std::vector<std::string> labels{};
  std::int64_t max_points{2500};
  std::int64_t diag_bins{14};
  std::int64_t diag_density_points{128};
  // ... sizing/grid fields, see PlussPl's own reference for the full struct
};

struct ScatterMatrixPlotOptions {            // pluss::table
  bool corner{false};
  pluss::pl::flash::PairPlotOptions pair{};
};

struct CatalogScatterMatrixPlotOptions {
  CatalogPairAlignOptions align{};
  pluss::table::ScatterMatrixPlotOptions matrix{};
};
```
`matrix.corner = true` additionally forces `pair.triangle` from `Full` to `Lower` (a
no-op if `triangle` was already `Lower` or `Upper`). `pair.kind = Reg` draws a fitted
regression line (via `flash::regplot`) on off-diagonal cells instead of a plain point
cloud. `pair.diag_kind = Density` swaps the diagonal cells from histograms to smoothed
density curves. `pair.labels`, if left empty, is filled in with the resolved key names.
`align`/`align_by` control the same cross-key alignment
[`corr_heatmap()`](corr_heatmap.md) uses.

Returns¶

pluss::pl::Studio A figure laid out as an N×N mosaic (one pane per visible cell, following triangle).

Examples¶

Example 1. Default: every plottable key, Full triangle, histogram diagonal.

using namespace pluss::kindle::literals;

auto weather = pluss::kindle::Catalog({
    "temp_c"_k = pluss::kindle::Stream(pluss::make_series({18.0, 19.5, 21.0, 20.0, 22.5, 17.5})),
    "humidity"_k = pluss::kindle::Stream(pluss::make_series({55.0, 60.0, 65.0, 62.0, 58.0, 53.0})),
    "pressure"_k = pluss::kindle::Stream(pluss::make_series({1005.0, 1008.0, 1010.0, 1009.0, 1012.0, 1004.0})),
});

auto chart = weather.plot().scatter_matrix();
chart.show();

Example 2. The triangle-overload: explicit keys, Lower triangle only (skips the redundant upper-right mirrored cells).

using namespace pluss::kindle::literals;

auto weather = pluss::kindle::Catalog({
    "temp_c"_k = pluss::kindle::Stream(pluss::make_series({18.0, 19.5, 21.0, 20.0, 22.5, 17.5})),
    "humidity"_k = pluss::kindle::Stream(pluss::make_series({55.0, 60.0, 65.0, 62.0, 58.0, 53.0})),
    "pressure"_k = pluss::kindle::Stream(pluss::make_series({1005.0, 1008.0, 1010.0, 1009.0, 1012.0, 1004.0})),
});

auto chart = weather.plot().scatter_matrix(
    {"temp_c", "humidity", "pressure"}, pluss::table::ScatterMatrixTriangle::Lower);
chart.show();

Example 3. CatalogScatterMatrixPlotOptions with matrix.corner = true and a Density diagonal.

using namespace pluss::kindle::literals;

auto weather = pluss::kindle::Catalog({
    "temp_c"_k = pluss::kindle::Stream(pluss::make_series({18.0, 19.5, 21.0, 20.0, 22.5, 17.5})),
    "humidity"_k = pluss::kindle::Stream(pluss::make_series({55.0, 60.0, 65.0, 62.0, 58.0, 53.0})),
    "pressure"_k = pluss::kindle::Stream(pluss::make_series({1005.0, 1008.0, 1010.0, 1009.0, 1012.0, 1004.0})),
});

pluss::kindle::CatalogScatterMatrixPlotOptions options;
options.matrix.corner = true;
options.matrix.pair.diag_kind = pluss::pl::flash::PairPlotDiagKind::Density;

auto chart = weather.plot().scatter_matrix({"temp_c", "humidity", "pressure"}, options);
chart.show();

matrix.corner = true forces the layout down to the lower triangle (same effect as passing ScatterMatrixTriangle::Lower directly); the three diagonal cells now show density curves instead of histograms.

Example 4. Fewer than two resolved keys throws.

using namespace pluss::kindle::literals;

auto weather = pluss::kindle::Catalog({
    "temp_c"_k = pluss::kindle::Stream(pluss::make_series({18.0, 19.5, 21.0})),
});

try {
  auto bad = weather.plot().scatter_matrix({"temp_c"});
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Catalog::plot().scatter_matrix: need at least two plottable streams

Notes¶

  • An empty keys selects every plottable key, the same rule line() uses.

  • At least two resolved keys are required — see Example 4.

  • matrix.corner = true overrides Full to Lower; it has no effect if triangle is already Lower or Upper.

  • Diagonal cells never participate in the pairwise-alignment machinery — each diagonal cell only ever looks at its own key’s own values.

  • Off-diagonal cells with zero aligned points after alignment/downsampling simply draw no points, rather than throwing.

  • Returns a pluss::pl::Studio — see line()’s important callout for how to view or save the result.

See Also¶

  • CatalogPlotAccessor::corr_heatmap: the same alignment machinery, summarized as a single correlation coefficient per pair instead of a full scatter panel.

  • CatalogPlotAccessor::scatter: the two-key version of the numeric-pair alignment this method generalizes to every pair among N keys.

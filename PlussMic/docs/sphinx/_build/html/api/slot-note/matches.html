SlotNoteAccessor::matches¶

Back to SlotNoteAccessor API Reference

Signature¶

Slot SlotNoteAccessor::matches(std::string_view pattern, bool full = false) const

What It Does¶

Tests each value in the bound slot against pattern as a regular expression, replacing each Note value with a Bool Series. Unlike has(), pattern here is always treated as a regex.

full controls the anchoring: false (default) uses regex_search (contains semantics); true uses regex_match (whole-value, equivalent to fullmatch(pattern)).

Parameters¶

pattern (std::string_view) A regular expression to test each value against.

full (bool, defaults to false) When true, the pattern must match the entire value.

Returns¶

Slot A new Series[bool] slot.

Examples¶

Example 1. Default (full = false): the pattern just needs to appear somewhere.

auto slot = pluss::scribble::Slot({pluss::make_note("AB-123"), pluss::make_note("99XY")});
auto out = slot.nt().matches("[0-9]+");
std::cout << std::boolalpha
          << std::get<pluss::Series>(out.at(0)).to_vec<bool>()[0] << " "
          << std::get<pluss::Series>(out.at(1)).to_vec<bool>()[0];

Output¶

true true

Example 2. full = true requires the whole value to match.

auto slot = pluss::scribble::Slot({pluss::make_note("AB-123"), pluss::make_note("99XY")});
auto out = slot.nt().matches("^[0-9]+$", true);
std::cout << std::boolalpha
          << std::get<pluss::Series>(out.at(0)).to_vec<bool>()[0] << " "
          << std::get<pluss::Series>(out.at(1)).to_vec<bool>()[0];

Output¶

false false

Notes¶

  • pattern is always a regular expression — no literal-text mode.

  • matches(pattern, true) is equivalent to fullmatch(pattern).

  • Changes each value’s kind from Note to Series (Bool).

  • Requires the slot to be Note-kind — a non-Note slot throws "Slot::nt: slot kind must be Note".

See Also¶

  • SlotNoteAccessor::fullmatch: the always-anchored form.

  • SlotNoteAccessor::has: substring/pattern presence with a literal-by-default mode this method doesn’t have.

  • Slot::nt: the entry point this accessor is reached from.

SlotNoteAccessor::rstrip¶

Back to SlotNoteAccessor API Reference

Signatures¶

Slot SlotNoteAccessor::rstrip() const

Slot SlotNoteAccessor::rstrip(std::string_view chars) const

What It Does¶

Trims characters from the right edge of each value in the bound slot, returning a new slot. The no-argument overload trims whitespace; the chars-argument overload trims any of the given characters.

Parameters¶

chars (std::string_view, one-argument overload only) The set of characters to strip from the right edge.

Returns¶

Slot A new slot, every value right-trimmed.

Examples¶

Example 1. No-argument overload trims trailing whitespace.

auto slot = pluss::scribble::Slot({pluss::make_note("  Accra  ")});
auto out = slot.nt().rstrip();
std::cout << "'" << std::get<pluss::Note>(out.at(0)).at(0) << "'";

Output¶

'  Accra'

Example 2. chars-argument overload trims a specific character set from the right edge only.

auto slot = pluss::scribble::Slot({pluss::make_note("xxAccraxx")});
auto out = slot.nt().rstrip("x");
std::cout << std::get<pluss::Note>(out.at(0)).at(0);

Output¶

xxAccra

Notes¶

  • Only trims the right edge — see lstrip() for the left edge and strip() for both.

  • Requires the slot to be Note-kind — a non-Note slot throws "Slot::nt: slot kind must be Note".

See Also¶

  • SlotNoteAccessor::lstrip: the left-edge counterpart.

  • SlotNoteAccessor::strip: trims both edges at once.

  • Slot::nt: the entry point this accessor is reached from.

SlotNoteAccessor::fullmatch¶

Back to SlotNoteAccessor API Reference

Signature¶

Slot SlotNoteAccessor::fullmatch(std::string_view pattern) const

What It Does¶

Tests whether each value’s entire text matches pattern as a regular expression, replacing each Note value with a Bool Series.

Unlike matches(), there’s no full toggle — fullmatch() always anchors the pattern to both ends of the value.

Parameters¶

pattern (std::string_view) A regular expression the entire value must match, start to end.

Returns¶

Slot A new Series[bool] slot.

Examples¶

Example 1. A code pattern that matches one value fully and not the other.

auto slot = pluss::scribble::Slot({pluss::make_note("AB-123"), pluss::make_note("99XY")});
auto out = slot.nt().fullmatch("[A-Z]{2}-[0-9]{3}");
std::cout << std::boolalpha
          << std::get<pluss::Series>(out.at(0)).to_vec<bool>()[0] << " "
          << std::get<pluss::Series>(out.at(1)).to_vec<bool>()[0];

Output¶

true false

Notes¶

  • Always anchored to both ends — contrast matches(pattern) (unanchored by default).

  • No TextOptions overload — use inline regex flags (e.g. (?i)) for case-insensitivity.

  • Changes each value’s kind from Note to Series (Bool).

  • Requires the slot to be Note-kind — a non-Note slot throws "Slot::nt: slot kind must be Note".

See Also¶

  • SlotNoteAccessor::matches: the more flexible sibling.

  • SlotNoteAccessor::has: substring/pattern presence, not a whole-value shape check.

  • Slot::nt: the entry point this accessor is reached from.

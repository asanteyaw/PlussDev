NexusQuery::drop¶

Back to NexusQuery API Reference

Signature¶

NexusQuery::drop(std::initializer_list<std::string_view> features) const -> NexusQuery

What It Does¶

Removes the named columns from what .collect() returns, keeping everything else — the complement of .pick(). Applied after every join step, same as .pick(). Calling .drop() again replaces the previous drop list rather than combining with it.

Parameters¶

features (std::initializer_list<std::string_view>) The feature names to remove from the final result. Same validation as .pick(): each name must be non-empty and unique within the request. Existence is checked when .collect() runs.

Returns¶

NexusQuery A new query with the drop list set (or replaced). The original query is unchanged.

Examples¶

Example 1. Drop the redundant join key after joining.

using namespace pluss::table;

auto customers = DataFrame({
    {"customer_id", Thread(pluss::make_series({1.0, 2.0, 3.0}))},
    {"name",        Thread(pluss::make_note({"Ada", "Ben", "Cy"}))},
});
auto orders = DataFrame({
    {"order_id",    Thread(pluss::make_series({101.0, 102.0, 103.0}))},
    {"customer_id", Thread(pluss::make_series({1.0, 2.0, 2.0}))},
    {"amount",      Thread(pluss::make_series({50.0, 75.0, 20.0}))},
});

auto biz = Nexus({
    {"customers", customers},
    {"orders", orders},
});

Relationship rel;
rel.name = "orders_to_customers";
rel.left_table = "orders";
rel.right_table = "customers";
rel.keys = {{"customer_id", "customer_id"}};

auto linked = biz.add_relationship(rel);

auto result = linked.from("orders").join("customers").drop({"customer_id"}).collect();

for (const auto& f : result.features()) {
  std::cout << f << " ";
}

Output¶

order_id amount name

customer_id (the join key, now redundant once the frames are joined) is gone; order_id, amount, and name all survive, in the joined frame’s own original order.

Notes¶

  • Applies to the final joined result, after .pick() if both are set — see that page’s Notes for the exact application order.

  • A second .drop() call replaces the earlier list rather than combining with it.

See Also¶

  • NexusQuery::collect: where .pick()/.drop() are actually applied.

  • Nexus::drop: the table-level (not column-level) analog.

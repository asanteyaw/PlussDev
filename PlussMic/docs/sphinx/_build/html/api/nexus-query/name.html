NexusQuery::name¶

Back to NexusQuery API Reference

Signature¶

NexusQuery::name(std::string_view value) const -> NexusQuery

What It Does¶

Sets the title .collect()’s returned DataFrame will carry, overriding the automatic root_table + "_" + <last table>-style name the underlying JoinPlan would otherwise use.

Parameters¶

value (std::string_view) The title to apply. Must be non-empty — an empty string throws "NexusQuery::name: title cannot be empty".

Returns¶

NexusQuery A new query with the title set (or replaced). The original query is unchanged.

Examples¶

Example 1. Naming the result of a join.

using namespace pluss::table;

auto customers = DataFrame({
    {"customer_id", Thread(pluss::make_series({1.0, 2.0, 3.0}))},
    {"name",        Thread(pluss::make_note({"Ada", "Ben", "Cy"}))},
});
auto orders = DataFrame({
    {"order_id",    Thread(pluss::make_series({101.0, 102.0, 103.0}))},
    {"customer_id", Thread(pluss::make_series({1.0, 2.0, 2.0}))},
});

auto biz = Nexus({
    {"customers", customers},
    {"orders", orders},
});

Relationship rel;
rel.name = "orders_to_customers";
rel.left_table = "orders";
rel.right_table = "customers";
rel.keys = {{"customer_id", "customer_id"}};

auto linked = biz.add_relationship(rel);

auto result = linked.from("orders").join("customers").name("orders_with_customers").collect();
std::cout << result.title();

Output¶

orders_with_customers

Example 2. An empty title throws.

try {
  auto bad = linked.from("orders").name("");
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

NexusQuery::name: title cannot be empty

Note that the throw happens immediately when .name("") is called — before .collect() even runs.

Notes¶

  • Validated (non-empty) immediately when .name() is called, not deferred to .collect().

  • A second .name() call replaces the earlier title rather than appending to it.

  • Without a call to .name(), .collect() falls back to the underlying JoinPlan’s own result_name — see Nexus::plan() for that default naming rule.

See Also¶

  • NexusQuery::collect: where the title is actually applied, via DataFrame::title().

  • Nexus::plan: the default naming rule this method overrides.

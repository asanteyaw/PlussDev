DataFrame::csmax¶

Back to DataFrame API Reference

Signature¶

DataFrame::csmax(Axis axis = Axis::Case, bool skipnull = true) const -> Thread

What It Does¶

Reports where each numeric feature’s maximum value occurs, not the maximum value itself — the argmax-style companion to max(). The returned Thread always holds label strings (case labels or feature names), never numeric values, so it always prints with ptype: Note.

Parameters¶

axis (Axis, default Axis::Case)

Direction to search along:

  • Axis::Case (the default): for each numeric feature, find which case holds that feature’s maximum value. The result has one entry per numeric feature, labeled by feature name.

  • Axis::Feature: for each case, find which feature holds that row’s maximum value. The result has one entry per case, labeled by the source frame’s case labels.

skipnull (bool, default true)

Missing-value policy while searching for the maximum.

Returns¶

Thread A Note-typed label thread: case labels (Axis::Case) or feature names (Axis::Feature), one per participating numeric feature or case respectively.

Examples¶

Example 1. Default axis: for each feature, which case holds its maximum.

using namespace pluss::table;

auto regions = DataFrame({
    {"sales", pluss::make_series({100.0, 120.0, 90.0})},
    {"cost",  pluss::make_series({60.0, 80.0, 95.0})},
}, pluss::make_note({"q1", "q2", "q3"}));

std::cout << regions;

Output (before)¶

==================
     | sales  cost
------------------
q1   | 100    60  
q2   | 120    80  
q3   | 90     95  
------------------
[3 cs x 2 feat]

auto peak_case = regions.csmax();
std::cout << peak_case;

Output (after)¶

sales  q2
 cost  q3
ptype: Note

sales peaks at case q2 (120), and cost peaks at case q3 (95). The result has one entry per numeric feature, labeled by feature name.

Example 2. Axis::Feature: for each case, which feature holds the larger value.

auto peak_feature = regions.csmax(Axis::Feature);
std::cout << peak_feature;

Output¶

q1  sales
q2  sales
q3  cost
ptype: Note

At q1 and q2, sales is larger than cost; at q3, cost (95) overtakes sales (90). The result now has one entry per case, labeled by the source frame’s case labels.

Example 3. skipnull = false: a single missing value anywhere in a feature poisons that feature’s whole result to NULL, even though the same feature still finds a perfectly good maximum among its non-null cells under the default skipnull = true.

auto regions2 = DataFrame({
    {"sales", pluss::make_series({100.0, std::numeric_limits<double>::quiet_NaN(), 90.0})},
    {"cost",  pluss::make_series({60.0, 80.0, 95.0})},
}, pluss::make_note({"q1", "q2", "q3"}));

auto peak_skip = regions2.csmax(Axis::Case, true);
std::cout << peak_skip;

auto peak_no_skip = regions2.csmax(Axis::Case, false);
std::cout << peak_no_skip;

Output (skipnull = true, the default)¶

sales  q1
 cost  q3
ptype: Note

Output (skipnull = false)¶

sales  NULL
 cost  q3
ptype: Note

sales is missing at q2; with skipnull = true, the search simply ignores that cell and finds the maximum (100) among what’s left, at q1. With skipnull = false, the presence of any missing value anywhere in sales invalidates the whole result for that feature — sales comes back NULL outright, even though a perfectly good maximum among the non-null values still exists. cost has no missing values at all, so it reports q3 identically under both settings. This same call also demonstrates Axis::Case passed explicitly, rather than relying on it being the default.

Notes¶

  • csmax() always returns label strings, never the numeric maximum itself — reach for max() when the value is what you want, and csmax() when you want to know where it came from.

  • The two axes produce results with different lengths and different label kinds: one entry per feature (Axis::Case) or one entry per case (Axis::Feature) — do not assume the result lines up positionally with the source frame’s rows.

See Also¶

  • DataFrame::csmin: the same lookup for the minimum instead of the maximum.

  • DataFrame::max: the numeric maximum value itself, instead of where it occurs.

  • DataFrame::cummax: a running maximum per case, instead of a single argmax lookup.

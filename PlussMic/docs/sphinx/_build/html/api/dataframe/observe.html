DataFrame::observe¶

Back to DataFrame API Reference

Signature¶

DataFrame::observe(std::int64_t row, bool render = false) const -> DataFrameView

What It Does¶

Transposes one row into a readable, feature-by-feature record — a DataFrameView with one case per source feature and two columns:

column

contents

dtype

that feature’s stored type (Series<float64>, Note<utf8>, Timeline<datetime64[ns, UTC]>, …)

value

that feature’s cell at row, stringified; an invalid cell shows <null>

The card’s case-label axis is the source feature names, so you read it top to bottom like a record card. This is the shape you actually want when a frame is dozens of columns wide and view(row, row + 1) (or a bare slice) hands back an unreadable one-row-tall strip you have to scroll sideways through.

observe is position-addressed, not label-addressed: row is an integer offset. Negative values count back from the end (observe(-1) is the last row). An out-of-range row — including any row on a frame with no cases — throws "DataFrame: row index out of bounds". To pick the row by its case label first, go through case_study().label(...) and observe position 0 of the result, or label().pos(...) to turn a label into an offset.

Use view() / slice() when you want a range of rows back as a frame to keep computing on; use observe when you want to look at a single observation. It does not mutate the source.

Parameters¶

row (std::int64_t)

Zero-based position of the row to inspect. Negative counts from the end. Out of range throws.

render (bool, default false)

Display toggle for the returned DataFrameView, identical in behavior to head()’s render parameter — true prints the card immediately on construction.

Returns¶

DataFrameView A two-column (dtype, value) view, one case per source feature, case-labelled by feature name, carrying the source frame’s title. nfeatures() of the source becomes ncases() of the card.

Examples¶

Example 1. Read one observation out of a wide frame.

using namespace pluss::table;

auto homes = DataFrame({
    {"home_id",   Slate(pluss::make_note({"H-104", "H-887", "H-231"}))},
    {"built_on",  Slate(pluss::make_timeline({"2021-06-14T00:00:00Z",
                                               "2019-02-03T00:00:00Z",
                                               "2022-11-30T00:00:00Z"}))},
    {"price",     Slate(pluss::make_series({412000.0, 268500.0, 559900.0}))},
    {"bedrooms",  Slate(pluss::make_series(std::vector<std::int64_t>{3, 2, 4}))},
    {"inspected", Slate(pluss::make_series(std::vector<bool>{true, false, true}))},
}).title("homes");

std::cout << homes.observe(1);

Example 2. A missing cell renders as <null>; negative row counts from the end.

auto with_gap = homes.assign(
    "bedrooms",
    homes.features("bedrooms").put(homes.features("home_id").eq("H-887"),
                                   pluss::null_t{}));

std::cout << with_gap.observe(-1);   // last row -> H-231
std::cout << with_gap.observe(1);    // the row whose bedrooms is now null

Example 3. The card is an ordinary DataFrameView — pull a column out to work with one feature’s value as text (handy when a long value is clipped by the display width).

auto card  = DataFrame(homes.observe(0));
auto value = card.features("value");   // a Note-kind Slate, one entry per feature
std::cout << value;

Output¶

    price  412000
 bedrooms  3
inspected  true
Name: value, ptype: Note

Example 4. Out-of-range position throws rather than clamping.

try {
  auto bad = homes.observe(9);
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

DataFrame: row index out of bounds

Notes¶

  • One card per row by design — observe has no range overload. For a contiguous window of rows as a frame, use view() or slice().

  • dtype reports the full stored type (Series<float64> etc.), not just the payload kind — enough to tell an int64 column from a float64 one, or a numeric column from a stringified Note.

  • The value column obeys the normal per-cell display width, so a very long field (a full-precision timestamp, a long string) can show clipped. Pull the column out as in Example 3 for the untruncated text.

  • The card carries the source frame’s title; observe never mutates the source.

See Also¶

  • DataFrame::head / DataFrame::tail: preview rows at the ends.

  • DataFrame::transpose: flip the whole frame, every row to a column.

  • DataFrame::case_study: select rows by position, label, or mask when the result feeds later work.

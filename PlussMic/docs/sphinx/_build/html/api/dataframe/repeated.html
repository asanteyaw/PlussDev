DataFrame::repeated¶

Back to DataFrame API Reference

Signature¶

DataFrame::repeated() const -> Thread

What It Does¶

Flags every row that belongs to a group sharing the same composite key across every feature currently on the frame — including that group’s very first occurrence, not just the ones after it. This is exactly duplicated(false, false) with its display name changed to "repeated": repeated() is what you reach for when you want “is this row part of a repeated group at all,” rather than “is this row a duplicate follower of an earlier one” (which is what duplicated()’s default keep_first = true answers instead).

repeated() carries no feature selector of its own: it always compares whole rows across every feature on the current frame, so narrow first with features() — roster.features({"student"}).repeated() — when only some features should form the composite key.

Parameters¶

None

Returns¶

Thread A boolean Series, one entry per case, labeled "repeated". true marks every row belonging to a key that occurs more than once anywhere in the frame; false marks a row whose key is unique.

Examples¶

Example 1. Flag every row belonging to a repeated student group.

using namespace pluss::table;

auto roster = DataFrame({
    {"student", Thread(pluss::make_note({"Ada", "Bola", "Ada", "Chen", "Bola"}))},
});
std::cout << roster;

Output¶

==============
     | student
--------------
0    | Ada    
1    | Bola   
2    | Ada    
3    | Chen   
4    | Bola   
--------------
[5 cs x 1 feat]

auto groups = roster.features({"student"}).repeated();
std::cout << groups;

Output¶

0  true
1  true
2  true
3  false
4  true
Name: repeated, ptype: Series

"Ada" and "Bola" each occur twice, so every row for either name is true, including case 0 and case 1 — their first appearances. "Chen" occurs only once, so case 3 is false.

Example 2. Compare against duplicated()’s default follower-only semantics on the same data.

auto followers = roster.features({"student"}).duplicated();
std::cout << followers;

Output¶

0  false
1  false
2  true
3  false
4  true
Name: duplicated, ptype: Series

duplicated()’s default (keep_first = true) marks only the second and later occurrence of each repeated name (false at cases 0 and 1, the first appearances) — repeated() marks all of them, first appearance included. The two methods answer genuinely different questions: “which rows are extras I could drop” (duplicated()) versus “which rows belong to a group that repeats at all” (repeated()).

Notes¶

  • repeated() is literally duplicated(/*keep_first=*/false, /*keep_last=*/false) under a different display name — it never has its own separate keep-policy parameters.

  • A missing value in every feature on the current frame is itself a valid “value” for grouping purposes — two rows that are both missing on every feature count as sharing a key, same as duplicated().

  • repeated() has no feature selector of its own — narrow with features() first to compare on a subset of columns.

See Also¶

  • DataFrame::duplicated: the keep-policy-driven sibling, for marking only the extras after (or before) the first occurrence.

  • DataFrame::drop_duplicates: removes duplicate rows outright instead of just flagging them.

  • DataFrame::freq: counts how many times each composite key occurs, rather than flagging individual rows.

  • DataFrame::features: narrow the frame to the feature(s) that define a “group” before calling repeated().

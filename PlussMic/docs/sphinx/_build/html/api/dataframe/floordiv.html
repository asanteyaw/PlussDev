What It Does¶

The named-method form of floor division: divide, then round down to the nearest whole number. floordiv() shares the exact same six-overload shape and alignment rules as add() and the rest of the arithmetic family, but is the one member of the family whose result is genuinely different from div()/truediv() — those two perform ordinary division, while floordiv() always floors the quotient afterward. Every example on this page uses the identical dataset and divisors as mod()’s own examples, since the two satisfy x == divisor * x.floordiv(divisor) + x.mod(divisor).

Parameters¶

other

The right-hand operand (the divisor), in one of three shapes:

  • double: one scalar divisor, applied to every numeric feature.

  • const DataFrame&: another frame supplying one divisor per cell, after the two frames are aligned.

  • const Thread&: one column of divisors, broadcast according to axis.

axis (Axis, default Axis::Feature, Thread overloads only)

  • Axis::Feature (the default): other supplies one divisor per feature.

  • Axis::Case: other supplies one divisor per case.

options (AlignOptions, optional)

Same meaning as add()’s options. Defaults to strict positional alignment (AlignBy::Pos).

Returns¶

DataFrame A new frame, same shape as the source, with every numeric feature floor-divided by other. Non-numeric features are left unchanged.

Examples¶

Example 1. Floor-divide every numeric feature by a scalar.

using namespace pluss::table;

auto counts = DataFrame({
    {"total", pluss::make_series({7.0, 9.0, 10.0})},
    {"extra", pluss::make_series({15.0, 22.0, 13.0})},
}, pluss::make_note({"a", "b", "c"}));

std::cout << counts;

Output (before)¶

====================
      | total  extra
--------------------
a     | 7      15   
b     | 9      22   
c     | 10     13   
--------------------
[3 cs x 2 feat]

auto out = counts.floordiv(2.0);
std::cout << out;

Output (after)¶

====================
      | total  extra
--------------------
a     | 3      7    
b     | 4      11   
c     | 5      6    
--------------------
[3 cs x 2 feat]

7 / 2 = 3.5 floors to 3; 10 / 2 = 5 divides evenly, so floordiv() and plain div() would agree on that one cell — compare against mod(2.0) on the same frame, which gives 0 for that same evenly-divided cell and non-zero remainders everywhere else.

Example 2. A Thread with one divisor per feature (Axis::Feature, the default) — total is floor-divided by 2, extra by 3.

auto per_feature_divisor = Thread(pluss::make_series({2.0, 3.0}));
auto out = counts.floordiv(per_feature_divisor);
std::cout << out;

Output¶

====================
      | total  extra
--------------------
a     | 3      5    
b     | 4      7    
c     | 5      4    
--------------------
[3 cs x 2 feat]

Example 3. A Thread with one divisor per case instead (Axis::Case) — row a’s divisor is 2, row b’s is 3, row c’s is 4.

auto per_case_divisor = Thread(pluss::make_series({2.0, 3.0, 4.0}));
auto out = counts.floordiv(per_case_divisor, Axis::Case);
std::cout << out;

Output¶

====================
      | total  extra
--------------------
a     | 3      7    
b     | 3      7    
c     | 2      3    
--------------------
[3 cs x 2 feat]

Example 4. Divide by another DataFrame using the default (const DataFrame&) overload — a plain positional pairing that ignores both frames’ case labels.

auto divisors = DataFrame({
    {"col1", Thread(pluss::make_series({2.0, 3.0, 4.0}))},
    {"col2", Thread(pluss::make_series({4.0, 5.0, 3.0}))},
}, Thread(pluss::make_note({"x", "y", "z"})));
std::cout << divisors;

auto out = counts.floordiv(divisors);
std::cout << out;

Output (divisors)¶

==================
      | col1  col2
------------------
x     | 2     4   
y     | 3     5   
z     | 4     3   
------------------
[3 cs x 2 feat]

Output (counts.floordiv(divisors))¶

====================
      | total  extra
--------------------
a     | 3      3    
b     | 3      4    
c     | 2      4    
--------------------
[3 cs x 2 feat]

divisors’s case labels (x, y, z) share nothing with counts’s (a, b, c); the default overload pairs purely by physical row position, regardless of what either side’s case labels say.

Example 5. The exact same divisors values, but with the case labels shuffled to c, a, b — now using AlignOptions{.align = AlignBy::Caselbl} to pair rows by case label instead of physical position.

auto divisors_by_label = DataFrame({
    {"col1", Thread(pluss::make_series({2.0, 3.0, 4.0}))},
    {"col2", Thread(pluss::make_series({4.0, 5.0, 3.0}))},
}, Thread(pluss::make_note({"c", "a", "b"})));
std::cout << divisors_by_label;

auto out = counts.floordiv(divisors_by_label, AlignOptions{.align = AlignBy::Caselbl});
std::cout << out;

Output (divisors_by_label)¶

==================
      | col1  col2
------------------
c     | 2     4   
a     | 3     5   
b     | 4     3   
------------------
[3 cs x 2 feat]

Output (counts.floordiv(divisors_by_label, Caselbl))¶

====================
      | total  extra
--------------------
a     | 2      3    
b     | 2      7    
c     | 5      3    
--------------------
[3 cs x 2 feat]

With AlignBy::Caselbl, case "a" in counts is matched to case "a" in divisors_by_label — its second physical row here (col1 = 3, col2 = 5) — giving total_a // 3 = 7 // 3 = 2 and extra_a // 5 = 15 // 5 = 3. Compare this to Example 4’s positional pairing, which matched counts’s row 0 ("a") to divisors’s row 0 ("x", col1 = 2, col2 = 4) and got a different answer (3, 3) — same underlying divisor values, different pairing rule, different result for total_a specifically (extra_a happens to agree at 3 both ways here).

Notes¶

  • Non-numeric features are always left unchanged.

  • floordiv() is the one member of this arithmetic family that differs from div()/truediv() in its actual result, not just its name — it always rounds the quotient down to the nearest whole number.

  • Shares its full overload shape, alignment semantics, and AlignOptions behavior with add(), sub(), mul(), div(), mod(), and pow().

See Also¶

  • DataFrame::div / DataFrame::truediv: ordinary division, without flooring.

  • DataFrame::mod: the remainder left over after floor division, using the identical dataset and divisors as this page’s examples.

  • DataFrame::round: round to a given decimal precision instead of always flooring.

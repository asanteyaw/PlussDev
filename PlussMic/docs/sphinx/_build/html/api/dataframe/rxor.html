DataFrame::rxor¶

Back to DataFrame API Reference

Signatures¶

DataFrame::rxor(const DataFrame& other) const -> DataFrame
DataFrame::rxor(const Thread& other) const -> DataFrame

What It Does¶

The reflected form of lxor(). Since logical XOR is commutative, frame.rxor(other) is indistinguishable from frame.lxor(other) in every observable respect — same cell values, and (for the DataFrame overload) the same case labels and title, both drawn from frame itself, exactly as lxor() documents. See rand() for the full explanation, including a note on a previous revision where the DataFrame overload’s case labels came from other instead — that has since been fixed, and rxor() shares the fix.

Parameters¶

other

const DataFrame& or const Thread& — identical shape requirements to land().

Returns¶

DataFrame A new frame holding the logical XOR of each cell against the corresponding other value, with case labels and title drawn from the frame rxor() was called on — identical in every respect to what lxor() would produce for the same arguments.

Examples¶

Example 1. rxor() and lxor() produce identical results, values and case labels both.

using namespace pluss::table;

auto left = DataFrame({
    {"a", pluss::make_series({true, false, true}, pluss::ScalarType::Bool)},
    {"b", pluss::make_series({true, true, false}, pluss::ScalarType::Bool)},
}, pluss::make_note({"p", "q", "r"}));

auto right = DataFrame({
    {"a", pluss::make_series({true, true, false}, pluss::ScalarType::Bool)},
    {"b", pluss::make_series({false, true, true}, pluss::ScalarType::Bool)},
}, pluss::make_note({"x", "y", "z"}));

auto out = left.rxor(right);
std::cout << out;

Output¶

===================
     | a      b    
-------------------
p    | false  true 
q    | true   false
r    | true   true 
-------------------
[3 cs x 2 feat]

The values match left.lxor(right) exactly, and the case labels are left’s own (p, q, r) — right’s labels (x, y, z) never appear in the result.

Example 2. XOR against a single shared Thread, applied identically to every feature — same result as left.lxor(mask).

auto mask = Thread(pluss::make_series({false, true, false}, pluss::ScalarType::Bool));
auto out_thread = left.rxor(mask);
std::cout << out_thread;

Output¶

===================
     | a     b    
-------------------
p    | true  true 
q    | true  false
r    | true  false
-------------------
[3 cs x 2 feat]

Notes¶

  • rxor() and lxor() are fully interchangeable for DataFrame arguments — same values, same case labels, same title. The reflected name exists purely for symmetry with the rest of the reflected method family, not because it produces a different result here.

  • Requires a genuine Bool scalar type on every participating Series, same as land().

See Also¶

  • DataFrame::rand: the fuller explanation of this reflected-family behavior, including a note on a previous case-label quirk that has since been fixed.

  • DataFrame::ror: the OR reflected form, sharing this same behavior.

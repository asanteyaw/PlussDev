DataFrame::truediv¶

Back to DataFrame API Reference

What It Does¶

The named-method form of elementwise division — and, verified against the underlying numeric kernel, the same operation as div(). truediv() shares the exact same overload shape and alignment rules as add() and the rest of the arithmetic family — see add()’s “What It Does” for the full explanation of the scalar/frame/Slate operand shapes and the axis/options parameters.

Important

truediv() and div() are the same operation Both names route to the identical division kernel and produce identical results for every input, including integer-typed features — neither one truncates or floors the way floordiv() does. truediv() exists as the more explicit name for readers who want it clear this is ordinary (non-floor) division; div() is the shorter alternative. There is no behavioral difference — pick whichever name reads better at the call site.

Parameters¶

other

The right-hand operand, dividing the current frame: double (broadcast scalar), const DataFrame& (aligned frame-to-frame), or const Slate& (broadcast per axis).

axis (Axis, default Axis::Feature, Slate overloads only)

Same meaning as add()’s axis: Axis::Feature (default) supplies one value per feature; Axis::Case supplies one value per case.

options (AlignOptions, optional)

Same meaning as add()’s options.

Returns¶

DataFrame A new frame, same shape as the source, with every numeric feature divided by other. Non-numeric features are left unchanged.

Examples¶

Example 1. Divide every numeric feature by a scalar.

using namespace pluss::table;

auto counts = DataFrame({
    {"total", pluss::make_series({7.0, 9.0, 10.0})},
}, pluss::make_note({"a", "b", "c"}));

auto out = counts.truediv(2.0);
std::cout << out;

Output¶

============
     | total
------------
a    | 3.5  
b    | 4.5  
c    | 5    
------------
[3 cs x 1 feat]

Example 2. div() on the same data produces the identical result.

auto out_div = counts.div(2.0);
std::cout << out_div;

Output¶

============
     | total
------------
a    | 3.5  
b    | 4.5  
c    | 5    
------------
[3 cs x 1 feat]

Notes¶

  • Non-numeric features are always left unchanged.

  • truediv() and div() are verified to be identical operations — see the note above.

  • For integer-style division that rounds down to the nearest whole number instead, use floordiv().

  • Shares its full overload shape, alignment semantics, and AlignOptions behavior with add(), sub(), mul(), floordiv(), mod(), and pow().

Signature¶

DataFrame::bounded(const WindowBoundsFn& bounds, WindowStatistic statistic = WindowStatistic::Mean, const WindowOptions& options = {}) -> DataFrame

Compute rolling-style statistics using custom row bounds generated by a callback.

DataFrame::bounded(...) is the most flexible windowing surface on DataFrame. Instead of supplying one fixed window width, you provide a callback that decides the [start, end) bounds for every row. That makes it useful for expanding windows, trailing windows, event-aligned windows, or any policy where each row chooses its own effective neighborhood.

Parameters¶

bounds

Callback that generates the per-row window boundaries.

  • It receives size, the number of rows, and the active WindowOptions.

  • It must return two equally sized vectors: starts and ends.

  • Each pair defines a half-open row interval [start, end) for the corresponding output row.

Use this when fixed-width rolling windows are not expressive enough for your policy.

statistic

Statistic to compute inside each row’s custom window.

Common choices include:

  • WindowStatistic::Mean

  • WindowStatistic::Sum

  • WindowStatistic::Minimum

  • WindowStatistic::Maximum

  • WindowStatistic::Var

  • WindowStatistic::Std

The larger the method surface here, the more important it is to choose the one that matches the interpretation you want from each window.

options

Additional windowing policy.

Important WindowOptions fields include:

  • min_count: minimum number of observed values required before the result becomes valid.

  • ddof: degrees of freedom used by variance- and standard-deviation-style statistics.

  • centered: whether the window should be interpreted as centered when a method honors that flag.

  • closure: boundary-closure policy for methods that honor interval closure.

For the most common bounded workflows, min_count is the field you will tune most often.

Returns¶

DataFrame A new frame containing the window statistic for each targeted numeric feature and each row.

The output keeps the same row count as the input.

See Also¶

  • DataFrame::window: derive several named rolling features from explicit window specs.

  • Thread::bounded: apply the same custom-bounds idea to one thread directly.

  • DataFrame::ts: open the time-series surface for time-bin resampling.

Notes¶

The callback receives the row count and the WindowOptions, then returns two vectors: starts and ends. Row i uses the half-open window [starts[i], ends[i]).

WindowStatistic controls the reduction applied inside each row’s window, such as mean, sum, minimum, maximum, variance, or standard deviation.

WindowOptions::min_count is often the most important toggle. If too few observed values fall inside one row’s window, that row’s result stays missing.

Examples¶

Example 1. Use an expanding window that starts at row 0 for every output row.

using namespace pluss::table;

auto metrics = DataFrame({
    {"sales", pluss::make_series({12.0, 27.0, 35.0, 49.0})},
    {"cost", pluss::make_series({5.0, 18.0, 33.0, 60.0})},
}).title("metrics");

auto out = metrics.bounded(
    [](std::int64_t size, const WindowOptions&) {
      std::vector<std::int64_t> starts(static_cast<std::size_t>(size), 0);
      std::vector<std::int64_t> ends;
      ends.reserve(static_cast<std::size_t>(size));
      for (std::int64_t row = 0; row < size; ++row) {
        ends.push_back(row + 1);
      }
      return std::pair{std::move(starts), std::move(ends)};
    },
    WindowStatistic::Mean);

Example 2. Use a trailing-two-row mean and require at least two observed values.

using namespace pluss::table;

auto metrics = DataFrame({
    {"sales", pluss::make_series({12.0, 27.0, 35.0, 49.0})},
    {"cost", pluss::make_series({5.0, 18.0, 33.0, 60.0})},
}).title("metrics");

auto out = metrics.bounded(
    [](std::int64_t size, const WindowOptions&) {
      std::vector<std::int64_t> starts;
      std::vector<std::int64_t> ends;
      starts.reserve(static_cast<std::size_t>(size));
      ends.reserve(static_cast<std::size_t>(size));
      for (std::int64_t row = 0; row < size; ++row) {
        starts.push_back(std::max<std::int64_t>(0, row - 1));
        ends.push_back(row + 1);
      }
      return std::pair{std::move(starts), std::move(ends)};
    },
    WindowStatistic::Mean,
    WindowOptions{.min_count = 2});

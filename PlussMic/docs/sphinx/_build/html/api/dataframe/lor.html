DataFrame::lor¶

Back to DataFrame API Reference

Signatures¶

DataFrame::lor(const DataFrame& other) const -> DataFrame
DataFrame::lor(const Thread& other) const -> DataFrame

What It Does¶

Elementwise logical OR — the same overload shape, Bool-only requirement, and positional (not case-label) matching as land(). See land()’s “What It Does” for the full explanation of the two overloads and the constraints on other.

Parameters¶

other

const DataFrame& (same feature names in order, same case count, matched positionally) or const Thread& (one boolean thread applied identically to every feature). See land() for the full breakdown.

Returns¶

DataFrame A new frame, same shape as the source, with every feature holding the logical OR of the source cell and the corresponding other value.

Examples¶

Example 1. OR two boolean frames with identical feature names, case-by-case.

using namespace pluss::table;

auto left = DataFrame({
    {"a", pluss::make_series({true, false, true}, pluss::ScalarType::Bool)},
    {"b", pluss::make_series({true, true, false}, pluss::ScalarType::Bool)},
}, pluss::make_note({"p", "q", "r"}));

auto right = DataFrame({
    {"a", pluss::make_series({true, true, false}, pluss::ScalarType::Bool)},
    {"b", pluss::make_series({false, true, true}, pluss::ScalarType::Bool)},
}, pluss::make_note({"x", "y", "z"}));

auto out = left.lor(right);
std::cout << out;

Output¶

=================
     | a     b   
-----------------
p    | true  true
q    | true  true
r    | true  true
-----------------
[3 cs x 2 feat]

Every position has at least one true operand on this particular data — feature a is true everywhere except where both sides happen to be false at once (which doesn’t occur here), and the same holds for b. OR only reports false where both operands are false at that position, which this example doesn’t happen to produce for either feature.

Notes¶

  • Requires a genuine Bool scalar type on every participating Series — see land()’s note on casting first with astype(..., pluss::ScalarType::Bool).

  • lor(const DataFrame&) matches positionally by feature name and case count only — it does not align by case label. See land() for the full explanation.

  • The reflected form ror() computes the same cell values (OR is commutative) and the same case labels and title too — ror() and lor() are fully interchangeable. See rand() for the fuller explanation, including a note on an earlier revision where this wasn’t the case.

  • DataFrame::lxor: the XOR counterpart.

  • DataFrame::ror: the reflected form.

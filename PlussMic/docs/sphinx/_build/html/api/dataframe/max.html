DataFrame::max¶

Back to DataFrame API Reference

Signature¶

DataFrame::max(Axis axis = Axis::Case, bool skipnull = true) const -> Slate

What It Does¶

Reduces every numeric feature to its largest observed value, returning one Slate whose entries line up with the frame’s numeric feature names — the same shape min(), sum(), and mean() return. Non-numeric features are skipped entirely rather than compared as an error.

Parameters¶

axis (Axis, default Axis::Case)

Reduction direction. Axis::Case (the default) reduces down each feature’s cases, producing one maximum per feature. Axis::Feature reduces across each row’s features instead, producing one value per case.

skipnull (bool, default true)

Controls how a missing value affects that feature’s result:

  • true (the default): missing values are excluded from the comparison entirely, so the maximum is whatever was actually observed.

  • false: a single missing value in a feature poisons that feature’s result, which comes back NULL.

Returns¶

Slate One entry per participating numeric feature, labeled by feature name, holding that feature’s largest observed value.

Examples¶

Example 1. Find the maximum of every numeric feature, skipping missing values (the default).

using namespace pluss::table;

auto orders = DataFrame({
    {"order_id",   Slate(pluss::make_series({101, 102, 103, 104, 105, 106}))},
    {"units",      Slate(pluss::make_series({2, 5, 1, 3, 4, 2}))},
    {"unit_price", Slate(pluss::make_series({1200.0, 45.5, 1150.0, 320.0, 42.0, std::numeric_limits<double>::quiet_NaN()}))},
    {"discount",   Slate(pluss::make_series({0.1, 0.05, std::numeric_limits<double>::quiet_NaN(), 0.08, 0.05, 0.12}))},
});

auto largest = orders.max();
std::cout << largest;

Output¶

  order_id  106
     units  5
unit_price  1200
  discount  0.12
ptype: Series

unit_price’s missing observation (case 5) is simply excluded from the comparison — its maximum of 1200 is the largest of the five values that were actually observed, not a NULL result.

Example 2. Disable null-skipping to see a missing value propagate.

auto largest_strict = orders.max(Axis::Case, false);
std::cout << largest_strict;

Output¶

  order_id  106
     units  5
unit_price  NULL
  discount  NULL
ptype: Series

With skipnull = false, unit_price and discount come back NULL entirely rather than the maximum of their remaining observed values. order_id and units, with no missing values, are unaffected either way.

Notes¶

  • max()’s result is labeled by feature name and prints like a small labeled Series, not like a row sliced from the source frame.

  • Non-numeric features never appear in the result; text and time features are not compared as an error, they are simply absent from the returned Slate.

  • max() reports the largest value, not the case it came from — pair it with arrange() or a boolean mask built from filter() if you also need the row that produced it.

See Also¶

  • DataFrame::min: the corresponding smallest observed value, sharing the same axis / skipnull shape.

  • DataFrame::describe: reports both min and max alongside several other statistics in one call.

  • DataFrame::clip: bound every numeric feature’s values into a range, rather than reporting the range’s current extremes.

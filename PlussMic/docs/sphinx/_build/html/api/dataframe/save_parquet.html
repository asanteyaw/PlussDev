DataFrame::save_parquet¶

Back to DataFrame API Reference

Signatures¶

DataFrame::save_parquet(std::string_view filepath) const -> void
DataFrame::save_parquet(std::string_view filepath, const pluss::loader::Config& config) const -> void
DataFrame::save_parquet(std::string_view filepath, std::initializer_list<pluss::loader::ConfigEntry> config_entries) const -> void

What It Does¶

Writes the frame to a Parquet file via Apache Arrow’s Parquet C++ library — compact, columnar, typed storage, the write-side counterpart to load_parquet().

Important

Requires an Arrow + Parquet C++ build Like load_parquet(), save_parquet() throws “built without parquet-cpp support” if PlussMic was compiled without the optional PLUSSMIC_HAS_PARQUET_CPP dependency.

Parameters¶

filepath (std::string_view)

Destination Parquet file path.

config (const pluss::loader::Config&) / config_entries (std::initializer_list<pluss::loader::ConfigEntry>)

Recognized keys:

  • addcases / cases / case / index (bool, default false): export the case axis as its own column, matching save_csv()’s add_cases convention.

  • caselabel / indexlabel / case_feature (std::string): column name for the exported case-axis column when the flag above is enabled.

Returns¶

void Performs the write and returns nothing.

Examples¶

Example 1. Save with the plain filepath-only overload — no case-axis column.

using namespace pluss::table;

auto orders = DataFrame({
    {"id",    Thread(pluss::make_series({101, 102, 103}))},
    {"city",  Thread(pluss::make_note({"Accra", "Tema", "Kumasi"}))},
    {"units", Thread(pluss::make_series({2, 1, 4}))},
});

orders.save_parquet("orders_out.parquet");

Resulting orders_out.parquet, shown as its logical column store:

| id  | city   | units |
| 101 | Accra  | 2     |
| 102 | Tema   | 1     |
| 103 | Kumasi | 4     |

Example 2. Export the case axis as its own named column.

orders.save_parquet("orders_with_case.parquet", {
    {"addcases", true},
    {"caselabel", std::string("case_id")},
});

Resulting orders_with_case.parquet:

| case_id | id  | city   | units |
| 0       | 101 | Accra  | 2     |
| 1       | 102 | Tema   | 1     |
| 2       | 103 | Kumasi | 4     |

Notes¶

  • Requires PlussMic to have been built with Arrow + Parquet C++ support, exactly like load_parquet(); otherwise every call throws immediately.

  • addcases/caselabel follow the same convention as save_csv()’s add_cases/case_label and save_excel()’s equivalent fields.

  • Values are written using Arrow’s own Parquet type mapping from PlussMic’s inferred Series/Note dtypes — but recall from load_parquet() that reading the file back re-infers types from stringified values rather than trusting the Parquet schema directly, so a save/load round trip is not guaranteed to preserve the exact original precision (for example, a narrower integer width).

See Also¶

  • DataFrame::load_parquet: the read-side counterpart, including the schema-discarding re-inference behavior worth knowing about before round-tripping.

  • DataFrame::save_csv: the analogous CSV writer and the fuller explanation of the add_cases/case_label convention shared across writers.

  • DataFrame::save_as: the format-switched entry point that can dispatch to save_parquet() via target_type = "parquet".

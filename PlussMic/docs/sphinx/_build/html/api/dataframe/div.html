What It Does¶

The named-method form of elementwise division. div() shares the exact same overload shape and alignment rules as add() and the rest of the arithmetic family — see add()’s “What It Does” for the full explanation of the scalar/frame/Thread operand shapes and the axis/options parameters.

Important

div() and truediv() are the same operation div() and truediv() both perform ordinary floating-point division — verified against the underlying numeric kernel, they compute identical results for every input, including integer-typed features. Neither one truncates or floors the result the way floordiv() does. Both names are provided so code reading like df.div(2) and code reading like df.truediv(2) (for readers coming from a background where “true division” is a meaningful distinction from floor division) are both available — pick whichever reads better at the call site, since there is no behavioral reason to prefer one over the other.

Parameters¶

other

The right-hand operand, dividing the current frame: double (broadcast scalar), const DataFrame& (aligned frame-to-frame), or const Thread& (broadcast per axis).

axis (Axis, default Axis::Feature, Thread overloads only)

Same meaning as add()’s axis: Axis::Feature (default) supplies one value per feature; Axis::Case supplies one value per case.

options (AlignOptions, optional)

Same meaning as add()’s options.

Returns¶

DataFrame A new frame, same shape as the source, with every numeric feature divided by other. Non-numeric features are left unchanged.

Examples¶

Example 1. Divide every numeric feature by a scalar.

using namespace pluss::table;

auto counts = DataFrame({
    {"total", pluss::make_series({7.0, 9.0, 10.0})},
}, pluss::make_note({"a", "b", "c"}));

auto out = counts.div(2.0);
std::cout << out;

Output¶

============
     | total
------------
a    | 3.5  
b    | 4.5  
c    | 5    
------------
[3 cs x 1 feat]

Example 2. truediv() on the same data produces the identical result.

auto out_truediv = counts.truediv(2.0);
std::cout << out_truediv;

Output¶

============
     | total
------------
a    | 3.5  
b    | 4.5  
c    | 5    
------------
[3 cs x 1 feat]

Example 3. Divide one frame by another elementwise, using the default positional alignment.

auto left = DataFrame({
    {"amount", Thread(pluss::make_series({100.0, 200.0, 50.0}))},
}, Thread(pluss::make_note({"a", "b", "c"})));

auto right = DataFrame({
    {"amount", Thread(pluss::make_series({4.0, 5.0, 2.0}))},
}, Thread(pluss::make_note({"x", "y", "z"})));

auto out = left.div(right);
std::cout << out;

Output¶

=============
     | amount
-------------
a    | 25    
b    | 40    
c    | 25    
-------------
[3 cs x 1 feat]

right’s case labels (x, y, z) are never consulted under the default AlignOptions{} (AlignBy::Pos): the two frames only need the same shape, and cells are paired by physical position — left’s row 0 (100) divides by right’s row 0 (4) regardless of either side’s labels — so the result keeps left’s own case labels (a, b, c).

Example 4. The Thread overload with axis passed explicitly as Axis::Feature — one divisor per feature, broadcast down every case in that column.

auto values = DataFrame({
    {"x", Thread(pluss::make_series({100.0, 200.0}))},
    {"y", Thread(pluss::make_series({50.0, 25.0}))},
}, Thread(pluss::make_note({"p", "q"})));

auto divisors = Thread(pluss::make_series({4.0, 5.0}));
auto out_thread = values.div(divisors, Axis::Feature);
std::cout << out_thread;

Output¶

=================
     | x     y   
-----------------
p    | 25    10  
q    | 50    5   
-----------------
[2 cs x 2 feat]

divisors’s two values pair up with x and y respectively: every case’s x is divided by 4 (100/4=25, 200/4=50), and every case’s y is divided by 5 (50/5=10, 25/5=5) — Axis::Feature is already the default for this overload, so passing it here changes nothing except making the broadcast direction explicit at the call site.

Notes¶

  • Non-numeric features are always left unchanged.

  • div() and truediv() are verified to be identical operations — see the note above.

  • For integer-style division that rounds down to the nearest whole number instead, use floordiv().

  • Shares its full overload shape, alignment semantics, and AlignOptions behavior with add(), sub(), mul(), floordiv(), mod(), and pow().

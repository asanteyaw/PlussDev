What It Does¶

Adds a new feature or replaces an existing one’s values through assignment-target helpers. set(name) returns a lightweight LetSlot proxy bound to *this; assigning a Thread, ThreadValue, pluss::Series/Note/Timeline/TimeIndex, or a single-feature DataFrame to that proxy mutates the calling frame in place. set({"a", "b"}) = {...} is the same idea for several features assigned together in one batch. A ThreadValue right-hand side broadcasts a single scalar to every row.

set_(name, value) is the direct one-line in-place counterpart when you do not want assignment syntax at the call site.

Parameters¶

name / names

The feature name (or names) to create or overwrite.

value / values

The replacement data: anything assignable to a LetSlot (Thread, ThreadValue, pluss::Series/Note/Timeline/TimeIndex, or a single-feature DataFrame).

options (const AlignOptions&, optional)

Controls how a right-hand Thread is aligned to the frame’s case axis when it doesn’t already match exactly.

Returns¶

LetSlot / LetSlots A proxy bound to *this; assigning to it performs the mutation and creates or overwrites the named feature(s) in place.

Examples¶

Example 1. The df.set(name) = value builder style, mutating the frame in place.

using namespace pluss::table;

auto orders = DataFrame({
    {"id",    Thread(pluss::make_series({1, 2, 3}))},
    {"sales", Thread(pluss::make_series({100.0, 120.0, 90.0}))},
    {"city",  Thread(pluss::make_note({"Accra", "Tema", "Kumasi"}))},
});

orders.set("profit") = Thread(pluss::make_series({40.0, 35.0, 30.0}));
std::cout << orders;

Output¶

==================================
     | id    sales  city    profit
----------------------------------
0    | 1     100    Accra   40    
1    | 2     120    Tema    35    
2    | 3     90     Kumasi  30    
----------------------------------
[3 cs x 4 feat]

orders itself now has a fourth feature, "profit" — set("profit") returned a LetSlot bound to orders, and assigning a Thread to it wrote the new column back into orders directly.

Example 2. Assign several new features together in one batch.

orders.set({"cost", "region"}) = {
    Thread(pluss::make_series({60.0, 85.0, 60.0})),
    Thread(pluss::make_note({"South", "North", "South"})),
};
std::cout << orders;

Output¶

================================================
     | id    sales  city    profit  cost  region
------------------------------------------------
0    | 1     100    Accra   40      60    South 
1    | 2     120    Tema    35      85    North 
2    | 3     90     Kumasi  30      60    South 
------------------------------------------------
[3 cs x 6 feat]

Both "cost" and "region" are added to orders in one call, matched to their names positionally against the right-hand {...} list.

Example 3. Overwrite an existing feature from a derived single-feature frame.

auto rebased = orders.features({"sales"}).div(10.0);
orders.set("sales") = rebased;
std::cout << orders;

Output¶

==========================
     | id    sales  city  
--------------------------
0    | 1     10     Accra 
1    | 2     12     Tema  
2    | 3     9      Kumasi
--------------------------
[3 cs x 3 feat]

Because the right-hand side has exactly one feature, set("sales") = rebased replaces the existing sales column directly.

Notes¶

  • set(...) is assignment-target only. To mutate in one call without =, use set_().

  • Assigning a ThreadValue to a LetSlot broadcasts a single scalar to every row — useful for df.set("flag") = ThreadValue(true)-style constant columns.

  • Batch-assigning with set({"a", "b"}) = {...} performs at most one schema reindex pass total, rather than one per feature — prefer it over several separate single-name assignments when setting many features at once.

See Also¶

  • DataFrame::set_: the direct one-line in-place counterpart to this page’s assignment-target form.

  • DataFrame::assign: derive new features from expressions evaluated against the frame itself, rather than assigning pre-built Threads.

  • DataFrame::insert, DataFrame::place: position a new feature at a specific index or next to a named anchor, instead of appending it.

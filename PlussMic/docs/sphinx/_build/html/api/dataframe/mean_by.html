DataFrame::mean_by¶

Back to DataFrame API Reference

Signature¶

DataFrame::mean_by(std::string_view group_feature, std::string_view value_feature, std::int64_t top_n = 0, std::int64_t min_count = 1, bool dropnull_group = true, bool render = false) const -> DataFrameView

What It Does¶

Groups rows by group_feature and computes the mean of value_feature within each group, returning a compact three-column summary (group_feature, "mean_" + value_feature, count) sorted by mean descending, ties broken alphabetically by group key. This is a focused convenience for the single most common group-and-summarize question — “what’s the average X per Y” — without building a full group() pipeline for it. count_by() is the sibling convenience for counting rows per group instead of averaging a value.

Parameters¶

group_feature (std::string_view)

The feature whose distinct values define the groups.

value_feature (std::string_view)

The numeric feature averaged within each group.

top_n (std::int64_t, default 0)

Keep only the top_n groups with the highest mean, after sorting. 0 (the default) keeps every group.

min_count (std::int64_t, default 1)

A group needs at least this many observations of value_feature to appear in the result at all; groups with fewer observations are dropped entirely, not shown with a NULL mean.

dropnull_group (bool, default true)

Whether a missing group_feature value forms its own group (false) or is excluded entirely (true, the default).

render (bool, default false)

Display toggle for the returned DataFrameView, identical in behavior to head()’s render parameter.

Returns¶

DataFrameView A frame with one row per surviving group, columns group_feature, "mean_" + value_feature, and count, sorted by mean descending (ties broken alphabetically by group key ascending).

Examples¶

Example 1. Compute the mean sales amount per region.

using namespace pluss::table;

auto sales = DataFrame({
    {"region", Thread(pluss::make_note({"East", "West", "East", "West", "East"}))},
    {"amount", Thread(pluss::make_series({100.0, 200.0, 150.0, 50.0, 90.0}))},
});
std::cout << sales;

Output (before)¶

=====================
     | region  amount
---------------------
0    | East    100   
1    | West    200   
2    | East    150   
3    | West    50    
4    | East    90    
---------------------
[5 cs x 2 feat]

auto by_region = sales.mean_by("region", "amount");
std::cout << by_region;

Output (after)¶

=================================
     | region  mean_amount  count
---------------------------------
0    | West    125          2    
1    | East    113.3333333  3    
---------------------------------
[2 cs x 3 feat]

West’s mean ((200 + 50) / 2 = 125) is higher than East’s ((100 + 150 + 90) / 3 ~= 113.33), so West sorts first.

Example 2. Use min_count to drop groups with too few observations to be meaningful.

auto sales_with_north = DataFrame({
    {"region", Thread(pluss::make_note({"East", "West", "East", "West", "East", "North"}))},
    {"amount", Thread(pluss::make_series({100.0, 200.0, 150.0, 50.0, 90.0, 500.0}))},
});

auto strict = sales_with_north.mean_by("region", "amount", 0, /*min_count=*/2);
std::cout << strict;

Output¶

=================================
     | region  mean_amount  count
---------------------------------
0    | West    125          2    
1    | East    113.3333333  3    
---------------------------------
[2 cs x 3 feat]

North has only one observation (500), which would otherwise be the highest mean by far — but min_count = 2 excludes it from the result entirely, rather than showing a mean computed from a single, potentially unrepresentative value.

Notes¶

  • The output column is always named "mean_" + value_feature (for example, mean_amount), never just the plain feature name.

  • Sorting is always mean descending, ties broken alphabetically by group key ascending — the same tie-break convention used by freq() and tally().

  • A group excluded by min_count is dropped entirely, not shown with a NULL mean — there is no way to distinguish “excluded by min_count” from “never existed” in the output alone.

See Also¶

  • DataFrame::count_by: the row-counting sibling of this method.

  • DataFrame::group: the general-purpose grouping primitive, for summaries this convenience doesn’t cover (multiple aggregates, multiple group keys).

  • DataFrame::mean: the ungrouped, whole-frame mean.

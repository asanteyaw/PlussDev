What It Does¶

The ordering relation “greater than or equal to”, returning a boolean-valued frame the same shape as the source. ge() shares the same scalar/string/DataFrame/Thread operand shapes as eq() — see eq()’s “What It Does” for the full explanation.

Important

ge() has no independent implementation Every ge() overload is a thin wrapper: frame.ge(other, ...) always calls straight through to gt(other, ..., /* strict = */ false). There is no strict parameter on ge() itself — if you need the strict “greater than” relation on the same call site, use gt() directly instead.

Parameters¶

other

The right-hand operand: double, std::string_view (Note-kind features only), const DataFrame&, or const Thread& (broadcast per axis). See eq() for the full breakdown.

axis (Axis, default Axis::Feature, Thread overloads only)

Same meaning as eq()’s axis.

options (AlignOptions, optional)

Same meaning as eq()’s options.

Returns¶

DataFrame A new frame, same shape as the source, where every feature holds true/false according to whether that cell is greater than or equal to other. A cell compared against a missing value on either side is itself missing (NULL), matching eq().

Examples¶

Example 1. “Greater than or equal to” against a scalar threshold.

using namespace pluss::table;

auto scores = DataFrame({
    {"quiz",  pluss::make_series({84.0, 90.0, 84.0})},
    {"final", pluss::make_series({84.0, 88.0, 72.0})},
}, pluss::make_note({"s1", "s2", "s3"}));

auto out = scores.ge(84.0);
std::cout << out;

Output¶

==================
     | quiz  final
------------------
s1   | true  true 
s2   | true  true 
s3   | true  false
------------------
[3 cs x 2 feat]

Every quiz value is at least 84, so that feature is all true. final fails only at s3, where 72 < 84 — the one cell that does not clear the threshold, strict or not.

Example 2. Broadcast one text value against a Note-kind feature — lexicographic comparison, same ordering std::string itself uses.

auto names = DataFrame({
    {"name", pluss::make_note({"Ada", "Bola", "Ada"})},
}, pluss::make_note({"s1", "s2", "s3"}));

auto out_names = names.ge("Bola");
std::cout << out_names;

Output¶

=============
      | name 
-------------
s1    | false
s2    | true 
s3    | false
-------------
[3 cs x 1 feat]

Only "Bola" itself clears the "Bola" threshold; "Ada" sorts before it lexicographically, so both "Ada" cases report false.

Example 3. Compare two frames cell by cell once they share the same structure.

auto changed = DataFrame({
    {"quiz",  pluss::make_series({84.0, 90.0, 83.0})},
    {"final", pluss::make_series({84.0, 88.0, 72.0})},
}, pluss::make_note({"s1", "s2", "s3"}));

auto out_frames = scores.ge(changed);
std::cout << out_frames;

Output¶

===================
      | quiz  final
-------------------
s1    | true  true 
s2    | true  true 
s3    | true  true 
-------------------
[3 cs x 2 feat]

Every cell is true here — changed only differs from scores at s3’s quiz (83 vs. 84), and scores’s 84 is still >= changed’s 83 there. Contrast this with scores.gt(changed) on the identical two frames: strict > turns every one of these equal cells to false, leaving only that one genuinely-larger cell true.

Example 4. Compare against a Thread with one value per feature — quiz checked against 84, final checked against 88.

auto thresholds = Thread(pluss::make_series({84.0, 88.0}));
auto out_thread = scores.ge(thresholds);
std::cout << out_thread;

Output¶

===================
      | quiz  final
-------------------
s1    | true  false
s2    | true  true 
s3    | true  false
-------------------
[3 cs x 2 feat]

quiz >= 84 holds everywhere; final >= 88 holds only at s2, the sole final value that reaches 88.

Notes¶

  • ge() always delegates to gt(other, false); there is no separate code path and no strict parameter on ge() itself.

  • A cell compared against a missing value on either side is NULL, not false, matching eq().

  • Shares its full comparison-family overload shape with eq(), ne(), lt(), le(), and gt().

DataFrame::save_excel¶

Back to DataFrame API Reference

Signatures¶

What It Does¶

Writes the frame to a single worksheet of an .xlsx workbook. The sheet name defaults to "Sheet1" unless you supply one (via the positional sheet_name parameter, or the sheet_name field of WriteExcelOptions/Config). As with save_csv(), the case axis is not written as its own column unless add_cases is turned on.

Parameters¶

filepath (std::string_view)

Destination .xlsx path.

sheet_name (std::string, positional overload, default "Sheet1")

Name of the worksheet to write within the workbook.

add_cases (bool, default false)

When true, the case axis is exported as its own leading column, named via case_label (or a default name if left unset) — the same convention save_csv() uses.

header (bool, default true)

Whether to write feature names as the sheet’s first row.

null_rep (std::string, default "")

Literal text written for a missing cell. Default is an empty cell.

case_label (std::optional<std::string>, default unset)

Column name for the exported case-axis column when add_cases=true.

config (const pluss::loader::Config&) / config_entries (std::initializer_list<pluss::loader::ConfigEntry>) / options (const pluss::loader::WriteExcelOptions&)

Equivalent settings expressed as a reusable config object, inline entries, or the typed WriteExcelOptions struct — recognizing the same sheet_name/add_cases (also accepted under the legacy alias cases)/header/case_label/null_rep fields as the positional overload.

Returns¶

void Performs the write and returns nothing.

Examples¶

Example 1. Save with the default sheet name ("Sheet1"), no case-axis column.

using namespace pluss::table;

auto orders = DataFrame({
    {"id",    Thread(pluss::make_series({101, 102, 103}))},
    {"city",  Thread(pluss::make_note({"Accra", "Tema", "Kumasi"}))},
    {"units", Thread(pluss::make_series({2, 1, 4}))},
});

orders.save_excel("orders_out.xlsx");

Resulting workbook orders_out.xlsx, sheet Sheet1:

| id  | city   | units |
| 101 | Accra  | 2     |
| 102 | Tema   | 1     |
| 103 | Kumasi | 4     |

Example 2. Save to a named sheet and export the case axis as its own column.

orders.save_excel("orders_with_case.xlsx", "Orders", /*add_cases=*/true,
                   /*header=*/true, /*null_rep=*/"", /*case_label=*/std::string{"case_id"});

Resulting workbook orders_with_case.xlsx, sheet Orders:

| case_id | id  | city   | units |
| 0       | 101 | Accra  | 2     |
| 1       | 102 | Tema   | 1     |
| 2       | 103 | Kumasi | 4     |

Loading this back with DataFrame::load_excel("orders_with_case.xlsx", "Orders") followed by treating case_id as the case column (via a Config/ReadExcelOptions case-column setting) restores the original case labels, the same way save_csv()/load_csv()’s case_label/case_col pair does.

Example 3. Save with a typed WriteExcelOptions struct.

pluss::loader::WriteExcelOptions options;
options.sheet_name = "Regions";
options.add_cases = true;

orders.save_excel("orders_options.xlsx", options);

Resulting workbook orders_options.xlsx, sheet Regions:

| case | id  | city   | units |
| 0    | 101 | Accra  | 2     |
| 1    | 102 | Tema   | 1     |
| 2    | 103 | Kumasi | 4     |

Since case_label wasn’t set here, the exported case column falls back to its default name ("case").

Notes¶

  • Only one sheet is written per call — there’s no multi-sheet write overload the way load_excel() has multi-sheet read overloads. Writing several sheets into one workbook means saving to the same filepath multiple times with different sheet_names and workbook-append handling managed at the file-format level, not through a single DataFrame::save_excel() call.

  • add_cases/case_label mirror save_csv()’s convention exactly — the case axis is opt-in, not written by default.

  • WriteExcelOptions accepts add_cases under the legacy field name cases as well, for compatibility with older call sites.

See Also¶

  • DataFrame::load_excel: the read-side counterpart, including the multi-sheet LoadResult return type this writer has no equivalent of.

  • DataFrame::save_csv: the analogous CSV writer and the fuller explanation of the add_cases/case_label convention shared across all writers.

  • DataFrame::save_as: the format-switched entry point that can dispatch to save_excel() via target_type = "excel"/"xlsx".

AxelCastAccessor::timeindex¶

Back to AxelCastAccessor API Reference

Signature¶

Axel AxelCastAccessor::timeindex() const

What It Does¶

Casts every bound field’s values, in every registry frame, to TimeIndex-kind and returns a new axel with those fields replaced. Applies RegistryCastAccessor::timeindex to every frame via Axel::map.

Parameters¶

None

Returns¶

Axel A new axel with every bound field, in every frame, cast to TimeIndex-kind; every unbound field unchanged.

Examples¶

Example 1. Cast a Timeline field to TimeIndex.

auto r0 = pluss::scribble::Registry({{"ts", pluss::scribble::Slot({pluss::make_timeline("2024-01-01T00:00:00Z")})}});
auto axel = pluss::scribble::Axel({r0});

auto out = axel.fields({"ts"}).cast().timeindex();
std::cout << out.registry(0).fields("ts").to_json();

Output¶

{
  "_type": "Slot",
  "defined": true,
  "size": 1,
  "values": [
    "TimeIndex[size=1]"
  ]
}

Each row’s Timeline value converts to its own single-element TimeIndex — a Slot stores one independent value per row rather than one shared column, mirroring Slot::tl().index()’s per-row behavior.

Notes¶

  • Bound via Axel::cast() — remember that entry point binds every field of every frame it’s called on, so scope it with fields(keys) first if you only want to cast some fields.

  • Whatever Slot::cast() throws for a non-Timeline-compatible source value propagates the same way here.

See Also¶

  • AxelCastAccessor::timeline: the related cast target for calendar timestamps without the sortedness requirement.

  • Axel::cast: the entry point this accessor is reached from.

  • RegistryCastAccessor::timeindex: the single-frame operation this method broadcasts.

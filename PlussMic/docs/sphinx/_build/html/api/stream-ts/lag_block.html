StreamTimeSeriesAccessor::lag_block¶

Back to StreamTimeSeriesAccessor API Reference

Signature¶

pluss::table::DataFrame StreamTimeSeriesAccessor::lag_block(pluss::msharp::RangeView::Int lags) const

What It Does¶

Computes several lag() shifts of the bound stream at once, each as its own output column named "lag" + <lag value>. Requires at least one lag.

Important

Returns a DataFrame, not a Stream Unlike every other method on this accessor except rolling_block() and calendar(), lag_block() leaves the kindle model entirely — its result is a pluss::table::DataFrame, not a Stream.

Parameters¶

lags (pluss::msharp::RangeView::Int) The lag distances to compute, in the order given. Must not be empty, or it throws.

Returns¶

pluss::table::DataFrame A new frame with one column per requested lag (named "lag1", "lag2", and so on).

Examples¶

Example 1. Compute two lags of the same stream at once.

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 15.0, 30.0}));
auto out = stream.ts().lag_block({1, 2});
std::cout << out;

Output¶

=================
     | lag1  lag2
-----------------
0    | nan   nan 
1    | 10    nan 
2    | 20    10  
3    | 15    20  
-----------------
[4 cs x 2 feat]

lag1 is the same as lag(1). lag2 is lag(2): each position now shows the value from two positions earlier.

Example 2 (edge case). An empty lags throws.

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 15.0, 30.0}));
try {
  auto out = stream.ts().lag_block({});
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n'));
}

Output¶

TimeSeriesAccessor::lag_block: expected at least one lag

Notes¶

  • See the important callout above.

  • Output columns are always named "lag" + <value> — there’s no way to customize the column names from this method directly.

  • A pre-existing missing entry in the source stream is honored in every lag column, the same as lag() itself.

See Also¶

  • StreamTimeSeriesAccessor::lag: the single-lag building block this method computes several of at once.

  • StreamTimeSeriesAccessor::rolling_block: the equivalent “several at once” pattern for rolling window statistics.

  • Stream::ts: the entry point this accessor is reached from.

  • TimeSeriesAccessor::lag_block: the underlying single-thread engine.

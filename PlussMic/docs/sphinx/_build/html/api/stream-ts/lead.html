StreamTimeSeriesAccessor::lead¶

Back to StreamTimeSeriesAccessor API Reference

Signature¶

Stream StreamTimeSeriesAccessor::lead(std::int64_t periods = 1) const

What It Does¶

Shifts the bound stream periods positions backward: out[i] = x[i + periods] where that index is in bounds, NULL otherwise. A negative periods delegates to lag() with the sign flipped.

Important

StreamTimeSeriesAccessor requires the bound stream to be numeric Series-kind Same precondition as every method on this accessor — see Stream::ts’s own important callout for the exact throw message pattern.

Parameters¶

periods (std::int64_t, default 1) The number of positions to shift backward. Negative values behave as lag(-periods) instead.

Returns¶

Stream A new stream, same length as the bound source, led by periods positions.

Examples¶

Example 1. Lead a numeric stream by one position.

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 15.0, 30.0}));
auto out = stream.ts().lead(1);
std::cout << out;

Output¶

========================================================================================================================
kindle::Stream  kind=Series  dtype=Series[float64]  records=4
label=no  mask=no  meta=0
------------------------------------------------------------------------------------------------------------------------
label        | value                                                                                                    
------------------------------------------------------------------------------------------------------------------------
0            | 20                                                                                                       
1            | 15                                                                                                       
2            | 30                                                                                                       
3            | nan                                                                                                      
========================================================================================================================

Each position now shows the next position’s value; position 3 has no successor, so it’s nan — the nan lands at the opposite end from lag().

Notes¶

  • lead(periods) with a negative periods is exactly lag(-periods).

  • A pre-existing missing entry in the source stream is honored, not just the NULLs the shift itself introduces.

  • See the important callout above.

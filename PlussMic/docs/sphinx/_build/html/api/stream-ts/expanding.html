StreamTimeSeriesAccessor::expanding¶

Back to StreamTimeSeriesAccessor API Reference

Signature¶

Stream StreamTimeSeriesAccessor::expanding(
    pluss::table::WindowStatistic statistic = pluss::table::WindowStatistic::Mean,
    const pluss::table::StatisticOptions& options = {}) const

What It Does¶

Computes a growing (expanding) window statistic: position i’s window is every position from the very start of the stream through i, so the window widens by one position at a time rather than staying a fixed size. It’s implemented as rolling() with the window fixed at the full stream length and centered = false, closure = Right.

Important

StreamTimeSeriesAccessor requires the bound stream to be numeric Series-kind Same precondition as every method on this accessor — see Stream::ts’s own important callout for the exact throw message pattern.

Parameters¶

statistic (pluss::table::WindowStatistic, default Mean) The statistic computed over each expanding window.

options (const pluss::table::StatisticOptions&) ddof (default 1), min_count (default 1).

Returns¶

Stream A new stream, same length as the bound source, holding the expanding statistic at each position.

Examples¶

Example 1. A growing mean — every position’s output is the mean of everything seen so far.

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0, 40.0}));
auto out = stream.ts().expanding();
std::cout << out;

Output¶

========================================================================================================================
kindle::Stream  kind=Series  dtype=Series[float64]  records=4
label=no  mask=yes  meta=0
------------------------------------------------------------------------------------------------------------------------
label        | value                                                                                                    
------------------------------------------------------------------------------------------------------------------------
0            | 10                                                                                                       
1            | 15                                                                                                       
2            | 20                                                                                                       
3            | 25                                                                                                       
========================================================================================================================

Position 2’s window is everything from position 0 through 2: mean(10, 20, 30) = 20.

Notes¶

  • Equivalent to rolling(max(1, size), statistic, options) with centered = false and closure = Right.

  • Var/Std additionally require the observation count to exceed ddof (default 1), independent of min_count.

  • A pre-existing missing entry in the source stream is skipped within every window that would otherwise contain it.

  • See the important callout above.

  • StreamTimeSeriesAccessor::ewm: an alternative “everything seen so far” statistic that weights recent observations more heavily instead of weighting every observation equally.

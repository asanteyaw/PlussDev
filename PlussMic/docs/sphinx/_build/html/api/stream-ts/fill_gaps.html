StreamTimeSeriesAccessor::fill_gaps¶

Back to StreamTimeSeriesAccessor API Reference

Signature¶

Stream StreamTimeSeriesAccessor::fill_gaps(
    pluss::subsp::stats::ts::GapFillMode mode = pluss::subsp::stats::ts::GapFillMode::Forward,
    std::optional<double> constant = std::nullopt) const

What It Does¶

Fills missing entries in the bound stream using one of four strategies: Forward (the default, nearest prior real value), Backward (nearest following real value), Zero (every missing position becomes 0), or Constant (every missing position becomes constant, required for this mode). A gap with no real value on the required side is left missing.

Important

StreamTimeSeriesAccessor requires the bound stream to be numeric Series-kind Same precondition as every method on this accessor — see Stream::ts’s own important callout for the exact throw message pattern.

Parameters¶

mode (pluss::subsp::stats::ts::GapFillMode, default Forward) Which fill strategy to use.

constant (std::optional<double>, default std::nullopt) The fill value for Constant. Required (throws if absent) when mode is Constant.

Returns¶

Stream A new stream, same length as the bound source, with gaps filled per mode.

Examples¶

Example 1. Forward (the default) — each gap takes the nearest prior value.

auto with_gap = pluss::kindle::Stream::from_slate(pluss::table::Slate(
    pluss::make_series({10.0, 20.0, 30.0, 40.0}),
    pluss::make_series(std::vector<bool>{true, false, true, true})));
auto out = with_gap.ts().fill_gaps();
std::cout << out;

Output¶

========================================================================================================================
kindle::Stream  kind=Series  dtype=Series[float64]  records=4
label=no  mask=no  meta=0
------------------------------------------------------------------------------------------------------------------------
label        | value                                                                                                    
------------------------------------------------------------------------------------------------------------------------
0            | 10                                                                                                       
1            | 10                                                                                                       
2            | 30                                                                                                       
3            | 40                                                                                                       
========================================================================================================================

Position 1 (masked-missing) takes position 0’s 10 — the nearest prior real value. Positions 2 and 3 were never missing, so they’re untouched.

Notes¶

  • A gap with nothing to fill from on the required side (a leading gap under Forward, a trailing gap under Backward) is left NULL rather than inventing a value.

  • GapFillMode::Constant throws "subsp::stats::ts::fill_gaps: constant mode requires a value" if constant is absent.

  • See the important callout above.

StreamTimeSeriesAccessor::grouped¶

Back to StreamTimeSeriesAccessor API Reference

Signature¶

Stream StreamTimeSeriesAccessor::grouped(
    const Stream& groups, std::int64_t window,
    pluss::table::WindowStatistic statistic = pluss::table::WindowStatistic::Mean,
    const pluss::table::WindowOptions& options = {}) const

What It Does¶

Computes the same fixed-row-count rolling window rolling() does, but restarted independently within each group — positions are partitioned by groups (compared by value, any stream kind), and within each group the rolling window only ever sees that group’s own positions, in their original relative order, never crossing a group boundary.

Every position whose groups entry is missing is treated as belonging to one single, shared “ungrouped” bucket — not its own separate group, and not excluded from the result.

Important

StreamTimeSeriesAccessor requires the bound stream to be numeric Series-kind Same precondition as every method on this accessor — see Stream::ts’s own important callout for the exact throw message pattern.

Parameters¶

groups (const Stream&) The grouping key, one entry per position, same length as the bound stream. Any stream kind; compared by value.

window (std::int64_t) The trailing window size, in positions, applied independently within each group.

statistic (pluss::table::WindowStatistic, default Mean) The statistic computed over each window — same set rolling() supports.

options (const pluss::table::WindowOptions&) Same meaning as rolling()’s fixed-window overload.

Returns¶

Stream A new stream, same length as the bound source, holding the per-group rolling statistic at each position.

Examples¶

Example 1. Two groups, each windowed independently — the window restarts at each group’s own first position, not the stream’s.

auto values = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0, 40.0, 50.0, 60.0}));
auto groups = pluss::kindle::Stream(pluss::make_note({"A", "A", "B", "B", "A", "B"}));
auto out = values.ts().grouped(groups, 2);
std::cout << out;

Output¶

========================================================================================================================
kindle::Stream  kind=Series  dtype=Series[float64]  records=6
label=no  mask=yes  meta=0
------------------------------------------------------------------------------------------------------------------------
label        | value                                                                                                    
------------------------------------------------------------------------------------------------------------------------
0            | 10                                                                                                       
1            | 15                                                                                                       
2            | 30                                                                                                       
3            | 35                                                                                                       
4            | 35                                                                                                       
5            | 50                                                                                                       
========================================================================================================================

Group "A" is positions 0, 1, 4 (values 10, 20, 50): its own rolling mean(2) is 10, 15, 35 — landing back at positions 0, 1, and 4 respectively. Group "B" is positions 2, 3, 5 (values 30, 40, 60): its rolling mean(2) is 30, 35, 50.

Notes¶

  • Groups are compared by value, not identity — any stream kind works as groups.

  • Every position with a missing groups entry shares one common bucket, windowed together in original relative order.

  • groups must be the same length as the bound stream, or it throws "Slate::grouped: group length mismatch".

  • A pre-existing missing entry in the values stream (as opposed to groups) is skipped within any window that contains it, the same as rolling().

  • See the important callout above.

Stream::kind¶

Back to Stream API Reference

Signature¶

Stream::kind() const -> StreamKind

What It Does¶

Returns which payload kind the stream currently stores, as a StreamKind enum value:

enum class StreamKind : std::uint8_t {
  Series = 0,
  Note = 1,
  Timeline = 2,
  TimeIndex = 3,
};

Important

StreamKind has no operator<< — cast to int or use ptype() for text StreamKind is a plain enum class with no stream-insertion operator defined. std::cout << stream.kind() does not compile. Use static_cast<int>(stream.kind()) for the numeric value, or ptype() for a human-readable string (“Series”, “Note”, “Timeline”, “TimeIndex”).

Parameters¶

None

Returns¶

StreamKind The payload kind — one of Series, Note, Timeline, TimeIndex.

Examples¶

Example 1. Compare kind() against a specific enumerator, and print it via static_cast.

using pluss::kindle::StreamKind;

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}));

std::cout << "is Series: " << (stream.kind() == StreamKind::Series) << "\n";
std::cout << "as int: " << static_cast<int>(stream.kind());

Output¶

is Series: 1
as int: 0

Example 2. For a human-readable name, use ptype() instead of kind().

auto note = pluss::kindle::Stream(pluss::make_note({"a", "b"}));

std::cout << "kind as int: " << static_cast<int>(note.kind()) << "\n";
std::cout << "ptype: " << note.ptype();

Output¶

kind as int: 1
ptype: Note

Notes¶

  • No operator<< — see the important callout above; this trips up a direct std::cout << stream.kind() with a wall of overload-resolution errors.

  • Requires a defined stream (defined()); throws "Stream: undefined handle" otherwise.

  • StreamKind’s four enumerators map 1:1 with Thread’s own payload kinds — a Stream always wraps exactly one of Series/Note/Timeline/TimeIndex.

See Also¶

  • Stream::ptype: the human-readable string counterpart to this enum.

  • Stream::dtype: a more specific string, including numeric sub-type for Series (e.g. "Series[float64]").

  • Stream::cast / Stream::astype: convert between kinds.

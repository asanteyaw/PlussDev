Stream::label¶

Back to Stream API Reference

Signature¶

Stream::label() const -> const std::optional<pluss::table::Thread>&

What It Does¶

Returns the stream’s row-label axis as a raw std::optional<pluss::table::Thread> — engaged when a label has been set (via a constructor’s cases argument, with_label()/with_label_(), or lbl().set()), and std::nullopt otherwise. It is the plain getter counterpart to has_label(); call has_label() first (or check .has_value()) before dereferencing with .value(), since an unset label has no fallback value here — that synthesis only happens on lbl().values()’s richer surface, not this one.

Parameters¶

None

Returns¶

const std::optional<pluss::table::Thread>& The label Thread if one is set; std::nullopt otherwise. Returned by reference — no copy is made.

Examples¶

Example 1. No label set: label() is an engaged-but-empty optional.

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}));

std::cout << stream.label().has_value();

Output¶

0

Example 2. A label set via the constructor’s cases argument is returned as-is.

auto cases = pluss::table::Thread(pluss::make_note({"a", "b", "c"}));
auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}), std::nullopt, cases);

std::cout << stream.label().value();

Output¶

0  a
1  b
2  c
ptype: Note

Example 3. Guard with has_label()/.has_value() before dereferencing — .value() on an unset label throws std::bad_optional_access, unlike lbl().values()’s silent fallback.

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}));

if (stream.label().has_value()) {
  std::cout << stream.label().value();
} else {
  std::cout << "no label set";
}

Output¶

no label set

Notes¶

  • Returns the raw optional by const& — no default-value synthesis, unlike lbl().values().

  • The returned Thread is whatever kind was originally supplied as cases — commonly Note for string labels, but any Thread payload kind is accepted.

See Also¶

  • Stream::has_label: the paired existence check — call it (or .has_value() on this method’s result) before dereferencing.

  • Stream::lbl: the fuller label accessor, whose values() always returns a displayable Stream even when no label has been set.

  • Stream::with_label: sets the value this method returns.

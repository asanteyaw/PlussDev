Stream::with_label¶

Back to Stream API Reference

Signature¶

Stream::with_label(const pluss::table::Thread& label) const -> Stream

What It Does¶

Returns a new stream carrying label as its row-label axis, leaving the receiver untouched — the immutable counterpart to with_label_(). label must be the same length as the stream’s own payload; a mismatch throws before any copy is made.

Important

label length must match the stream’s own length Unlike alignment operations (which tolerate length differences by design), with_label() requires label.size() == this->size() exactly. A mismatch throws "Stream: label axis length must match payload length" — check lengths up front if label comes from a different source than the stream’s own row count.

Parameters¶

label (const pluss::table::Thread&) The row-label axis to attach. Commonly a Note-kind thread of string labels, but any Thread payload kind is accepted. Must match the stream’s own length.

Returns¶

Stream A new stream, identical payload to the receiver, with label attached as its label axis.

Examples¶

Example 1. Attach a Note-kind label to a numeric stream.

using pluss::table::Thread;

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}));
auto labels = Thread(pluss::make_note({"a", "b", "c"}));

auto out = stream.with_label(labels);
std::cout << "original has_label: " << stream.has_label() << "\n";
std::cout << "out has_label: " << out.has_label() << "\n";
std::cout << out.label().value();

Output¶

original has_label: 0
out has_label: 1
0  a
1  b
2  c
ptype: Note

Example 2. A length mismatch throws immediately, before the receiver is touched.

using pluss::table::Thread;

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}));
auto too_short = Thread(pluss::make_note({"a", "b"}));

try {
  auto out = stream.with_label(too_short);
} catch (const std::exception& e) {
  std::cout << "threw (message starts): "
            << std::string_view(e.what()).substr(0, 51);
}

Output¶

threw (message starts): Stream: label axis length must match payload length

Notes¶

  • Requires an exact length match with the stream’s payload — see the important callout above. This is stricter than lbl().align(), which is built specifically to reconcile length/order mismatches instead of rejecting them.

  • Returns a new Stream; the receiver is unmodified. Use with_label_() to mutate in place instead.

  • The thrown exception’s .what() appends a native stack trace after the message text shown above (this build enables it for this internal validation path) — examples here show only the leading message for readability.

See Also¶

  • Stream::with_label_: the mutating in-place version of this method.

  • Stream::clear_label: remove a label axis instead of attaching one.

  • Stream::lbl.set(): the accessor-surface equivalent, accepting either a Stream or a Thread.

  • Stream::lbl.align(): reconciles length/order mismatches instead of rejecting them outright.

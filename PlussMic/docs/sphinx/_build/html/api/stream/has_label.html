Stream::has_label¶

Back to Stream API Reference

Signature¶

Stream::has_label() const -> bool

What It Does¶

Reports whether this stream carries a row-label axis — an optional pluss::table::Thread of per-row labels, set via the constructor’s cases parameter or via with_label()/Stream::lbl().set(...). Most streams don’t carry one; Stream(data) alone leaves it unset, and has_label() returns false.

Important

Two related but distinct surfaces: label()/has_label() and lbl() has_label()/label() are a plain getter pair for the raw optional label Thread — cheap, no-frills, no default-value synthesis. lbl() returns a StreamLabelAccessor with a richer surface (values(), set(), range(), reset(), align()) — notably, lbl().values() always returns something displayable, synthesizing a positional 0..n-1 range when no label has actually been set. has_label() still reports false in that synthesized case; only an explicitly set label counts.

Parameters¶

None

Returns¶

bool true if a row-label Thread has been explicitly set (via a constructor’s cases argument, with_label()/with_label_(), or lbl().set()); false otherwise, including right after lbl().reset() or clear_label().

Examples¶

Example 1. A plain stream built without a cases argument has no label.

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}));

std::cout << stream.has_label();

Output¶

0

Example 2. Passing cases to the constructor sets the label immediately.

auto cases = pluss::table::Thread(pluss::make_note({"a", "b", "c"}));
auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}), std::nullopt, cases);

std::cout << stream.has_label();

Output¶

1

Example 3. has_label() stays false even though lbl().values() already returns a displayable (synthesized) range — the two report different things.

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}));

std::cout << "has_label: " << stream.has_label() << "\n";
std::cout << stream.lbl().values();

Output¶

Notes¶

  • Cheap and side-effect-free; safe to call before deciding whether to fall back to lbl().range() for a synthesized default.

  • Mirrors has_meta()’s existence-check shape, but for the label axis instead of the free-form metadata map.

See Also¶

  • Stream::label: the paired getter — returns the actual optional label Thread this method is only checking for.

  • Stream::lbl: the fuller label accessor (values(), set(), range(), reset(), align()).

  • Stream::with_label / Stream::clear_label: set or clear the label this method reports on.

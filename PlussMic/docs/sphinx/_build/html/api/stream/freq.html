Stream::freq¶

Back to Stream API Reference

Signature¶

Stream::freq(FreqOptions options = {}) const -> Stream

struct FreqOptions {
  std::int64_t top{0};
  bool dropnull{true};
};

What It Does¶

Returns a value-counts table: one row per distinct value, sorted by descending occurrence count. The distinct values become the result’s row labels — see lbl() — and the result’s own numeric payload is each value’s occurrence count. top limits the result to the top most frequent values (0, the default, means no limit); dropnull controls whether NULL is counted as its own distinct value, same as distinct()/ndistinct().

Important

The distinct values are labels, not the payload — counts are the payload Unlike distinct() (which returns the values themselves as the payload), freq()’s returned stream has Series[int64] counts as its payload, with the original values attached via lbl() as row labels. Read a value with out.lbl().values(), not out directly, if you need the values rather than the counts.

Parameters¶

options (FreqOptions, defaults to {}) top (default 0, meaning unlimited) caps the result to the top most frequent values. dropnull (default true) controls whether NULL is counted.

Returns¶

Stream A Series[int64] stream of occurrence counts, sorted descending, with the corresponding distinct values attached as row labels.

Examples¶

Example 1. Value counts, sorted by descending frequency, values as labels.

auto mask = pluss::make_series(std::vector<bool>{true, true, true, true, false});
auto stream = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 2.0, 3.0, 1.0}), mask);

std::cout << stream.freq();

Output¶

========================================================================================================================
kindle::Stream  kind=Series  dtype=Series[int64]  records=3
label=yes  mask=no  meta=0
------------------------------------------------------------------------------------------------------------------------
label        | value                                                                                                    
------------------------------------------------------------------------------------------------------------------------
2            | 2                                                                                                        
1            | 1                                                                                                        
3            | 1                                                                                                        
========================================================================================================================

Value 2 occurs twice (the most frequent), so it sorts first; the leftmost column is the label (the original value), not a positional row index.

Example 2. top limits the result to the single most frequent value.

auto mask = pluss::make_series(std::vector<bool>{true, true, true, true, false});
auto stream = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 2.0, 3.0, 1.0}), mask);

std::cout << stream.freq(pluss::kindle::FreqOptions{.top = 1});

Output¶

========================================================================================================================
kindle::Stream  kind=Series  dtype=Series[int64]  records=1
label=yes  mask=no  meta=0
------------------------------------------------------------------------------------------------------------------------
label        | value                                                                                                    
------------------------------------------------------------------------------------------------------------------------
2            | 2                                                                                                        
========================================================================================================================

Notes¶

  • The distinct values become row labels, not the payload — see the important callout above. This is the single most important thing to know before consuming this method’s result.

  • Sorted by descending count; ties are not documented as stable in any particular secondary order — don’t rely on tie order.

  • top=0 (the default) means unlimited — every distinct value gets a row.

See Also¶

  • Stream::distinct: the distinct values themselves as the payload, with no counts.

  • Stream::ndistinct: just the total count of distinct values.

  • Stream::lbl: the accessor to read this method’s row labels (the original values) back out.

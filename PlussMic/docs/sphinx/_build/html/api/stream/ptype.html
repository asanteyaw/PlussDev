Stream::ptype¶

Back to Stream API Reference

Signature¶

Stream::ptype() const -> std::string

What It Does¶

Returns the stream’s payload kind as a human-readable string — the same information as kind(), but rendered as text ("Series", "Note", "Timeline", "TimeIndex") instead of an enum value. Unlike dtype(), it never includes a numeric sub-type: "Series", not "Series[float64]".

Parameters¶

None

Returns¶

std::string One of "Series", "Note", "Timeline", "TimeIndex".

Examples¶

Example 1. ptype() for a numeric stream is plain "Series", regardless of numeric sub-type.

auto float_stream = pluss::kindle::Stream(pluss::make_series({1.0, 2.0}));
auto int_stream = pluss::kindle::Stream(pluss::make_series(std::vector<std::int64_t>{1, 2, 3}));

std::cout << "float: " << float_stream.ptype() << "\n";
std::cout << "int: " << int_stream.ptype();

Output¶

float: Series
int: Series

Example 2. ptype() across the other three payload kinds.

auto note = pluss::kindle::Stream(pluss::make_note({"a", "b"}));
auto timeline = pluss::kindle::Stream(pluss::make_timeline({"2024-01-01T00:00:00Z"}));

std::cout << "note: " << note.ptype() << "\n";
std::cout << "timeline: " << timeline.ptype();

Output¶

note: Note
timeline: Timeline

Notes¶

  • Requires a defined stream (defined()); throws "Stream: undefined handle" otherwise.

  • Never carries numeric sub-type information — both int64 and float64 Series streams report plain "Series"; use dtype() if you need that distinction.

See Also¶

  • Stream::kind: the enum counterpart to this string, with no operator<<.

  • Stream::dtype: a more specific string, including numeric sub-type for Series streams.

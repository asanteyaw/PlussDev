Stream::lbl¶

Back to Stream API Reference

Signature¶

Stream::lbl() const -> StreamLabelAccessor

What It Does¶

The entry point into Stream’s fuller row-label surface. lbl() binds the current stream and hands back a StreamLabelAccessor:

class StreamLabelAccessor {
public:
  Stream values() const;
  bool has() const;
  Stream set(const Stream& labels) const;
  Stream set(const pluss::table::Thread& labels) const;
  Stream range() const;
  Stream reset() const;
  Stream align(const Stream& target_labels, const pluss::table::AlignOptions& options = {}) const;
  Stream align(const pluss::table::Thread& target_labels, const pluss::table::AlignOptions& options = {}) const;
};

This has no equivalent on Catalog — lbl() is Stream-specific, since row labels are a per-column (per-Stream) concept, not something that makes sense collection-wide.

Important

Two related but distinct surfaces: label()/has_label() and lbl() has_label()/label() are a plain getter pair for the raw optional label Thread — no default-value synthesis. lbl() is richer: notably, lbl().values() always returns something displayable, synthesizing a positional 0..n-1 range when no label has actually been set — where label().value() would throw std::bad_optional_access in the same situation. has_label() still reports false for the synthesized case; only an explicitly set label counts as “has a label.”

Important

set()/align() overload resolution: prefer an explicit Thread pluss::make_note(...) (and other make_* helpers) implicitly convert to both Stream and pluss::table::Thread — passing one directly to set() or align() is ambiguous and fails to compile. Wrap it explicitly: set(pluss::table::Thread(pluss::make_note({...}))). A Stream value (not a bare make_note(...) call) resolves the Stream overload cleanly with no wrapping needed.

Parameters¶

None (parameters belong to the individual StreamLabelAccessor methods, not to lbl() itself).

Returns¶

StreamLabelAccessor A binder for the current stream — call one of its methods to inspect, set, reset, or align its row-label axis.

Examples¶

Example 1. values() always returns a displayable Stream — even with no label set, it synthesizes a positional range rather than throwing or returning empty.

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}));

std::cout << "has(): " << stream.lbl().has() << "\n";
std::cout << stream.lbl().values();

Example 2. set() attaches a label; reset() clears it back to the unlabeled state (note has() goes back to false, even though values() would still show a synthesized range).

using pluss::table::Thread;

auto stream = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0}));
auto labeled = stream.lbl().set(Thread(pluss::make_note({"a", "b", "c"})));
std::cout << "labeled has(): " << labeled.lbl().has() << "\n";

auto back = labeled.lbl().reset();
std::cout << "after reset has(): " << back.lbl().has();

Output¶

labeled has(): 1
after reset has(): 0

Example 3. range() returns a fresh Stream holding the default positional labels (0..n-1) — the same values values() synthesizes when unlabeled, but as an independent value you can inspect or reuse, rather than a display fallback tied to this stream.

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}));

std::cout << stream.lbl().range();

Example 4. align(target_labels, options) reorders/relabels by case label under AlignBy::Caselbl. An unmatched target label produces NULL unless options.fill is set — identical rules to Thread::align, applied through the label accessor.

using pluss::table::Thread;
using pluss::table::AlignOptions;
using pluss::table::AlignBy;

auto labeled = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}))
                   .lbl().set(Thread(pluss::make_note({"b", "a", "c"})));

auto aligned = labeled.lbl().align(
    Thread(pluss::make_note({"a", "b", "d"})),
    AlignOptions{.align = AlignBy::Caselbl});
std::cout << aligned;

Example 5. Setting options.fill replaces the unmatched-label NULL with a scalar instead.

using pluss::table::Thread;
using pluss::table::AlignOptions;
using pluss::table::AlignBy;

auto labeled = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}))
                   .lbl().set(Thread(pluss::make_note({"b", "a", "c"})));

auto aligned = labeled.lbl().align(
    Thread(pluss::make_note({"a", "b", "d"})),
    AlignOptions{.align = AlignBy::Caselbl, .fill = -1.0});
std::cout << aligned;

Notes¶

  • lbl() alone does no work — it only binds the stream; call one of its methods to actually inspect, set, reset, or align.

  • values()/range() never throw and never return “nothing” — they synthesize a positional range when no label is set. has() is the accurate existence check; don’t infer “has a label” from values() alone.

  • set()/align() both overload on Stream vs Thread — see the second important callout above for the make_note(...) ambiguity gotcha.

  • align() follows exactly the same AlignBy/AlignOptions rules as Thread::align; see that page for the full breakdown of Caselbl/Feature/Both (note Both is rejected for a single Stream, same as for Thread).

See Also¶

  • Stream::with_label / Stream::with_label_: a narrower set-only surface, equivalent to lbl().set() but strict about length matching.

  • Stream::clear_label / Stream::clear_label_: equivalent to lbl().reset(), reached through the plain getter/setter surface.

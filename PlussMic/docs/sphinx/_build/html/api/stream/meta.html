Stream::meta¶

Back to Stream API Reference

Signatures¶

Stream::meta() const -> const std::unordered_map<std::string, std::string>&
Stream::meta(std::string_view key) const -> std::optional<std::string>

What It Does¶

Two ways to read the stream’s free-form metadata map: the no-argument overload returns the entire map by reference; the key overload returns a single value as std::optional<std::string> — engaged if key is present, std::nullopt otherwise.

Parameters¶

key (std::string_view, only for the single-key overload) The metadata key to look up.

Returns¶

const std::unordered_map<std::string, std::string>& (no-argument overload) The full metadata map, by reference — no copy is made.

std::optional<std::string> (key overload) The value for key if present; std::nullopt otherwise.

Examples¶

Example 1. Look up a single key that exists.

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}))
                   .with_meta("units", "kg");

std::cout << stream.meta("units").value();

Output¶

kg

Example 2. Looking up an absent key returns std::nullopt, not a throw.

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}));

std::cout << stream.meta("units").has_value();

Output¶

0

Example 3. The no-argument overload returns the whole map — useful for iterating every key at once.

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}))
                   .with_meta({{"units", "kg"}, {"source", "sensor"}});

std::cout << "count: " << stream.meta().size();

Output¶

count: 2

Notes¶

  • The single-key overload returns std::optional<std::string>, which has no operator<< — call .value() (after checking .has_value() or has_meta()) to print it directly, as in Example 1.

  • The no-argument overload returns const& — no copy of the map is made just to read it.

  • Requires a defined stream; throws "Stream: undefined handle" on a default-constructed Stream().

See Also¶

  • Stream::has_meta: a cheaper existence check when you don’t need the value itself.

  • Stream::with_meta / Stream::with_meta_: set the values this method reads.

  • Stream::drop_meta / Stream::drop_meta_: remove a key.

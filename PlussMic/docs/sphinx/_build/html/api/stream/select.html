What It Does¶

Chooses row-wise between whole streams, using boolean Thread masks as the conditions.

Payload selection delegates to Thread::select. If the streams carry labels, label selection is delegated a second time on the label axis so the output keeps the matching row labels too.

Notes¶

  • conditions.size() must equal choices.size().

  • All conditions must be boolean Thread masks of the same length.

  • All choices and the default must have matching payload kind.

  • If any choice carries labels, all choices and the default must carry labels.

See Also¶

  • Thread::select: the lower-level row-wise chooser this delegates to.

  • Catalog::select: the whole-catalog coordinator built on this.

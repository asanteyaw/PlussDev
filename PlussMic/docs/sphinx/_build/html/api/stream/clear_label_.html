Stream::clear_label_¶

Back to Stream API Reference

Signature¶

Stream::clear_label_() -> Stream&

What It Does¶

The mutating, in-place counterpart to clear_label(): removes the row- label axis from the receiver directly and returns a reference to *this, rather than allocating a new Stream. Like the immutable version, calling it when no label is set is a harmless no-op.

Parameters¶

None

Returns¶

Stream& A reference to *this, now with no label axis — enabling chained calls on the same object.

Examples¶

Example 1. Mutate a labeled stream in place and confirm it’s the same object.

using pluss::table::Thread;

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}))
                   .with_label(Thread(pluss::make_note({"a", "b", "c"})));

auto& ref = stream.clear_label_();
std::cout << "same object: " << (&ref == &stream) << "\n";
std::cout << "has_label after clear_label_: " << stream.has_label();

Output¶

same object: 1
has_label after clear_label_: 0

Notes¶

  • Returns *this by reference, unlike clear_label()’s fresh Stream — mutates the receiver directly.

  • Never throws, whether or not a label was set beforehand.

  • Requires a non-const Stream to call, since it mutates the receiver.

See Also¶

  • Stream::clear_label: the immutable version, returning a new Stream instead of mutating in place.

  • Stream::with_label_: the mutating counterpart for attaching a label.

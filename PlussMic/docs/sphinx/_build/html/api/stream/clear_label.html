Stream::clear_label¶

Back to Stream API Reference

Signature¶

Stream::clear_label() const -> Stream

What It Does¶

Returns a new stream with its row-label axis removed, leaving the receiver untouched — the immutable counterpart to clear_label_(). Calling it on a stream that has no label already is a harmless no-op: it returns an equivalent unlabeled stream rather than throwing.

Parameters¶

None

Returns¶

Stream A new stream, identical payload to the receiver, with no label axis.

Examples¶

Example 1. Clear a label that was previously set.

using pluss::table::Thread;

auto labeled = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}))
                   .with_label(Thread(pluss::make_note({"a", "b", "c"})));

auto cleared = labeled.clear_label();
std::cout << "labeled has_label: " << labeled.has_label() << "\n";
std::cout << "cleared has_label: " << cleared.has_label();

Output¶

labeled has_label: 1
cleared has_label: 0

Example 2. Calling it on an already-unlabeled stream is a harmless no-op.

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}));

std::cout << stream.clear_label().has_label();

Output¶

0

Notes¶

  • Safe to call unconditionally, whether or not a label is currently set — never throws.

  • Returns a new Stream; the receiver’s own label (if any) is unaffected. Use clear_label_() to mutate in place instead.

  • Equivalent in effect to lbl().reset(), reached through the plain getter/setter surface rather than the StreamLabelAccessor.

See Also¶

  • Stream::clear_label_: the mutating in-place version of this method.

  • Stream::with_label: the inverse operation — attach a label instead of removing one.

  • Stream::lbl.reset(): the accessor-surface equivalent.

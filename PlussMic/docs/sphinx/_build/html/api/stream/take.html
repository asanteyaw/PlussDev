Stream::take¶

Back to Stream API Reference

Signature¶

Stream::take(std::span<const std::int64_t> indices) const -> Stream

What It Does¶

Returns a new stream containing the rows at indices, in the order given — unlike slice(), indices need not be contiguous or increasing, and may repeat a position more than once. This makes take() the general reordering/gather primitive: use it to reorder rows, duplicate a row, or select an arbitrary, non-contiguous subset.

Parameters¶

indices (std::span<const std::int64_t>) The row positions to select, in the order they should appear in the result. Accepts anything convertible to std::span — e.g. a std::vector<std::int64_t>.

Returns¶

Stream A new stream with one row per entry in indices, in that order.

Examples¶

Example 1. Reorder and repeat positions in a single call.

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}));

std::vector<std::int64_t> picks{2, 0, 0, 1};
std::cout << stream.take(picks);

Example 2. An out-of-range index throws.

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0}));

try {
  std::vector<std::int64_t> bad{5};
  auto out = stream.take(bad);
} catch (const std::exception& e) {
  std::cout << std::string_view(e.what()).substr(0, 24);
}

Output¶

Slate: index out of bou

Notes¶

  • Order and repetition are both meaningful — the result has exactly indices.size() rows, in the order given, with duplicates preserved.

  • An out-of-range index throws "Slate: index out of bounds" — unlike head()/tail()/slice(), which clamp instead.

  • The thrown exception’s .what() appends a native stack trace after the message text shown above; examples here show only the leading message for readability.

See Also¶

  • Stream::slice: a contiguous [start, stop) range, which clamps rather than throwing on an out-of-range stop.

  • Stream::filter: select rows by a boolean mask instead of explicit positions.

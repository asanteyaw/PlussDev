Stream::fillnull¶

Back to Stream API Reference

Signatures¶

Stream::fillnull(double value) const -> Stream
Stream::fillnull(std::string_view value) const -> Stream
Stream::fillnull(const char* value) const -> Stream
Stream::fillnull(const pluss::Timeline& value) const -> Stream
Stream::fillnull(const pluss::TimeIndex& value) const -> Stream

What It Does¶

Replaces every NULL cell in the stream with value, returning a new stream. value’s C++ type must match the stream’s own payload kind exactly — double for Series, std::string_view/const char* for Note, pluss::Timeline for Timeline, pluss::TimeIndex for TimeIndex. Delegates straight to Thread::fillnull().

Important

Kind mismatch throws here — unlike Catalog::fillnull()’s silent skip Stream::fillnull() operates on a single, already-typed stream, so a kind mismatch throws immediately (e.g. calling the string_view overload on a Series-kind stream throws "Thread::fillnull(string) is only valid for Note payload"). This is the opposite of Catalog::fillnull(), which silently skips any stream whose kind doesn’t match value’s type across the whole collection — there, kind selection is the point; here, on a single stream, a mismatch is a caller error worth surfacing.

Parameters¶

value (double / std::string_view / const char* / const pluss::Timeline& / const pluss::TimeIndex&) The fill value. Its C++ type must match the stream’s payload kind — see the important callout above.

Returns¶

Stream A new stream, same kind and length as the receiver, with every NULL cell replaced by value.

Examples¶

Example 1. Fill NULL cells in a numeric stream with 0.0.

auto mask = pluss::make_series(std::vector<bool>{true, false, true});
auto stream = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0}), mask);

std::cout << stream.fillnull(0.0);

Example 3. Fill a TimeIndex-kind stream with a fixed timestamp.

auto mask = pluss::make_series(std::vector<bool>{true, false});
auto stream = pluss::kindle::Stream(
    pluss::make_timeindex({"2024-01-01T09:10:00Z", "2024-01-01T09:40:00Z"}), mask);

auto out = stream.fillnull(pluss::make_timeindex({"2024-01-01T00:00:00Z"}));
std::cout << out;

Example 4. Calling the string_view overload on a Series-kind stream throws — a kind mismatch is a hard error here, not a silent no-op.

auto mask = pluss::make_series(std::vector<bool>{true, false, true});
auto stream = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0}), mask);

try {
  auto out = stream.fillnull("nope");
} catch (const std::exception& e) {
  std::cout << std::string_view(e.what()).substr(0, 51);
}

Output¶

Thread::fillnull(string) is only valid for Note pay

Notes¶

  • value’s C++ type selects both the overload and the required payload kind — see the important callout above for what happens on a mismatch.

  • Requires a defined stream; throws "Stream: undefined handle" on a default-constructed Stream().

  • Calling fillnull() on a stream with no NULL cells is a harmless no-op — it returns an equivalent stream unchanged.

  • The thrown exception’s .what() appends a native stack trace after the message text shown above; examples here show only the leading message for readability.

See Also¶

  • Stream::ffill / Stream::bfill: fill using neighboring values instead of a fixed scalar.

  • Stream::dropnull: remove NULL rows instead of filling them.

  • Catalog::fillnull: the whole-collection counterpart, which silently skips kind-mismatched streams instead of throwing.

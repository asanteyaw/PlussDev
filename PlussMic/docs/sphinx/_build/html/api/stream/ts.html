Stream::ts¶

Back to Stream API Reference

Signature¶

StreamTimeSeriesAccessor Stream::ts() const

What It Does¶

The entry point into time-series transformations on the stream. ts() binds the current stream and hands back a StreamTimeSeriesAccessor, which exposes 17 methods: period-shift transforms (returns, log_returns, diff, lag, lead), windowed statistics (rolling — three overloads, timed, grouped, expanding, ewm, zscore_rolling), gap/alignment utilities (fill_gaps, align_to, sort), block extraction (lag_block, rolling_block), and calendar decomposition (calendar) — see the StreamTimeSeriesAccessor API Reference for every method’s own dedicated page.

Important

A much larger surface than CatalogTimeSeriesAccessor Stream::ts() exposes 17 methods — Catalog::ts() exposes only 6 (the period-shift family plus one basic rolling() overload). The extra 11 methods here (expanding, ewm, zscore_rolling, fill_gaps, align_to, lag_block, rolling_block, calendar, sort, and the axis-driven rolling()/timed()/ grouped() overloads) need a companion time axis or per-stream context that a multi-key catalog can’t supply implicitly — see Catalog::ts’s own important callout for the reverse view of this same asymmetry.

Important

Requires the stream itself to be numeric Series-kind Calling any method on this accessor with a non-numeric stream (Note, Timeline, TimeIndex) throws — the exact message names whichever method actually ran, e.g. "TimeSeriesAccessor::diff: source must be Series". Cast first with Stream::cast(ThreadCastTarget::Series) if the stream isn’t already numeric.

Parameters¶

None

Returns¶

StreamTimeSeriesAccessor A binder for the current stream — call one of its 17 methods to shift, window-aggregate, or otherwise transform the stream along a time dimension.

Examples¶

Example 1. ts().diff(1) computes the one-period absolute change — see StreamTimeSeriesAccessor::diff for this specific method’s own page.

auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 15.0}));
auto out = stream.ts().diff(1);
std::cout << out;

Example 2 (edge case). A non-numeric stream throws — see the second important callout above.

auto stream = pluss::kindle::Stream(pluss::make_note({"a", "b"}));
try {
  auto out = stream.ts().diff(1);
} catch (const pluss::Error& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n'));
}

Output¶

TimeSeriesAccessor::diff: source must be Series

Notes¶

  • Not noexcept; the returned accessor itself does no work, but every method it exposes eagerly re-checks the bound stream’s kind.

  • See the important callouts above — both the surface-size asymmetry with Catalog::ts() and the numeric-only precondition apply.

  • Requires a defined stream; throws "Stream: undefined handle" otherwise.

Stream::nt¶

Back to Stream API Reference

Signature¶

StreamNoteAccessor Stream::nt() const

What It Does¶

The entry point into text-processing operations on the stream. nt() binds the current stream and hands back a StreamNoteAccessor, which exposes 23 methods: trimming (strip, lstrip, rstrip), case conversion (lower, upper, casefold, titlecase), inspection (length, starts, ends, has, count, matches, fullmatch), splitting/extraction (findall, split, partition, indicate), and transformation (pad, chars, normalize, encode, replace) — see the StreamNoteAccessor API Reference for every method’s own dedicated page.

Important

Requires the stream itself to be Note-kind Unlike Catalog::nt(), which binds every key of a multi-key collection, Stream::nt() binds a single stream — but that stream must already be Note-kind. Calling any StreamNoteAccessor method on a Series/Timeline/ TimeIndex stream throws (the exact message names whichever method actually ran, e.g. "Thread::strip is only valid for Note payload"). Cast first with Stream::cast(ThreadCastTarget::Note) if the stream isn’t already text.

Parameters¶

None

Returns¶

StreamNoteAccessor A binder for the current stream — call one of its 23 methods to inspect or transform its text.

Examples¶

Example 1. nt().strip() trims whitespace from a Note-kind stream — see StreamNoteAccessor::strip for this specific method’s own page.

auto stream = pluss::kindle::Stream(pluss::make_note({"  Accra  ", "Tema"}));
auto out = stream.nt().strip();
std::cout << out;

Example 2 (edge case). Calling any method on this accessor with a non-Note stream throws — see the important callout above.

auto stream = pluss::kindle::Stream(pluss::make_series({1.0, 2.0}));
try {
  auto out = stream.nt().strip();
} catch (const pluss::Error& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n'));
}

Output¶

Thread::strip is only valid for Note payload

Notes¶

  • Not noexcept; the returned accessor itself does no work, but every method it exposes eagerly re-checks the bound stream’s kind.

  • See the important callout above — every one of the 23 methods on the returned accessor shares this Note-kind-required precondition.

  • Requires a defined stream; throws "Stream: undefined handle" otherwise (checked when a method is actually called, not by nt() itself).

Stream::notnull¶

Back to Stream API Reference

Signature¶

Stream::notnull() const -> Stream

What It Does¶

Returns a new Bool-dtype Series stream, same length as the receiver, marking which rows have a value — the exact logical complement of isnull(). Works uniformly across all four payload kinds; delegates to Thread::notnull().

Parameters¶

None

Returns¶

Stream A new Series-kind stream of bool values: true where the row has a value, false where it’s NULL.

Examples¶

Example 1. notnull() is the exact inverse of isnull(), row for row.

auto mask = pluss::make_series(std::vector<bool>{true, false, true, false});
auto stream = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0, 4.0}), mask);

std::cout << stream.notnull();

Output¶

========================================================================================================================
kindle::Stream  kind=Series  dtype=Series[bool]  records=4
label=no  mask=no  meta=0
------------------------------------------------------------------------------------------------------------------------
label        | value                                                                                                    
------------------------------------------------------------------------------------------------------------------------
0            | true                                                                                                     
1            | false                                                                                                    
2            | true                                                                                                     
3            | false                                                                                                    
========================================================================================================================

Notes¶

  • Works on every payload kind — no Series-only restriction.

  • The result is always Series-kind (Series[bool]), regardless of the receiver’s own kind.

  • Combine with filter() to select only the non-NULL rows: stream.filter(stream.notnull().as_series()) (see filter() for the full pattern), or use dropnull() directly for that common case.

See Also¶

  • Stream::isnull: the exact logical complement of this method.

  • Stream::dropnull: removes the rows this method marks false for, directly.

Stream::to_string¶

Back to Stream API Reference

Signature¶

Stream::to_string() const -> std::string

What It Does¶

Renders the stream’s boxed-table view as a std::string — the same rendering operator<< and show() write to a stream, minus the trailing newline those two append.

Important

Not quite byte-identical to show()/operator<< — a trailing newline show(ostream)/operator<< end their output with \n; to_string() does not. Two otherwise-identical captures differ by exactly that one trailing byte — verified directly: to_string().size() is one less than an ostringstream populated via show(). If you’re comparing rendered output across these three, account for the difference.

Parameters¶

None

Returns¶

std::string The rendered stream table, without a trailing newline.

Examples¶

Example 1. Render a stream to a string.

auto stream = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0}));

std::cout << stream.to_string();

Output¶

========================================================================================================================
kindle::Stream  kind=Series  dtype=Series[float64]  records=3
label=no  mask=no  meta=0
------------------------------------------------------------------------------------------------------------------------
label        | value                                                                                                    
------------------------------------------------------------------------------------------------------------------------
0            | 1                                                                                                        
1            | 2                                                                                                        
2            | 3                                                                                                        
========================================================================================================================

Example 2. to_string() is one byte shorter than the equivalent show() capture — the missing trailing newline.

auto stream = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0}));

auto str = stream.to_string();
std::ostringstream oss;
stream.show(oss);

std::cout << "to_string length: " << str.size() << "\n";
std::cout << "show length: " << oss.str().size();

Output¶

to_string length: 1055
show length: 1056

Notes¶

  • One byte shorter than show()/operator<<’s output — see the important callout above.

  • A distinct text representation from to_json(), which returns a structural JSON document rather than this plain-text table.

See Also¶

  • Stream::show: the same rendering, written to a stream instead of returned as a string, with a trailing newline this method omits.

  • Stream::to_json: a structural JSON dump of the same stream, distinct from this plain-text rendering.

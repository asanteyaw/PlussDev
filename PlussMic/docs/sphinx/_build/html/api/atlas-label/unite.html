AtlasLabelAccessor::unite¶

Back to AtlasLabelAccessor API Reference

Signature¶

AtlasLabelAccessor::unite(const Thread& other) const -> Thread

What It Does¶

Returns the set union of the atlas’s current depth labels and other — every distinct label that appears in either, with duplicates collapsed. This is a pure set operation: it returns a Thread of labels, not a new Atlas, and does not touch the bound atlas’s frames.

Parameters¶

other (const Thread&) The other set of labels to union with the atlas’s current depth labels.

Returns¶

Thread The union of the two label sets, named "unite".

Examples¶

Example 1. Union the depth labels of two atlases that only partially overlap.

auto q1 = pluss::table::DataFrame({
    {"sales", pluss::table::Thread(pluss::make_series({100.0, 120.0}))},
});
auto q2 = pluss::table::DataFrame({
    {"sales", pluss::table::Thread(pluss::make_series({110.0, 90.0}))},
});
auto q3 = pluss::table::DataFrame({
    {"sales", pluss::table::Thread(pluss::make_series({95.0, 130.0}))},
});
auto a1 = pluss::table::Atlas({q1, q2, q3}, pluss::table::Thread(pluss::make_note({"jan", "feb", "mar"})));
auto a2 = pluss::table::Atlas({q1, q2, q3}, pluss::table::Thread(pluss::make_note({"feb", "mar", "apr"})));

std::cout << a1.label().unite(a2.label().values());

Output¶

0  jan
1  feb
2  mar
3  apr
Name: unite, ptype: Note

Notes¶

  • Pure set operation — returns a Thread, not an Atlas; it doesn’t select or reorder the bound atlas’s own frames.

  • The result is named "unite" regardless of the input Thread’s own name.

See Also¶

  • AtlasLabelAccessor::intersect: the labels present in both sets, rather than either.

  • AtlasLabelAccessor::diff / AtlasLabelAccessor::symdiff: the one-sided and two-sided complements of this union.

  • AtlasLabelAccessor::align: apply a target label order to the bound atlas’s frames, rather than just computing a label set.

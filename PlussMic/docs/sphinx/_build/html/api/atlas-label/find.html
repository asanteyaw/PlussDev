AtlasLabelAccessor::find¶

Back to AtlasLabelAccessor API Reference

Signature¶

AtlasLabelAccessor::find(const Thread& targets) const -> Thread

What It Does¶

Looks up the position of each value in targets within the atlas’s current depth labels, returning one integer position per target, in the same order as targets.

Important

A target with no match returns -1 — it does not throw Unlike align(), which throws on an unmatched target label, find() reports a missing label as position -1 in the result rather than raising. Check for -1 in the returned Thread if you need to detect misses.

Parameters¶

targets (const Thread&) The depth-label values to look up.

Returns¶

Thread One integer position per value in targets, named "find", indexed by the target values themselves. A target with no match yields -1.

Examples¶

Example 1. Look up the positions of two known depth labels.

auto q1 = pluss::table::DataFrame({
    {"sales", pluss::table::Thread(pluss::make_series({100.0, 120.0}))},
});
auto q2 = pluss::table::DataFrame({
    {"sales", pluss::table::Thread(pluss::make_series({110.0, 90.0}))},
});
auto q3 = pluss::table::DataFrame({
    {"sales", pluss::table::Thread(pluss::make_series({95.0, 130.0}))},
});
auto atlas = pluss::table::Atlas({q1, q2, q3}, pluss::table::Thread(pluss::make_note({"jan", "feb", "mar"})));

std::cout << atlas.label().find(pluss::table::Thread(pluss::make_note({"mar", "jan"})));

Output¶

mar  2
jan  0
Name: find, ptype: Series

Example 2. A target that isn’t one of the atlas’s depth labels resolves to -1, no throw.

auto q1 = pluss::table::DataFrame({
    {"sales", pluss::table::Thread(pluss::make_series({100.0, 120.0}))},
});
auto q2 = pluss::table::DataFrame({
    {"sales", pluss::table::Thread(pluss::make_series({110.0, 90.0}))},
});
auto q3 = pluss::table::DataFrame({
    {"sales", pluss::table::Thread(pluss::make_series({95.0, 130.0}))},
});
auto atlas = pluss::table::Atlas({q1, q2, q3}, pluss::table::Thread(pluss::make_note({"jan", "feb", "mar"})));

std::cout << atlas.label().find(pluss::table::Thread(pluss::make_note({"nope"})));

Output¶

nope  -1
Name: find, ptype: Series

Notes¶

  • See the important callout above: unmatched targets yield -1, they do not throw (a real difference from align()).

  • The result’s index is the target values themselves, not 0, 1, 2, ... — see both examples.

See Also¶

  • AtlasLabelAccessor::pos: look up a single label’s position directly, without wrapping it in a Thread first.

  • AtlasLabelAccessor::align: reorder/subset the bound atlas’s frames to a target label order — throws on a miss instead of returning -1.

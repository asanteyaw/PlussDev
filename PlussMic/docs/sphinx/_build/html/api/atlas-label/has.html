AtlasLabelAccessor::has¶

Back to AtlasLabelAccessor API Reference

Signature¶

AtlasLabelAccessor::has() const -> bool

What It Does¶

Reports whether the bound atlas has depth labels set at all — the same check as Atlas::label().has().

Parameters¶

None

Returns¶

bool true if the atlas has depth labels set; false otherwise.

Examples¶

Example 1. An unlabeled atlas reports false; setting labels flips it to true.

auto f0 = pluss::table::DataFrame({
    {"id", pluss::table::Thread(pluss::make_series({1.0}))},
});
auto atlas = pluss::table::Atlas({f0});

std::cout << "has() before: " << atlas.label().has() << "\n";

auto labeled = atlas.label().set(pluss::table::Thread(pluss::make_note({"jan"})));
std::cout << "has() after: " << labeled.label().has();

Output¶

has() before: 0
has() after: 1

Notes¶

  • Never throws, regardless of whether depth labels are set.

  • Every other accessor method that reads the depth labels (values(), and the set-algebra/lookup helpers) requires has() to be true first — check it before calling them on a possibly-unlabeled atlas.

See Also¶

  • AtlasLabelAccessor::values: read the depth labels this method confirms exist.

  • AtlasLabelAccessor::set / AtlasLabelAccessor::reset: set or clear the depth labels this method checks for.

Catalog::nrecords¶

Back to Catalog API Reference

Signature¶

Catalog::nrecords() const -> std::int64_t

What It Does¶

Returns the row count shared by every stream in the catalog — but only when every stream actually agrees on that count. Unlike a DataFrame, a Catalog doesn’t enforce that all its streams have the same length; nrecords() is the strict form that asserts they do, and throws the moment it finds two streams of different lengths (“ragged”).

Important

Throws on a ragged catalog — use minrecords()/maxrecords()/tabelize() instead If the catalog’s streams don’t all have the same length, nrecords() throws rather than guessing which length is “the” record count. Use minrecords() or maxrecords() if you want a specific bound instead of an assertion, or tabelize() to align everything into a single DataFrame first. See Example 2.

Parameters¶

None

Returns¶

std::int64_t The common row count, once every stream is confirmed to share it.

Examples¶

Example 1. Every stream has the same length, so nrecords() returns that shared count.

using namespace pluss::kindle::literals;

auto ct = pluss::kindle::Catalog({
    "id"_k     = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0})),
    "metric"_k = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0})),
});

std::cout << ct.nrecords();

Output¶

3

Example 2. A ragged catalog — streams of different lengths — throws instead of guessing.

auto ragged = pluss::kindle::Catalog({
    "a"_k = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0})),
    "b"_k = pluss::kindle::Stream(pluss::make_series({1.0, 2.0})),
});

try {
  auto n = ragged.nrecords();
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Catalog::nrecords: catalog has ragged stream lengths; use minrecords()/maxrecords() or tabelize()

Notes¶

  • Throws on any length disagreement across streams — it never silently picks a “winning” length.

  • A catalog with zero streams reports nrecords() == 0 rather than throwing.

  • See minrecords()/maxrecords() for the ragged-safe alternatives, and shape() (which uses maxrecords() internally) for a ragged-safe row/stream-count summary.

See Also¶

  • Catalog::minrecords / Catalog::maxrecords: the ragged-safe bounds this method’s strict check is built from.

  • Catalog::shape: a ragged-safe (rows, streams) summary.

  • Catalog::tabelize: align a ragged catalog into a single DataFrame.

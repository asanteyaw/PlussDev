Catalog::load_csv¶

Back to Catalog API Reference

Signatures¶

static Catalog Catalog::load_csv(std::string_view filepath)
static Catalog Catalog::load_csv(std::string_view filepath, const pluss::loader::ReadCsvOptions& options)

What It Does¶

A static factory method — reads a CSV file into a new Catalog, one stream per column, with the column’s dtype inferred from its values (numeric columns become Series, everything else becomes Note).

Parameters¶

filepath (std::string_view) The CSV file to read.

options (const pluss::loader::ReadCsvOptions&, optional) Fine-grained control over parsing — delimiter detection, quoting, parallel-read thresholds, and more.

Returns¶

Catalog A new catalog with one stream per CSV column.

Examples¶

Example 1. Load a CSV file with default options.

auto ct = pluss::kindle::Catalog::load_csv("cities.csv");
std::cout << ct;

Output¶

========================================================================================================================
kindle::Catalog  keys=3
keys: [id, city, population]
------------------------------------------------------------------------------------------------------------------------
key                      | kind         | dtype            | cs      | preview                                          
------------------------------------------------------------------------------------------------------------------------
id                       | Series       | Series[int64]    | 3       | [1, 2, 3]                                        
city                     | Note         | Note             | 3       | [Accra, Tema, Kumasi]                            
population               | Series       | Series[int64]    | 3       | [2388000, 300000, 3348000]                       
========================================================================================================================

Numeric columns (id, population) are inferred as Series; the text column (city) becomes Note.

Notes¶

  • Column dtype is inferred per-column from its values, not declared up front.

  • load()("csv", filepath) is equivalent to this method’s no-options overload.

  • Catalog::load: the format-dispatching entry point this method backs.

  • Catalog::save_csv: the write-side counterpart.

Catalog::load_labeled¶

Back to Catalog API Reference

Signature¶

Catalog::load_labeled(std::string_view filepath, std::string_view label_field, const pluss::loader::ReadCsvOptions& options = {}) -> Catalog

What It Does¶

Loads a CSV catalog and uses one field as stream case labels.

Parameters¶

filepath File location to read from or write to. Use a neutral project path such as path/to/data.csv.

label_field Parameter used by this overload. The examples below show the supported call shapes and how the argument changes behavior.

options Typed loader, renderer, SQL, plotting, or policy options for this overload.

Returns¶

Catalog Value produced by this call.

Examples¶

Example 1. Pass a typed reader-options object to control file loading details.

auto out = pluss::kindle::Catalog::load_labeled("path/to/data.csv", "id");

Output¶

out.head():
id     -> Series([1, 2, 3])
metric -> Series([10.0, 20.0, 30.0])
city   -> Note(["Accra", "Tema", "Kumasi"])

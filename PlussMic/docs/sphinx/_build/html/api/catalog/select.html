What It Does¶

Chooses row-wise between whole catalogs, using boolean Thread masks as the conditions.

Every choice catalog and the default catalog must have the same keys in the same order. For each key, Catalog::select(...) delegates to Stream::select.

To keep only named keys, do not use this method anymore. Project them with keys(...).

Notes¶

  • conditions.size() must equal choices.size().

  • Every choice catalog and the default catalog must be defined.

  • Every choice catalog must match the default catalog’s key set and key order exactly.

See Also¶

  • Stream::select: the lower-level stream chooser this delegates to.

  • Catalog::keys: projection by key selection.

  • Catalog::drop: remove named streams from one catalog.

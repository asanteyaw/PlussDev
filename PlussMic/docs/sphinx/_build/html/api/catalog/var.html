What It Does¶

Computes variance either per stream (ReduceAxis::Record) or across the selected numeric keys row-by-row (ReduceAxis::Key).

Options¶

CatalogReduceOptions::unbiased controls the divisor:

  • true uses sample variance (ddof = 1)

  • false uses population variance (ddof = 0)

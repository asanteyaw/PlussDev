Catalog::load_streams¶

Back to Catalog API Reference

Signature¶

Catalog::load_streams(std::string_view directory) -> Catalog

What It Does¶

Loads the object from disk using the corresponding PlussMic loader route.

Parameters¶

directory Parameter used by this overload. The examples below show the supported call shapes and how the argument changes behavior.

Returns¶

Catalog Value produced by this call.

Examples¶

Example 1. Use the overload whose parameter combination matches the data you already have and the amount of control you want over the result.

auto out = pluss::kindle::Catalog::load_streams("path/to/data.csv");

Catalog::to_string¶

Back to Catalog API Reference

Signature¶

Catalog::to_string() const -> std::string

What It Does¶

Renders the catalog’s ASCII-table view as a std::string — the same rendering operator<<, display(), info(), and show() all write to a stream; to_string() returns it instead.

Parameters¶

None

Returns¶

std::string The rendered catalog table.

Examples¶

Example 1. Render a catalog to a string.

using namespace pluss::kindle::literals;

auto ct = pluss::kindle::Catalog({
    "id"_k = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0})),
});

auto out = ct.to_string();
std::cout << out;

Output¶

========================================================================================================================
kindle::Catalog  keys=1
keys: [id]
------------------------------------------------------------------------------------------------------------------------
key                      | kind         | dtype            | cs      | preview                                          
------------------------------------------------------------------------------------------------------------------------
id                       | Series       | Series[float64]  | 3       | [1, 2, 3]                                        
========================================================================================================================

Notes¶

  • Same rendering as operator<</display()/info()/ show() — see display()’s important callout for how these all relate — but not quite byte-identical: show()/operator<< append a trailing newline that to_string() does not have. Verified directly: to_string() is one byte shorter than an ostringstream populated via show() for the same catalog.

  • A distinct text representation from to_json(), which returns a structural JSON document rather than this plain-text table.

See Also¶

  • Catalog::show: the same rendering, written to a stream instead of returned as a string, with a trailing newline this method omits.

  • Catalog::to_json: a structural JSON dump of the same catalog, distinct from this plain-text rendering.

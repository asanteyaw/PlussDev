Catalog::astype¶

Back to Catalog API Reference

Signature¶

Catalog::astype(pluss::codem::ScalarType dtype) const -> Catalog

What It Does¶

A single-argument shorthand for cast(), applied across every stream: astype(dtype) is exactly cast(ThreadCastTarget::Series, {.series_dtype = dtype}). Everything documented on cast()’s page — including the important callout that it applies uniformly to every stream, not just the ones that obviously need it — applies here too.

Parameters¶

dtype (pluss::codem::ScalarType) The target scalar dtype for every stream’s numeric conversion.

Returns¶

Catalog A new catalog with every stream cast to Series at the requested dtype.

Examples¶

Example 1. Parse Note-kind numeric text into Int64.

using namespace pluss::kindle::literals;

auto ct = pluss::kindle::Catalog({
    "id"_k = pluss::kindle::Stream(pluss::make_note({"1", "2", "3"})),
});

auto out = ct.astype(pluss::codem::ScalarType::Int64);
std::cout << out;

Output¶

========================================================================================================================
kindle::Catalog  keys=1
keys: [id]
------------------------------------------------------------------------------------------------------------------------
key                      | kind         | dtype            | cs      | preview                                          
------------------------------------------------------------------------------------------------------------------------
id                       | Series       | Series[int64]    | 3       | [1, 2, 3]                                        
========================================================================================================================

Notes¶

  • A thin shorthand for cast() — see that page for the full conversion rules and the important callout about applying to every stream unconditionally.

  • Always targets Series — use cast() directly for Note/Timeline/ TimeIndex targets.

See Also¶

  • Catalog::cast: the full, target-configurable casting method this is a shorthand for.

  • Thread::astype: the underlying single-stream conversion this method applies uniformly.

Catalog::transform¶

Back to Catalog API Reference

Signature¶

Catalog::transform(const std::function<Stream(const Stream&)>& fn) const -> Catalog

What It Does¶

Transforms every stream in the catalog and returns the updated catalog. This is the whole-catalog root transform surface: one callback, called once per stream, with the replacement stream returned directly.

Important

Whole-catalog transform only Scoped transforms no longer live on the root Catalog surface. If you want to transform only some keys, select them first with keys(...) and then call map(...) on the accessor.

Parameters¶

fn (const std::function<Stream(const Stream&)>&) Called once per stream; must return a defined Stream of the same length as its input.

Returns¶

Catalog A new catalog with every stream replaced by fn’s result.

Examples¶

Example 1. Transform every stream.

using namespace pluss::kindle::literals;

auto ct = pluss::kindle::Catalog({
    "id"_k     = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0})),
    "metric"_k = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0})),
});

auto out = ct.transform([](const pluss::kindle::Stream& s) {
  if (s.kind() != pluss::kindle::StreamKind::Series) return s;
  return pluss::kindle::Stream(s.as_series() + 1.0);
});
std::cout << out;

Notes¶

  • Every returned stream must be defined and the same length as its input.

  • map() is a pure alias for this const-returning method.

  • map_() is the in-place sibling when you want to mutate the catalog object itself rather than receive a transformed copy.

  • For scoped transforms, use keys(...) followed by map(...) on the accessor.

See Also¶

  • Catalog::map: a pure alias for the one-argument overload.

  • Catalog::map_: the in-place sibling of this transform surface.

  • Catalog::keys: select one or more keys, then transform only that selection with accessor map(...).

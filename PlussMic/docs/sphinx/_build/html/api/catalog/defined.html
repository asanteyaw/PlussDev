Catalog::defined¶

Back to Catalog API Reference

Signature¶

Catalog::defined() const noexcept -> bool

What It Does¶

Reports whether the catalog owns a concrete backing handle at all — the same undefined/defined distinction Thread::defined() and DataFrame::defined() make. A default-constructed Catalog is undefined; almost every other method throws "Catalog: undefined handle" if called on one. A Catalog built from an explicit (even empty) stream list is defined — defined() is about handle existence, not about whether the catalog has any streams. See the important callout below.

Important

An empty-but-defined catalog is different from an undefined one Catalog{} (default-constructed) is undefined — defined() is false, and calling almost anything else on it throws. Catalog(std::vector<std::pair<std::string, Stream>>{}) (an explicit, zero-length stream list) is defined but empty — defined() is true, empty() is also true, and every introspection method works normally, reporting zero streams. See Example 3.

Parameters¶

None

Returns¶

bool true if the catalog owns a backing handle; false for a default-constructed (moved-from, or otherwise handle-less) catalog.

Examples¶

Example 1. A catalog built from named streams is defined.

using namespace pluss::kindle::literals;

auto ct = pluss::kindle::Catalog({
    "id"_k     = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0})),
    "metric"_k = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0})),
});

std::cout << std::boolalpha << ct.defined();

Output¶

true

Example 2. A default-constructed catalog is undefined, and most other methods throw when called on it.

pluss::kindle::Catalog ct;
std::cout << std::boolalpha << ct.defined() << "\n";

try {
  auto n = ct.nkeys();
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

false
Catalog: undefined handle

Example 3. An explicitly empty stream list produces a defined catalog with zero streams — not an undefined one. Compare with Example 2.

pluss::kindle::Catalog ct(std::vector<std::pair<std::string, pluss::kindle::Stream>>{});
std::cout << std::boolalpha << ct.defined() << "\n";
std::cout << std::boolalpha << ct.empty() << "\n";
std::cout << ct.nkeys();

Output¶

true
true
0

Notes¶

  • noexcept: safe to call on any catalog, including an undefined one.

  • Undefined is not the same as empty — see the important callout above and Example 3.

  • Almost every other Catalog method throws "Catalog: undefined handle" when called on an undefined catalog; check defined() first if you’re unsure of a catalog’s origin.

See Also¶

  • Catalog::empty: whether a defined catalog has zero streams — a different question from whether it’s defined at all.

  • Catalog::unique: whether this catalog is the sole owner of its backing storage, a separate question from whether that storage exists.

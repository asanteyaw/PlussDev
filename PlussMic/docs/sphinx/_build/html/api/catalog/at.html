Catalog::at¶

Back to Catalog API Reference

Signature¶

Catalog::at(std::string_view key) const -> Stream

What It Does¶

Fetches the named stream directly, by exact key match — the throwing counterpart to get(), for when a missing key genuinely represents a programming error you want to fail loudly on, rather than a case to handle gracefully.

Parameters¶

key (std::string_view) The stream name to fetch. Must exist exactly (case-sensitive) — see has() to check first without risking a throw.

Returns¶

Stream The stream stored under key.

Examples¶

Example 1. Fetch an existing stream by name.

using namespace pluss::kindle::literals;

auto ct = pluss::kindle::Catalog({
    "id"_k     = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0})),
    "metric"_k = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 30.0})),
});

auto out = ct.at("metric");
std::cout << out;

Output¶

========================================================================================================================
kindle::Stream  kind=Series  dtype=Series[float64]  records=3
label=no  mask=no  meta=0
------------------------------------------------------------------------------------------------------------------------
label        | value                                                                                                    
------------------------------------------------------------------------------------------------------------------------
0            | 10                                                                                                       
1            | 20                                                                                                       
2            | 30                                                                                                       
========================================================================================================================

Example 2. Fetching a missing key throws.

auto ct = pluss::kindle::Catalog({
    "id"_k = pluss::kindle::Stream(pluss::make_series({1.0, 2.0, 3.0})),
});

try {
  auto out = ct.at("zzz");
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Catalog: key 'zzz' not found

Notes¶

  • Throws on a missing key — use get() instead if a missing key is an expected, handleable case rather than an error.

  • Key comparison is exact and case-sensitive, same as has().

  • Returns a Stream by value — Stream itself is a cheap, copy-on-write handle, so this is not an expensive copy of the underlying data.

See Also¶

  • Catalog::get: the non-throwing counterpart, returning std::optional<Stream>.

  • Catalog::has: check for a key’s existence without fetching anything.

  • Catalog::keys: the name-argument overloads select one or more streams for further transformation, rather than fetching a single Stream directly.

Catalog::load_txt¶

Back to Catalog API Reference

Signatures¶

static Catalog Catalog::load_txt(std::string_view filepath)
static Catalog Catalog::load_txt(std::string_view filepath, const pluss::loader::Config& config)

What It Does¶

Loads a delimited text file (tab-separated by default, with the same auto-detecting parser load_csv() uses under the hood) into a new Catalog, one stream per column, with per-column dtype inference.

Parameters¶

filepath (std::string_view) The text file to read.

config (const pluss::loader::Config&, optional) A generic configuration bundle, translated into the underlying CSV-style reader options.

Returns¶

Catalog A new catalog with one stream per column.

Examples¶

Example 1. Load a tab-separated text file.

auto ct = pluss::kindle::Catalog::load_txt("cities.txt");
std::cout << ct;

Output¶

========================================================================================================================
kindle::Catalog  keys=3
keys: [id, city, population]
------------------------------------------------------------------------------------------------------------------------
key                      | kind         | dtype            | cs      | preview                                          
------------------------------------------------------------------------------------------------------------------------
id                       | Series       | Series[int64]    | 3       | [1, 2, 3]                                        
city                     | Note         | Note             | 3       | [Accra, Tema, Kumasi]                            
population               | Series       | Series[int64]    | 3       | [2388000, 300000, 3348000]                       
========================================================================================================================

Notes¶

  • Shares its parsing engine with load_csv(), just with a text-file-style default separator rather than comma.

  • Column dtype is inferred per-column from its values.

  • load()("txt", filepath) (or "text") is equivalent to this method’s no-config overload.

See Also¶

  • Catalog::load_csv: the comma-delimited counterpart, sharing the same underlying parser.

  • Catalog::save_txt: the write-side counterpart.

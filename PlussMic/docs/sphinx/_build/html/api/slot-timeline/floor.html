SlotTimelineAccessor::floor¶

Back to SlotTimelineAccessor API Reference

Signature¶

Slot SlotTimelineAccessor::floor(std::string_view unit) const

What It Does¶

Rounds each value in the bound slot down to the nearest unit boundary, replacing each Timeline value’s values in place (stays Timeline-kind).

Parameters¶

unit (std::string_view) One of "S"/"s"/"sec"/"second", "min"/"m"/"minute", "H"/"h"/"hour", or "D"/"d"/"day". Cannot be empty.

Returns¶

Slot A new slot with each value floored to unit.

Examples¶

Example 1. Floor two timestamps to the nearest hour.

auto slot = pluss::scribble::Slot({pluss::make_timeline("2024-01-31T09:15:30Z"), pluss::make_timeline("2024-02-29T23:45:00Z")});
auto out = slot.tl().floor("H");
auto fmted = out.tl().fmt("%Y-%m-%d %H:%M:%S");
std::cout << std::get<pluss::Note>(fmted.at(0)).at(0) << " | "
          << std::get<pluss::Note>(fmted.at(1)).at(0);

Output¶

2024-01-31 09:00:00 | 2024-02-29 23:00:00

Example 2. An unsupported unit throws.

auto slot = pluss::scribble::Slot({pluss::make_timeline("2024-01-31T09:15:30Z")});
try {
  auto out = slot.tl().floor("bogus");
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n'));
}

Output¶

Timeline: unsupported unit (expected S/min/H/D)

Notes¶

  • unit cannot be empty, and only accepts the fixed clock units listed above.

  • Requires the slot to be Timeline-kind — a non-Timeline slot throws "Slot::tl: slot kind must be Timeline".

See Also¶

  • SlotTimelineAccessor::ceil / round(): round up, or to the nearest boundary, instead of always down.

  • SlotTimelineAccessor::date: shorthand for floor("D").

  • Slot::tl: the entry point this accessor is reached from.

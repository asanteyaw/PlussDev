SlotTimelineAccessor::minute¶

Back to SlotTimelineAccessor API Reference

Signature¶

Slot SlotTimelineAccessor::minute() const

What It Does¶

Extracts the minute-of-hour (0-59) of each value in the bound slot, replacing each Timeline value with an Int64 Series.

Parameters¶

None

Returns¶

Slot A new Series[int64] slot of minute numbers.

Examples¶

Example 1. Extract the minute component from two timestamps.

auto slot = pluss::scribble::Slot({pluss::make_timeline("2024-01-31T09:15:30Z"), pluss::make_timeline("2024-02-29T23:45:00Z")});
auto out = slot.tl().minute();
std::cout << std::get<pluss::Series>(out.at(0)).to_vec<std::int64_t>()[0] << " "
          << std::get<pluss::Series>(out.at(1)).to_vec<std::int64_t>()[0];

Output¶

15 45

Notes¶

  • Reads local calendar fields relative to whatever timezone the value currently carries.

  • Requires the slot to be Timeline-kind — a non-Timeline slot throws "Slot::tl: slot kind must be Timeline".

See Also¶

  • SlotTimelineAccessor::hour / second(): the neighboring time-of-day components.

  • SlotTimelineAccessor::time: the whole time-of-day portion at once.

  • Slot::tl: the entry point this accessor is reached from.

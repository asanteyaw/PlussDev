Slate::repeated¶

Back to Slate API Reference

Signature¶

Slate::repeated() const -> Slate

What It Does¶

Returns a boolean slate, the same length as the source, marking every entry whose value occurs more than once — including the occurrence that duplicated() would leave unmarked as the “survivor.” Where duplicated() answers “which entries are extra copies to drop,” repeated() answers “which entries belong to a repeated group at all.” For values [A, B, A, C, B], repeated() marks [true, true, true, false, true] — both As and both Bs are true, C (unique) is false — whereas duplicated() with the default policy would mark only the second A and second B ([false, false, true, false, true]).

Parameters¶

None

Returns¶

Slate A boolean Series, same length as the source, true at every position whose value occurs more than once anywhere in the slate.

Examples¶

Example 1. Mark every member of a repeated value’s group.

using namespace pluss::table;

auto cities = Slate(pluss::make_note({"Accra", "Tema", "Accra", "Kumasi", "Tema"}));
auto out = cities.repeated();
std::cout << out;

Output¶

0  true
1  true
2  true
3  false
4  true

ptype: Series

Both "Accra" occurrences (positions 0, 2) and both "Tema" occurrences (positions 1, 4) are true. Only "Kumasi" (unique) is false.

Notes¶

  • Grouping is by each value’s string form, matching distinct()/duplicated()/freq(); works across every payload kind.

  • Marks the whole repeated group, unlike duplicated(), which leaves one designated survivor per group unmarked.

See Also¶

  • Slate::duplicated: mark only the extra occurrences under a keep-first/keep-last policy, leaving one survivor per group unmarked.

  • Slate::distinct: the deduplicated values themselves.

  • Slate::filter: apply the mask this method returns to actually select the repeated rows.

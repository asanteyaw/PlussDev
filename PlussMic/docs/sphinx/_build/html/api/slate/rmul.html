Slate::rmul¶

Back to Slate API Reference

Signatures¶

Slate::rmul(double other) const -> Slate
Slate::rmul(const Slate& other) const -> Slate

What It Does¶

The reflected form of mul(). Multiplication is commutative, so rmul() and mul() always agree — including for Note-slate repetition, since the repetition special case never inspects operand order.

Parameters¶

other (double or const Slate&)

Same shape as mul().

Returns¶

Slate Identical to what mul() would produce for the same arguments.

Examples¶

Example 1. rmul() and mul() agree, for numbers and for Note repetition alike.

using namespace pluss::table;

auto prices = Slate(pluss::make_series({10.0, 20.0, 30.0}));
auto word = Slate(pluss::make_note({"ab", "xy", "q"}));

std::cout << prices.rmul(2.0) << "\n" << word.rmul(3.0);

Output¶

0  20
1  40
2  60

ptype: Series
0  ababab
1  xyxyxy
2  qqq

ptype: Note

Both match prices.mul(2.0) and word.mul(3.0) exactly.

Notes¶

  • rmul() exists purely for API symmetry with the rest of the reflected family — there is no case where it behaves differently from mul().

See Also¶

  • Slate::mul: the forward form, and the full documentation of the Note-repetition special case.

Slate::upper¶

Back to Slate API Reference

Signature¶

Slate::upper() const -> Slate

What It Does¶

Uppercases every character in a Note (string) thread’s cells — the mirror image of lower(). Common uses include normalizing free-typed codes or abbreviations before comparing or grouping by them. Requires the thread to be Note-kind.

Note

ASCII vs. Unicode case mapping Exactly the same caveat as lower(): ASCII a-z mapping is always available; correct handling of accented or non-Latin uppercase mapping depends on whether this build links the optional Unicode backend.

Parameters¶

None

Returns¶

Slate A new Note-kind thread, same length as *this, with every character uppercased; non-alphabetic characters are left exactly as they were.

Examples¶

Example 1. Uppercase a text thread.

using namespace pluss::table;

auto codes = Slate(pluss::make_note({"gh-001", "Gh-002", "GH-003"}));
auto out = codes.upper();
std::cout << out;

Output¶

0  GH-001
1  GH-002
2  GH-003

ptype: Note

"gh", "Gh", and "GH" all normalize to the same "GH" — the hyphen and digits are untouched throughout, since upper() only ever changes letters.

Example 2. A non-Note thread throws.

auto numbers = Slate(pluss::make_series({1.0, 2.0, 3.0}));
try {
  auto bad = numbers.upper();
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n')) << "\n";
}

Output¶

Slate::upper: expected Note payload

Notes¶

  • A null cell on input stays null on output.

  • For the opposite transform, see lower().

See Also¶

  • Slate::lower: the inverse transform.

  • Slate::casefold: case folding intended for comparison rather than display.

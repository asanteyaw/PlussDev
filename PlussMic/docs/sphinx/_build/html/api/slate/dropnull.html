Slate::dropnull¶

Back to Slate API Reference

Signature¶

Slate::dropnull() const -> Slate

What It Does¶

Returns a new, compacted slate containing only the entries not marked missing by the validity mask. If the slate carries no validity mask at all, this is a no-op — the slate is returned unchanged (there’s nothing to drop). Otherwise, it gathers the indices of every valid entry and calls take() with them, so the result is a genuinely shorter slate (no null holes left in place) rather than the original length with gaps. The result never carries a leftover validity mask, even if take()’s bookkeeping would otherwise attach one — dropnull() explicitly clears it, so a fully-valid result reports no mask at all.

Note

mask-driven, not NaN-driven dropnull() inspects the slate’s validity mask only. A plain NaN inside a numeric Series is not, by itself, “missing” to dropnull() unless that position is also marked invalid in the mask — see isnull() for the same mask-vs-NaN distinction.

Parameters¶

None

Returns¶

Slate A new slate holding only the valid entries, compacted (re-indexed from 0), with no validity mask attached.

Examples¶

Example 1. Drop the entries marked missing.

using namespace pluss::table;

auto values = Slate(
    pluss::make_series({10.0, 20.0, 30.0, 40.0}),
    pluss::make_series(std::vector<bool>{true, false, true, false})
);
auto out = values.dropnull();
std::cout << out;

Output¶

0  10
1  30

ptype: Series

Only the two entries marked valid (positions 0 and 2) survive, and the result is re-indexed from 0 — not left with gaps at the old positions 1/3.

Example 2. No validity mask at all is a no-op — the slate comes back unchanged.

auto plain = Slate(pluss::make_series({1.0, 2.0, 3.0}));
auto out2 = plain.dropnull();
std::cout << out2.size();

Output¶

3

Example 3. Every entry marked invalid drops the whole slate to empty.

auto all_missing = Slate(
    pluss::make_series({1.0, 2.0, 3.0}),
    pluss::make_series(std::vector<bool>{false, false, false})
);
auto out3 = all_missing.dropnull();
std::cout << out3;

Output¶

ptype: Series

Notes¶

  • No-op when there’s no validity mask — returns the slate unchanged, not a copy with a fresh empty mask.

  • The result is compacted: surviving entries are re-indexed, never left with holes at their old positions.

  • The result never carries a leftover validity mask, even when every surviving entry happens to be valid.

  • Driven entirely by the validity mask, not by NaN/sentinel values inside the payload — see the note above.

See Also¶

  • Slate::isnull / Slate::notnull: inspect the mask without dropping anything.

  • Slate::fillnull: replace missing entries instead of removing them.

  • Slate::take: the underlying selection mechanism this method uses.

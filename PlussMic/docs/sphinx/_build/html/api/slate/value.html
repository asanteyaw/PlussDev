Slate::value¶

Back to Slate API Reference

Signature¶

Slate::value() const -> SlateValue

What It Does¶

Wraps *this in a SlateValue — a lightweight box around a whole Slate that adds typed scalar-extraction helpers (to_dbl(), to_int(), to_str(), host()) and implicit conversions to the underlying payload types (pluss::Series, pluss::Note, pluss::Timeline, pluss::TimeIndex). value() itself does not reduce or require a single-element slate — it wraps the slate as-is, at whatever length it already has. The reduction methods (sum(), mean(), min(), and the rest) also return SlateValue, typically already length-1 after their own reduction; value() is the direct way to get the same box type around a slate you already have, without any reduction step.

Important

Scalar accessors require exactly one element to_dbl(), to_int(), to_str(), and host() all check that the wrapped slate has size() == 1, throwing "SlateValue::host: Slate payload must contain exactly one value" otherwise. Calling .value() on a multi-element slate is legal; calling .to_dbl() on the result of that isn’t. See Example 3.

Parameters¶

None

Returns¶

SlateValue A box around *this, same length and kind as the source slate.

Examples¶

Example 1. Wrap a single-element slate and pull out its scalar value.

using namespace pluss::table;

auto single = Slate(pluss::make_series({42.0}));
auto boxed = single.value();
std::cout << boxed.to_dbl();

Output¶

42

Example 2. value() works on Note-kind slates too, via to_str().

auto label = Slate(pluss::make_note({"Accra"}));
std::cout << label.value().to_str();

Output¶

Accra

Example 3. value() on a multi-element slate succeeds — the scalar accessors are what enforce the single-element requirement, not value() itself.

auto many = Slate(pluss::make_series({1.0, 2.0, 3.0}));
auto boxed_many = many.value();
std::cout << std::boolalpha << boxed_many.defined() << " " << boxed_many.kind() << "\n";

try {
  auto bad = boxed_many.to_dbl();
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

true Series
SlateValue::host: Slate payload must contain exactly one value

Notes¶

  • value() never reduces or validates length — it’s a plain wrapper.

  • to_dbl() / to_int() / to_str() / host() all require the wrapped slate to have exactly one element.

  • SlateValue also converts implicitly back to pluss::Series / pluss::Note / pluss::Timeline / pluss::TimeIndex, matching the wrapped slate’s kind().

See Also¶

  • Slate::sum / Slate::mean: reductions that return a SlateValue already narrowed to a single element.

  • Slate::kind: the payload kind a SlateValue’s scalar accessor dispatches on internally.

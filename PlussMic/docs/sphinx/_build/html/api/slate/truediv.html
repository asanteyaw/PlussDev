Slate::truediv¶

Back to Slate API Reference

Signatures¶

Slate::truediv(double other) const -> Slate
Slate::truediv(const Slate& other) const -> Slate

What It Does¶

Elementwise division that always promotes to floating point first — internally, both operands are converted to Float64 and divided via the library’s true_divide() primitive, regardless of what numeric type the source slate holds. This is a stricter guarantee than div(), which delegates to the raw Series::div() algebra and may not promote integer types the same way. For the Float64-typed examples used throughout this reference, truediv() and div() produce identical results.

Parameters¶

other (double or const Slate&)

The divisor(s). For the Slate overload, must be the same length as *this.

Returns¶

Slate A new Float64 slate, same length as *this, holding the elementwise quotient.

Examples¶

Example 1. Divide every value by a scalar.

using namespace pluss::table;

auto prices = Slate(pluss::make_series({10.0, 20.0, 30.0}));
auto out = prices.truediv(4.0);
std::cout << out;

Output¶

0  2.5
1  5
2  7.5

ptype: Series

Example 2. Divide two slates positionally.

auto splits = Slate(pluss::make_series({4.0, 8.0, 9.0}));
auto out_pair = prices.truediv(splits);
std::cout << out_pair;

Output¶

0  2.5
1  2.5
2  3.333333333

ptype: Series

Both examples match div()’s results exactly for this Float64 data — the distinction between the two methods only shows up on integer-typed slates.

Notes¶

  • See add() for the family-wide mechanics: positional matching and the length-mismatch throw.

  • Prefer truediv() over div() when you want a guaranteed floating-point result regardless of the source slate’s underlying numeric type.

See Also¶

  • Slate::div: the more permissive counterpart, delegating to the raw Series::div() algebra instead of always promoting to float.

  • Slate::rtruediv: the reflected form.

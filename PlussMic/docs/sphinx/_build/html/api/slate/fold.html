Slate::fold¶

Back to Slate API Reference

Signature¶

Slate::fold(const std::function<Slate(const Slate&)>& fn, ResultShape shape = ResultShape::Reduce) const -> Slate

What It Does¶

Calls fn exactly once, passing the entire current thread, and returns whatever fn returns — after checking the result’s size against shape. Despite the name, this is not a row-by-row accumulator-style fold (there’s no running accumulator, and fn never sees individual rows in isolation) — it’s a whole-thread escape hatch for a transform that doesn’t fit Slate’s built-in vectorized methods, with shape documenting (and enforcing) what kind of result you’re expected to produce.

enum class ResultShape : std::uint8_t {
  Infer = 0,     // no size check
  Reduce = 1,    // result must have exactly one row
  Preserve = 2,  // result must have the same number of rows as the input
  Expand = 3,    // no size check
};

Important

fold() calls fn() once with the whole thread — it does not iterate rows If you want fn invoked once per row instead, with a running per-row callback, use map() — its SlateValue(const SlateValue&) callback runs once for each valid row. fold()’s shape parameter only validates the size of whatever fn returns after that single call; it does not change how many times fn is invoked.

Parameters¶

fn (const std::function<Slate(const Slate&)>&) Called exactly once with *this. Must return a defined Slate; must not be empty.

shape (ResultShape, default Reduce) What size the returned Slate is expected to have. Reduce requires exactly one row (throws otherwise); Preserve requires the same row count as the input (throws otherwise); Infer and Expand perform no size check at all.

Returns¶

Slate Exactly what fn returned, once its size has been checked against shape.

Examples¶

Example 1. ResultShape::Reduce (the default) — collapse the whole thread to one value.

using namespace pluss::table;

auto scores = Slate(pluss::make_series({10.0, 20.0, 30.0}));

auto out = scores.fold([](const Slate& t) {
  return Slate(pluss::make_series({t.sum().to_dbl()}));
}, ResultShape::Reduce);
std::cout << out;

Output¶

0  60
ptype: Series

Example 2. ResultShape::Preserve — the result must come back the same length as the input; here, doubling every value naturally satisfies that.

auto scores = Slate(pluss::make_series({10.0, 20.0, 30.0}));

auto out = scores.fold([](const Slate& t) {
  return t.astype(pluss::codem::ScalarType::Float64) * 2.0;
}, ResultShape::Preserve);
std::cout << out;

Output¶

0  20
1  40
2  60
ptype: Series

Example 3. ResultShape::Infer performs no size check at all — a result of any length is accepted, even one that neither reduces to one row nor preserves the input length.

auto scores = Slate(pluss::make_series({10.0, 20.0, 30.0}));

auto out = scores.fold([](const Slate& t) {
  return Slate(pluss::make_series({1.0, 2.0}));
}, ResultShape::Infer);
std::cout << out;

Output¶

0  1
1  2
ptype: Series

Example 4. A size mismatch against the requested shape throws — here, a two-row result against the default Reduce (which requires exactly one row).

auto scores = Slate(pluss::make_series({10.0, 20.0, 30.0}));
try {
  auto out = scores.fold([](const Slate& t) {
    return Slate(pluss::make_series({1.0, 2.0}));
  });
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Slate::fold: Reduce requires one value

Notes¶

  • fn is called exactly once, with the whole thread — not once per row. See the important callout above; use map() for genuine row-by-row iteration.

  • shape only validates the size of fn’s return value; it never changes how fn is invoked or how many times.

  • Infer and Expand currently behave identically (no size check) — pick whichever name reads more clearly at the call site.

  • Slate::transform’s Slate-callback overload is a pure alias for fold(), forwarding fn and shape unchanged.

See Also¶

  • Slate::flow: the same “call fn once with the whole thread” shape, but with no size validation at all — not even the loose Infer/Expand bookkeeping.

  • Slate::map: the row-by-row counterpart — calls fn once per valid row instead of once for the whole thread.

  • Slate::transform: dispatches to fold() for the Slate-callback overload.

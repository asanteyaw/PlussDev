Slate::ge¶

Back to Slate API Reference

Signatures¶

Slate::ge(double other) const -> Slate
Slate::ge(std::string_view other) const -> Slate
Slate::ge(const char* other) const -> Slate
Slate::ge(const Slate& other) const -> Slate

What It Does¶

Elementwise “greater than or equal”, the mirror image of le(), following eq()’s shared overload shape and positional matching. Like le(), the string overload stringifies numeric values before comparing lexicographically — see lt() for a concrete example of why that can disagree with numeric ordering.

Parameters¶

other (double, std::string_view, or const Slate&)

Same shape as eq().

Returns¶

Slate A new Bool-typed thread, same length as *this, holding the elementwise “greater than or equal” result.

Examples¶

Example 1. Compare every value against a scalar.

using namespace pluss::table;

auto scores = Slate(pluss::make_series({72.0, 85.0, 91.0}));
auto out = scores.ge(85.0);
std::cout << out;

Output¶

0  false
1  true
2  true

ptype: Series

Position 1 is true here (85 >= 85) where gt(85.0) gave false — the only difference between the two operators.

Example 2. Compare two threads positionally.

auto targets = Slate(pluss::make_series({72.0, 80.0, 95.0}));
auto out_pair = scores.ge(targets);
std::cout << out_pair;

Output¶

0  true
1  true
2  false

ptype: Series

Example 3. String comparison on a Note thread.

auto names = Slate(pluss::make_note({"Ada", "Bola", "Chen"}));
auto out_names = names.ge("Bola");
std::cout << out_names;

Output¶

0  false
1  true
2  true

ptype: Series

Notes¶

  • See eq() for the family-wide mechanics.

  • ge(x) is always the exact logical negation of lt(x) for the same argument.

See Also¶

  • Slate::gt: the strict form.

  • Slate::le: the opposite direction’s inclusive form.

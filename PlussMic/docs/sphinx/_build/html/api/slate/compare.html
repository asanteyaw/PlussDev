What It Does¶

The single, op-parameterized entry point behind every comparison on Slate — the eq(), ne(), lt(), le(), gt(), ge() convenience methods, and the free comparison operators (==, !=, <, <=, >, >=), are all thin wrappers that call compare() with a fixed SlateBinaryCompareOp. Reach for compare() directly when the operator is itself a runtime value (selected from a variable, a config file, a user-facing filter builder); otherwise the named methods or operators read more naturally at the call site.

enum class SlateBinaryCompareOp : std::uint8_t {
  Eq = 0,  // equal
  Ne = 1,  // not equal
  Lt = 2,  // less than
  Le = 3,  // less than or equal
  Gt = 4,  // greater than
  Ge = 5,  // greater than or equal
};

The right-hand side can be a numeric scalar, a text scalar, one of the four native pluss payload types (Series, Note, Timeline, Duration), or another Slate — every overload converges on the same row-by-row boolean result.

Important

A text literal against a Timeline slate is parsed as a date, not compared as text Calling the std::string_view overload on a Timeline-kind slate does not perform a lexical string comparison — the literal is parsed as a timestamp first (via pluss::make_timeline), then compared temporally. Only Note-kind slates (and, as a fallback, everything else) compare the literal as plain text. See Example 4.

Parameters¶

other The right-hand comparison target — a numeric scalar (double), a text scalar (std::string_view/const char*), one of Series/Note/Timeline/Duration, or another Slate. Non-Slate payloads that carry more than one row are compared positionally and must match size(); a single-element (dim() == 0) payload broadcasts across every row instead.

op (SlateBinaryCompareOp) Which comparison to perform — Eq, Ne, Lt, Le, Gt, or Ge.

Returns¶

Slate A Series-kind slate of Bool values, one per row. Rows that are invalid in the source slate compare false rather than propagating invalidity.

Examples¶

Example 1. Broadcast one numeric scalar across a numeric slate.

using namespace pluss::table;

auto scores = Slate(pluss::make_series({10.0, 20.0, 30.0, 40.0}));

auto out = scores.compare(20.0, SlateBinaryCompareOp::Ge);
std::cout << out;

Output¶

0  false
1  true
2  true
3  true
ptype: Series

Example 2. Compare a Note-backed slate against a text literal — case-sensitive, exact text comparison, since the source is Note-kind.

auto names = Slate(pluss::make_note({"Ada", "BOLA", "cHeN"}));

auto out = names.compare("BOLA", SlateBinaryCompareOp::Eq);
std::cout << out;

Output¶

0  false
1  true
2  false
ptype: Series

Example 3. Compare two numeric slates element by element — a positional, row-by-row comparison, not a broadcast.

auto scores = Slate(pluss::make_series({10.0, 20.0, 30.0, 40.0}));
auto other = Slate(pluss::make_series({10.0, 10.0, 35.0, 45.0}));

auto out = scores.compare(other, SlateBinaryCompareOp::Ne);
std::cout << out;

Output¶

0  false
1  true
2  true
3  true
ptype: Series

Example 4. Against a Timeline-kind slate, a text literal is parsed as a date before comparing — see the important callout above.

auto stamps = Slate(pluss::make_timeline({
    "2024-01-01T00:00:00Z",
    "2024-02-01T00:00:00Z",
}));

auto out = stamps.compare("2024-01-15T00:00:00Z", SlateBinaryCompareOp::Lt);
std::cout << out;

Output¶

0  true
1  false
ptype: Series

Example 5. Positional (Slate-to-Slate) comparison requires matching lengths — a size mismatch throws rather than broadcasting or truncating.

auto a = Slate(pluss::make_series({1.0, 2.0}));
auto b = Slate(pluss::make_series({1.0, 2.0, 3.0}));
try {
  auto out = a.compare(b, SlateBinaryCompareOp::Eq);
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Slate::compare: positional alignment requires identical lengths

Notes¶

  • Invalid (NULL) rows in the source slate compare false, not NULL — compare() never propagates invalidity into the result.

  • A scalar Series/Note payload (dim() == 0) broadcasts; a 1D payload must match size() exactly or the call throws.

  • Every named comparison method (eq, ne, lt, le, gt, ge) and every free comparison operator ultimately calls compare() with a fixed op — prefer those for readability when the operator is known at the call site.

See Also¶

  • Slate::eq / ne / lt / le / gt / ge: the fixed-operator convenience methods compare() is generalized from.

  • Slate::between: interval membership — two comparisons combined with a logical AND, in one call.

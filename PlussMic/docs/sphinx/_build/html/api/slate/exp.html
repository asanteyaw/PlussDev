Slate::exp¶

Back to Slate API Reference

Signature¶

Slate::exp() const -> Slate

What It Does¶

Applies the elementwise natural exponential (e^x) — the inverse of log(). Requires the slate to be Series-kind. A non-floating scalar type (integer, bool) is promoted to Float64 before the exponential is computed.

Parameters¶

None

Returns¶

Slate A new Series-kind slate, same length as *this, holding exp(x) for each element (promoted to a floating scalar type if the input was integral).

Examples¶

Example 1. Exponentiate a small numeric slate.

using namespace pluss::table;

auto values = Slate(pluss::make_series({0.0, 1.0, 2.0}));
auto out = values.exp();
std::cout << out;

Output¶

0  1
1  2.718281828
2  7.389056099

ptype: Series

Example 2. log() and exp() round-trip back to the original values (subject to ordinary floating-point precision).

auto original = Slate(pluss::make_series({5.0, 12.5, 100.0}));
auto round_trip = original.log().exp();
std::cout << round_trip;

Output¶

0  5
1  12.5
2  100

ptype: Series

Example 3. A non-Series slate throws.

auto notes = Slate(pluss::make_note({"a", "b"}));
try {
  auto bad = notes.exp();
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Slate::exp is only valid for Series payload

Notes¶

  • Requires the calling slate to be Series-kind.

  • Integer/bool input is promoted to Float64 automatically before computing.

  • A NULL cell on input stays NULL on output.

See Also¶

  • Slate::log: the inverse transform.

  • Slate::pow: general exponentiation, for bases other than e.

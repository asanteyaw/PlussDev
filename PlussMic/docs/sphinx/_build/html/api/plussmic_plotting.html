PlussMic Plotting¶

This branch holds plotting and display-oriented surfaces attached to the table model.

  • Use DataFramePlotAccessor for plotting.

  • Use DataFramePlot3DAccessor for 3D plotting.

  • Use SlatePlotAccessor for plotting a single Slate.

  • Use DataFrame Display when you want display/rendering behavior explained in workflow form.

RegistryCastAccessor::series¶

Back to RegistryCastAccessor API Reference

Signature¶

Registry RegistryCastAccessor::series() const

What It Does¶

Casts every bound field’s values to Series-kind and returns a new registry with those fields replaced.

Important

Unparseable text becomes null, not a throw Casting a Note value that can’t be parsed as numeric (e.g. "Accra") doesn’t throw — it silently becomes a null value (std::monostate) in the resulting field. Check Registry::isnull after casting if you need to detect values that failed to convert.

Parameters¶

None

Returns¶

Registry A new registry with every bound field cast to Series-kind; every unbound field unchanged.

Examples¶

Example 1. Cast a Note field of numeric-looking text to Series.

auto rg = pluss::scribble::Registry({
    {"id", pluss::scribble::Slot({pluss::make_note("1"), pluss::make_note("2")})},
});

auto out = rg.fields({"id"}).cast().series();
auto ids = out.fields("id");
std::cout << std::get<pluss::Series>(ids.at(0)).to_vec<std::int64_t>()[0] << " ";
std::cout << std::get<pluss::Series>(ids.at(1)).to_vec<std::int64_t>()[0];

Output¶

1 2

Example 2. Unparseable text becomes null rather than throwing — see the important callout above.

auto rg = pluss::scribble::Registry({
    {"city", pluss::scribble::Slot({pluss::make_note("Accra"), pluss::make_note("Tema")})},
});

auto out = rg.fields({"city"}).cast().series();
std::cout << out.fields("city").to_json();

Output¶

{
  "_type": "Slot",
  "defined": true,
  "size": 2,
  "values": [
    null,
    null
  ]
}

Notes¶

  • Bound via Registry::cast() — remember that entry point binds every field of the registry it’s called on, so scope it with fields(keys) first if you only want to cast some fields.

  • See the important callout above for the silent-null behavior on unparseable text.

See Also¶

  • RegistryCastAccessor::note: the inverse direction, casting numeric fields to text.

  • Registry::cast: the entry point this accessor is reached from.

  • Slot::cast: the per-field casting this method applies across every bound field.

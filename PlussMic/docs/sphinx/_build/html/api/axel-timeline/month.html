AxelTimelineAccessor::month¶

Back to AxelTimelineAccessor API Reference

Signature¶

Axel AxelTimelineAccessor::month() const

What It Does¶

Extracts the calendar month (1-12) of each bound field’s timestamp, in every registry frame, replacing each Timeline field with an Int64 Series field. Applies RegistryTimelineAccessor::month to every frame via Axel::map.

Parameters¶

None

Returns¶

Axel A new axel with every bound field, in every frame, replaced by an Int64 Series field of month numbers; every unbound field unchanged.

Examples¶

Example 1. Extract the month from a January and a February timestamp.

auto r0 = pluss::scribble::Registry({{"ts", pluss::scribble::Slot({pluss::make_timeline("2024-01-31T09:15:30Z"), pluss::make_timeline("2024-02-29T23:45:00Z")})}});
auto axel = pluss::scribble::Axel({r0});

auto out = axel.fields({"ts"}).tl().month();
auto ts = out.registry(0).fields("ts");
std::cout << std::get<pluss::Series>(ts.at(0)).to_vec<std::int64_t>()[0] << " "
          << std::get<pluss::Series>(ts.at(1)).to_vec<std::int64_t>()[0];

Output¶

1 2

Notes¶

  • 1 is January, 12 is December.

  • Reads local calendar fields relative to whatever timezone the field’s Timeline currently carries ("UTC" unless changed via tz()/localize()).

  • Requires every bound field, in every frame, to be Timeline-kind — a non-Timeline field throws "Slot::tl: slot kind must be Timeline".

See Also¶

  • AxelTimelineAccessor::month_name: the same information spelled out as a full English name.

  • AxelTimelineAccessor::year / day(): the other calendar-date components.

  • AxelTimelineAccessor::month_start / month_end(): whether the day is the first or last day of this month.

  • Axel::tl: the entry point this accessor is reached from.

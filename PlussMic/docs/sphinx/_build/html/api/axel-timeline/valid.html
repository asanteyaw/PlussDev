AxelTimelineAccessor::valid¶

Back to AxelTimelineAccessor API Reference

Signature¶

Axel AxelTimelineAccessor::valid() const

What It Does¶

Flags whether each bound field’s timestamp is a real, present timestamp (not NaT), in every registry frame, replacing each Timeline field with a Bool Series field. Exactly the logical inverse of isnat(). Applies RegistryTimelineAccessor::valid to every frame via Axel::map.

Parameters¶

None

Returns¶

Axel A new axel with every bound field, in every frame, replaced by a Bool Series field: true where the value is a real timestamp, false where it’s NaT.

Examples¶

Example 1. Flag a valid timestamp alongside a NaT one.

auto r0 = pluss::scribble::Registry({{"ts", pluss::scribble::Slot({pluss::make_timeline(""), pluss::make_timeline("2024-01-01T00:00:00Z")})}});
auto axel = pluss::scribble::Axel({r0});

auto out = axel.fields({"ts"}).tl().valid();
auto ts = out.registry(0).fields("ts");
std::cout << std::boolalpha
          << std::get<pluss::Series>(ts.at(0)).to_vec<bool>()[0] << " "
          << std::get<pluss::Series>(ts.at(1)).to_vec<bool>()[0];

Output¶

false true

Notes¶

  • Exactly !isnat(), provided for readability at call sites that want to filter for present timestamps rather than for missing ones.

  • Requires every bound field, in every frame, to be Timeline-kind — a non-Timeline field throws "Slot::tl: slot kind must be Timeline".

  • Bound via Axel::tl(), which binds every field of every frame unless you project first with fields(keys).

See Also¶

  • AxelTimelineAccessor::isnat: the logical inverse.

  • Axel::tl: the entry point this accessor is reached from.

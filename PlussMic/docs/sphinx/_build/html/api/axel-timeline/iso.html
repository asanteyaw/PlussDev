AxelTimelineAccessor::iso¶

Back to AxelTimelineAccessor API Reference

Signature¶

Axel AxelTimelineAccessor::iso() const

What It Does¶

Renders each bound field’s timestamp as a fixed ISO-8601-with-offset text representation, in every registry frame, replacing each Timeline field with a Note (text) Series field. Equivalent to fmt("%Y-%m-%dT%H:%M:%S.%f%z"). Applies RegistryTimelineAccessor::iso to every frame via Axel::map.

Parameters¶

None

Returns¶

Axel A new axel with every bound field, in every frame, replaced by a Note field holding each row as "YYYY-MM-DDTHH:MM:SS.fffffffff+HH:MM"; every unbound field unchanged.

Examples¶

Example 1. Render a timestamp as ISO-8601 text.

auto r0 = pluss::scribble::Registry({{"ts", pluss::scribble::Slot({pluss::make_timeline("2024-01-31T09:15:30Z")})}});
auto axel = pluss::scribble::Axel({r0});

auto out = axel.fields({"ts"}).tl().iso();
std::cout << std::get<pluss::Note>(out.registry(0).fields("ts").at(0)).at(0);

Output¶

2024-01-31T09:15:30.000000000+00:00

Notes¶

  • Always includes the full 9-digit nanosecond fraction and a signed %z offset — use fmt() with your own pattern for a more compact string.

  • Changes each bound field’s kind from Timeline to Note.

  • Requires every bound field, in every frame, to be Timeline-kind — a non-Timeline field throws "Slot::tl: slot kind must be Timeline".

See Also¶

  • AxelTimelineAccessor::fmt: the general form this method is a fixed pattern of.

  • Axel::tl: the entry point this accessor is reached from.

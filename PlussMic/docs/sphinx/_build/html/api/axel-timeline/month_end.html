AxelTimelineAccessor::month_end¶

Back to AxelTimelineAccessor API Reference

Signature¶

Axel AxelTimelineAccessor::month_end() const

What It Does¶

Flags whether each bound field’s timestamp falls on the last day of its calendar month, in every registry frame, replacing each Timeline field with a Bool Series field. Applies RegistryTimelineAccessor::month_end to every frame via Axel::map.

Parameters¶

None

Returns¶

Axel A new axel with every bound field, in every frame, replaced by a Bool Series field: true where the row’s day-of-month is that month’s last valid day, false otherwise.

Examples¶

Example 1. Both sample timestamps are the last day of their respective month.

auto r0 = pluss::scribble::Registry({{"ts", pluss::scribble::Slot({pluss::make_timeline("2024-01-31T09:15:30Z"), pluss::make_timeline("2024-02-29T23:45:00Z")})}});
auto axel = pluss::scribble::Axel({r0});

auto out = axel.fields({"ts"}).tl().month_end();
auto ts = out.registry(0).fields("ts");
std::cout << std::boolalpha
          << std::get<pluss::Series>(ts.at(0)).host<bool>()[0] << " "
          << std::get<pluss::Series>(ts.at(1)).host<bool>()[0];

Output¶

true true

"2024-01-31" is January’s last day; "2024-02-29" is February’s last day in this leap year — see leap(), since the correct “last day” for February depends on whether the year is a leap year.

Notes¶

  • Correctly accounts for each month’s actual length, including leap-year February — see the important callout on leap().

  • Only checks the date component; the time-of-day portion doesn’t affect the result.

  • Reads local calendar fields relative to whatever timezone the field’s Timeline currently carries ("UTC" unless changed via tz()/localize()).

  • Requires every bound field, in every frame, to be Timeline-kind — a non-Timeline field throws "Slot::tl: slot kind must be Timeline".

See Also¶

  • AxelTimelineAccessor::month_start: the mirror check at the beginning of the month.

  • AxelTimelineAccessor::leap: where leap-year status actually changes February’s last valid day.

  • Axel::tl: the entry point this accessor is reached from.

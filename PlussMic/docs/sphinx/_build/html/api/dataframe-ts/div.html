DataFrameTsAccessor::div¶

Back to DataFrameTsAccessor API Reference

Signature¶

DataFrameTsAccessor::div(const DataFrame& other, TsAlignMode mode = TsAlignMode::Exact) const -> DataFrame

What It Does¶

Divides every bound feature by other, first aligning other’s rows onto this accessor’s own time axis according to mode — the exact same alignment model as add(), with division in place of addition. For each bound feature name, other must have a same-named feature; that feature’s values are aligned onto this accessor’s axis (producing NULL wherever no match is found), then divided elementwise into the bound feature’s own values.

Parameters¶

other (const DataFrame&)

The right-hand frame (the divisor). Must contain a feature with the same name as every feature currently bound on this accessor.

mode (TsAlignMode, default Exact)

How other’s rows are matched onto this accessor’s time axis — see add() for the full description of Exact/Backward/Forward/Nearest.

Returns¶

DataFrame A new frame, same shape and case labels as this accessor’s bound features, with each feature replaced by its quotient with other’s aligned values.

Examples¶

Example 1. Divide two frames whose time axes don’t fully overlap, using the default Exact alignment.

using namespace pluss::table;

auto left = DataFrame(
    {{"sales", Thread(pluss::make_series({100.0, 120.0, 90.0}))}},
    Thread(pluss::make_timeline({
        "2024-01-01T00:00:00Z", "2024-01-02T00:00:00Z", "2024-01-05T00:00:00Z"})));

auto right = DataFrame(
    {{"sales", Thread(pluss::make_series({10.0, 5.0, 3.0}))}},
    Thread(pluss::make_timeline({
        "2024-01-01T00:00:00Z", "2024-01-02T00:00:00Z", "2024-01-03T00:00:00Z"})));

auto out = left.ts().div(right);
std::cout << out;

Output¶

==================
           | sales
------------------
2024-01-01 | 10   
2024-01-02 | 24   
2024-01-05 | NULL 
------------------
[3 cs x 1 feat]

2024-01-01 and 2024-01-02 exist on both sides, so they divide normally (100 / 10 = 10, 120 / 5 = 24). 2024-01-05 has no exact match on right (which only reaches 2024-01-03), so with the default Exact mode it’s NULL.

Example 2. The same two frames, using Backward instead of Exact — 2024-01-05 now picks up right’s most recent prior value instead of NULL.

auto out_backward = left.ts().div(right, TsAlignMode::Backward);
std::cout << out_backward;

Output¶

==================
           | sales
------------------
2024-01-01 | 10   
2024-01-02 | 24   
2024-01-05 | 30   
------------------
[3 cs x 1 feat]

2024-01-01 and 2024-01-02 divide exactly as before. 2024-01-05 has no exact match on right, but Backward carries forward right’s most recent prior value, 2024-01-03’s 3 — so 90 / 3 = 30 instead of NULL.

Example 3. Divide by an aligned zero, and see other missing a same-named feature throw.

auto right_with_zero = DataFrame(
    {{"sales", Thread(pluss::make_series({0.0, 5.0, 3.0}))}},
    Thread(pluss::make_timeline({
        "2024-01-01T00:00:00Z", "2024-01-02T00:00:00Z", "2024-01-03T00:00:00Z"})));

auto out2 = left.ts().div(right_with_zero);
std::cout << out2;

auto other_missing = DataFrame(
    {{"units", Thread(pluss::make_series({1.0, 2.0, 3.0}))}},
    Thread(pluss::make_timeline({
        "2024-01-01T00:00:00Z", "2024-01-02T00:00:00Z", "2024-01-03T00:00:00Z"})));

try {
  auto out3 = left.ts().div(other_missing);
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n')) << "\n";
}

Output (division by an aligned zero)¶

==================
           | sales
------------------
2024-01-01 | inf  
2024-01-02 | 24   
2024-01-05 | NULL 
------------------
[3 cs x 1 feat]

Output (missing feature)¶

DataFrameTsAccessor::binary: right frame is missing feature 'sales'

100 / 0 follows ordinary floating-point rules and displays as inf, not a special NULL case. other_missing has no "sales" feature at all — unlike the zero case, there’s nothing to align and divide into, so that throws instead.

Notes¶

  • The result’s case labels are always this accessor’s own axis — see add() for the full notes on alignment and matching behavior, which apply identically here.

  • Every bound feature must have a same-named counterpart on other, or the call throws.

  • Division by an aligned zero follows ordinary floating-point division rules (producing infinity or NaN, displayed accordingly), not a special NULL case.

See Also¶

  • DataFrameTsAccessor::align_to: the lower-level reindex primitive this method’s alignment step is built from.

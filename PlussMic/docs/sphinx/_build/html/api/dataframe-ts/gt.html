DataFrameTsAccessor::gt¶

Back to DataFrameTsAccessor API Reference

Signature¶

DataFrameTsAccessor::gt(const DataFrame& other, TsAlignMode mode = TsAlignMode::Exact) const -> DataFrame

What It Does¶

Checks whether every bound feature is strictly greater than other, first aligning other’s rows onto this accessor’s own time axis according to mode — the mirror image of lt(), sharing the same alignment model. For each bound feature name, other must have a same-named feature; that feature’s values are aligned onto this accessor’s axis (producing NULL wherever no match is found), then compared elementwise with > against the bound feature’s own values.

Parameters¶

other (const DataFrame&)

The right-hand frame. Must contain a feature with the same name as every feature currently bound on this accessor.

mode (TsAlignMode, default Exact)

How other’s rows are matched onto this accessor’s time axis — see eq() for the full description of Exact/Backward/Forward/Nearest.

Returns¶

DataFrame A new frame, same shape and case labels as this accessor’s bound features, with each feature replaced by a Bool column: true where the bound value is strictly greater than the aligned other value, false otherwise, NULL where no aligned value exists.

Examples¶

Example 1. Compare two frames whose time axes don’t fully overlap, using the default Exact alignment.

using namespace pluss::table;

auto left = DataFrame(
    {{"sales", Thread(pluss::make_series({100.0, 120.0, 90.0}))}},
    Thread(pluss::make_timeline({
        "2024-01-01T00:00:00Z", "2024-01-02T00:00:00Z", "2024-01-05T00:00:00Z"})));

auto right = DataFrame(
    {{"sales", Thread(pluss::make_series({100.0, 5.0, 3.0}))}},
    Thread(pluss::make_timeline({
        "2024-01-01T00:00:00Z", "2024-01-02T00:00:00Z", "2024-01-03T00:00:00Z"})));

auto out = left.ts().gt(right);
std::cout << out;

Output¶

==================
           | sales
------------------
2024-01-01 | false
2024-01-02 | true 
2024-01-05 | NULL 
------------------
[3 cs x 1 feat]

2024-01-01 is 100 > 100 → false (equal is not strictly greater). 2024-01-02 is 120 > 5 → true. 2024-01-05 has no exact match on right, so it’s NULL rather than true — an unmatched row is neither greater than nor not-greater-than.

Notes¶

  • Equal values compare false under gt(), the same as any strict-inequality operator — use ge() if the boundary should count.

  • Every bound feature must have a same-named counterpart on other, or the call throws "DataFrameTsAccessor::binary: right frame is missing feature '<name>'".

See Also¶

  • DataFrameTsAccessor::ge: the inclusive counterpart (>=).

  • DataFrameTsAccessor::lt, DataFrameTsAccessor::le: the opposite-direction comparisons.

  • DataFrameTsAccessor::eq, DataFrameTsAccessor::ne: the equality-based comparisons sharing this same alignment model.

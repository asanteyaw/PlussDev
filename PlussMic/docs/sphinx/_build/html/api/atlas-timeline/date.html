AtlasTimelineAccessor::date¶

Back to AtlasTimelineAccessor API Reference

Signature¶

AtlasTimelineAccessor::date() const -> Atlas

What It Does¶

Replaces every Timeline feature in every frame of the stack with just its date portion (time-of-day dropped to midnight), in local wall time — the same transform DataFrame::tl().date() applies to a single frame, broadcast across the whole Atlas via map_frames(). Equivalent to floor("D").

Parameters¶

None

Returns¶

Atlas A new atlas, same depth and depth labels as the source, with each frame’s time feature’s clock-time portion zeroed out.

Examples¶

Example 1. Strip the time-of-day from a Timeline feature stacked across two frames.

using namespace pluss::table;

auto q1 = DataFrame({
    {"ts", Slate(pluss::make_timeline({"2024-01-31T09:15:30Z", "2024-02-29T23:45:00Z"}))},
});
auto q2 = DataFrame({
    {"ts", Slate(pluss::make_timeline({"2024-07-06T14:00:00Z", "2023-03-01T00:00:00Z"}))},
});
auto atlas = Atlas({q1, q2});

auto out = atlas.tl().date();
std::cout << out.frame(0) << "\n" << out.frame(1);

Output¶

=================
     | ts        
-----------------
0    | 2024-01-31
1    | 2024-02-29
-----------------
[2 cs x 1 feat]
=================
     | ts        
-----------------
0    | 2024-07-06
1    | 2023-03-01
-----------------
[2 cs x 1 feat]

Every row’s clock-time portion is now 00:00:00, so both frames display without any time-of-day text at all.

Notes¶

  • Operates in local wall time, per each frame’s Timeline’s current timezone.

  • Atlas::tl() requires every feature on each stacked frame to already be Timeline-kind, checked lazily per frame the first time a method like this one is actually called — see Atlas::tl.

  • A NaT row stays NaT (displays as "NULL").

  • Each frame is transformed independently — see AtlasTimelineAccessor::year for a worked example of this per-frame independence.

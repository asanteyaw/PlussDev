SlateTimelineAccessor::fmt¶

Back to SlateTimelineAccessor API Reference

Signature¶

SlateTimelineAccessor::fmt(std::string_view pattern) const -> Slate

What It Does¶

Replaces the bound thread with a custom text representation built from pattern, as a Note Series.

Parameters¶

pattern (std::string_view)

A strftime-style format string. Recognized tokens: %Y (4-digit year), %m/%d (2-digit month/day), %H/%M/%S (2-digit hour/minute/second), %f (9-digit zero-padded nanoseconds), %z (UTC offset as +HH:MM/-HH:MM — never a bare Z), %a/%A (abbreviated/full weekday name), %b/%B (abbreviated/full month name), and %% (a literal %). Any other % sequence, or any character outside a % token, is copied through literally. Cannot be empty.

Returns¶

Slate A new Note-kind thread, same length as the bound thread, holding each row’s text rendered per pattern.

Examples¶

Example 1. Format every row with a custom pattern.

using namespace pluss::table;

auto events = Slate(pluss::make_timeline({
    "2024-01-31T09:15:30Z",
    "2024-02-29T23:45:00Z",
    "2024-07-06T14:00:00Z",
}));
auto out = events.tl().fmt("%d %b %Y");
std::cout << out;

Output¶

0  31 Jan 2024
1  29 Feb 2024
2  06 Jul 2024

ptype: Note

Example 2. Combine %f and %z to reproduce iso()’s pattern by hand.

auto sub = Slate(pluss::make_timeline({"2024-01-31T09:15:30.123456789Z"}));
auto out2 = sub.tl().fmt("%Y-%m-%dT%H:%M:%S.%f%z");
std::cout << out2;

Output¶

0  2024-01-31T09:15:30.123456789+00:00

ptype: Note

%f emits all 9 nanosecond digits (123456789, not a truncated 123), and %z renders the UTC offset as the signed "+00:00", never a bare "Z".

Example 3. An empty pattern throws.

try {
  auto bad = events.tl().fmt("");
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n')) << "\n";
}

Output¶

Slate::tl().fmt: pattern cannot be empty

Notes¶

  • pattern cannot be empty.

  • %f always emits all 9 nanosecond digits, zero-padded — there’s no way to ask for fewer digits (e.g. milliseconds only) directly; slice the resulting text with SlateNoteAccessor methods if fewer digits are needed.

  • %z always renders as a signed HH:MM offset (e.g. "+00:00"), never the bare "Z" suffix some ISO-8601 tooling uses for UTC.

  • .tl() requires the bound thread to already be Timeline-kind — the accessor’s constructor throws otherwise.

  • A NaT row (or one already null on the underlying thread) displays as "NULL", regardless of pattern.

See Also¶

  • SlateTimelineAccessor::iso: a fixed ISO-8601-with-offset pattern, equivalent to fmt("%Y-%m-%dT%H:%M:%S.%f%z").

  • SlateTimelineAccessor::weekday_name, SlateTimelineAccessor::month_name: pre-built single-field text conveniences.

SlateTimelineAccessor::year¶

Back to SlateTimelineAccessor API Reference

Signature¶

SlateTimelineAccessor::year() const -> Slate

What It Does¶

Replaces the bound slate with its calendar year, as a numeric Series.

Parameters¶

None

Returns¶

Slate A new Series-kind (Int64) slate, same length as the bound slate, holding each row’s calendar year.

Examples¶

Example 1. Extract the year from every row.

using namespace pluss::table;

auto events = Slate(pluss::make_timeline({
    "2024-01-31T09:15:30Z",
    "2024-07-06T14:00:00Z",
    "2023-03-01T00:00:00Z",
}));
auto out = events.tl().year();
std::cout << out;

Output¶

0  2024
1  2024
2  2023

ptype: Series

Notes¶

  • .tl() requires the bound slate to already be Timeline-kind — the accessor’s constructor throws otherwise.

  • A row whose underlying timestamp is NaT (or whose slate already carries a null mask) displays as "NULL" in the year output, not some sentinel number.

  • year() reads local calendar fields — i.e. relative to whatever timezone the slate currently carries ("UTC" unless changed via tz()/localize()).

See Also¶

  • SlateTimelineAccessor::month, SlateTimelineAccessor::day: the other calendar-date components.

  • SlateTimelineAccessor::leap: whether the row’s year is a leap year.

Locus::nexus¶

Back to Locus API Reference

Signature¶

Locus::nexus(const Policy& policy = std::nullopt) const -> Nexus

using Policy = std::optional<TabelizePolicy>;

What It Does¶

Returns the aligned DataFrame workspace reports, SQL (query()), and nexus()-based delegation use – every catalog tabelized into a rectangular table under the given (or this Locus’s own) TabelizePolicy, every declared link, table meta entry, and saved plan carried over unchanged. The result is cached: calling nexus() again on the same Locus with the same policy returns the cached Nexus directly, without re-aligning anything – see alignment_cache_stats for the lower-level, per-catalog cache this sits on top of.

Parameters¶

Parameter

Meaning

policy

The TabelizePolicy to align under. Defaults to this Locus’s own policy().

Returns¶

A Nexus with one aligned DataFrame per catalog, and the same links, table metadata, and saved plans.

Examples¶

Example 1. nexus() carries over the workspace’s tables and links.

const auto linked = make_linked_shop();
const auto nx = linked.nexus();
std::cout << "nexus ntables=" << nx.ntables() << " nexus relationships=" << nx.relationships().size() << "\n";

Output¶

nexus ntables=3 nexus relationships=2

See Also¶

  • policy: the alignment nexus() uses by default.

  • alignment_cache_stats: what nexus() reuses, and when.

  • query: SQL over the same aligned view.

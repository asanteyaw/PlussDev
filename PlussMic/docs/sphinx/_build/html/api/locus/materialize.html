Locus::materialize¶

Back to Locus API Reference

Signature¶

Locus::materialize(const JoinPlan& plan, const JoinOptions& options = {}) const -> Catalog

What It Does¶

Runs a JoinPlan – one native join per step, in order, accumulating columns table by table, each hop enforcing its own link’s cardinality the same as a direct join() call would. This is the method run calls internally once a plan is resolved, whether that plan came from plan() directly or from a saved plan looked up by name.

Parameters¶

Parameter

Meaning

plan

The JoinPlan to execute.

options

Raggedness policy applied to every hop.

Returns¶

A Catalog: the result of joining every step of the plan.

Examples¶

Example 1. Materializing a plan built by hand.

JoinPlan plan;
plan.root_table = "orders";
plan.result_name = "orders_with_customers";
JoinPlanStep step;
step.left_table = "orders";
step.right_table = "customers";
step.spec.keys = {{"cust_id", "id"}};
step.spec.how = JoinHow::Inner;
plan.steps.push_back(step);
const auto linked = make_linked_shop();
const auto direct = linked.materialize(plan);
std::cout << "materialize rows=" << direct.get("amount")->size() << "\n";

Output¶

materialize rows=3

The default Inner join at this one step drops order 13 (customer 9 doesn’t exist), matching join’s own single-hop behavior.

See Also¶

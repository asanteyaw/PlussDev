Locus::plan¶

Back to Locus API Reference

Signature¶

Locus::plan(std::string_view from, std::string_view to, JoinHow how = JoinHow::Left) const -> JoinPlan
Locus::plan(const JoinPath& path, JoinHow how = JoinHow::Left) const -> JoinPlan

What It Does¶

Builds a JoinPlan – the shortest chain of links between two catalogs, as a concrete sequence of join steps – without executing anything. The (from, to) overload finds the path itself (the same shortest-path search path exposes); the JoinPath overload builds a plan directly from a path already found. Neither call joins any data; see materialize to actually run the plan, or store to save it under a name for repeated use.

Parameters¶

Parameter

Meaning

from, to

The two catalogs to connect.

path

A JoinPath (from path) to build a plan from directly.

how

The join kind applied at every hop. Default Left.

Returns¶

A JoinPlan: a root_table and an ordered list of JoinPlanSteps.

Examples¶

Example 1. The shortest plan between two catalogs two hops apart.

const auto linked = make_linked_shop();
const auto shortest = linked.plan("items", "customers", JoinHow::Left);
std::cout << "plan steps=" << shortest.steps.size() << " root_table=" << shortest.root_table << "\n";

Output¶

plan steps=2 root_table=items

See Also¶

  • store: saving a plan under a name to run again later.

  • link: path, the shortest-path search this builds a plan from.

Locus::scan¶

Back to Locus API Reference

Signature¶

Locus::scan() const -> pluss::table::DataFrame

What It Does¶

Calls Nexus::scan on this Locus’s aligned nexus() view: a unified diagnostics table mixing table rows and relationship rows in one place – the closest thing to a command-center overview of the whole workspace. This is the same frame audit_report returns.

Parameters¶

None.

Returns¶

A DataFrame with one row per catalog plus one row per declared relationship.

Examples¶

Example 1. Three catalogs plus two relationships: five rows – the same count audit_report reports, since they’re the same underlying frame.

auto shop = make_linked_shop();
TableMeta meta;
meta.primary_key = {"id"};
shop.meta_("customers", meta);
std::cout << "scan ncases=" << shop.scan().ncases() << "\n";

Output¶

scan ncases=5

See Also¶

  • audit_report: the same combined frame, under its integrity-focused name.

  • profile: the table-only version of this diagnostics view.

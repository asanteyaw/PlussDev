Locus::deduce¶

Back to Locus API Reference

Signature¶

Locus::deduce(double min_confidence = 0.5) const -> pluss::table::DataFrame

What It Does¶

Calls Nexus::deduce on this Locus’s aligned nexus() view: scans the workspace for plausible relationship candidates – column-name and value overlaps that look like an undeclared link – and returns them as an advisory DataFrame. It never creates a relationship, mutates the workspace, or validates that a candidate is actually correct; it’s a suggestion to review, not a declaration to link automatically.

Parameters¶

Parameter

Meaning

min_confidence

The minimum confidence score a candidate must reach to be reported. Default 0.5.

Returns¶

A DataFrame with one row per candidate relationship found, possibly empty.

Examples¶

Example 1. A workspace whose real relationships are already declared has nothing left to suggest.

const auto linked = make_linked_shop();
std::cout << "deduce ncases=" << linked.deduce().ncases() << "\n";

Output¶

deduce ncases=0

See Also¶

  • link: declaring a relationship deduce() only suggests.

  • audit_report: checking relationships that are already declared, rather than finding undeclared ones.

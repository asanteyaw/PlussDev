ThreadLabelAccessor::sort¶

Back to ThreadLabelAccessor API Reference

Signature¶

ThreadLabelAccessor::sort(bool ascending = true, bool nulls_last = true) const -> Thread

What It Does¶

Reorders the entire bound thread — its own values together with their case labels — by case-label value. This is the one ThreadLabelAccessor method that touches the thread’s actual data rather than just the case-label companion sequence: every row moves together as a unit, so a value and the case label it was originally paired with always stay matched after sorting.

Parameters¶

ascending (bool, default true)

Sort ascending if true, descending if false.

nulls_last (bool, default true)

Where null case labels sort relative to real values.

Returns¶

Thread A new thread with the same rows as *this, reordered by case label.

Examples¶

Example 1. Sort a case-labeled thread ascending and descending.

using namespace pluss::table;

auto tagged = Thread(pluss::make_series({100.0, 200.0, 150.0, 90.0}))
                  .label().set(Thread(pluss::make_note({"east", "west", "east", "north"})));
std::cout << tagged;

auto ascending = tagged.label().sort();
std::cout << ascending;

auto descending = tagged.label().sort(false);
std::cout << descending;

Output (before)¶

east   100
west   200
east   150
north  90

ptype: Series

Output (ascending)¶

east   100
east   150
north  90
west   200

ptype: Series

Output (descending)¶

west   200
north  90
east   100
east   150

ptype: Series

Each value (100, 200, 150, 90) moves together with the case label it started paired with — "east" stays next to 100 (its first occurrence) and 150 (its second) throughout. Ties (the two "east" rows) keep their original relative order either way — the sort is stable.

Notes¶

  • Sorting is stable: rows with equal case labels retain their original relative order.

  • Unlike most other ThreadLabelAccessor methods (which only return a transformed view of the case labels themselves), sort() reorders the bound thread’s actual values along with its labels.

See Also¶

  • ThreadLabelAccessor::monotonic: check sortedness without reordering.

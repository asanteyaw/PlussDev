ThreadLabelAccessor::intersect¶

Back to ThreadLabelAccessor API Reference

Signature¶

ThreadLabelAccessor::intersect(const Thread& other) const -> Thread

What It Does¶

Treats the bound thread’s case labels and other as two sets of values, and returns the values present in both — deduplicated, in the case labels’ own first-occurrence order.

Parameters¶

other (const Thread&)

The values to intersect with.

Returns¶

Thread The distinct case-label values also found in other, in first-occurrence order, display_name "intersect".

Examples¶

Example 1. Intersect case labels with a repeat against a target set.

using namespace pluss::table;

auto tagged = Thread(pluss::make_series({100.0, 200.0, 150.0, 90.0}))
                  .label().set(Thread(pluss::make_note({"east", "west", "east", "north"})));

auto other = Thread(pluss::make_note({"west", "south", "north"}));
auto out = tagged.label().intersect(other);
std::cout << out;

Output¶

0  west
1  north

ptype: Note

"east" doesn’t appear in other, so it’s excluded even though it’s the case labels’ most frequent value; "west" and "north" are shared, in the order they first appear on the left side.

Notes¶

  • Symmetric in content but not in order: a.label().intersect(b) and b.intersect(a) (thought of as sets) contain the same values, ordered by whichever side’s first-occurrence order you called it from.

  • Duplicates on either side are collapsed; the result never repeats a value.

See Also¶

  • ThreadLabelAccessor::unite, ThreadLabelAccessor::diff, ThreadLabelAccessor::symdiff: the other set-algebra operations over case-label values.

ThreadLabelAccessor::fillnull¶

Back to ThreadLabelAccessor API Reference

Signatures¶

ThreadLabelAccessor::fillnull(double value) const -> Thread
ThreadLabelAccessor::fillnull(std::string_view value) const -> Thread
ThreadLabelAccessor::fillnull(const pluss::Timeline& value) const -> Thread
ThreadLabelAccessor::fillnull(const pluss::TimeIndex& value) const -> Thread

What It Does¶

Replaces every null case label with value and applies the result back to the bound thread directly, returning the full thread (same values, filled case labels) — a direct forward to Thread::caselbl(Thread::caselbl().fillnull(value)).

Note

Applies immediately — unlike DataFrameLabelAccessor::fillnull DataFrameLabelAccessor::fillnull returns only the filled label values, requiring a follow-up .label().set(...) call to actually update the frame. ThreadLabelAccessor::fillnull skips that step: it fills and reattaches the labels in the same call, so the returned Thread is already fully updated.

Pick the overload matching the case labels’ own kind: double for a numeric (Series) axis, std::string_view for Note, Timeline/TimeIndex for their respective temporal kinds.

Parameters¶

value

The replacement for every null case label, typed to match the case labels’ own kind.

Returns¶

Thread A new thread, holding the same values as *this, with null case labels replaced by value.

Examples¶

Example 1. Fill a null in a numeric case-label axis.

using namespace pluss::table;

auto readings = Thread(pluss::make_series({1.0, 2.0, 3.0}))
    .label().set(Thread(pluss::make_series(
        {10.0, std::numeric_limits<double>::quiet_NaN(), 30.0})));
std::cout << readings;

auto filled = readings.label().fillnull(0.0);
std::cout << filled;

Output (before)¶

10    1
NULL  2
30    3

ptype: Series

Output (after)¶

10  1
0   2
30  3

ptype: Series

The middle case label’s NULL became 0, and — unlike the DataFrame-level version — filled is already the complete, updated thread; no separate set() call was needed.

Example 2. Fill a NaT in a Timeline case-label axis.

auto with_nat = Thread(pluss::make_series({1.0, 2.0, 3.0}))
    .label().set(Thread(pluss::make_timeline(
        {"2024-01-01T00:00:00Z", "", "2024-01-03T00:00:00Z"})));
std::cout << with_nat;

auto filled2 = with_nat.label().fillnull(pluss::make_timeline("2024-01-02T00:00:00Z"));
std::cout << filled2;

Output (before)¶

2024-01-01  1
NULL        2
2024-01-03  3

ptype: Series

Output (after)¶

2024-01-01  1
2024-01-02  2
2024-01-03  3

ptype: Series

Notes¶

  • Applies immediately — the returned thread already carries the filled labels; no follow-up set() call is needed (contrast with DataFrameLabelAccessor::fillnull, see the note above).

  • Choose the overload matching the case labels’ own kind — passing a double to a Note axis (or vice versa) doesn’t fit any overload and won’t compile.

  • The pluss::TimeIndex overload behaves identically to the pluss::Timeline overload — the same fill mechanics apply to either temporal kind.

See Also¶

  • ThreadLabelAccessor::isnull, ThreadLabelAccessor::notnull: check which case labels are null before (or instead of) filling them.

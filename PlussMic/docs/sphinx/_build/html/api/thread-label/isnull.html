ThreadLabelAccessor::isnull¶

Back to ThreadLabelAccessor API Reference

Signature¶

ThreadLabelAccessor::isnull() const -> Thread

What It Does¶

Marks each row true where its case label is null, false where it’s a genuine value.

Parameters¶

None

Returns¶

Thread A Bool thread, one entry per row, display_name "isnull", displayed against the case labels themselves.

Examples¶

Example 1. A numeric case-label axis with one null.

using namespace pluss::table;

auto readings = Thread(pluss::make_series({1.0, 2.0, 3.0}))
    .label().set(Thread(pluss::make_series(
        {10.0, std::numeric_limits<double>::quiet_NaN(), 30.0})));

auto out = readings.label().isnull();
std::cout << out;

Output¶

10    false
NULL  true
30    false

ptype: Series

Notes¶

  • Inspects the case labels, not the thread’s own data.

See Also¶

  • ThreadLabelAccessor::notnull: the exact logical negation of this method.

  • ThreadLabelAccessor::fillnull: replace nulls instead of just locating them.

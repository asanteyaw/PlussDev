ThreadLabelAccessor::repeated¶

Back to ThreadLabelAccessor API Reference

Signature¶

ThreadLabelAccessor::repeated() const -> Thread

What It Does¶

Marks every row true whose case-label value occurs more than once anywhere in the thread — including its first occurrence, unlike duplicated(), which spares one occurrence (by default, the first). A value that never repeats is false everywhere it appears.

Parameters¶

None

Returns¶

Thread A Bool thread, one entry per row, display_name "repeated", displayed against the same case labels as *this.

Examples¶

Example 1. Mark repeats on the case labels — every occurrence, not just the extras.

using namespace pluss::table;

auto tagged = Thread(pluss::make_series({100.0, 200.0, 150.0, 90.0}))
                  .label().set(Thread(pluss::make_note({"east", "west", "east", "north"})));

auto out = tagged.label().repeated();
std::cout << out;

Output¶

east   true
west   false
east   true
north  false

ptype: Series

Both "east" rows are true — including row 0, the first occurrence, which duplicated() would mark false by default.

Notes¶

  • Unlike duplicated(), there’s no keep_first/keep_last option here — every occurrence of a repeated value is marked, with no exception.

  • The result carries the same case labels as *this.

See Also¶

  • ThreadLabelAccessor::duplicated: spares one occurrence of each repeated value (first, by default).

Thread::mean¶

Back to Thread API Reference

Signature¶

Thread::mean() const -> ThreadValue

What It Does¶

Returns the arithmetic mean of every observed (non-missing) value in a numeric Series thread, as a scalar ThreadValue. Missing entries are excluded before the mean is computed — both from the sum and from the count used to divide it, so a missing entry never drags the average toward zero. The computation is carried out in Float64 (or Float32 on a non-CPU platform), regardless of the source dtype, so an integer-dtype thread still produces a proper fractional mean rather than a truncated integer result. Restricted to Series payloads; every other kind throws. An empty thread, or one where every entry is missing, also throws.

See Thread::sum’s note on printing a ThreadValue — every example below uses .to_dbl() to extract a clean number instead of streaming the ThreadValue directly.

Parameters¶

None

Returns¶

ThreadValue A scalar Float64 (or Float32 off-CPU) holding the mean of the observed values.

Examples¶

Example 1. Mean of a numeric thread with no missing entries.

using namespace pluss::table;

auto scores = Thread(pluss::make_series({10.0, 20.0, 30.0}));
auto out = scores.mean();
std::cout << out.to_dbl();

Output¶

20

Example 2. Missing entries are excluded from both the sum and the divisor.

auto with_gap = Thread(
    pluss::make_series({10.0, 20.0, 40.0}),
    pluss::make_series(std::vector<bool>{true, false, true})
);
auto out2 = with_gap.mean();
std::cout << out2.to_dbl();

Output¶

25

Only 10.0 and 40.0 participate: (10 + 40) / 2 = 25, not (10 + 40) / 3.

Example 3. A thread with no observed values throws.

auto all_missing = Thread(
    pluss::make_series({10.0, 20.0}),
    pluss::make_series(std::vector<bool>{false, false})
);
try {
  auto bad = all_missing.mean();
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Thread::mean on an empty (all-null) selection

Example 4. Any non-Series payload throws.

auto words = Thread(pluss::make_note({"a", "b"}));
try {
  auto bad = words.mean();
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Thread::mean is only valid for Series payload

Notes¶

  • Missing entries are excluded from both the numerator and the divisor.

  • Always computed in Float64 (CPU) or Float32 (off-CPU), regardless of the source dtype — an integer thread’s mean is a proper fraction, not a truncated integer.

  • An empty thread, or one where every entry is missing, throws "Thread::mean on an empty (all-null) selection".

  • Restricted to Series payloads; anything else throws "Thread::mean is only valid for Series payload".

See Also¶

  • Thread::sum: the total this method divides by the observed count.

  • Thread::median: the middle value, less sensitive to outliers than the mean.

  • Thread::std / Thread::var: spread around this mean.

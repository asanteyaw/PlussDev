What It Does¶

Uses the public contract shown above to inspect, transform, summarize, or combine the current object without changing the rest of its alignment model unexpectedly.

Parameters¶

lo Lower/upper boundary used by this overload.

hi Lower/upper boundary used by this overload.

include_left Boolean switch that changes how this overload behaves. Read the method notes and examples to see the effect of true versus false.

include_right Boolean switch that changes how this overload behaves. Read the method notes and examples to see the effect of true versus false.

inclusive Boolean switch that changes how this overload behaves. Read the method notes and examples to see the effect of true versus false.

a Lower/upper boundary used by this overload.

b Lower/upper boundary used by this overload.

Returns¶

Thread Value produced by this call.

Examples¶

Example 1. Apply between to the current thread using explicit lo, hi, include_left, include_right arguments.

auto thread = pluss::table::Thread(pluss::make_series({45.0, 65.0, 82.0}));
auto lo = pluss::table::Thread(pluss::make_series({40.0, 60.0, 80.0}));
auto hi = pluss::table::Thread(pluss::make_series({50.0, 70.0, 81.0}));

auto out = thread.between(lo, hi, true);

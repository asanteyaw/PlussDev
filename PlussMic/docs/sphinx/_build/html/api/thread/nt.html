Thread::nt¶

Back to Thread API Reference

Signature¶

Thread::nt() const -> ThreadNoteAccessor

What It Does¶

Enters the dedicated text-operations accessor for this thread — string stripping, casing, length, pattern matching, splitting, padding, encoding, and more, one method per operation. nt() requires the thread to already be Note-kind.

Unlike tl(), which checks its payload kind eagerly (the moment you call .tl()), nt() performs no validation at all when constructing the accessor — it just binds a copy of the thread. The Note-kind requirement is only enforced lazily, the first time you call one of the accessor’s own methods (strip(), lower(), has(), and so on each independently check the payload kind before doing any work). This means thread.nt() alone never throws, even on a non-Note thread — the throw only happens once you actually call a method on the accessor. See Example 2.

Unlike DataFrame::nt(), which operates across every selected feature at once, this accessor is bound to a single thread — there’s no equivalent of .features(...) narrowing to do first.

This page previews the accessor’s most common entry points. Every one of its methods has its own dedicated, example-rich reference page — start at the ThreadNoteAccessor API Reference and use its left sidebar to jump straight to any method (strip, has, count, split, pad, replace, and more).

Parameters¶

None

Returns¶

ThreadNoteAccessor A lightweight accessor bound to this thread (its Note-kind isn’t checked yet). Nearly every method on it returns a new Thread with the text operation applied; the source thread is never mutated.

Examples¶

Example 1. Lowercase a Note thread, then check whether it starts with a prefix.

using namespace pluss::table;

auto cities = Thread(pluss::make_note({"Accra", "TEMA", "Kumasi"}));

auto lowered = cities.nt().lower();
std::cout << lowered;

Output¶

0  accra
1  tema
2  kumasi

ptype: Note

auto starts_a = cities.nt().starts("A");
std::cout << starts_a;

Output¶

0  true
1  false
2  false

ptype: Series

.lower() returns a new Note-kind thread; .starts(prefix) returns a bool Series-kind thread — only "Accra" (case-sensitively) starts with "A".

Example 2. nt() itself never throws — the Note-kind check happens lazily, on the accessor’s first method call.

auto numbers = Thread(pluss::make_series({1.0, 2.0}));
auto accessor = numbers.nt();  // does not throw

try {
  auto bad = accessor.lower();
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Thread::lower: expected Note payload

Compare this to .tl() on the same non-matching thread, which throws immediately at the .tl() call itself rather than waiting for a method call.

Notes¶

  • nt() performs no eager validation, unlike tl() — a non-Note thread only fails once you call a method on the accessor, not at .nt() itself.

  • Every accessor method independently enforces the Note-kind requirement with its own error message (for example "Thread::lower: expected Note payload").

  • No options/narrowing step is needed before calling .nt(), unlike DataFrame::nt() — a Thread is already a single payload.

See Also¶

  • Thread::tl: the equivalent dedicated accessor for Timeline/TimeIndex payloads, which validates its payload kind eagerly instead of lazily.

  • Thread::label: the dedicated accessor for the case-label axis, which works regardless of the thread’s own payload kind.

  • DataFrame::nt: the frame-level equivalent, which requires every selected feature to already be Note-kind and validates eagerly.

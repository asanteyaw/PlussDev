What It Does¶

Use this to reduce the current object to the rows or fields that matter for the next step.

Parameters¶

conditions Ordered collection used by a select-style overload. Each condition or choice is matched positionally with the others.

choices Ordered collection used by a select-style overload. Each condition or choice is matched positionally with the others.

default_value Fallback value written anywhere the input is missing or unmatched.

Returns¶

Thread Value produced by this call.

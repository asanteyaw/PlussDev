Thread::median¶

Back to Thread API Reference

Signature¶

Thread::median() const -> ThreadValue

What It Does¶

Returns the median of every observed (non-missing) value in a numeric Series thread, as a scalar ThreadValue — the middle value when the observed values are sorted, less sensitive to outliers than mean(). For an even number of observed values, it’s the average of the two middle values (the same linear-interpolation convention describe()’s 50% quartile uses). Missing entries are excluded first, exactly like mean(). The computation is carried out in Float64 (or Float32 off-CPU), regardless of the source dtype. Restricted to Series payloads; every other kind throws. An empty thread, or one where every entry is missing, also throws.

See Thread::sum’s note on printing a ThreadValue — every example below uses .to_dbl() to extract a clean number instead of streaming the ThreadValue directly.

Parameters¶

None

Returns¶

ThreadValue A scalar Float64 (or Float32 off-CPU) holding the median of the observed values.

Examples¶

Example 1. Median of an odd-length thread — the exact middle value.

using namespace pluss::table;

auto scores = Thread(pluss::make_series({1.0, 9.0, 5.0}));
auto out = scores.median();
std::cout << out.to_dbl();

Output¶

5

Example 2. Median of an even-length thread — the average of the two middle values.

auto scores2 = Thread(pluss::make_series({1.0, 3.0, 5.0, 9.0}));
auto out2 = scores2.median();
std::cout << out2.to_dbl();

Output¶

4

The two middle values (sorted) are 3 and 5; the median is their average, 4 — not either value alone.

Example 3. Missing entries are excluded before finding the median.

auto with_gap = Thread(
    pluss::make_series({1.0, 100.0, 5.0, 9.0}),
    pluss::make_series(std::vector<bool>{true, false, true, true})
);
auto out3 = with_gap.median();
std::cout << out3.to_dbl();

Output¶

5

Excluding the missing 100.0, the observed values are {1, 5, 9} — median 5. The excluded value never enters the sort at all, however extreme it is.

Example 4. A thread with no observed values throws.

auto all_missing = Thread(
    pluss::make_series({1.0, 2.0}),
    pluss::make_series(std::vector<bool>{false, false})
);
try {
  auto bad = all_missing.median();
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Thread::median on an empty (all-null) selection

Notes¶

  • Missing entries are excluded before the median is computed.

  • Even-length observed sets average their two middle values, using the same linear-interpolation convention as describe()’s 50% quartile.

  • Always computed in Float64 (CPU) or Float32 (off-CPU), regardless of the source dtype.

  • An empty thread, or one where every entry is missing, throws "Thread::median on an empty (all-null) selection".

  • Restricted to Series payloads; anything else throws "Thread::median is only valid for Series payload".

See Also¶

  • Thread::mean: the arithmetic average, more sensitive to outliers than the median.

  • Thread::percentiles: the median is exactly the 0.5 percentile computed by this method’s more general sibling.

  • Thread::describe: reports this method’s result as part of a wider numeric summary.

Thread::lor¶

Back to Thread API Reference

Signature¶

Thread::lor(const Thread& other) const -> Thread

What It Does¶

Elementwise logical OR, following land()’s shared mechanics: single overload, Bool-only requirement, positional matching, and display labels carried from *this.

Parameters¶

other (const Thread&)

A Bool-typed Series thread, the same length as *this.

Returns¶

Thread A new Bool-typed thread, same length as *this, holding the elementwise logical OR.

Examples¶

Example 1. OR two boolean threads.

using namespace pluss::table;

auto left = Thread(pluss::make_series({true, false, false}, pluss::ScalarType::Bool));
auto right = Thread(pluss::make_series({false, false, true}, pluss::ScalarType::Bool));

auto out = left.lor(right);
std::cout << out;

Output¶

0  true
1  false
2  true

ptype: Series

Position 1 is the only one where OR reports false — the only position where both operands are false at once.

Notes¶

  • See land() for the family-wide mechanics: the Bool-only requirement, positional matching, and the length-mismatch/non-Bool throws.

  • See ror() for how its reflected form’s display-label behavior differs from lor(), the same way rand() differs from land().

See Also¶

  • Thread::ror: the reflected form.

  • Thread::land: the canonical reference for this family’s shared mechanics.

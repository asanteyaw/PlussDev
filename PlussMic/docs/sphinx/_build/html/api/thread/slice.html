Thread::slice¶

Back to Thread API Reference

Signature¶

Thread::slice(std::int64_t start, std::int64_t stop) const -> Thread

What It Does¶

Returns a contiguous [start, stop) slice as a plain Thread (not a ThreadView — compare view(), which wraps this exact operation in a ThreadView). Python-slice semantics throughout: negative start/stop count from the end, both are clamped into [0, size()], and a stop at or before the resolved start produces an empty (not erroring) result. Internally implemented as take({start, start+1, ..., stop-1}).

Parameters¶

start (std::int64_t) Inclusive starting position. Negative values count from the end.

stop (std::int64_t) Exclusive ending position. Negative values count from the end.

Returns¶

Thread A new thread over positions [start, stop), clamped into range.

Examples¶

Example 1. A plain forward slice.

using namespace pluss::table;

auto scores = Thread(pluss::make_series({10.0, 20.0, 30.0, 40.0, 50.0}));
auto out = scores.slice(1, 4);
std::cout << out;

Output¶

0  20
1  30
2  40

ptype: Series

Example 2. Negative indices count from the end.

auto out2 = scores.slice(-2, 5);
std::cout << out2;

Output¶

0  40
1  50

ptype: Series

Example 3. An inverted range (stop <= start after resolving negatives) is an empty result, not an error.

auto out3 = scores.slice(4, 1);
std::cout << out3;

Output¶

ptype: Series

Notes¶

  • Negative start/stop count from the end (Python-slice convention).

  • Both bounds are clamped into [0, size()] — never throws for out-of-range values.

  • An inverted or empty resulting range produces a valid, zero-length Thread.

See Also¶

  • Thread::view: the same operation, wrapped in a ThreadView.

  • Thread::take: the arbitrary-index generalization this method delegates to.

  • Thread::head / Thread::tail: anchored convenience forms.

Thread::prod¶

Back to Thread API Reference

Signature¶

Thread::prod() const -> ThreadValue

What It Does¶

Returns the product of every observed (non-missing) value in a numeric Series thread, as a scalar ThreadValue — the multiplicative counterpart to sum(). Missing entries are excluded before the product is computed, not treated as 1. Restricted to Series payloads; every other kind throws. A thread whose every entry is missing (or that is empty) also throws.

See Thread::sum’s note on printing a ThreadValue — streaming the result directly prints its diagnostic form, not a bare number; use .to_dbl() (as every example below does) for a clean scalar.

Parameters¶

None

Returns¶

ThreadValue A scalar wrapping the product, in the source Series’s own numeric dtype (or its promoted equivalent).

Examples¶

Example 1. Multiply every observed value together.

using namespace pluss::table;

auto factors = Thread(pluss::make_series({2.0, 3.0, 4.0}));
auto out = factors.prod();
std::cout << out.to_dbl();

Output¶

24

Example 2. Missing entries are excluded before multiplying, not treated as 1.

auto with_gap = Thread(
    pluss::make_series({2.0, 3.0, 4.0}),
    pluss::make_series(std::vector<bool>{true, false, true})
);
auto out2 = with_gap.prod();
std::cout << out2.to_dbl();

Output¶

8

Only 2.0 and 4.0 (the two observed entries) participate — 2 * 4 = 8, not 2 * 3 * 4 = 24.

Example 3. A thread with no observed values throws.

auto all_missing = Thread(
    pluss::make_series({2.0, 3.0}),
    pluss::make_series(std::vector<bool>{false, false})
);
try {
  auto bad = all_missing.prod();
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Thread::prod on an empty (all-null) selection

Example 4. Any non-Series payload throws.

auto words = Thread(pluss::make_note({"a", "b"}));
try {
  auto bad = words.prod();
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Thread::prod is only valid for Series payload

Notes¶

  • Missing entries are excluded before multiplying — never treated as 1.

  • An empty thread, or one where every entry is missing, throws "Thread::prod on an empty (all-null) selection".

  • Restricted to Series payloads; anything else throws "Thread::prod is only valid for Series payload".

See Also¶

  • Thread::sum: the additive counterpart, including the note on how ThreadValue prints.

  • Thread::cumprod: the running product at every position, instead of one final total.

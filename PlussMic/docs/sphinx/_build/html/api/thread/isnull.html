Thread::isnull¶

Back to Thread API Reference

Signature¶

Thread::isnull() const -> Thread

What It Does¶

Returns a Bool-typed Series thread, same length as *this, marking true wherever the source thread is NULL and false everywhere else. Works on every payload kind — Series, Note, Timeline, TimeIndex — with no kind restriction, unlike most of the payload-specific methods elsewhere in this API.

Important

isnull() checks the validity mask, not the numeric value For a Series-kind thread, isnull() only looks at the thread’s validity mask — a NaN value that’s still marked valid is reported false by isnull(), not true. Use isnan() to check for NaN specifically, or invalid() to catch both NULL and non-finite values (NaN/Inf) in one call. See Example 2.

For a Timeline/TimeIndex-kind thread, isnull() also folds in the payload’s own internal validity signal (its own “not-a-time” sentinel), in addition to the thread’s validity mask — so a timestamp that’s intrinsically invalid is reported as NULL here even without an explicit mask entry.

Parameters¶

None

Returns¶

Thread A new Bool-typed Series thread, same length as *this.

Examples¶

Example 1. isnull() works the same way across every payload kind.

using namespace pluss::table;

auto numbers = Thread(pluss::make_series({1.0, 2.0, 3.0}),
    pluss::make_series(std::vector<bool>{true, false, true}));
auto out = numbers.isnull();
std::cout << out;

Output¶

0  false
1  true
2  false

ptype: Series

Example 2. isnull() is validity-mask-only — a NaN that’s still marked valid is false, not true. Compare with isnan().

auto readings = Thread(pluss::make_series({1.0, std::nan(""), 3.0}));
std::cout << readings.isnull() << "\n";
std::cout << readings.isnan();

Output¶

0  false
1  false
2  false

ptype: Series
0  false
1  true
2  false

ptype: Series

readings has no validity mask attached at all, so isnull() reports every position as valid (false) — even the NaN at index 1. isnan(), which checks the actual floating-point value, correctly flags it.

Notes¶

  • Works on every payload kind, with no kind() restriction.

  • Checks the validity mask (plus, for Timeline/TimeIndex, the payload’s own internal invalid-timestamp signal) — not the numeric value. See the important callout above.

  • A thread with no validity mask at all reports false (not null) at every position.

See Also¶

  • Thread::notnull: the logical inverse.

  • Thread::isnan: checks the floating-point value itself, for Series-kind threads.

  • Thread::invalid: the union of isnull() and non-finite, for Series-kind threads.

  • Thread::dropnull: remove NULL rows instead of just flagging them.

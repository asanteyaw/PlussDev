Thread::top¶

Back to Thread API Reference

Signature¶

Thread::top(std::int64_t n, bool render = false) const -> ThreadView

What It Does¶

Returns the n largest-valued entries, sorted descending, as a ThreadView (see head() for the shared ThreadView mechanics). n is clamped into [0, size()], the same as head()/tail() — a negative n clamps to 0 (an empty result) rather than throwing, and an n larger than size() clamps to size().

Parameters¶

n (std::int64_t) Number of largest-valued entries to keep. Clamped into [0, size()] — no error for a negative or oversized value.

render (bool, default false) See head()’s parameter description — auto-render-on-scope-exit only.

Returns¶

ThreadView A view over the n largest values, in descending order, with NULLs sorted last.

Examples¶

Example 1. The three largest values, descending.

using namespace pluss::table;

auto scores = Thread(pluss::make_series({30.0, 10.0, 50.0, 20.0, 40.0}));
auto out = scores.top(3);
std::cout << out;

Output¶

0  50
1  40
2  30

ptype: Series

Example 2. A negative n clamps to an empty result rather than throwing.

auto out2 = scores.top(-1);
std::cout << out2;

Output¶

ptype: Series

Notes¶

  • n is clamped into [0, size()] — never throws for a negative or oversized value, matching head()/tail().

  • NULL cells sort last, so they only appear in the result if n is large enough to reach past every valid value.

See Also¶

  • Thread::bottom: the smallest-values counterpart.

  • Thread::head / Thread::tail: positional (not value-sorted) previews, with the same clamping convention.

  • Thread::arrange: the full sort this method takes a prefix of.

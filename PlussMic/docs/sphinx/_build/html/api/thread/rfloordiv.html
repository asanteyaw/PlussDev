Thread::rfloordiv¶

Back to Thread API Reference

Signatures¶

Thread::rfloordiv(double other) const -> Thread
Thread::rfloordiv(const Thread& other) const -> Thread

What It Does¶

The reflected form of floordiv() — computes floor(other / (*this)) instead of floor((*this) / other).

Parameters¶

other (double or const Thread&)

Same shape as floordiv().

Returns¶

Thread A new thread holding floor(other / (*this)), elementwise.

Examples¶

Example 1. Floor-divide a scalar by every value.

using namespace pluss::table;

auto amounts = Thread(pluss::make_series({17.0, 26.0, 33.0}));
auto out = amounts.rfloordiv(100.0);
std::cout << out;

Output¶

0  5
1  3
2  3
ptype: Series

floor(100 / 17) = floor(5.88) = 5; floor(100 / 26) = floor(3.84) = 3; floor(100 / 33) = floor(3.03) = 3 — how many whole amounts-worth fit into a budget of 100, the opposite framing from amounts.floordiv(...).

Example 2. Reflected against another thread.

auto multiples = Thread(pluss::make_series({50.0, 80.0, 90.0}));
auto out_pair = amounts.rfloordiv(multiples);
std::cout << out_pair;

Output¶

0  2
1  3
2  2
ptype: Series

amounts.rfloordiv(multiples) computes exactly what multiples.floordiv(amounts) would: floor(50 / 17) = 2, floor(80 / 26) = 3, floor(90 / 33) = 2.

Notes¶

  • amounts.rfloordiv(x) always equals floor(x / amounts) — the mirror image of floordiv().

  • See rmod() for the complementary reflected remainder.

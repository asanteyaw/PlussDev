Thread::info_string¶

Back to Thread API Reference

Signature¶

Thread::info_string() const -> std::string

What It Does¶

Builds a short, fixed-format summary of the thread’s metadata — name, payload kind, dtype, row count, and a valid/null breakdown — as a plain std::string. This is metadata only; unlike to_string() or show(), it never renders the thread’s actual row values. Use it for logging, quick sanity checks, or anywhere you want a one-glance summary of what a thread contains without printing every row.

Parameters¶

None

Returns¶

std::string A multi-line summary in this fixed shape (no trailing newline): text     Thread Info     Name: <name, or "<unnamed>">     Kind: <Series|Note|Timeline|TimeIndex>     Dtype: <dtype string, e.g. float64, utf8, int64>     Cases: <total row count>     Non-Null Cases: <valid row count>     Null Cases: <invalid row count>    

Examples¶

Example 1. An unnamed numeric thread with no NULL rows.

using namespace pluss::table;

auto scores = Thread(pluss::make_series({10.0, 20.0, 30.0}));

auto out = scores.info_string();
std::cout << out;

Output¶

Thread Info
Name: <unnamed>
Kind: Series
Dtype: float64
Cases: 3
Non-Null Cases: 3
Null Cases: 0

Example 2. A named thread with a NULL row — name() assigns the display name that shows up as Name: here, and Non-Null Cases/Null Cases reflect the validity mask.

auto scores = Thread(pluss::make_series({10.0, 20.0, 30.0}),
    pluss::make_series(std::vector<bool>{true, false, true})).name("sales");

auto out = scores.info_string();
std::cout << out;

Output¶

Thread Info
Name: sales
Kind: Series
Dtype: float64
Cases: 3
Non-Null Cases: 2
Null Cases: 1

Example 3. Non-numeric payload kinds report their own Kind/Dtype — here, Note-kind text reports dtype utf8.

auto names = Thread(pluss::make_note({"Ada", "Bola"}));

auto out = names.info_string();
std::cout << out;

Output¶

Thread Info
Name: <unnamed>
Kind: Note
Dtype: utf8
Cases: 2
Non-Null Cases: 2
Null Cases: 0

Notes¶

  • Metadata only — never renders row values. Use to_string() or show() instead if you want the actual data rendered.

  • The returned string has no trailing newline — info() is the convenience wrapper that both calls this and adds one when writing to a stream.

  • Name: reads <unnamed> unless the thread was given one via name().

See Also¶

  • Thread::info: writes this same text straight to a stream (std::cout by default) with a trailing newline, instead of returning it as a string.

  • Thread::to_string / Thread::show: render the thread’s actual row values, rather than metadata.

  • Thread::name / Thread::named: set or check the display name that shows up as Name: here.

  • Thread::size / Thread::kind / Thread::dtype: the individual accessors this summary is built from.

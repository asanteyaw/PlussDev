Thread::named¶

Back to Thread API Reference

Signature¶

Thread::named() const -> bool

What It Does¶

Reports whether the thread currently has a name attached — the safe way to check before calling name()’s getter overload, which throws on an unnamed thread.

Parameters¶

None

Returns¶

bool true if a name is attached (via name(value)), false otherwise (including on a freshly constructed thread, or one that had its name removed via unname()).

Examples¶

Example 1. A freshly constructed thread reports false.

using namespace pluss::table;

auto balance = Thread(pluss::make_series({100.0, 250.5, 75.25}));

std::cout << balance.named();

Output¶

false

Example 2. After attaching a name, named() reports true, and the getter no longer throws.

auto named_balance = balance.name("balance");

std::cout << named_balance.named();

if (named_balance.named()) {
  std::cout << named_balance.name();
}

Output¶

true

balance

Notes¶

  • Guards name()’s getter overload, which throws "Thread::name: name is not set" on an unnamed thread.

  • Reports false again after unname().

  • Non-mutating; simply inspects the thread’s current state.

See Also¶

  • Thread::name: the getter/setter pair this method guards.

  • Thread::unname: removes an attached name, after which named() reports false again.

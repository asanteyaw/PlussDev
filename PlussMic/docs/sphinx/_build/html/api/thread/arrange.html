Thread::arrange¶

Back to Thread API Reference

Signature¶

Thread::arrange(bool ascending = true, bool nulls_last = true) const -> Thread

What It Does¶

Returns a new thread with every entry reordered by value — the payload kind is unchanged, only the order changes. The comparison key depends on what the thread holds:

  • Numeric Series: sorted numerically. If there’s no validity mask, this is a single stable argsort (descending = !ascending) followed by a take(). If there is a validity mask, valid and NULL positions are argsorted separately (only the valid subset is compared), then concatenated in the order nulls_last dictates.

  • Timeline/TimeIndex: sorted by epoch-nanosecond value via a stable sort, with the same null-grouping logic applied.

  • Note-kind, or a non-numeric Series: sorted lexicographically by string key (each entry’s string form), with the same null-grouping logic applied.

In every case the sort is stable — entries that compare equal keep their original relative order — and NULL entries are grouped to one end according to nulls_last rather than being compared to real values at all. A thread with size() <= 1 returns unchanged immediately.

Parameters¶

ascending (bool, default true) true sorts smallest/earliest/alphabetically-first values first; false reverses the comparison.

nulls_last (bool, default true) true places every NULL entry after all valid entries, regardless of ascending; false places them before all valid entries instead.

Returns¶

Thread A new thread of the same kind and length, reordered.

Examples¶

Example 1. Ascending numeric sort, no validity mask.

using namespace pluss::table;

auto scores = Thread(pluss::make_series({30.0, 10.0, 50.0, 20.0}));
auto out = scores.arrange();
std::cout << out;

Output¶

0  10
1  20
2  30
3  50

ptype: Series

Example 2. Descending numeric sort.

auto out2 = scores.arrange(false);
std::cout << out2;

Output¶

0  50
1  30
2  20
3  10

ptype: Series

Example 3. With a validity mask, NULLs sort last by default regardless of ascending.

auto masked = Thread(
    pluss::make_series({30.0, 10.0, 50.0, 20.0}),
    pluss::make_series(std::vector<bool>{true, false, true, true})
);
auto out3 = masked.arrange();
std::cout << out3;

Output¶

0  20
1  30
2  50
3  NULL

ptype: Series

Example 4. nulls_last = false moves the NULL entries to the front instead.

auto out4 = masked.arrange(true, false);
std::cout << out4;

Output¶

0  NULL
1  20
2  30
3  50

ptype: Series

Example 5. Note-kind threads sort lexicographically.

auto words = Thread(pluss::make_note({"banana", "apple", "cherry"}));
auto out5 = words.arrange();
std::cout << out5;

Output¶

0  apple
1  banana
2  cherry

ptype: Note

Example 6. The sort is stable — equal keys keep their original relative order. Here two entries tie at 20.0; the one that appeared first in the input (originally at position 1) still precedes the one that appeared later (originally at position 3) in the sorted result.

auto ties = Thread(pluss::make_series({30.0, 20.0, 10.0, 20.0}));
auto out6 = ties.arrange();
std::cout << out6;

Output¶

0  10
1  20
2  20
3  30

ptype: Series

Notes¶

  • Always stable, across every payload kind.

  • NULL entries are never compared against real values — they’re grouped wholesale to one end per nulls_last.

  • size() <= 1 short-circuits to the thread unchanged.

  • Backs both top() and bottom(), which take a prefix of a descending or ascending arrange() call respectively.

See Also¶

  • Thread::top / Thread::bottom: value-sorted previews built on this method.

  • Thread::shuffle: reorder randomly instead of by value.

  • Thread::take: reorder (or subset) by explicit position.

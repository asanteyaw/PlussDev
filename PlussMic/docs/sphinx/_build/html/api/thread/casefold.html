Thread::casefold¶

Back to Thread API Reference

Signature¶

Thread::casefold() const -> Thread

What It Does¶

Produces a case-insensitive-comparison form of a Note (string) thread’s text — conceptually similar to lower(), but intended specifically as a normalization step before equality comparison, not as a display transform. True Unicode case folding can differ from a simple lowercase mapping for certain characters (the canonical example is German ß, which case-folds to ss rather than lowercasing to itself).

Important

This build’s actual behavior casefold()’s Unicode-aware folding is only active when this build links the optional Unicode backend (GNU libunistring). Without it, casefold() falls back to being functionally identical to lower(). On plain ASCII input, the two always produce the same result regardless of build configuration.

Requires the thread to be Note-kind — calling it on a numeric or other kind of thread throws.

Parameters¶

None

Returns¶

Thread A new Note-kind thread, same length as *this, holding the case-folded text.

Examples¶

Example 1. Case-fold mixed-case text.

using namespace pluss::table;

auto roles = Thread(pluss::make_note({"MEMBER", "Guest", "Admin"}));
auto out = roles.casefold();
std::cout << out;

Output¶

0  member
1  guest
2  admin

ptype: Note

On this plain-ASCII input, identical to what roles.lower() would produce.

Example 2. Calling it on a non-Note thread throws.

auto numbers = Thread(pluss::make_series({1.0, 2.0, 3.0}));
try {
  auto bad = numbers.casefold();
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n')) << "\n";
}

Output¶

Thread::casefold: expected Note payload

Notes¶

  • A null cell on input stays null on output.

  • Reach for casefold(), not lower(), whenever the goal is a case-insensitive comparison — even though the two produce identical output on ASCII text in every build, casefold() states the intent explicitly and picks up full Unicode folding automatically if this build’s Unicode support changes.

  • See DataFrameNoteAccessor::casefold for the multi-feature counterpart and a worked comparison example.

See Also¶

  • Thread::lower: the plain lowercase display transform this method is easy to confuse with.

  • Thread::eq: the comparison this method is usually a normalization step for.

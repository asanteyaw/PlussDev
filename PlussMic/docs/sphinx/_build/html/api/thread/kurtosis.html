Thread::kurtosis¶

Back to Thread API Reference

Signature¶

Thread::kurtosis(std::int64_t min_count = 4) const -> ThreadValue

What It Does¶

Returns the sample excess kurtosis (bias-corrected) of every observed value in a numeric Series thread — a measure of tail weight relative to a normal distribution: 0 for normal-like tails, positive for heavier (“fat”) tails, negative for lighter tails. Rather than throwing on a too-small sample, this method returns a result marked invalid whenever the observed count is below max(4, min_count) — kurtosis needs at least 4 observations regardless of what you pass. See Thread::sum’s note on why you should check the scalar validity mask rather than trust the printed number for an invalid result.

If every observed value is identical (zero variance), the result is 0 exactly, rather than the NaN/Infinity that dividing by a zero variance would otherwise produce.

Parameters¶

min_count (std::int64_t, default 4) The smallest observed count still considered valid. The effective floor is always max(4, min_count) — kurtosis needs at least 4 observations regardless of what you pass here.

Returns¶

ThreadValue A scalar Float64 (or Float32 off-CPU) holding the sample excess kurtosis.

Examples¶

Example 1. A sample with a pronounced outlier — heavier tails than normal.

using namespace pluss::table;

auto values = Thread(pluss::make_series({1.0, 2.0, 2.0, 3.0, 10.0}));
auto out = values.kurtosis();
std::cout << out.to_dbl();

Output¶

4.27215

Example 2. Identical values produce exactly 0, not NaN.

auto flat = Thread(pluss::make_series({5.0, 5.0, 5.0, 5.0}));
auto out2 = flat.kurtosis();
std::cout << out2.to_dbl();

Output¶

0

Example 3. Fewer than 4 observed values marks the result invalid rather than throwing.

auto small = Thread(pluss::make_series({1.0, 2.0, 3.0}));
auto out3 = small.kurtosis();
std::cout << out3.thread().notnull().as_series().to_vec<bool>()[0];

Output¶

false

Notes¶

  • The effective minimum observed count is always max(4, min_count) — passing a smaller min_count doesn’t lower the floor below 4.

  • Zero variance (every observed value identical) yields 0 exactly, never NaN.

  • Below the effective minimum count, the result is marked invalid rather than thrown — see the caveat on Thread::sum’s page about checking the scalar validity mask rather than trusting the printed number.

  • Restricted to numeric Series payloads; anything else throws "Thread::kurtosis: expected a real numeric Series Thread".

See Also¶

  • Thread::skew: the third-moment counterpart, measuring asymmetry instead of tail weight.

  • Thread::mean / Thread::var: the lower moments kurtosis builds on.

  • Thread::describe: a broader numeric summary that doesn’t include kurtosis.

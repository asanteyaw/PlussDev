Thread::unname¶

Back to Thread API Reference

Signature¶

Thread::unname() const -> Thread

What It Does¶

Removes an attached name from the thread, returning a new thread with no name — the inverse of name(value)’s setter overload. The underlying values, validity mask, and row labels are all carried over unchanged; only the name is cleared.

Parameters¶

None

Returns¶

Thread A new thread with no name attached, everything else unchanged. Non-mutating — the source thread is never modified, even if it had no name to begin with.

Examples¶

Example 1. Attach a name, then remove it.

using namespace pluss::table;

auto balance = Thread(pluss::make_series({100.0, 250.5, 75.25}));
auto named_balance = balance.name("balance");

std::cout << named_balance.named();

auto unnamed_again = named_balance.unname();

std::cout << unnamed_again.named();

Output¶

true

false

named_balance itself is left unmodified — unname() is non-mutating, so unnamed_again is a distinct copy with the name cleared.

Example 2. Calling unname() on a thread that already has no name is a no-op; it still returns a valid (still-unnamed) copy rather than throwing.

auto still_unnamed = balance.unname();

std::cout << still_unnamed.named();

Output¶

false

Notes¶

  • Non-mutating — always returns a new Thread, even when there was no name to remove.

  • After unname(), named() reports false and name()’s getter throws again.

  • Values, validity mask, and row labels are unaffected — only the name is cleared.

See Also¶

  • Thread::name: attach a name (the setter overload this method reverses).

  • Thread::named: check whether a name is currently attached.

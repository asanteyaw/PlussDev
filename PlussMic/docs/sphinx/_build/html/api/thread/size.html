Thread::size¶

Back to Thread API Reference

Signature¶

Thread::size() const -> std::int64_t

What It Does¶

Returns the number of elements (rows) in the thread — the one dimension a Thread has, regardless of payload kind. This is the same count shape() reports as its first element and ncases() returns under a different name.

Parameters¶

None

Returns¶

std::int64_t The element count. 0 for an empty (but still defined) thread.

Examples¶

Example 1. A thread’s size is independent of payload kind.

using namespace pluss::table;

auto numbers = Thread(pluss::make_series({10.0, 20.0, 30.0}));
auto words = Thread(pluss::make_note({"a", "b"}));
std::cout << numbers.size() << "\n";
std::cout << words.size();

Output¶

3
2

Example 2. size() counts every element, including NULL ones — it’s not a non-null count.

auto with_nulls = Thread(pluss::make_series({1.0, 2.0, 3.0}),
    pluss::make_series(std::vector<bool>{true, false, true}));
std::cout << with_nulls.size();

Output¶

3

Notes¶

  • Counts every element, valid or NULL — see count() for a non-null-only count.

  • Calling size() on an undefined thread throws "Thread: undefined handle" — see defined().

See Also¶

  • Thread::ncases: the same count, under DataFrame-consistent naming.

  • Thread::shape: {size(), 1} — the thread’s shape as a pair.

  • Thread::count: the non-null element count.

Thread::lxor¶

Back to Thread API Reference

Signature¶

Thread::lxor(const Thread& other) const -> Thread

What It Does¶

Elementwise logical XOR, following land()’s shared mechanics: single overload, Bool-only requirement, positional matching, and display labels carried from *this. Unlike AND/OR, XOR reports true exactly where the two operands disagree.

Parameters¶

other (const Thread&)

A Bool-typed Series thread, the same length as *this.

Returns¶

Thread A new Bool-typed thread, same length as *this, holding the elementwise logical XOR.

Examples¶

Example 1. XOR two boolean threads.

using namespace pluss::table;

auto left = Thread(pluss::make_series({true, false, true}, pluss::ScalarType::Bool));
auto right = Thread(pluss::make_series({true, true, false}, pluss::ScalarType::Bool));

auto out = left.lxor(right);
std::cout << out;

Output¶

0  false
1  true
2  true

ptype: Series

Position 0 (true vs true) agrees, so XOR reports false; positions 1 and 2 disagree, so XOR reports true.

Notes¶

  • See land() for the family-wide mechanics.

  • See rxor() for how its reflected form’s display-label behavior differs, the same way rand() differs from land().

See Also¶

  • Thread::rxor: the reflected form.

  • Thread::land: the canonical reference for this family’s shared mechanics.

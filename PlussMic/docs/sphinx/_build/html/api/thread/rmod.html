Thread::rmod¶

Back to Thread API Reference

Signatures¶

Thread::rmod(double other) const -> Thread
Thread::rmod(const Thread& other) const -> Thread

What It Does¶

The reflected form of mod() — computes other % (*this) instead of (*this) % other. Same positive-operands-only caveat as mod() applies: the underlying remainder algorithm’s negative-operand convention isn’t verified in this repository.

Parameters¶

other (double or const Thread&)

Same shape as mod().

Returns¶

Thread A new thread holding other % (*this), elementwise.

Examples¶

Example 1. Remainder of a scalar against every value.

using namespace pluss::table;

auto amounts = Thread(pluss::make_series({17.0, 26.0, 33.0}));
auto out = amounts.rmod(200.0);
std::cout << out;

Output¶

0  13
1  18
2  2
ptype: Series

200 = 17*11 + 13, 200 = 26*7 + 18, 200 = 33*6 + 2 — the opposite framing from amounts.mod(...), where amounts supplied the dividends.

Example 2. Reflected against another thread.

auto multiples = Thread(pluss::make_series({50.0, 80.0, 90.0}));
auto out_pair = amounts.rmod(multiples);
std::cout << out_pair;

Output¶

0  16
1  2
2  24
ptype: Series

amounts.rmod(multiples) computes exactly what multiples.mod(amounts) would: 50 % 17 = 16, 80 % 26 = 2, 90 % 33 = 24.

Notes¶

  • amounts.rmod(x) always equals x % amounts — the mirror image of mod().

  • If the scalar or other value at a position is smaller than the corresponding value in *this, the remainder is just that smaller value itself (dividing 0 whole times) — for example, amounts.rmod(5.0) would give 5, 5, 5 here, since 5 is smaller than every value in amounts.

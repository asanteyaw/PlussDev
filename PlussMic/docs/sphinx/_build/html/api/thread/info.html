Thread::info¶

Back to Thread API Reference

Signatures¶

Thread::info() const -> void
Thread::info(std::ostream& os) const -> void

What It Does¶

Writes the same metadata summary info_string() builds — name, payload kind, dtype, row count, valid/null breakdown — straight to a stream, with a trailing newline appended. info() (no arguments) writes to std::cout; info(os) writes to whatever stream you provide. Both are pure conveniences over os << thread.info_string() << '\n'.

Parameters¶

os (std::ostream&, info(os) overload only) The destination stream. Defaults to std::cout for the no-argument overload.

Returns¶

void Writes to the stream as a side effect; produces no return value.

Examples¶

Example 1. info() with no arguments writes the summary to std::cout.

using namespace pluss::table;

auto scores = Thread(pluss::make_series({10.0, 20.0, 30.0}));

scores.info();

Output¶

Thread Info
Name: <unnamed>
Kind: Series
Dtype: float64
Cases: 3
Non-Null Cases: 3
Null Cases: 0

Example 2. info(os) writes to any stream — useful for capturing the summary into a std::ostringstream, a log file stream, or similar, rather than the console.

auto scores = Thread(pluss::make_series({10.0, 20.0, 30.0}));

std::ostringstream captured;
scores.info(captured);
std::cout << "[" << captured.str() << "]";

Output¶

[Thread Info
Name: <unnamed>
Kind: Series
Dtype: float64
Cases: 3
Non-Null Cases: 3
Null Cases: 0
]

Notes¶

  • Both overloads are a thin convenience over info_string(): os << thread.info_string() << '\n'.

  • Unlike info_string()’s returned string, the stream output does end with a trailing newline.

  • Metadata only — like info_string(), this never renders the thread’s actual row values. Use show() for that.

See Also¶

  • Thread::info_string: the same summary, returned as a std::string instead of written to a stream — see that page for the exact field-by-field format.

  • Thread::show: render the thread’s actual row values to a stream, rather than metadata.

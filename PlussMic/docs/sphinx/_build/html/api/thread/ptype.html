Thread::ptype¶

Back to Thread API Reference

Signature¶

Thread::ptype() const -> std::string

What It Does¶

Returns the broad payload family as a display string: "Series", "Note", "Timeline", or "TimeIndex" — the same information kind() returns as a typed ThreadKind enum, formatted for printing. This is the 1D analog of DataFrame::ptypes(), which reports the same family names per feature.

Parameters¶

None

Returns¶

std::string One of "Series", "Note", "Timeline", "TimeIndex".

Examples¶

Example 1. ptype() across all four payload kinds.

using namespace pluss::table;

auto numeric = Thread(pluss::make_series({10.0, 20.0, 30.0}));
auto text = Thread(pluss::make_note({"a", "b"}));
auto dates = Thread(pluss::make_timeline({"2024-01-01T00:00:00Z"}));

std::cout << numeric.ptype() << "\n";
std::cout << text.ptype() << "\n";
std::cout << dates.ptype();

Output¶

Series
Note
Timeline

Notes¶

  • ptype() is for dispatching or displaying by payload family. Use dtype() when you need the concrete storage detail within that family (e.g. which numeric scalar type a Series thread holds).

  • Calling ptype() on an undefined thread throws "Thread: undefined handle".

See Also¶

  • Thread::kind: the same information as a typed ThreadKind enum, for use in C++ comparisons and switch statements.

  • Thread::dtype: the concrete dtype, one level more specific.

  • DataFrame::ptypes: the same summary across every feature of an entire frame.

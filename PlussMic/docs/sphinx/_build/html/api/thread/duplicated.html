Thread::duplicated¶

Back to Thread API Reference

Signature¶

Thread::duplicated(bool keep_first = true, bool keep_last = false) const -> Thread

What It Does¶

Returns a boolean thread, the same length as the source, marking which entries are duplicate followers of an earlier (or later) occurrence — one designated occurrence per distinct value is left false (the “survivor”), and every other occurrence of that value is marked true. Which occurrence survives is controlled by keep_first/keep_last:

  • keep_first = true (the default): the first occurrence of each value is the survivor; every later repeat is marked true.

  • keep_last = true: the last occurrence is the survivor instead; every earlier repeat is marked true.

keep_first and keep_last cannot both be true — that throws. A value that appears only once is never marked, regardless of the policy. This method only reports duplicate membership — it never removes or reorders anything itself; pass the result to filter() to actually drop the flagged rows.

Parameters¶

keep_first (bool, default true) Treat each value’s first occurrence as the survivor (left false).

keep_last (bool, default false) Treat each value’s last occurrence as the survivor (left false) instead. Cannot be true at the same time as keep_first.

Returns¶

Thread A boolean Series, same length as the source, true at every non-survivor duplicate position.

Examples¶

Example 1. Default policy — keep the first occurrence of each value.

using namespace pluss::table;

auto cities = Thread(pluss::make_note({"Accra", "Tema", "Accra", "Kumasi", "Tema"}));
auto out = cities.duplicated();
std::cout << out;

Output¶

0  false
1  false
2  true
3  false
4  true

ptype: Series

Positions 0 and 1 (the first "Accra" and first "Tema") stay false; their later repeats at 2 and 4 are flagged true. "Kumasi" (unique) is never flagged.

Example 2. keep_last = true flips which occurrence survives.

auto out2 = cities.duplicated(false, true);
std::cout << out2;

Output¶

0  true
1  true
2  false
3  false
4  false

ptype: Series

Now the last "Accra" (position 2) and last "Tema" (position 4) are the survivors; their earlier occurrences flip to true instead.

Example 3. keep_first and keep_last cannot both be true.

try {
  auto bad = cities.duplicated(true, true);
} catch (const std::exception& e) {
  std::cout << e.what();
}

Output¶

Thread::duplicated: keep_first and keep_last cannot both be true

Notes¶

  • Grouping is by each value’s string form, matching distinct()/freq(); works across every payload kind.

  • A value occurring only once is never flagged, under either policy.

  • Reports membership only — combine with filter() (or its logical negation) to actually drop or keep duplicates.

  • keep_first && keep_last throws "Thread::duplicated: keep_first and keep_last cannot both be true".

See Also¶

  • Thread::repeated: mark every member of a repeated group (including the would-be survivor), rather than just the followers.

  • Thread::distinct: the deduplicated values themselves, instead of a boolean mask over the original positions.

  • Thread::filter: apply the mask this method returns to actually drop or keep rows.

RegistryTimelineAccessor::weekday¶

Back to RegistryTimelineAccessor API Reference

Signature¶

Registry RegistryTimelineAccessor::weekday() const

What It Does¶

Extracts the weekday number (0 = Monday through 6 = Sunday) of each bound field’s timestamp, replacing each Timeline field with an Int64 Series field.

Parameters¶

None

Returns¶

Registry A new registry with every bound field replaced by an Int64 Series field of weekday numbers; every unbound field unchanged.

Examples¶

Example 1. Extract the weekday number from a Wednesday and a Thursday.

auto rg = pluss::bundle::Registry({
    {"ts", pluss::bundle::Slot({pluss::make_timeline("2024-01-31T09:15:30Z"), pluss::make_timeline("2024-02-29T23:45:00Z")})},
});

auto out = rg.fields({"ts"}).tl().weekday();
auto ts = out.fields("ts");
std::cout << std::get<pluss::Series>(ts.at(0)).to_vec<std::int64_t>()[0] << " "
          << std::get<pluss::Series>(ts.at(1)).to_vec<std::int64_t>()[0];

Output¶

2 3

"2024-01-31" is a Wednesday (2), "2024-02-29" is a Thursday (3) — see weekday_name() for the same information spelled out.

Notes¶

  • 0 is Monday, 6 is Sunday (ISO weekday numbering).

  • Reads local calendar fields relative to whatever timezone the field’s Timeline currently carries ("UTC" unless changed via tz()/localize()).

  • Requires every bound field to be Timeline-kind — a non-Timeline field throws "Slot::tl: slot kind must be Timeline".

See Also¶

  • RegistryTimelineAccessor::weekday_name: the same information as a full English name instead of a number.

  • RegistryTimelineAccessor::weekend: whether the weekday falls on a weekend.

  • RegistryTimelineAccessor::week: the ISO week-of-year this weekday belongs to.

  • Registry::tl: the entry point this accessor is reached from.

RegistryTimelineAccessor::date¶

Back to RegistryTimelineAccessor API Reference

Signature¶

Registry RegistryTimelineAccessor::date() const

What It Does¶

Strips the time-of-day from each bound field’s timestamp (dropped to midnight), replacing each Timeline field’s values in place. Equivalent to floor("D").

Parameters¶

None

Returns¶

Registry A new registry with every bound field’s time-of-day portion zeroed out; every unbound field unchanged.

Examples¶

Example 1. Strip the time-of-day from two timestamps.

auto rg = pluss::bundle::Registry({
    {"ts", pluss::bundle::Slot({pluss::make_timeline("2024-01-31T09:15:30Z"), pluss::make_timeline("2024-02-29T23:45:00Z")})},
});

auto out = rg.fields({"ts"}).tl().date();
auto fmted = out.fields("ts").tl().fmt("%Y-%m-%d %H:%M:%S");
std::cout << std::get<pluss::Note>(fmted.at(0)).at(0) << " | "
          << std::get<pluss::Note>(fmted.at(1)).at(0);

Output¶

2024-01-31 00:00:00 | 2024-02-29 00:00:00

Notes¶

  • Requires every bound field to be Timeline-kind — a non-Timeline field throws "Slot::tl: slot kind must be Timeline".

See Also¶

  • RegistryTimelineAccessor::time: the mirror-image operation, keeping the time-of-day and zeroing the date.

  • RegistryTimelineAccessor::floor: the general form date() is a fixed "D" unit of.

  • Registry::tl: the entry point this accessor is reached from.

RegistryTimelineAccessor::weekend¶

Back to RegistryTimelineAccessor API Reference

Signature¶

Registry RegistryTimelineAccessor::weekend() const

What It Does¶

Flags whether each bound field’s timestamp falls on a Saturday or Sunday, replacing each Timeline field with a Bool Series field.

Parameters¶

None

Returns¶

Registry A new registry with every bound field replaced by a Bool Series field: true where the row falls on a weekend, false otherwise.

Examples¶

Example 1. Flag a Saturday and a Wednesday.

auto rg = pluss::scribble::Registry({
    {"ts", pluss::scribble::Slot({pluss::make_timeline("2024-07-06T14:00:00Z"), pluss::make_timeline("2023-03-01T00:00:00Z")})},
});

auto out = rg.fields({"ts"}).tl().weekend();
auto ts = out.fields("ts");
std::cout << std::boolalpha
          << std::get<pluss::Series>(ts.at(0)).host<bool>()[0] << " "
          << std::get<pluss::Series>(ts.at(1)).host<bool>()[0];

Output¶

true false

"2024-07-06" is a Saturday; "2023-03-01" is a Wednesday.

Notes¶

  • Saturday and Sunday only — there’s no configurable weekend definition on this method.

  • Reads local calendar fields relative to whatever timezone the field’s Timeline currently carries ("UTC" unless changed via tz()/localize()).

  • Requires every bound field to be Timeline-kind — a non-Timeline field throws "Slot::tl: slot kind must be Timeline".

See Also¶

  • RegistryTimelineAccessor::weekday: the underlying weekday number this method is derived from.

  • RegistryTimelineAccessor::weekday_name: the weekday spelled out as a full English name.

  • Registry::tl: the entry point this accessor is reached from.

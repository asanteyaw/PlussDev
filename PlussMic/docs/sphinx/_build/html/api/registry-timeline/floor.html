RegistryTimelineAccessor::floor¶

Back to RegistryTimelineAccessor API Reference

Signature¶

Registry RegistryTimelineAccessor::floor(std::string_view unit) const

What It Does¶

Rounds each bound field’s timestamp down to the nearest unit boundary, replacing each Timeline field’s values in place (the field stays Timeline-kind).

Parameters¶

unit (std::string_view) One of "S"/"s"/"sec"/"second", "min"/"m"/"minute", "H"/"h"/"hour", or "D"/"d"/"day". Cannot be empty. An unsupported unit throws.

Returns¶

Registry A new registry with every bound field’s timestamps floored to unit; every unbound field unchanged.

Examples¶

Example 1. Floor two timestamps to the nearest hour.

auto rg = pluss::scribble::Registry({
    {"ts", pluss::scribble::Slot({pluss::make_timeline("2024-01-31T09:15:30Z"), pluss::make_timeline("2024-02-29T23:45:00Z")})},
});

auto out = rg.fields({"ts"}).tl().floor("H");
auto fmted = out.fields("ts").tl().fmt("%Y-%m-%d %H:%M:%S");
std::cout << std::get<pluss::Note>(fmted.at(0)).at(0) << " | "
          << std::get<pluss::Note>(fmted.at(1)).at(0);

Output¶

2024-01-31 09:00:00 | 2024-02-29 23:00:00

09:15:30 drops to 09:00:00; 23:45:00 was already exactly on the hour in terms of its floor target, so it advances to 23:00:00.

Example 2. An unsupported unit throws.

auto rg = pluss::scribble::Registry({
    {"ts", pluss::scribble::Slot({pluss::make_timeline("2024-01-31T09:15:30Z")})},
});

try {
  auto out = rg.fields({"ts"}).tl().floor("bogus");
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n'));
}

Output¶

Timeline: unsupported unit (expected S/min/H/D)

Notes¶

  • unit cannot be empty, and only accepts the fixed clock units listed above — an unrecognized unit throws, per Example 2.

  • Requires every bound field to be Timeline-kind — a non-Timeline field throws "Slot::tl: slot kind must be Timeline".

See Also¶

  • RegistryTimelineAccessor::ceil / round(): round up, or to the nearest boundary, instead of always down.

  • RegistryTimelineAccessor::date: shorthand for floor("D").

  • Registry::tl: the entry point this accessor is reached from.

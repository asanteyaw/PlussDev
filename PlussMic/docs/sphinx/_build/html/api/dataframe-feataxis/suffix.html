DataFrameFeatureAxisAccessor::suffix¶

Back to DataFrameFeatureAxisAccessor API Reference

Signature¶

DataFrameFeatureAxisAccessor::suffix(std::string_view suffix) const -> DataFrame

What It Does¶

Appends suffix to every feature name on the frame. Values, case labels, and row order are all unaffected — only the names change.

Parameters¶

suffix (std::string_view)

Text appended after every existing feature name.

Returns¶

DataFrame A new frame with every feature renamed to original_name + suffix.

Examples¶

Example 1. Suffix every feature name on a mixed-kind frame.

using namespace pluss::table;

auto orders = DataFrame(
    {{"sales_units", Slate(pluss::make_series({100.0, 120.0, 90.0}))},
     {"sales_price", Slate(pluss::make_series({1.5, 2.0, 1.8}))},
     {"city",        Slate(pluss::make_note({"Accra", "Tema", "Kumasi"}))}});
std::cout << orders;

auto out = orders.feataxis().suffix("_v2");
std::cout << out;

Output (before)¶

=======================================
     | sales_units  sales_price  city  
---------------------------------------
0    | 100          1.5          Accra 
1    | 120          2            Tema  
2    | 90           1.8          Kumasi
---------------------------------------
[3 cs x 3 feat]

Output (after)¶

==============================================
     | sales_units_v2  sales_price_v2  city_v2
----------------------------------------------
0    | 100             1.5             Accra  
1    | 120             2               Tema   
2    | 90              1.8             Kumasi 
----------------------------------------------
[3 cs x 3 feat]

Every feature name gets "_v2" appended — there’s no way to target only some of them with this method.

Notes¶

  • Applies to every feature, unconditionally — combine with like()/match() first (and rejoin) if only some features should be renamed.

  • Values, case labels, and row order are completely unaffected.

See Also¶

  • DataFrameFeatureAxisAccessor::prefix: the mirror-image operation, prepending instead of appending.

  • DataFrameLabelAccessor::rename: rename case-label levels rather than feature columns.

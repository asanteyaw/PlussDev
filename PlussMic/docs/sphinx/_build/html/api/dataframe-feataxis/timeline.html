DataFrameFeatureAxisAccessor::timeline¶

Back to DataFrameFeatureAxisAccessor API Reference

Signature¶

DataFrameFeatureAxisAccessor::timeline() const -> DataFrame

What It Does¶

Selects every feature whose Thread kind is Timeline or TimeIndex — dropping numeric (Series) and text (Note) features. Case labels and row order are preserved unchanged.

Returns¶

DataFrame A new frame with only the Timeline/TimeIndex-kind features; same case labels and rows as the source.

Examples¶

Example 1. Keep only the temporal feature out of a mixed frame.

using namespace pluss::table;

auto orders = DataFrame(
    {{"sales_units", Thread(pluss::make_series({100.0, 120.0, 90.0}))},
     {"city",        Thread(pluss::make_note({"Accra", "Tema", "Kumasi"}))},
     {"visit_date",  Thread(pluss::make_timeline({
          "2024-01-01T00:00:00Z", "2024-01-02T00:00:00Z", "2024-01-03T00:00:00Z"}))}});
std::cout << orders;

auto out = orders.feataxis().timeline();
std::cout << out;

Output (before)¶

======================================
     | sales_units  city    visit_date
--------------------------------------
0    | 100          Accra   2024-01-01
1    | 120          Tema    2024-01-02
2    | 90           Kumasi  2024-01-03
--------------------------------------
[3 cs x 3 feat]

Output (after)¶

=================
     | visit_date
-----------------
0    | 2024-01-01
1    | 2024-01-02
2    | 2024-01-03
-----------------
[3 cs x 1 feat]

Notes¶

  • Includes both Timeline and TimeIndex kinds — it does not distinguish between them.

  • If no feature is temporal, the result has zero features but the same case labels and row count.

See Also¶

  • DataFrameFeatureAxisAccessor::series, DataFrameFeatureAxisAccessor::note: the analogous filters for the other two payload kinds.

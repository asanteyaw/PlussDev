Nexus API Reference¶

This page documents the public Nexus surface as part of the bundle workspace model.

Nexus is a named, multi-table workspace built on top of DataFrame — it holds a keyed collection of frames, layers on declared relationships between them, and provides key/relationship auditing, join-graph pathfinding, a fluent pull builder (pull(root)), a fluent graph builder (NexusTraverse, returned by from()), a SQL workspace accessor (NexusQuery, returned by query()), and save/load persistence.

Use the pluss::bundle namespace for Nexus itself, and pluss::table for the DataFrame and Atlas objects it coordinates.

Note

No dedicated constructor page Construct a Nexus with Nexus({{"name", frame}, ...}) (a vector or brace list of name/DataFrame pairs); there is no dedicated constructor page, the same as DataFrame’s own constructors.

Method Pages¶

The sidebar lists methods alphabetically. You can also use the search box to jump directly to a method name. Several names are exact aliases of a canonical method (names↔keys, links↔relationships/add_relationship, meta↔table_meta/ set_table_meta, duplicates↔detect_duplicates, check↔validate_relationship, orphans↔detect_orphans, audit↔relationship_audit) — each alias has its own short page pointing back to the canonical one.

The Query Builder¶

Nexus::pull(root) now has two layers:

  • pull(root) returns a fluent root-grain feature builder

  • pull(root, {...}) executes immediately from string expressions or typed PullSpecs

The fluent builder is the preferred spelling for real feature assembly because it avoids repeating namespace qualifiers on every requested field, while still delegating to the same underlying pull engine.

Its builder edge now follows the same pattern as DataFrame: canonical RangeView inputs, with ergonomic brace-list / vector / array call sites adapted through StackArray where needed. That keeps ordinary user code short while avoiding fragile overload proliferation in the public API.

Nexus::from(table) returns a NexusTraverse, a separate fluent builder for walking the join graph from one anchor table (.join()/.via()/.pick()/.drop()/.collect()).

Nexus::query() returns a NexusQuery, the workspace SQL accessor for SELECT ... FROM ... JOIN ... queries over the named tables already loaded into the Nexus.

## `df.plot(...)` Defaults And Options

### Signature

`DataFramePlotAccessor plot(self)`

`DataFramePlotAccessor plot(self, DataFramePlotOptions options)`

### What `DataFramePlotOptions` Controls

`default_x_feature` (`std::optional<std::string>`, default `nullopt`)
: Default x-axis feature used when a plot call does not provide an explicit `x_feature`.

`default_hue_feature` (`std::optional<std::string>`, default `nullopt`)
: Default grouping/color feature used by plot types that support hue/group splits.

`default_bins` (`std::int64_t`, default `20`)
: Default bin count for histogram-style plots when bins are not explicitly passed.

`datetime_label_view` (`DateTimeLabelView`, default `DateTimeLabelView::Full`)
: Datetime tick label rendering mode (`Full`, `Date`, or `Time`) for datetime axes.

`max_labeled_ticks` (`std::int64_t`, default `14`)
: Upper bound on how many tick labels are rendered to avoid dense, unreadable axes.

`labeled_tick_rotation_deg` (`std::optional<double>`, default `nullopt`)
: Optional tick-label rotation (degrees) for crowded categorical or datetime labels.

`width` (`std::optional<double>`, default `nullopt`)
: Optional figure width override.

`height` (`std::optional<double>`, default `nullopt`)
: Optional figure height override.

`use_tight_layout` (`bool`, default `false`)
: When enabled, applies tight layout spacing rules to reduce label clipping.

`tight_layout_padding` (`double`, default `6.0`)
: Padding used by tight layout when `use_tight_layout=true`.

### Usage Pattern

```cpp
using namespace pluss::table;

DataFramePlotOptions opts{};
opts.default_x_feature = "timestamp";
opts.default_hue_feature = "sector";
opts.default_bins = 30;
opts.datetime_label_view = DateTimeLabelView::Date;
opts.max_labeled_ticks = 10;
opts.labeled_tick_rotation_deg = 35.0;
opts.width = 13.0;
opts.height = 7.0;
opts.use_tight_layout = true;
opts.tight_layout_padding = 4.0;

auto plot = df.plot(opts);
auto line_fig = plot.line({"open", "close"});
auto hist_fig = plot.hist("returns");
```

### Output

```text
Figure(...)
Figure(...)
```

## Method-Level Options Reference

All method options are regular C++ structs. Create, edit fields, then pass into the corresponding `plot.*(...)` call.

```cpp
pluss::table::ActPlotOptions o{};
o.max_lag = 60;
o.confidence_level = 0.99;
auto fig = df.plot().act("returns", o);
```

### `LinePlotOptions`

`LinePlotOptions(alpha=1.0, line_width=1.6, y_limit_method=pluss::pl::LimitMethod::Padded)`

- `alpha` (`double`): line opacity.
- `line_width` (`double`): line thickness.
- `y_limit_method` (`std::optional<pluss::pl::LimitMethod>`): y-axis limit strategy.

### `StepPlotOptions`

`StepPlotOptions(alpha=1.0, line_width=1.5)`

- `alpha` (`double`): step trace opacity.
- `line_width` (`double`): step trace thickness.

### `AreaPlotOptions`

`AreaPlotOptions(alpha=0.88, line_width=1.3)`

- `alpha` (`double`): fill opacity.
- `line_width` (`double`): boundary line thickness.

### `AreaStackedPlotOptions`

`AreaStackedPlotOptions(alpha=0.7, line_width=1.2)`

- `alpha` (`double`): stacked area opacity.
- `line_width` (`double`): boundary line thickness.

### `ScatterPlotOptions`

`ScatterPlotOptions(alpha=0.92, line_width=1.1)`

- `alpha` (`double`): marker opacity.
- `line_width` (`double`): marker edge width.

### `BarPlotOptions`

`BarPlotOptions(ci_enabled=false, ci_level=0.95, horizontal=false)`

- `ci_enabled` (`bool`): enable confidence interval bars.
- `ci_level` (`double`): confidence level when CI is enabled.
- `horizontal` (`bool`): draw horizontal bars.

### `BarStackedPlotOptions`

`BarStackedPlotOptions(alpha=0.65, line_width=1.0)`

- `alpha` (`double`): stacked bar opacity.
- `line_width` (`double`): bar edge thickness.

### `BoxPlotOptions`

`BoxPlotOptions(alpha=0.95, line_width=1.1)`

- `alpha` (`double`): box body opacity.
- `line_width` (`double`): outline thickness.

### `ViolinPlotOptions`

`ViolinPlotOptions(alpha=0.92, line_width=1.1, width=0.8, bw_adjust=1.0, cut=2.0, scale=pluss::pl::ViolinScale::Area, inner=pluss::pl::ViolinInner::Box, side=pluss::pl::ViolinSide::Full)`

- `alpha` (`double`): violin fill opacity.
- `line_width` (`double`): outline thickness.
- `width` (`double`): violin width scale.
- `bw_adjust` (`double`): KDE bandwidth adjustment.
- `cut` (`double`): tail extension in bandwidth units.
- `scale` (`pluss::pl::ViolinScale`): area/count/width scaling behavior.
- `inner` (`pluss::pl::ViolinInner`): inner annotation style.
- `side` (`pluss::pl::ViolinSide`): full/left/right rendering.

### `HistPlotOptions`

`HistPlotOptions(bins=20, alpha=0.95, line_width=1.0)`

- `bins` (`std::int64_t`): histogram bin count.
- `alpha` (`double`): bar opacity.
- `line_width` (`double`): bar edge thickness.

### `DensityPlotOptions`

`DensityPlotOptions(points=128, alpha=1.0, line_width=1.5)`

- `points` (`std::int64_t`): sampled KDE points.
- `alpha` (`double`): curve opacity.
- `line_width` (`double`): curve thickness.

### `HeatmapPlotOptions`

`HeatmapPlotOptions(annotate_levels=false, scale_guide=true, borderless=false)`

- `annotate_levels` (`bool`): print values in cells.
- `scale_guide` (`bool`): show color scale legend.
- `borderless` (`bool`): remove cell border strokes.

### `CorrHeatmapPlotOptions`

`CorrHeatmapPlotOptions(annotate_levels=true, scale_guide=true, borderless=false)`

- `annotate_levels` (`bool`): print correlation values in cells.

### `ScatterMatrixPlotOptions`

`ScatterMatrixPlotOptions(corner=false, pair={})`

- `corner` (`bool`): render only one matrix triangle.
- `pair` (`pluss::pl::flash::PairPlotOptions`): low-level pair-plot styling options.

### `ParallelPlotOptions`

`ParallelPlotOptions(labels={}, normalize=true, max_points=1200, alpha=0.24, trace_width=0.9f, show_grid=true, show_legend=true)`

- `labels` (`std::vector<std::string>`): display labels for classes/groups.
- `normalize` (`bool`): scale features before plotting.

- `alpha` (`double`): polyline opacity.
- `trace_width` (`float`): polyline thickness.

- `show_legend` (`bool`): show legend.

### `AndrewsCurvesPlotOptions`

`AndrewsCurvesPlotOptions(labels={}, normalize=true, points=220, max_curves=600, alpha=0.28, trace_width=0.9f, show_grid=true, show_legend=true)`

- `labels` (`std::vector<std::string>`): class labels.

- `points` (`std::int64_t`): points per curve.
- `max_curves` (`std::int64_t`): max curves rendered.

### `RadvizPlotOptions`

`RadvizPlotOptions(labels={}, normalize=true, max_points=3000, marker_area=18.0, trace_width=0.55f, show_grid=true, show_anchors=true, show_legend=true)`

- `labels` (`std::vector<std::string>`): class labels.
- `normalize` (`bool`): normalize features before projection.
- `max_points` (`std::int64_t`): max points rendered.
- `marker_area` (`double`): marker size.
- `trace_width` (`float`): marker edge width.
- `show_grid` (`bool`): show grid.
- `show_anchors` (`bool`): show anchor positions.
- `show_legend` (`bool`): show legend.

### `LagPlotOptions`

`LagPlotOptions(lag=1, max_points=2500, marker_area=16.0, trace_width=0.55f)`

- `lag` (`std::int64_t`): lag step.
- `max_points` (`std::int64_t`): max points rendered.
- `marker_area` (`double`): marker size.
- `trace_width` (`float`): marker edge width.

### `ActPlotOptions`

`ActPlotOptions(max_lag=40, show_confidence_band=true, confidence_level=0.95, trace_width=1.2f)`

- `max_lag` (`std::int64_t`): max lag for ACF/PACF style plot.
- `show_confidence_band` (`bool`): draw confidence band.
- `confidence_level` (`double`): confidence level for band.
- `trace_width` (`float`): trace line width.

### `BootstrapPlotOptions`

`BootstrapPlotOptions(samples=300, sample_size=0, seed=7, bins=24, statistic=BootstrapStatistic::Mean, trace_width=0.85f)`

- `samples` (`std::int64_t`): bootstrap draw count.
- `sample_size` (`std::int64_t`): sample size per draw; `0` means default dataset size.
- `seed` (`std::uint64_t`): RNG seed.
- `bins` (`int`): histogram bins for bootstrap distribution.
- `statistic` (`BootstrapStatistic`): one of `Mean`, `Median`, `Std`.
- `trace_width` (`float`): trace width.

### `PiePlotOptions`

`PiePlotOptions(show_label=true, show_percent=true, show_value=false, precision=1, separator=" | ")`

- `show_label` (`bool`): show labels.
- `show_percent` (`bool`): show percent text.
- `show_value` (`bool`): show raw values.
- `precision` (`int`): decimal precision for labels.
- `separator` (`std::string`): label text separator.

### `AutoPlotOptions`

`AutoPlotOptions()`

- No fields currently. Use default automatic chart selection.

### 3D Shared Option Structs

#### `Plot3DSceneOptions`

`Plot3DSceneOptions(preset=nullopt, theme=nullopt, camera_preset=nullopt, camera=nullopt, lighting=nullopt, grid_style=nullopt)`

- `preset` (`std::optional<pluss::pl::flash::ScenePreset3D>`): scene preset.

- `camera_preset` (`std::optional<pluss::pl::flash::CameraPreset3D>`): camera preset.

### Bonus: `BriefPlotOptions` (used by `plot.brief`)

`BriefPlotOptions(title="table", precision=4, include_header=true, max_cases=10, transpose=false, include_case_index=true, features_per_table=0, tables_per_row=1, table_gap_spaces=4)`

- `title` (`std::string`): figure title.
- `precision` (`int`): numeric precision.
- `include_header` (`bool`): include feature header row.
- `max_cases` (`std::int64_t`): max rows shown.
- `transpose` (`bool`): transpose preview table.
- `include_case_index` (`bool`): show case index.
- `features_per_table` (`std::int64_t`): chunk width per table block.
- `tables_per_row` (`std::int64_t`): number of blocks per row.
- `table_gap_spaces` (`std::int64_t`): spacing between blocks.

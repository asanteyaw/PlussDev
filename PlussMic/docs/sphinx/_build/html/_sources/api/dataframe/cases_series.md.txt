# DataFrame::cases_series

[Back to DataFrame API Reference](../../dataframe_api_reference.md)

## Signature

```cpp
DataFrame::cases_series() -> pluss::Series
```

Return the current case axis as a numeric `Series`.

Use this when your frame already has a numeric case axis and you want to feed those labels into numeric PlussQit or PlussMic operations.

## Parameters

`None`

## Returns

`pluss::Series`
    Materialized numeric series containing the current case labels.

## Notes

This is the numeric-axis bridge. Use it when the case axis is already series-backed or when the current case representation can be expressed as a numeric series.

If you only want to inspect the case axis without changing representation, use `cases()`.

## Examples

Example 1. Materialize a numeric case axis as a Series.

```cpp
using namespace pluss::table;

auto numeric_cases = DataFrame({
    {"student", pluss::make_note({"Ada", "Bola", "Chen"})},
    {"score", pluss::make_series({88.0, 79.0, 91.0})},
}, pluss::make_series({101.0, 102.0, 103.0}));

auto out = Thread(numeric_cases.cases_series());
```

### Output

```text
0  101
1  102
2  103
dtype: Series
```

# SlateNoteAccessor::lower

[Back to SlateNoteAccessor API Reference](../../slate_note_accessor_api_reference)

## Signature

```cpp
SlateNoteAccessor::lower() const -> Slate
```

## What It Does

Lowercases every character in the bound thread's cells — the classic normalization
step before a case-insensitive comparison, a grouping key that shouldn't be split by
casing accidents, or a lookup against a canonical lowercase reference list. A direct
forward to [`Slate::lower()`](../thread/lower.md). Requires the bound thread to be
`Note`-kind.

```{note} ASCII vs. Unicode case mapping
On plain ASCII text, `lower()` behaves exactly as you'd expect. Non-ASCII case
mapping depends on whether this build links the optional Unicode backend (GNU
libunistring).
```

## Parameters

`None`

## Returns

`Slate`
    A new `Note`-kind thread, same length as the bound thread, with every character
    lowercased.

## Examples

Example 1. Lowercase a text thread via the accessor.

```cpp
using namespace pluss::table;

auto cities = Slate(pluss::make_note({"Accra", "TEMA", "Kumasi"}));
auto out = cities.nt().lower();
std::cout << out;
```

### Output

```text
0  accra
1  tema
2  kumasi

ptype: Note
```

Example 2. A non-`Note` thread throws — the same message
[`Slate::lower()`](../thread/lower.md) produces directly.

```cpp
auto numbers = Slate(pluss::make_series({1.0, 2.0, 3.0}));
try {
  auto bad = numbers.nt().lower();
} catch (const std::exception& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n')) << "\n";
}
```

### Output

```text
Slate::lower: expected Note payload
```

## Notes

- `SlateNoteAccessor::lower()` is a one-line forward to
  [`Slate::lower()`](../thread/lower.md) — identical behavior and throws.
- A null cell on input stays null on output.
- For the opposite transform, see [`upper()`](upper.md). For a comparison-oriented
  case normalization, see [`casefold()`](casefold.md).

## See Also

- [`Slate::lower`](../thread/lower.md): the direct, non-accessor form this method
  forwards to.
- [`SlateNoteAccessor::upper`](upper.md): the inverse transform.
- [`SlateNoteAccessor::casefold`](casefold.md): case folding intended for
  comparison rather than display.

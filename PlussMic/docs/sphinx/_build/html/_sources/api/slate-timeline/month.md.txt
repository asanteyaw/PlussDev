# SlateTimelineAccessor::month

[Back to SlateTimelineAccessor API Reference](../../slate_timeline_accessor_api_reference)

## Signature

```cpp
SlateTimelineAccessor::month() const -> Slate
```

## What It Does

Replaces the bound thread with its calendar month (`1`-`12`), as a numeric
`Series`.

## Parameters

`None`

## Returns

`Slate`
    A new `Series`-kind (`Int64`) thread, same length as the bound thread,
    holding each row's calendar month.

## Examples

Example 1. Extract the month from every row.

```cpp
using namespace pluss::table;

auto events = Slate(pluss::make_timeline({
    "2024-01-31T09:15:30Z",
    "2024-02-29T23:45:00Z",
    "2024-07-06T14:00:00Z",
}));
auto out = events.tl().month();
std::cout << out;
```

### Output

```text
0  1
1  2
2  7

ptype: Series
```

## Notes

- `.tl()` requires the bound thread to already be `Timeline`-kind —
  the accessor's constructor throws otherwise.
- A `NaT` row (or one already null on the underlying thread) displays as
  `"NULL"`, not a sentinel month number.
- Reads the local calendar month relative to the thread's current timezone.

# SlateTimelineAccessor::month_end

[Back to SlateTimelineAccessor API Reference](../../slate_timeline_accessor_api_reference)

## Signature

```cpp
SlateTimelineAccessor::month_end() const -> Slate
```

## What It Does

Replaces the bound thread with a boolean `Series` flagging whether each row
falls on the last day of its month.

## Parameters

`None`

## Returns

`Slate`
    A new `Bool`-typed `Series` thread, same length as the bound thread:
    `true` when the row's day-of-month is its month's last valid day, `false`
    otherwise.

## Examples

Example 1. Flag month-end rows.

```cpp
using namespace pluss::table;

auto events = Slate(pluss::make_timeline({
    "2024-01-31T09:15:30Z",
    "2024-02-29T23:45:00Z",
    "2024-07-06T14:00:00Z",
}));
auto out = events.tl().month_end();
std::cout << out;
```

### Output

```text
0  true
1  true
2  false

ptype: Series
```

`"2024-01-31"` is January's last day, and `"2024-02-29"` is February's last
day in this leap year — both flag `true`.

## Notes

- Correctly accounts for leap years: `"2024-02-29"` is month-end (2024 is
  leap), but a February 28th in a non-leap year would also flag `true`.
- Only checks the date portion — the time-of-day (if any) doesn't affect the
  result.
- `.tl()` requires the bound thread to already be `Timeline`-kind —
  the accessor's constructor throws otherwise.
- A `NaT` row (or one already null on the underlying thread) displays as
  `"NULL"`, not `false`.

# Thread::display_labels

[Back to Thread API Reference](../../thread_api_reference)

## Signature

```cpp
Thread::display_labels() -> Thread
```

Return the display-label metadata attached to the thread.

Display labels are presentation metadata; they do not replace or mutate the payload itself.

## Parameters

`None`

## Returns

`Thread`
    Label thread currently attached as display metadata.

## See Also

- <a href="with_display_labels.html"><code>Thread::with_display_labels</code></a>, <a href="clear_display_labels.html"><code>Thread::clear_display_labels</code></a>: attach or remove the metadata.
- <a href="display_name.html"><code>Thread::display_name</code></a>: inspect the single-name display label instead.

## Examples

Example 1. Inspect display labels attached to a thread.

```cpp
using namespace pluss::table;

auto out = Thread(pluss::make_series({10.0, 20.0, 30.0, 40.0}))
               .with_display_labels(Thread(pluss::make_note({"a", "b", "c", "d"})))
               .display_labels();
```

### Output

```text
0  a
1  b
2  c
3  d
dtype: Note
```

# Thread::clear_display_labels

[Back to Thread API Reference](../../thread_api_reference)

## Signature

```cpp
Thread::clear_display_labels() -> Thread
```

Remove display labels from the current thread without changing its values.

## Parameters

`None`

## Returns

`Thread`
    Thread with display labels cleared.

## Notes

This only affects display metadata. The underlying payload values are preserved exactly.

## Examples

Example 1. Strip display labels while keeping the numeric payload unchanged.

```cpp
using namespace pluss::table;

auto scores = Thread(pluss::make_series({10.0, 20.0, 30.0, 40.0}));
auto labeled = scores.with_display_labels(Thread(pluss::make_note({"a", "b", "c", "d"})));

auto out = labeled.clear_display_labels();
```

### Output

```text
0  10
1  20
2  30
3  40
dtype: Series
```

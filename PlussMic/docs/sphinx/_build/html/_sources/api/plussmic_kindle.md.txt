# PlussMic `kindle`

The `kindle` model is the stream-first surface.

- Use [`Stream`](../stream_api_reference.md) for one typed vector with optional cases and validity mask.
- Use [`Catalog`](../catalog_api_reference.md) for named collections of aligned streams.
- Use [`Archive`](../archive_api_reference.md) for depth-stacked catalogs.

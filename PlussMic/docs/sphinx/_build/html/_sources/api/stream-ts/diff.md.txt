# StreamTimeSeriesAccessor::diff

[Back to StreamTimeSeriesAccessor API Reference](../../stream_ts_accessor_api_reference)

## Signature

```cpp
Stream StreamTimeSeriesAccessor::diff(std::int64_t periods = 1) const
```

## What It Does

Computes the absolute period-over-period change of the bound stream:
`out[i] = x[i] - base[i]`, where `base` is `x` shifted by `periods` (a lag
when `periods > 0`, a lead when `periods < 0`). A position is `NULL` wherever
`x[i]` or `base[i]` is missing. `periods = 0` produces an all-zero result
rather than throwing.

```{important} StreamTimeSeriesAccessor requires the bound stream to be numeric Series-kind
Every method on this accessor routes through `Slate::ts()` for the bound
stream. If the stream isn't a numeric `Series`, the call throws — e.g.
`"TimeSeriesAccessor::diff: source must be Series"` for a `Note`-kind stream.
```

## Parameters

**periods** (`std::int64_t`, default `1`)
    The shift distance used to build the comparison base.

## Returns

`Stream`
    A new stream, same length as the bound source, holding the
    period-over-period absolute difference.

## Examples

Example 1. Compute the one-period difference of a numeric stream.

```cpp
auto stream = pluss::kindle::Stream(pluss::make_series({10.0, 20.0, 15.0, 30.0}));
auto out = stream.ts().diff(1);
std::cout << out;
```

### Output

```text
========================================================================================================================
kindle::Stream  kind=Series  dtype=Series[float64]  records=4
label=no  mask=no  meta=0
------------------------------------------------------------------------------------------------------------------------
label        | value                                                                                                    
------------------------------------------------------------------------------------------------------------------------
0            | nan                                                                                                      
1            | 10                                                                                                       
2            | -5                                                                                                       
3            | 15                                                                                                       
========================================================================================================================
```

Position `0` has no prior position, so it's `nan`. Position `1` is
`20 - 10 = 10`; position `2` is `15 - 20 = -5`; position `3` is
`30 - 15 = 15`.

Example 2 (edge case). A non-numeric stream throws — see the important
callout above.

```cpp
auto stream = pluss::kindle::Stream(pluss::make_note({"a", "b"}));
try {
  auto out = stream.ts().diff(1);
} catch (const pluss::Error& e) {
  std::string msg(e.what());
  std::cout << msg.substr(0, msg.find('\n'));
}
```

### Output

```text
TimeSeriesAccessor::diff: source must be Series
```

## Notes

- Unlike a hand-rolled shift-based approach, `diff()` handles `periods = 0`
  explicitly by returning an all-zero identity comparison rather than a
  stream of `NULL`s.
- A pre-existing missing entry in the source stream is honored — it produces
  `NULL` in every difference that would otherwise reference it.
- See the important callout above.

# TimeSeriesAccessor::diff

[Back to TimeSeriesAccessor API Reference](../../slate_ts_accessor_api_reference)

## Signature

```cpp
TimeSeriesAccessor::diff(std::int64_t periods = 1) const -> Slate
```

## What It Does

Computes the absolute period-over-period change of the bound thread:
`out[i] = x[i] - base[i]`, where `base` is `x` shifted by `periods` (a lag when
`periods > 0`, a lead when `periods < 0`). A position is `NULL` wherever `x[i]` or
`base[i]` is missing. `periods = 0` produces an all-zero result rather than
throwing. Restricted to a numeric `Series` thread; anything else throws.

## Parameters

**periods** (`std::int64_t`, default `1`)
    The shift distance used to build the comparison base. Positive shifts compare
    each position against an earlier one (a lag); negative shifts compare against
    a later one (a lead).

## Returns

`Slate`
    A new thread, same length as the bound source, holding the period-over-period
    absolute difference.

## Examples

Example 1. Compute the one-period difference of a numeric thread.

```cpp
using namespace pluss::table;

auto load = Slate(pluss::make_series({10.0, 20.0, 15.0, 30.0}));
auto out = load.ts().diff(1);
std::cout << out;
```

### Output

```text
0  NULL
1  10
2  -5
3  15

ptype: Series
```

Position `0` has no prior position, so it's `NULL`. Position `1` is
`20 - 10 = 10`; position `2` is `15 - 20 = -5`; position `3` is `30 - 15 = 15`.

Example 2. `periods = 0` produces an all-zero result rather than throwing.

```cpp
auto out2 = load.ts().diff(0);
std::cout << out2;
```

### Output

```text
0  0
1  0
2  0
3  0

ptype: Series
```

Unlike a hand-rolled [`shift()`](../thread/shift.md)-based approach, `diff()`
handles `periods = 0` explicitly by returning an all-zero identity comparison
rather than a thread of `NULL`.

Example 3. A pre-existing missing entry in the source thread propagates into
every difference that touches it.

```cpp
auto with_gap = Slate(
    pluss::make_series({10.0, 20.0, 30.0, 40.0}),
    pluss::make_series(std::vector<bool>{true, false, true, true})
);
auto out3 = with_gap.ts().diff(1);
std::cout << out3;
```

### Output

```text
0  NULL
1  NULL
2  NULL
3  10

ptype: Series
```

Position `1` is `NULL` because `x[1]` (`20.0`) itself is masked-missing. Position
`2` is `NULL` because its `base` (`x[1]`, the same masked `20.0`) is missing, even
though `x[2]` (`30.0`) is a real, valid value. Only position `3` (`40 - 30 = 10`)
has both sides valid.

Example 4. A non-numeric thread throws.

```cpp
auto words = Slate(pluss::make_note({"a", "b"}));
try {
  auto bad = words.ts().diff(1);
} catch (const std::exception& e) {
  std::cout << e.what();
}
```

### Output

```text
TimeSeriesAccessor::diff: source must be Series
```

## Notes

- Unlike a [`shift()`](../thread/shift.md)-based approach you might build by hand,
  `diff()` handles `periods = 0` explicitly by returning all zeros (an identity
  comparison) rather than a thread of `NULL`.
- A pre-existing missing entry in the source thread is honored — it produces
  `NULL` in every difference that would otherwise reference it, not just the
  `NULL`s the shift itself introduces at the vacated end. See Example 3.
- Restricted to numeric `Series` payloads; a `Note`/`Timeline`/`TimeIndex` thread
  throws `"TimeSeriesAccessor::diff: source must be Series"`; a non-numeric
  `Series` throws `"TimeSeriesAccessor::diff: source Series must be numeric"`.

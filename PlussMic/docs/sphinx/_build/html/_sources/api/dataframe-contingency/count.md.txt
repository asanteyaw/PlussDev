# DataFrameContingencyTableBuilder::count

[Back to DataFrame contingency accessor API Reference](../../dataframe_contingency_accessor_api_reference)

## Signature

```cpp
DataFrameContingencyTableBuilder::count() const -> DataFrame
```

## What It Does

Materializes the contingency table as raw cell frequencies.

Each output row corresponds to one distinct row-key tuple. Each output value
column corresponds to one distinct column-key tuple. The numeric cells are the
number of source rows that fell into that crossed combination.

## Parameters

`None`

## Returns

`DataFrame`
    A rendered contingency table with the row key feature(s) first and one
    count column per column-key combination.

## Examples

Example 1. Basic two-way contingency count.

```cpp
using namespace pluss::table;

auto df = DataFrame({
    {"city", Thread(pluss::make_note({"A", "A", "B", "B", "B"}))},
    {"channel", Thread(pluss::make_note({"Cash", "Card", "Cash", "Cash", "Card"}))},
    {"amount", Thread(pluss::make_series({10.0, 20.0, 30.0, 40.0, 50.0}))},
});

auto out = df.contingency("city", "channel").count();
std::cout << out;
```

### Output

```text
=======================
     | city  Card  Cash
-----------------------
0    | A     1     1
1    | B     1     2
-----------------------
[2 cs x 3 feat]
```

`"A"` has one `"Card"` row and one `"Cash"` row. `"B"` has one `"Card"` row
and two `"Cash"` rows.

Example 2. Add row totals, column totals, and the grand total.

```cpp
auto out2 = df.contingency("city", "channel")
              .totals()
              .count();
std::cout << out2;
```

### Output

```text
===============================
     | city   Card  Cash  Total
-------------------------------
0    | A      1     1     2
1    | B      1     2     3
2    | Total  2     3     5
-------------------------------
[3 cs x 4 feat]
```

## Notes

- The grouping is by tuple, not by "only the first key". With one row feature
  and one column feature that tuple is just `(city)` crossed with `(channel)`.
- If you bind multiple row or column features, each distinct tuple becomes one
  rendered group in the output.
- `count()` is a contingency terminal, not a generic DataFrame axis reduction.

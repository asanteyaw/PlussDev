# DataFrameContingencyTableBuilder::preserve

[Back to DataFrame contingency accessor API Reference](../../dataframe_contingency_accessor_api_reference)

## Signature

```cpp
DataFrameContingencyTableBuilder::preserve() const -> DataFrameContingencyTableBuilder
```

## What It Does

Configures the contingency builder to preserve first-seen row-key and column-key
order instead of sorting the distinct groups.

## Parameters

`None`

## Returns

`DataFrameContingencyTableBuilder`
    A new builder that renders groups in first-observed order.

## Examples

Example 1. Preserve encounter order for both row groups and column groups.

```cpp
using namespace pluss::table;

auto df = DataFrame({
    {"city", Thread(pluss::make_note({"B", "A", "B", "A"}))},
    {"channel", Thread(pluss::make_note({"Cash", "Card", "Card", "Cash"}))},
});

auto out = df.contingency("city", "channel")
             .preserve()
             .count();
std::cout << out;
```

### Output

```text
=======================
     | city  Cash  Card
-----------------------
0    | B     1     1
1    | A     1     1
-----------------------
[2 cs x 3 feat]
```

The first observed row group is `"B"`, and the first observed column group is
`"Cash"`, so both remain first in the rendered table.

## Notes

- `preserve()` is the counterpart to [`sort()`](sort.md).
- This is also tuple-based when multiple row or column features are bound.

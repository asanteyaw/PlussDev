# DataFrameContingencyTableBuilder::dropnull

[Back to DataFrame contingency accessor API Reference](../../dataframe_contingency_accessor_api_reference)

## Signature

```cpp
DataFrameContingencyTableBuilder::dropnull() const -> DataFrameContingencyTableBuilder
```

## What It Does

Configures the contingency builder to exclude any source row whose row-key tuple
or column-key tuple contains a null.

## Parameters

`None`

## Returns

`DataFrameContingencyTableBuilder`
    A new builder with null-key rows excluded at materialization time.

## Examples

Example 1. Drop rows whose row or column key is null before counting.

```cpp
using namespace pluss::table;

auto city = Thread(
    pluss::make_note({"A", "A", "B", "B"}),
    pluss::make_series(std::vector<bool>{true, false, true, true}));
auto channel = Thread(
    pluss::make_note({"Cash", "Card", "Cash", "Cash"}),
    pluss::make_series(std::vector<bool>{true, true, true, false}));

auto df = DataFrame({
    {"city", city},
    {"channel", channel},
});

auto out = df.contingency("city", "channel")
             .dropnull()
             .count();
std::cout << out;
```

### Output

```text
=======================
     | city  Card  Cash
-----------------------
0    | A     0     1
1    | B     0     1
-----------------------
[2 cs x 3 feat]
```

The row with null `city` and the row with null `channel` are both excluded.

## Notes

- `dropnull()` affects grouping membership, not just rendering.
- A null in either side of the crossed key removes that source row from the
  contingency table.

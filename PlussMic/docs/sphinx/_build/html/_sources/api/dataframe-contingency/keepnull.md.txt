# DataFrameContingencyTableBuilder::keepnull

[Back to DataFrame contingency accessor API Reference](../../dataframe_contingency_accessor_api_reference)

## Signature

```cpp
DataFrameContingencyTableBuilder::keepnull() const -> DataFrameContingencyTableBuilder
```

## What It Does

Configures the contingency builder to retain null-valued row keys and column
keys as explicit groups.

## Parameters

`None`

## Returns

`DataFrameContingencyTableBuilder`
    A new builder that materializes null groups instead of dropping them.

## Examples

Example 1. Keep null keys as explicit `NULL` row and column groups.

```cpp
using namespace pluss::table;

auto city = Thread(
    pluss::make_note({"A", "A", "B", "B"}),
    pluss::make_series(std::vector<bool>{true, false, true, true}));
auto channel = Thread(
    pluss::make_note({"Cash", "Card", "Cash", "Cash"}),
    pluss::make_series(std::vector<bool>{true, true, true, false}));

auto df = DataFrame({
    {"city", city},
    {"channel", channel},
});

auto out = df.contingency("city", "channel")
             .keepnull()
             .count();
std::cout << out;
```

### Output

```text
=============================
     | city  Card  Cash  NULL
-----------------------------
0    | A     0     1     0
1    | B     0     1     1
2    | NULL  1     0     0
-----------------------------
[3 cs x 4 feat]
```

## Notes

- Nulls are rendered as `NULL`, matching the table/atlas/thread display
  contract.
- The null label participates as a normal crossed group once you keep it.

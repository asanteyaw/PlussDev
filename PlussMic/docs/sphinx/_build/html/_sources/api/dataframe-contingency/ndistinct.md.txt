# DataFrameContingencyTableBuilder::ndistinct

[Back to DataFrame contingency accessor API Reference](../../dataframe_contingency_accessor_api_reference)

## Signature

```cpp
DataFrameContingencyTableBuilder::ndistinct(std::string_view feature) const -> DataFrame
```

## What It Does

Counts distinct observed values of a chosen feature inside each crossed cell.

## Parameters

**feature** (`std::string_view`)
    The value feature whose distinct values should be counted per cell.

## Returns

`DataFrame`
    A contingency table whose numeric cells are distinct-counts for the named
    feature inside each row-key/column-key combination.

## Examples

Example 1. Count distinct `weekend` values within each contingency cell.

```cpp
using namespace pluss::table;

auto df = DataFrame({
    {"city", Thread(pluss::make_note({"A", "A", "B", "B", "B"}))},
    {"channel", Thread(pluss::make_note({"Cash", "Card", "Cash", "Cash", "Card"}))},
    {"weekend", Thread(pluss::make_note({"no", "no", "no", "yes", "yes"}))},
});

auto out = df.contingency("city", "channel").ndistinct("weekend");
std::cout << out;
```

### Output

```text
=======================
     | city  Card  Cash
-----------------------
0    | A     1     1
1    | B     1     2
-----------------------
[2 cs x 3 feat]
```

The `"B"` and `"Cash"` cell contains both `"no"` and `"yes"`, so its distinct
count is `2`.

## Notes

- `ndistinct()` is cell-wise over the contingency grid.
- Unlike numeric reducers, `ndistinct()` does not require the feature to be a
  numeric `Series`.

# DataFrameContingencyTableBuilder::colshare

[Back to DataFrame contingency accessor API Reference](../../dataframe_contingency_accessor_api_reference)

## Signature

```cpp
DataFrameContingencyTableBuilder::colshare() const -> DataFrame
```

## What It Does

Materializes the contingency table as column-normalized proportions.

Each cell is `count(cell) / count(this column-key tuple across all rows)`.

## Parameters

`None`

## Returns

`DataFrame`
    A contingency table where each numeric column expresses the within-column
    distribution across the crossed row groups.

## Examples

Example 1. Normalize each column by its own column total.

```cpp
using namespace pluss::table;

auto df = DataFrame({
    {"city", Thread(pluss::make_note({"A", "A", "B", "B", "B"}))},
    {"channel", Thread(pluss::make_note({"Cash", "Card", "Cash", "Cash", "Card"}))},
});

auto out = df.contingency("city", "channel").colshare();
std::cout << out;
```

### Output

```text
===============================
     | city  Card  Cash
-------------------------------
0    | A     0.5   0.3333333333
1    | B     0.5   0.6666666667
-------------------------------
[2 cs x 3 feat]
```

The `"Cash"` column has `3` total observations, so the `"B"` and `"Cash"` cell
is `2 / 3`.

## Notes

- Each non-empty numeric column sums to `1`.
- This is useful when you want the composition of each column group rather than
  the composition of each row group.

# DataFrameContingencyTableBuilder::nototals

[Back to DataFrame contingency accessor API Reference](../../dataframe_contingency_accessor_api_reference)

## Signature

```cpp
DataFrameContingencyTableBuilder::nototals() const -> DataFrameContingencyTableBuilder
```

## What It Does

Configures the contingency builder to materialize without appended totals.

This is most useful when you have already chained [`totals()`](totals.md) and
want to turn totals back off before the terminal call.

## Parameters

`None`

## Returns

`DataFrameContingencyTableBuilder`
    A new builder with totals disabled.

## Examples

Example 1. Remove totals after they were enabled earlier in the chain.

```cpp
using namespace pluss::table;

auto df = DataFrame({
    {"city", Thread(pluss::make_note({"A", "A", "B", "B", "B"}))},
    {"channel", Thread(pluss::make_note({"Cash", "Card", "Cash", "Cash", "Card"}))},
});

auto out = df.contingency("city", "channel")
             .totals()
             .nototals()
             .count();
std::cout << out;
```

### Output

```text
=======================
     | city  Card  Cash
-----------------------
0    | A     1     1
1    | B     1     2
-----------------------
[2 cs x 3 feat]
```

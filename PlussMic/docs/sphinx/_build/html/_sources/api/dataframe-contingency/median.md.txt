# DataFrameContingencyTableBuilder::median

[Back to DataFrame contingency accessor API Reference](../../dataframe_contingency_accessor_api_reference)

## Signature

```cpp
DataFrameContingencyTableBuilder::median(std::string_view feature) const -> DataFrame
```

## What It Does

Computes the per-cell median of a numeric value feature inside the contingency
layout.

## Parameters

**feature** (`std::string_view`)
    The numeric value feature to reduce per cell.

## Returns

`DataFrame`
    A contingency table whose numeric cells are medians for the selected value
    feature.

## Examples

Example 1. Median `amount` in each crossed cell.

```cpp
using namespace pluss::table;

auto df = DataFrame({
    {"city", Thread(pluss::make_note({"A", "A", "B", "B", "B"}))},
    {"channel", Thread(pluss::make_note({"Cash", "Card", "Cash", "Cash", "Card"}))},
    {"amount", Thread(pluss::make_series({10.0, 20.0, 30.0, 40.0, 50.0}))},
});

auto out = df.contingency("city", "channel").median("amount");
std::cout << out;
```

### Output

```text
=======================
     | city  Card  Cash
-----------------------
0    | A     20    10
1    | B     50    35
-----------------------
[2 cs x 3 feat]
```

## Notes

- For the `"B"` and `"Cash"` cell, the median of `{30, 40}` is `35`.

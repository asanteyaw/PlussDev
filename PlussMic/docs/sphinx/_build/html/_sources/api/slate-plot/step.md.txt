# SlatePlotAccessor::step

[Back to SlatePlotAccessor API Reference](../../slate_plot_api_reference)

## Signatures

```cpp
SlatePlotAccessor::step() const -> pluss::pl::Studio
SlatePlotAccessor::step(const Slate& x) const -> pluss::pl::Studio
SlatePlotAccessor::step(const StepPlotOptions& options) const -> pluss::pl::Studio
SlatePlotAccessor::step(const Slate& x, const StepPlotOptions& options) const -> pluss::pl::Studio
```

## What It Does

Identical in shape to [`line()`](line.md) — the bound thread's values drawn against an
optional companion `x` thread, wrapped into the same one- or two-column `DataFrame` and
delegated to [`DataFramePlotAccessor::step`](../../api/dataframe-plot/step.md) — but each
trace is drawn as a step function (horizontal-then-vertical jumps between points) instead
of straight line segments. See [`line()`](line.md) for the full naming and row-label
inheritance rules shared by every method on this accessor.

## Parameters

**x** (`const Slate&`, optional)
    Same as [`line()`](line.md)'s `x` — a companion thread used as the x-axis, must match
    the bound thread's size or the call throws `"Slate::plot: thread size mismatch"`.
    Omitted falls back to the wrapped frame's own row labels.

**options** (`StepPlotOptions`)
    The identical struct documented on
    [`DataFramePlotAccessor::step`](../../api/dataframe-plot/step.md) (`alpha`,
    `line_width`, `align`). `align` is inert here — a mismatched-size `x` throws
    unconditionally before it could ever apply, same as [`line()`](line.md).

## Returns

`pluss::pl::Studio`
    A figure with one pane containing a single step trace of the bound thread's values.

## Examples

Example 1. No companion thread: falls back to a plain case index.

```cpp
using namespace pluss::table;

auto price = Slate(pluss::make_series({9.99, 19.99, 39.99, 79.99}));
price = price.name("price");

auto chart = price.plot().step();
chart.show();
```

![Output of Example 1](img/step-1.svg)

Example 2. An explicit companion thread as the x-axis.

```cpp
auto tier = Slate(pluss::make_note({"Bronze", "Silver", "Gold", "Platinum"}));
tier = tier.name("tier");

auto chart = price.plot().step(tier);
chart.show();
```

`price` is drawn as a step function against `tier`'s categorical positions — visually
emphasizing that the price is constant within a tier and jumps at tier boundaries.

![Output of Example 2](img/step-2.svg)

Example 3. An explicit `StepPlotOptions`.

```cpp
StepPlotOptions options;
options.alpha = 0.8;
options.line_width = 2.0;

auto chart = price.plot().step(tier, options);
chart.show();
```

![Output of Example 3](img/step-3.svg)

## Notes

- Shares every mechanic described on [`line()`](line.md)'s page except the step-vs-line
  trace shape.
- A companion `x` thread must match the bound thread's size, or the call throws.
- Returns a `pluss::pl::Studio` — see [`line()`](line.md) for how to view or save the
  result.

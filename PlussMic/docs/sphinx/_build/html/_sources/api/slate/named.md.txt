# Slate::named

[Back to Slate API Reference](../../slate_api_reference)

## Signature

```cpp
Slate::named() const -> bool
```

## What It Does

Reports whether the thread currently has a name attached — the safe way to check before
calling [`name()`](name.md)'s getter overload, which throws on an unnamed thread.

## Parameters

`None`

## Returns

`bool`
    `true` if a name is attached (via [`name(value)`](name.md)), `false` otherwise
    (including on a freshly constructed thread, or one that had its name removed via
    [`unname()`](unname.md)).

## Examples

Example 1. A freshly constructed thread reports `false`.

```cpp
using namespace pluss::table;

auto balance = Slate(pluss::make_series({100.0, 250.5, 75.25}));

std::cout << balance.named();
```

### Output

```text
false
```

Example 2. After attaching a name, `named()` reports `true`, and the getter no longer
throws.

```cpp
auto named_balance = balance.name("balance");

std::cout << named_balance.named();

if (named_balance.named()) {
  std::cout << named_balance.name();
}
```

### Output

```text
true
```

```text
balance
```

## Notes

- Guards [`name()`](name.md)'s getter overload, which throws
  `"Slate::name: name is not set"` on an unnamed thread.
- Reports `false` again after [`unname()`](unname.md).
- Non-mutating; simply inspects the thread's current state.

## See Also

- [`Slate::name`](name.md): the getter/setter pair this method guards.
- [`Slate::unname`](unname.md): removes an attached name, after which `named()` reports
  `false` again.

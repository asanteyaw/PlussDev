Part XI: Kindle: Stream, Catalog, and Archive¶

Kindle is the stream/catalog model in PlussMic. It is useful when your data is still typed and column-like, but you want metadata and catalog operations instead of strict DataFrame ergonomics.

Stream¶

A Stream is similar to a Slate, with optional cases and metadata.

auto stream = pluss::kindle::Stream::from_slate(df.features("balance"));

Common stream operations:

stream.size();
stream.kind();
stream.dtype();

stream.isnull();
stream.notnull();
stream.fillnull(0.0);
stream.dropnull();
stream.ffill();
stream.bfill();

stream.head(10);
stream.tail(10);
stream.slice(10, 20);
stream.take({0, 2, 5});
stream.filter(mask);

Numeric stream reductions:

stream.sum();
stream.mean();
stream.min();
stream.max();
stream.var();
stream.std();

Metadata:

auto annotated = stream.with_meta("source", "raw_import");
auto source = annotated.meta("source");
auto stripped = annotated.drop_meta("source");

Cases:

auto with_cases = stream.with_cases(df.labels().values());
auto no_cases = with_cases.clear_cases();

Catalog¶

A Catalog is a named set of streams. Convert from DataFrame:

auto catalog = df.kindelize();

Convert back:

auto frame = catalog.tabelize();

Catalog operations include stream selection, mutation, merge, transform, text cleanup, and export.

auto cleaned = catalog.apply("balance", [](const pluss::kindle::Stream& s) {
  return s.fillnull(0.0);
});

auto table = cleaned.tabelize();

Use Catalog when:

  • stream metadata matters;

  • you want named-stream transformations outside a DataFrame;

  • your workflow moves between typed streams and table display;

  • text-oriented catalog operations are useful.

Archive¶

An Archive is a stack of catalogs. It mirrors Atlas in the Kindle model.

auto archive = atlas.kindelize();
auto atlas2 = archive.tabelize();

Common archive operations:

archive.depth();
archive.empty();
archive.catalog(0);
archive.dloc(0);
archive.loc("scenario_a");
archive.head(5);
archive.tail(5);
archive.slice_depth(0, 3);
archive.sort_depth();

Map catalogs:

auto cleaned = archive.map_catalogs([](const pluss::kindle::Catalog& catalog) {
  return catalog.map([](const pluss::kindle::Stream& stream) {
    return stream.dropnull();
  });
});

Kindle and DataFrame policy¶

Conversion functions accept policy objects:

auto catalog = df.kindelize(policy);
auto frame = catalog.tabelize(policy);

Use policies when you need to control how cases, metadata, and stream types map between the table and Kindle models.

See Kindle, Stream API Reference, Catalog API Reference, and Archive API Reference.

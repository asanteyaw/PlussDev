Part XII: Scribble: Slot, Registry, and Axel¶

Scribble is PlussMic’s heterogeneous record model. It is useful when values are not naturally represented as one typed Thread.

Slot¶

A Slot is a vector of values. Values can represent multiple scalar/value families depending on the Scribble API surface.

Common Slot operations:

slot.defined();
slot.size();
slot.empty();
slot.values();
slot.at(0);

slot.head(10);
slot.tail(10);
slot.slice(10, 20);
slot.take(indices);
slot.filter(predicate);
slot.transform(fn);

Slot mutation style follows the Pluss convention:

auto next = slot.push(value);
slot.push_(value);

Use non-mutating operations in pipelines and mutating operations when updating owned state.

Registry¶

A Registry is a named collection of slots.

auto registry = catalog.scribbelize();
auto catalog2 = registry.kindelize();

Load and save registry data:

auto reg = pluss::scribble::Registry::load_csv("data.csv");
reg.save_json("registry.json");

Inspect:

registry.nfields();
registry.fields();
registry.has("field");
registry.get("field");
registry.sizes();
registry.profiles();

Select and reshape:

auto first = registry.head(10);
auto rows = registry.slice(10, 20);
auto one_row = registry.cloc(0);
auto selected = registry.select({"name", "score"});
auto dropped = registry.drop("temporary");
auto renamed = registry.rename("old", "new");

Transform:

auto changed = registry.apply("score", [](const pluss::scribble::Slot& slot) {
  return slot;
});

auto all = registry.map([](const pluss::scribble::Slot& slot) {
  return slot;
});

Update fields:

auto with_slot = registry.set("new_field", slot);
auto pushed = registry.push("events", value);

Combine:

auto merged = registry.combine(other, "_other");

Kindle bridge¶

Some Registry operations require slots that can map cleanly to streams. The public surface no longer exposes separate compatibility checkers; kindelize() is the single contract point.

try {
  auto catalog = registry.kindelize();
} catch (const std::exception& e) {
  std::cout << e.what();
}

Axel¶

Axel is the higher collection-oriented scribble type. Use it when you need to organize registries/slots into a broader scribble workflow. See the Axel API Reference for exact constructors and operations.

Scribble conversion strategy¶

DataFrame path:

auto catalog = df.kindelize();
auto registry = catalog.scribbelize();

Back to table:

auto catalog = registry.kindelize();
auto df = catalog.tabelize();

Use Scribble for heterogeneous data, but return to DataFrame when you need rectangular analysis, group-by, plotting, or file export.

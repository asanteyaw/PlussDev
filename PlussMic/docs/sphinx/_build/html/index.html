PlussMic¶

Pluss · Space

PlussMic

The data-analysis layer of Pluss: tabular data (DataFrame), typed columns (Slate), stacks of related frames (Atlas), aligned streaming containers, heterogeneous record scribbles, and multi-table workbenches.

API Reference

What's in this space

PlussMic's public surface is organized around four models, plus a plotting/display branch shared across them.

table DataFrame · Slate · Atlas

Named, mixed-type tabular analysis: DataFrame for 2D tables, Slate for one typed column, Atlas for a depth stack of frames.

kindle Stream · Catalog · Archive

Aligned stream containers: a single named Stream, a Catalog of streams, and an Archive stack of catalogs.

scribble Slot · Registry · Axel

Heterogeneous record containers: a one-dimensional Slot, a Registry of named slots, and an Axel stack of registries.

bundle Locus · Nexus · traversal · pull · query

Multi-table workbenches: Locus coordinates related ragged catalogs, while Nexus coordinates rectangular frames; both retain declared links and reusable workspace plans.

Plotting DataFramePlotAccessor · DataFramePlot3DAccessor

Plotting and display-oriented surfaces attached to the table model, reached through DataFrame::plot() and DataFrame::plot3d().

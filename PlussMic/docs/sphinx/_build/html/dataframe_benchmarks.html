DataFrame Benchmark Results¶

This gate compares equivalent PlussMic and pandas workloads for alignment, grouping, key unification, wide-to-long reshaping, fixed windows, and covariance. It is a reproducible engineering benchmark, not a claim that the two runtimes have identical allocation, caching, or process-startup behavior.

Reproduce¶

cmake --build build_cpp_env --target plussmic_table_gap_benchmark
conda run -n cpp_env python PlussMic/benchmarks/compare_dataframe_ops.py \
  --rows 1000000 \
  --output PlussMic/benchmarks/latest_dataframe_ops.json

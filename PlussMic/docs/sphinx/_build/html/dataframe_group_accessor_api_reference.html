DataFrameGroupBuilder API Reference¶

This page documents the public grouped-workflow surface entered via DataFrame::group() – the DataFrameGroupBuilder returned by group() itself, and the DataFrameGrouped handle returned by its .by(...).

Using This Reference¶

  • Use the left sidebar to open one method page at a time.

  • Each method page contains its own signatures, parameter details, notes, verified outputs, and working previous/next navigation.

  • Grouping is best learned as a workflow, not as a loose list of methods.

The Surface In One Sentence¶

group() captures grouping policy, by(...) defines group identity, and then a grouped terminal decides whether you want one row per group, one row per source row, or a regrouped row-grain view.

Learn It In This Order¶

  1. DataFrame::group Learn the top-level mental model and what GroupOptions actually control.

  2. by() Learn the two grouping domains: ordinary feature keys and case-label keys.

  3. agg(), transform(), filter(), yield() Learn the four grouped execution shapes.

  4. The convenience terminals Learn when count(), mean(), sum(), mode(), and friends are just concise syntax for uniform grouped reductions.

The Four Execution Shapes¶

  • agg(...): collapse to one row per group

  • transform(...): compute one grouped value per group, then broadcast it back to every row in that group

  • filter(keep): keep or drop whole groups from the original frame

  • yield(): keep the original rows, but physically reorder them into grouped blocks

The Big Conceptual Distinctions¶

  • Grouping by several keys is tuple grouping, not “first key now, second key later.”

  • sort in GroupOptions affects the order of groups in collapsed outputs; it does not sort rows within a group by a value column.

  • Convenience terminals operate on non-key value features by default, but many of them also accept a targeted feature list when you do not want to aggregate the full value side.

  • count() is special: when no value features remain after excluding keys, it still returns an explicit row-count column named count.

Choosing The Right Grouped Method¶

Use agg(...) when:

  • you want mixed grouped operations

  • you want explicit output names

  • you want row count beside other grouped metrics

Use transform(...) when:

  • the output must stay aligned to original row order

  • you are engineering row-wise features from group statistics

Use filter(...) when:

  • the keep/drop decision is at the group level, not the row level

Use yield() when:

  • you want grouped row neighborhoods before a later row-wise operation

  • you are debugging or inspecting how the grouping plan partitions the frame

Method Pages¶

The sidebar lists methods alphabetically. You can also use the search box to jump directly to a method name.

by() fixes the grouping keys, then DataFrameGrouped executes the grouped work:

  • Plan grouping keys: by()

  • Explicit grouped reductions: agg(), transform(), filter(), yield()

  • Uniform grouped reducers: count(), ndistinct(), sum(), mean(), median(), min(), max(), std(), var(), mode(), mode_ties()

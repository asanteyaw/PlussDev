DataFramePlotAccessor API Reference¶

Practical DataFramePlotAccessor API Reference¶

API Reference Style¶

This page documents the public plotting accessor returned by DataFrame::plot() and Atlas::plot().

df.plot(...) Defaults And Options¶

Signature¶

DataFramePlotAccessor plot(self)

DataFramePlotAccessor plot(self, DataFramePlotOptions options)

What DataFramePlotOptions Controls¶

default_x_feature (std::optional<std::string>, default nullopt)

Default x-axis feature used when a plot call does not provide an explicit x_feature.

default_hue_feature (std::optional<std::string>, default nullopt)

Default grouping/color feature used by plot types that support hue/group splits.

default_bins (std::int64_t, default 20)

Default bin count for histogram-style plots when bins are not explicitly passed.

datetime_label_view (DateTimeLabelView, default DateTimeLabelView::Full)

Datetime tick label rendering mode (Full, Date, or Time) for datetime axes.

max_labeled_ticks (std::int64_t, default 14)

Upper bound on how many tick labels are rendered to avoid dense, unreadable axes.

x_tick_rotation_deg (std::optional<double>, default nullopt)

Optional x-axis tick-label rotation (degrees).

y_tick_rotation_deg (std::optional<double>, default nullopt)

Optional y-axis tick-label rotation (degrees).

x_label_rotation_deg (std::optional<double>, default nullopt)

Optional x-axis label rotation (degrees).

y_label_rotation_deg (std::optional<double>, default nullopt)

Optional y-axis label rotation (degrees).

labeled_tick_rotation_deg (std::optional<double>, default nullopt)

Legacy x-axis tick-label rotation alias. Prefer x_tick_rotation_deg.

width (std::optional<double>, default nullopt)

Optional figure width override.

height (std::optional<double>, default nullopt)

Optional figure height override.

use_tight_layout (bool, default false)

When enabled, applies tight layout spacing rules to reduce label clipping.

tight_layout_padding (double, default 6.0)

Padding used by tight layout when use_tight_layout=true.

Usage Pattern¶

using namespace pluss::table;

DataFramePlotOptions opts{};
opts.default_x_feature = "timestamp";
opts.default_hue_feature = "sector";
opts.default_bins = 30;
opts.datetime_label_view = DateTimeLabelView::Date;
opts.max_labeled_ticks = 10;
opts.x_tick_rotation_deg = 35.0;
opts.y_tick_rotation_deg = 20.0;
opts.x_label_rotation_deg = 0.0;
opts.y_label_rotation_deg = -90.0;
opts.width = 13.0;
opts.height = 7.0;
opts.use_tight_layout = true;
opts.tight_layout_padding = 4.0;

auto plot = df.plot(opts);
auto line_fig = plot.line({"open", "close"});
auto hist_fig = plot.hist("returns");

Method-Level Options Reference¶

All method options are regular C++ structs. Create, edit fields, then pass into the corresponding plot.*(...) call.

pluss::table::ActPlotOptions o{};
o.max_lag = 60;
o.confidence_level = 0.99;
auto fig = df.plot().act("returns", o);

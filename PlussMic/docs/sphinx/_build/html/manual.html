PlussMic User Manual¶

This manual is the long-form guide for PlussMic, the data-analysis layer of the Pluss ecosystem. It is written for readers who want to use PlussMic as a daily tool, not only look up signatures.

PlussMic has four related models:

table  -> DataFrame, Slate, Atlas
kindle -> Stream, Catalog, Archive
bundle -> Nexus, NexusTraverse, NexusQuery
scribble -> Slot, Registry, Axel

Most users start with DataFrame, because it is the table abstraction used for CSV, Excel, JSON, Parquet, feature engineering, exploratory analysis, plotting, and export. Slate is the typed column model underneath DataFrame. Atlas stacks related frames. Kindle is the aligned stream layer. Scribble covers heterogeneous records, while Bundle covers the multi-table Nexus workbench when the job is broader than one rectangular table.

Example policy¶

This manual does not use one token example per feature. Important APIs are shown in several contexts: a minimal call, a realistic workflow, option and error cases, and combinations with adjacent APIs. A short example teaches the shape of a call; later examples teach how to use it in a program.

In-memory frames are created directly when the lesson is about table operations. I/O chapters use files such as "sales.csv" and "transactions.parquet", assumed to be in the program’s working directory. The manual shows the relevant input file contents before the code. Public examples never contain paths from the author’s machine.

Pluss values are passed directly where Slate conversion is implicit:

DataFrame sales({
    {"city", pluss::make_note({"Accra", "Tema"})},
    {"units", pluss::make_series({10.0, 7.0})},
});

Explicit Slate construction appears only when the example needs Slate metadata, a validity mask, or a named standalone column.

Verified examples¶

Examples marked as verified are backed by this source file:

PlussMic/docs/sphinx/manual/examples/plussmic_manual_examples.cpp

It is compiled as an external SDK consumer with:

cmake -S PlussMic/docs/sphinx/manual/examples \
  -B /tmp/plussmic_manual_examples_build \
  -DCMAKE_PREFIX_PATH="/path/to/pluss-sdk;/path/to/cpp_env"

cmake --build /tmp/plussmic_manual_examples_build --target plussmic_manual_examples
/tmp/plussmic_manual_examples_build/plussmic_manual_examples

The printed outputs in this manual come from running the exact displayed operations against the current PlussMic build. A table shown after df.to_string() is its to_string() result; output from head(), show(), or another renderer is never substituted. When output reveals surprising behavior, the source and tests are checked first; source-level defects are fixed before the manual teaches the behavior as correct.

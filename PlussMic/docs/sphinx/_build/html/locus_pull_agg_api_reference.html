LocusPullAgg API Reference¶

LocusPullAgg is the table-scoped reducer returned by LocusPull::agg(table). It borrows the owning LocusPull, appends reducer specifications to that plan, and returns the owner through end(). It is a temporary planning scope, not a standalone workspace or result container.

Each reducer accepts one (feature, alias) pair or a batch of such pairs. The scope supplies the catalog name; the feature remains relative to that catalog. The supported reducers are count, ndistinct, sum, mean, median, min, max, std, and var.

Every reducer has a scalar (feature, alias) overload and an initializer-list overload of ordered (feature, alias) pairs. Feature names are relative to the scoped catalog. Empty batches are no-ops; empty feature names are rejected immediately. Catalog, relationship, stream-kind, duplicate-spec, and output-alias validation occurs when the parent plan is collected.

The scope stores a borrowed parent pointer. Keep the LocusPull alive until all scoped calls and end() have completed. Opening a scope and adding reducers does not read a stream or allocate a result.

Method Pages¶

  • count() counts usable occurrences.

  • end() returns the exact parent builder.

  • max() adds upper-extreme reducers.

  • mean() adds arithmetic means.

  • median() adds midpoint reducers.

  • min() adds lower-extreme reducers.

  • ndistinct() counts unique values.

  • std() adds sample standard deviations.

  • sum() adds numeric totals.

  • var() adds sample variances.

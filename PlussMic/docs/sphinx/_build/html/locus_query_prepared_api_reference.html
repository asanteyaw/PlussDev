LocusQueryPrepared API Reference¶

LocusQueryPrepared owns a Locus workspace, a statement template, and the SQL options captured when Locus::query(options) was called. Its execute() overloads either run the template unchanged or merge runtime value and identifier bindings over those captured defaults.

Preparation stores a reusable recipe; schema lookup and SQL compilation happen at execution. This means a prepared object is cheap to construct, but an unknown catalog, unknown stream, or malformed statement is reported by execute(), not by prepare().

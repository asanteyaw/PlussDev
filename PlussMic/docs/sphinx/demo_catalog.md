# Demo Catalog

## Table Examples

- `PlussMic/examples/table/dataframe_initial_demo.cpp`: loading CSV files, viewing rows, info, describe, and a simple `Atlas`
- `PlussMic/examples/table/dataframe_describe_demo.cpp`: summary statistics plus CSV loader benchmarking
- `PlussMic/examples/table/dataframe_view_demo.cpp`: row windows and quick inspection patterns
- `PlussMic/examples/table/dataframe_thread_values_demo.cpp`: working with typed `Thread` columns
- `PlussMic/examples/table/dataframe_versatile_methods_demo.cpp`: selection, transforms, grouping, joins, and reshaping verbs
- `PlussMic/examples/table/loader_saver_parity_demo.cpp`: CSV, TXT, JSON, Excel, and Parquet loader/saver parity
- `PlussMic/examples/table/dataframe_plot_demo.cpp`: plotting accessors and integration with PlussPl
- `PlussMic/examples/table/display_policy_demo.cpp`: terminal display policy and compact rendering
- `PlussMic/examples/table/eda_us_accidents.cpp`: end-to-end exploratory analysis workflow on the accidents dataset
- `PlussMic/examples/table/us_accidents_eda_verbs_demo.cpp`: richer EDA verbs and derived-feature workflow

# PlussQit API Reference

PlussQit is the typed array layer underneath the table surfaces.

Use this branch when you want the core typed containers directly:

- `Series` for numeric vectors and numeric kernels
- `Note` for text vectors and text kernels
- `Timeline` for temporal vectors
- `TimeIndex` for temporal index vectors

These pages are being moved into the same object-first format as the PlussMic reference so the whole stack reads consistently.

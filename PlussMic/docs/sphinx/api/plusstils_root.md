# PlussTils API Reference

PlussTils holds the support surfaces around the core analysis stack.

The first public branches to expose here are:

- `Pathing` for filesystem/path helper types
- `PlussView` for rendering and window/viewer surfaces
- `Aux Utilities` for small support helpers that are public and reusable

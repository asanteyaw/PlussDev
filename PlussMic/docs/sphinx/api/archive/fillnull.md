# Archive::fillnull

[Back to Archive API Reference](../../archive_api_reference)

## Signatures

```cpp
Archive::fillnull(const char* value) -> Archive

Archive::fillnull(const pluss::TimeIndex& value) -> Archive

Archive::fillnull(const pluss::Timeline& value) -> Archive

Archive::fillnull(double value) -> Archive

Archive::fillnull(std::string_view value) -> Archive
```

## What It Does

This is part of the missing-data cleanup path and is usually applied before summaries, grouping, or export.

## Parameters

**value**
    Replacement, fill, or write value used by mutation-style methods such as `put(...)`, `fillnull(...)`, or `replace(...)`.

## Returns

`Archive`
    Value produced by this call.

using namespace pluss::kindle::literals;

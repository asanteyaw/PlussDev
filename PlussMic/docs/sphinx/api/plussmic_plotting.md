# PlussMic `Plotting`

This branch holds plotting and display-oriented surfaces attached to the table model.

- Use [`DataFramePlotAccessor`](../dataframe_plot_api_reference.md) for plotting.
- Use [`DataFramePlot3DAccessor`](../dataframe_plot3d_accessor_api_reference.md) for 3D plotting.
- Use [`SlatePlotAccessor`](../slate_plot_api_reference.md) for plotting a single `Slate`.
- Use [`DataFrame Display`](../dataframe_display.md) when you want display/rendering behavior explained in workflow form.

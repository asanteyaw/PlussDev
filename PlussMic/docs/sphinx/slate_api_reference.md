# Slate API Reference

This page documents the full public `Slate` surface with direct typed-column examples.

## Using This Reference

- Use the left sidebar to open one method page at a time.
- Each method page contains its own signatures, parameter details, notes, verified outputs, and working previous/next navigation.
- This landing page stays intentionally short so the content panel is not one giant scroll of every method.

## Method Pages

The sidebar lists methods alphabetically. You can also use the search box to jump directly to a method name.

## Accessors

`Slate` exposes nested accessors, each with its own method pages and sidebar:

- `label()` -> [`SlateLabelAccessor`](slate_label_accessor_api_reference.md)
- `nt()` -> [`SlateNoteAccessor`](slate_note_accessor_api_reference.md)
- `tl()` -> [`SlateTimelineAccessor`](slate_timeline_accessor_api_reference.md)
- `ts()` -> [`TimeSeriesAccessor`](slate_ts_accessor_api_reference.md)
- `plot()` -> [`SlatePlotAccessor`](slate_plot_api_reference.md)

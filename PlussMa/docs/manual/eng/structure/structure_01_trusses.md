# Structures 1: Trusses

A truss is a set of straight bars joined at pins. Loads act only at the joints, so every bar carries a single axial force, tension or compression, and nothing else. This chapter describes a truss to the solver, solves its static response, and covers supports, prescribed motion, mechanisms and sweeps over many loads or sizes in one call, always with structures whose answers can be checked by hand.

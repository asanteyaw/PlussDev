# Signals 2: Recursive Filters

A recursive filter feeds its own past output back, so a short list of coefficients can describe an impulse response that never ends. This chapter shows how to run one, how to run a long signal in blocks, why a high-order filter must be a cascade of second-order sections, and how to remove a filter's delay when the whole record is available.

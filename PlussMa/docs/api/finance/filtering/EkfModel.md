# `filtering::EkfModel`

A nonlinear state-space model for the extended Kalman filter: the dynamics, the observation and their Jacobians.

`x_t = f(x_{t−1}, t) + w_t`, `y_t = h(x_t, t) + v_t`, with Gaussian noise of covariances `Q` and `R`. The functions take the state `[n]` and the date index and return `[n]` and `[m]`; the Jacobians (`[n, n]` and `[m, n]`) are evaluated at the current estimate, and the filter runs the Kalman equations with them in place of `F` and `H`. The approximation is good while the nonlinearity is mild over the uncertainty of the state; where it is not, use the [unscented filter](UkfModel.md) or a [particle filter](particle_filter.md). The examples all use the model `x` a random walk observed through `h(x) = x + 0.2x²`, and print the root-mean-square error of the filtered level.

## Fields

### `transition`

`filtering::StateFn`, default `empty`.

`Series (const Series &x, std::int64_t t)`: `f`, state `[n]` to `[n]`. Required.

### `observation`

`filtering::ObsFn`, default `empty`.

`h`: state `[n]` to observation `[m]`. Required.

### `transition_jacobian`

`filtering::JacobianFn`, default `empty`.

`∂f/∂x`, `[n, n]`. Required.

### `observation_jacobian`

`filtering::JacobianFn`, default `empty`.

`∂h/∂x`, `[m, n]`. Required.

### `process_cov`

`pluss::Series`, default `undefined`.

`Q`, `[n, n]`.

### `observation_cov`

`pluss::Series`, default `undefined`.

`R`, `[m, m]`.

### `initial_mean`

`pluss::Series`, default `undefined`.

State before the first observation, `[n]`.

### `initial_cov`

`pluss::Series`, default `undefined`.

`[n, n]`.

### `info_tol`

`double`, default `0.0`.

Channels with forecast variance at most this are ignored.

## Guidance

Passed to `ekf_filter`.

## Practical Examples

### Example 1

The transition `f`: a mean-reverting state instead of a random walk, `f(x) = 0.5x`. With data generated by the random walk the wrong dynamics lose accuracy.

```cpp
#include <pluss/ma.h>
#include <pluss/tils/kit/output.h>

#include <cmath>

using namespace pluss::tils;

namespace fin = pluss::subsp::math::finance;
namespace flt = fin::filtering;
using pluss::Series;

int main() {
  OutputEngine out;
  out.print_defaults(PrintOptions{}.fixed(4));
  const auto cfg = pluss::Config{}.with_dtype(pluss::ScalarType::Float64);
  const std::int64_t T = 200;
  const double q = 0.01, r = 0.01;
  const Series x = (pluss::series::randn({T}, cfg, 1) * std::sqrt(q)).cumsum(0, false);
  const Series y = x + x.square() * 0.2 + pluss::series::randn({T}, cfg, 2) * std::sqrt(r);
  flt::EkfModel m;
  m.transition = [&](const Series &s, std::int64_t) { return s; };
  m.observation = [&](const Series &s, std::int64_t) { return s + s.square() * 0.2; };
  m.transition_jacobian = [&](const Series &, std::int64_t) { return pluss::series::full({1, 1}, 1.0, cfg); };
  m.observation_jacobian = [&](const Series &s, std::int64_t) { return (s * 0.4 + 1.0).reshape({1, 1}); };
  m.process_cov = pluss::series::full({1, 1}, q, cfg);
  m.observation_cov = pluss::series::full({1, 1}, r, cfg);
  m.initial_mean = pluss::series::zeros({1}, cfg);
  m.initial_cov = pluss::series::full({1, 1}, 1.0, cfg);
  m.transition = [&](const Series &s, std::int64_t) { return s * 0.5; };
  m.transition_jacobian = [&](const Series &, std::int64_t) { return pluss::series::full({1, 1}, 0.5, cfg); };
  const auto res = flt::ekf_filter(y, m, cfg);
  out.writeln("rms error with f(x) = 0.5 x:", (res.filtered_mean.reshape({T}) - x).square().mean().sqrt().item<double>());
  m.transition = [&](const Series &s, std::int64_t) { return s; };
  m.transition_jacobian = [&](const Series &, std::int64_t) { return pluss::series::full({1, 1}, 1.0, cfg); };
  const auto right = flt::ekf_filter(y, m, cfg);
  out.writeln("rms error with the true f:", (right.filtered_mean.reshape({T}) - x).square().mean().sqrt().item<double>());
}
```

Output

```text
rms error with f(x) = 0.5 x: 0.2053
rms error with the true f: 0.0705
```

### Example 2

The observation `h` and its Jacobian must agree: if the Jacobian is wrong the filter is inconsistent and does worse. Here the right Jacobian `1 + 0.4x` against a wrong constant 1.

```cpp
#include <pluss/ma.h>
#include <pluss/tils/kit/output.h>

#include <cmath>

using namespace pluss::tils;

namespace fin = pluss::subsp::math::finance;
namespace flt = fin::filtering;
using pluss::Series;

int main() {
  OutputEngine out;
  out.print_defaults(PrintOptions{}.fixed(4));
  const auto cfg = pluss::Config{}.with_dtype(pluss::ScalarType::Float64);
  const std::int64_t T = 200;
  const double q = 0.01, r = 0.01;
  const Series x = (pluss::series::randn({T}, cfg, 1) * std::sqrt(q)).cumsum(0, false);
  const Series y = x + x.square() * 0.2 + pluss::series::randn({T}, cfg, 2) * std::sqrt(r);
  flt::EkfModel m;
  m.transition = [&](const Series &s, std::int64_t) { return s; };
  m.observation = [&](const Series &s, std::int64_t) { return s + s.square() * 0.2; };
  m.transition_jacobian = [&](const Series &, std::int64_t) { return pluss::series::full({1, 1}, 1.0, cfg); };
  m.observation_jacobian = [&](const Series &s, std::int64_t) { return (s * 0.4 + 1.0).reshape({1, 1}); };
  m.process_cov = pluss::series::full({1, 1}, q, cfg);
  m.observation_cov = pluss::series::full({1, 1}, r, cfg);
  m.initial_mean = pluss::series::zeros({1}, cfg);
  m.initial_cov = pluss::series::full({1, 1}, 1.0, cfg);

  const auto right = flt::ekf_filter(y, m, cfg);
  m.observation_jacobian = [&](const Series &, std::int64_t) { return pluss::series::full({1, 1}, 1.0, cfg); };
  const auto wrong = flt::ekf_filter(y, m, cfg);
  out.writeln("rms error, right Jacobian:", (right.filtered_mean.reshape({T}) - x).square().mean().sqrt().item<double>(), ", wrong Jacobian:", (wrong.filtered_mean.reshape({T}) - x).square().mean().sqrt().item<double>());
}
```

Output

```text
rms error, right Jacobian: 0.0705 , wrong Jacobian: 0.0762
```

```cpp
  m.transition_jacobian = [&](const Series &, std::int64_t) { return pluss::series::full({1, 1}, 1.0, cfg); };
  m.observation_jacobian = [&](const Series &s, std::int64_t) { return (s * 0.4 + 1.0).reshape({1, 1}); };
  m.process_cov = pluss::series::full({1, 1}, q, cfg);

  try {
    (void)(flt::ekf_filter(y, m, cfg));

    const std::string text(e.what());
    out.writeln(text.substr(0, text.find('\n')));
  }
}
```

Output

```text
subsp::math::finance::filtering::ekf_filter: transition_jacobian missing
```

### Example 4

The process covariance `Q`: too small a value makes the filter slow to follow the state, too large lets noise through.

```cpp
#include <pluss/ma.h>
#include <pluss/tils/kit/output.h>

#include <cmath>

using namespace pluss::tils;

namespace fin = pluss::subsp::math::finance;
namespace flt = fin::filtering;
using pluss::Series;

int main() {
  OutputEngine out;
  out.print_defaults(PrintOptions{}.fixed(4));
  const auto cfg = pluss::Config{}.with_dtype(pluss::ScalarType::Float64);
  const std::int64_t T = 200;
  const double q = 0.01, r = 0.01;
  const Series x = (pluss::series::randn({T}, cfg, 1) * std::sqrt(q)).cumsum(0, false);
  const Series y = x + x.square() * 0.2 + pluss::series::randn({T}, cfg, 2) * std::sqrt(r);
  flt::EkfModel m;
  m.transition = [&](const Series &s, std::int64_t) { return s; };
  m.observation = [&](const Series &s, std::int64_t) { return s + s.square() * 0.2; };
  m.transition_jacobian = [&](const Series &, std::int64_t) { return pluss::series::full({1, 1}, 1.0, cfg); };
  m.observation_jacobian = [&](const Series &s, std::int64_t) { return (s * 0.4 + 1.0).reshape({1, 1}); };
  m.process_cov = pluss::series::full({1, 1}, q, cfg);
  m.observation_cov = pluss::series::full({1, 1}, r, cfg);
  m.initial_mean = pluss::series::zeros({1}, cfg);
  m.initial_cov = pluss::series::full({1, 1}, 1.0, cfg);

  for (const double process : {1e-4, 0.01, 1.0}) {
    m.process_cov = pluss::series::full({1, 1}, process, cfg);
    const auto res = flt::ekf_filter(y, m, cfg);
    out.writeln("Q =", process, ": rms error", (res.filtered_mean.reshape({T}) - x).square().mean().sqrt().item<double>());
  }
}
```

Output

```text
Q = 0.0001 : rms error 0.1962
Q = 0.0100 : rms error 0.0705
Q = 1.0000 : rms error 0.0874
```

### Example 6

The initial mean: a start far from the truth is corrected within a few observations.

```cpp

#include <cmath>

using namespace pluss::tils;

namespace fin = pluss::subsp::math::finance;

int main() {
  OutputEngine out;
  out.print_defaults(PrintOptions{}.fixed(3));
  const auto cfg = pluss::Config{}.with_dtype(pluss::ScalarType::Float64);
  const std::int64_t T = 200;
  const double q = 0.01, r = 0.01;
  const Series x = (pluss::series::randn({T}, cfg, 1) * std::sqrt(q)).cumsum(0, false);
  const Series y = x + x.square() * 0.2 + pluss::series::randn({T}, cfg, 2) * std::sqrt(r);
  flt::EkfModel m;
  m.transition = [&](const Series &s, std::int64_t) { return s; };
  m.observation = [&](const Series &s, std::int64_t) { return s + s.square() * 0.2; };
  m.transition_jacobian = [&](const Series &, std::int64_t) { return pluss::series::full({1, 1}, 1.0, cfg); };
  m.observation_jacobian = [&](const Series &s, std::int64_t) { return (s * 0.4 + 1.0).reshape({1, 1}); };
  m.process_cov = pluss::series::full({1, 1}, q, cfg);
  m.observation_cov = pluss::series::full({1, 1}, r, cfg);
  m.initial_mean = pluss::series::zeros({1}, cfg);
  m.initial_cov = pluss::series::full({1, 1}, 1.0, cfg);

  }
}
```

Output

```text

initial mean 3.000 : filtered level at dates 0, 1, 5, 30 = 0.821 0.224 -0.133 0.144 (truth at date 30: 0.096 )
```

### Example 8

The information tolerance, as for the Kalman filter: a tolerance above every forecast variance skips all the observations.

```cpp
#include <pluss/ma.h>
#include <pluss/tils/kit/output.h>

#include <cmath>

using namespace pluss::tils;

namespace fin = pluss::subsp::math::finance;
namespace flt = fin::filtering;
using pluss::Series;

int main() {
  OutputEngine out;
  out.print_defaults(PrintOptions{}.fixed(0));
  const auto cfg = pluss::Config{}.with_dtype(pluss::ScalarType::Float64);
  const std::int64_t T = 200;
  const double q = 0.01, r = 0.01;
  const Series x = (pluss::series::randn({T}, cfg, 1) * std::sqrt(q)).cumsum(0, false);
  const Series y = x + x.square() * 0.2 + pluss::series::randn({T}, cfg, 2) * std::sqrt(r);
  flt::EkfModel m;
  m.transition = [&](const Series &s, std::int64_t) { return s; };
  m.observation = [&](const Series &s, std::int64_t) { return s + s.square() * 0.2; };
  m.transition_jacobian = [&](const Series &, std::int64_t) { return pluss::series::full({1, 1}, 1.0, cfg); };
  m.observation_jacobian = [&](const Series &s, std::int64_t) { return (s * 0.4 + 1.0).reshape({1, 1}); };
  m.process_cov = pluss::series::full({1, 1}, q, cfg);
  m.observation_cov = pluss::series::full({1, 1}, r, cfg);
  m.initial_mean = pluss::series::zeros({1}, cfg);
  m.initial_cov = pluss::series::full({1, 1}, 1.0, cfg);

  for (const double tol : {0.0, 1e6}) {
    m.info_tol = tol;
    out.writeln("info_tol", tol, ": observations used", flt::ekf_filter(y, m, cfg).data_used.sum().item<double>(), "of", T);
  }
}
```

Output

```text
info_tol 0 : observations used 200 of 200
info_tol 1000000 : observations used 0 of 200
```

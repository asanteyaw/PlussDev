# `prc::ImpliedVolOptions`

The algorithm, the volatility bracket, the tolerance and the iteration limit of `Field::implied_vol`.

`method` picks the root-finder ([`ImpliedVolMethod`](ImpliedVolMethod.md)). The volatility is searched in `[lower_vol, upper_vol]`; a price that no volatility in that range reproduces gives NaN. `tolerance` is relative to the **time value** of the option (its price less the discounted intrinsic value, or the whole price out of the money), so a tiny price is matched to a correspondingly tiny absolute error and a deep-in-the-money price is not judged against its large intrinsic part; the match is never required to be finer than a few units in the last place of the price. `max_iterations` caps each method's iterations; `vega_floor` is the smallest vega at which Newton will take a derivative step.

## Fields

### `method`

`prc::ImpliedVolMethod`, default `Auto`.

The root-finder; the default is Brent. The answer is correct for every method, only the speed differs.

### `lower_vol`

`double`, default `1e-8`.

Lower end of the search bracket; finite and positive. A price below the value at `lower_vol` has no solution in the bracket (NaN).

### `upper_vol`

`double`, default `10.0`.

Upper end of the search bracket; above `lower_vol`. A price above the value at `upper_vol` has no solution (NaN). 10 is a volatility of 1000%, far above any market quote.

### `tolerance`

`double`, default `1e-8`.

Relative to the time value of the option; positive. Tighten it only as far as the price itself is accurate.

### `max_iterations`

`std::int64_t`, default `128`.

Iteration cap per method; positive. Bisection needs about `log₂((upper − lower)/tolerance)`.

### `vega_floor`

`double`, default `1e-12`.

Smallest vega at which Newton takes a derivative step; positive.

## Guidance

Passed to `Field::implied_vol`.

## Practical Examples

### Example 1

The method. The same price inverted by Newton and Bisection: both converge to the 25% volatility used to make it.

```cpp
#include <pluss/ma.h>
#include <pluss/tils/kit/output.h>

using namespace pluss::tils;

namespace fin = pluss::subsp::math::finance;
namespace prc = fin::pricing;
namespace mod = fin::module;
using pluss::Series;

static double bs(fin::pricing::OptionType type, double S, double K, double r, double q, double T, double vol) {
  fin::module::Field f{.instrument = fin::instrument::make(type, K, T), .market = fin::market::make(S, r, q),
                       .model = fin::model::BlackScholes{.volatility = pluss::make_series({vol})},
                       .controls = {.engine = fin::module::Engine::Analytic, .risk = fin::module::Risk::PriceOnly}};
  return f.price().price.items<double>()[0];
}

                       .model = fin::model::BlackScholes{.volatility = pluss::make_series({vol})},

  return fin::hedging::delta_hedge(f, path);
}
static double iv(double price, double S, double K, double r, double q, double T, const fin::pricing::ImpliedVolOptions &o = {}) {

                       .controls = {.engine = fin::module::Engine::Analytic, .risk = fin::module::Risk::PriceOnly}};
  return f.implied_vol(pluss::make_series({price}), o).items<double>()[0];
}

int main() {
  OutputEngine out;
  out.print_defaults(PrintOptions{}.fixed(10));
  const double S = 100.0, K = 100.0, r = 0.05, q = 0.02, T = 1.0, v = 0.2;
  const double price = bs(prc::Call, S, K, r, q, T, 0.25);

  for (const prc::ImpliedVolMethod method : {prc::Newton, prc::Bisection}) {
    prc::ImpliedVolOptions options;
    options.method = method;
    out.writeln(static_cast<int>(method), ":", iv(price, S, K, r, q, T, options));
  }
}
```

Output

```text

2 : 0.2500000042
```

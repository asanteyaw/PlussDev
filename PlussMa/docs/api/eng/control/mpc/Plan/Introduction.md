# `control::mpc::Plan` Introduction

The condensed quadratic program of a model, weights, bounds and horizon, with its solver prepared. A `Plan` can be created only by `build` and is solved by `solve`. It is immutable, so one plan can serve every sample of a control loop.

Reuse the plan: the second example solves one plan for four initial states and shows the bounded first move (0.4 for the far states, falling to 0.09 near the reference and turning negative once the state has overshot it). A plan gives exactly the controls of the one-shot `solve` (the third example).

## Practical Examples

The following programs isolate this symbol's normal contract, the property that distinguishes it, and its validation behavior. Every program and displayed output is generated from the same compiled source.

```text
initial state 1.2000 : first control -0.1832
```

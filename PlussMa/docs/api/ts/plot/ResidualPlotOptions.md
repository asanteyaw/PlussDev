# `pluss::subsp::stats::ts::ResidualPlotOptions`

Options of the residual plot.

`ResidualPlotOptions` selects the reference line and the line width.

## Fields

| Field | Type | Default | Meaning |
|---|---|---|---|
| `show_zero_line` | `bool` | true | Draw a horizontal line at zero. |
| `trace_width` | `float` | 1.2 | Line width. |

## Guidance

The defaults are a sensible starting point; change a field only for the reason its row gives.

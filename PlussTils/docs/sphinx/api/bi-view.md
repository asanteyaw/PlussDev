# `pluss::bi::View`

[Back to PlussBI API Reference](bi.md)

```cpp
#include <pluss/bi/specs.h>

class View;
```

A `View` is one tile of a board that shows data. Build one with a DSL constructor such as `bi::bar("key")`, or with `View::make` when you already have a `BindSpec`. Every view has a key, a query that chooses rows, a binding that chooses what to show, and a layout that places it on the grid. A view with no query is refused when the studio renders.

The DSL constructors set the kind for you. Each setter returns the view, so you chain them. Nothing is checked until the studio renders, so a bad column name or a missing binding is reported at render time, not when you call the setter.

## Parameters

`View` has no constructor parameters beyond the key used by the DSL. See the members below.

## Returns

A `View` that carries its key, query, binding, and layout. The DSL constructors and the setters each return a `View`.

## Errors

The studio refuses a view with a duplicate key, a view with no query, a view that is out of the grid, a zero span, or a binding that names a missing column. Each refusal is raised by `Studio::render`, not by the setter.

## Practical Examples

### Example 1

Example 1 builds a view with the DSL constructor, then reads the binding back. The output shows that the view is a kpi and that it holds a scalar once rendered.

```cpp
#include <pluss/bi/bi.h>
#include <pluss/bundle/bundle.h>
#include <pluss/mic.h>

#include <cstdint>
#include <filesystem>
#include <fstream>
#include <iostream>
#include <iterator>
#include <string>
#include <vector>

namespace bi = pluss::bi;
namespace fs = std::filesystem;

// Six sales rows. Regions: north, south, north, east, south, north. Months: jan, jan, feb, feb, mar, mar.
// Amounts 10 to 60, units 1 to 6, and one date per row from January to June 2024.
pluss::bundle::Nexus make_nexus() {
  using pluss::table::DataFrame;
  using pluss::table::Slate;
  const auto cfg = pluss::Config{}.with_dtype(pluss::ScalarType::Float64).with_platform(pluss::pCPU);
  const DataFrame sales({
      {"region", Slate(pluss::make_note({"north", "south", "north", "east", "south", "north"}))},
      {"month", Slate(pluss::make_note({"jan", "jan", "feb", "feb", "mar", "mar"}))},
      {"amount", Slate(pluss::make_series(std::vector<double>{10, 20, 30, 40, 50, 60}, {6}, cfg))},
      {"units", Slate(pluss::make_series(std::vector<double>{1, 2, 3, 4, 5, 6}, {6}, cfg))},
      {"placed", Slate(pluss::make_timeline({"2024-01-05", "2024-02-10", "2024-03-15", "2024-04-20", "2024-05-25", "2024-06-30"}))},
  });
  return pluss::bundle::Nexus({{"sales", sales}});
}

// Renders a studio that holds one board with one view, and returns the first rendered tile.
template <class Build>
bi::TileRender one_tile(Build build) {
  const auto nexus = make_nexus();
  bi::Studio studio("sales_studio");
  studio.source(nexus);
  studio.board("overview").grid(1, 1);
  studio.board("overview").view(build());
  return studio.render().boards.front().tiles.front();
}

// The text of the page a studio exports, for checks on what is shown.
std::string page_text(const bi::Studio& studio) {
  const fs::path dir = fs::temp_directory_path() / "pluss_view_page_example";
  fs::remove_all(dir);
  fs::create_directories(dir);
  studio.export_html((dir / "page.html").string(), "T", 900, 600, bi::DashboardChrome::None);
  std::ifstream in((dir / "page.html").string());
  std::string text((std::istreambuf_iterator<char>(in)), std::istreambuf_iterator<char>());
  fs::remove_all(dir);
  return text;
}

template <class Fn>
bool throws(Fn fn) {
  try {
    fn();
  } catch (const std::exception&) {
    return true;
  }
  return false;
}

int main() {
  std::cout << std::boolalpha;
  // A DSL constructor names the presentation. Rendering a kpi shows one scalar.
  const auto tile = one_tile([] { return bi::kpi("headline").feature("amount").query(bi::from("sales")).place(0, 0); });
  std::cout << "kind is kpi: " << (tile.kind == bi::ViewKind::Kpi) << '\n';
  std::cout << "holds a scalar: " << tile.scalar.has_value() << '\n';
  return 0;
}
```

Output

```text
kind is kpi: true
holds a scalar: true
```

The first output line reads back the kind, and the second confirms the kpi rendered a scalar value.

Example 2 chains the setters that name the title, the x and y columns, and the query. The output reads each one back from the binding.

```cpp
  try {
    fn();
  } catch (const std::exception&) {
    return true;

  return false;

int main() {
  // Setters write the binding. The view records what you set and nothing else.
  bi::View view = bi::bar("sales_by_region").title("Sales by region").x("region").y("amount").query(bi::from("sales"));
  std::cout << "title: " << view.bind().title << '\n';
  std::cout << "x feature: " << view.bind().columns.x_feature.value_or("<unset>") << '\n';
  std::cout << "y feature: " << view.bind().columns.y_feature.value_or("<unset>") << '\n';
  std::cout << "key: " << view.key() << '\n';
  return 0;
}
```

Output

```text
title: Sales by region
x feature: region
y feature: amount
key: sales_by_region
```

Each line is a value the setter stored. The studio reads the same binding when it renders the view.

### Example 3

Example 3 attaches a query that narrows the rows. The rendered tile counts only the rows that match.

```cpp
#include <pluss/bi/bi.h>
#include <pluss/bundle/bundle.h>
#include <pluss/mic.h>

#include <cstdint>
#include <filesystem>
#include <fstream>
#include <iostream>
#include <iterator>
#include <string>
#include <vector>

namespace bi = pluss::bi;
namespace fs = std::filesystem;

// Six sales rows. Regions: north, south, north, east, south, north. Months: jan, jan, feb, feb, mar, mar.
// Amounts 10 to 60, units 1 to 6, and one date per row from January to June 2024.
pluss::bundle::Nexus make_nexus() {
  using pluss::table::DataFrame;
  using pluss::table::Slate;
  const auto cfg = pluss::Config{}.with_dtype(pluss::ScalarType::Float64).with_platform(pluss::pCPU);
  const DataFrame sales({
      {"region", Slate(pluss::make_note({"north", "south", "north", "east", "south", "north"}))},
      {"month", Slate(pluss::make_note({"jan", "jan", "feb", "feb", "mar", "mar"}))},
      {"amount", Slate(pluss::make_series(std::vector<double>{10, 20, 30, 40, 50, 60}, {6}, cfg))},
      {"units", Slate(pluss::make_series(std::vector<double>{1, 2, 3, 4, 5, 6}, {6}, cfg))},
      {"placed", Slate(pluss::make_timeline({"2024-01-05", "2024-02-10", "2024-03-15", "2024-04-20", "2024-05-25", "2024-06-30"}))},

std::string page_text(const bi::Studio& studio) {
  const fs::path dir = fs::temp_directory_path() / "pluss_view_page_example";
  fs::remove_all(dir);
  fs::create_directories(dir);
  studio.export_html((dir / "page.html").string(), "T", 900, 600, bi::DashboardChrome::None);
  std::ifstream in((dir / "page.html").string());
  std::string text((std::istreambuf_iterator<char>(in)), std::istreambuf_iterator<char>());
  fs::remove_all(dir);
  return text;

template <class Fn>
bool throws(Fn fn) {
  try {
    fn();
  } catch (const std::exception&) {
    return true;
  }
  return false;
}

int main() {
  // A query can carry a filter. The rows the table shows follow the query.
  const auto tile = one_tile([] {
    return bi::table("north_rows").query(bi::from("sales").where(bi::Filter::eq("region", std::string("north")))).place(0, 0);
  });
  std::cout << "rows shown: " << tile.table->height() << '\n';
  return 0;
}
```

Output

```text
rows shown: 3
```

A north-only query leaves three of the six rows, so the tile counts three.

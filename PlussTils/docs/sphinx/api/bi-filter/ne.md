# `pluss::bi::Filter::ne`

[Back to PlussBI API Reference](../bi.md)

```cpp
#include <pluss/bi/specs.h>

static Filter ne(std::string_view feature, double value);
static Filter ne(std::string_view feature, std::string_view value);
static Filter ne(std::string_view feature, const pluss::Duration& value);
```

`ne` builds a filter that keeps rows whose feature differs from the value. It is `eq` with the
operator changed to `Ne`, so it has the same key rule and the same handling of unknown features.
A value that occurs nowhere excludes no rows. The factory has no timeline overload; a timeline
inequality is not offered by this factory.

## Overloads

| Overload | Value type | Column kind |
|---|---|---|
| `ne(feature, double)` | number | numeric |
| `ne(feature, std::string_view)` | text | text |
| `ne(feature, const pluss::Duration&)` | duration | duration |

## Parameters

| Parameter | Meaning |
|---|---|
| `feature` | The column name to test. |
| `value` | The number, text, or duration to exclude. |

## Returns

A filter with the `Ne` operator and the given payload.

## Errors

A payload whose kind does not match the column is refused when the studio renders.

## Practical Examples

### Example 1

Example 1 excludes the one row with amount 30, so five rows remain.

```cpp
#include <pluss/bi/bi.h>
#include <pluss/bundle/bundle.h>
#include <pluss/mic.h>

#include <cstdint>
#include <iostream>
#include <string>
#include <variant>
#include <vector>

namespace bi = pluss::bi;

// Six sales rows: regions north, south, north, east, south, north; amounts 10 to 60.
pluss::bundle::Nexus make_nexus() {
  using pluss::table::DataFrame;
  using pluss::table::Slate;
  const auto cfg = pluss::Config{}.with_dtype(pluss::ScalarType::Float64).with_platform(pluss::pCPU);
  const DataFrame sales({
      {"region", Slate(pluss::make_note({"north", "south", "north", "east", "south", "north"}))},
      {"amount", Slate(pluss::make_series(std::vector<double>{10, 20, 30, 40, 50, 60}, {6}, cfg))},
  });
  return pluss::bundle::Nexus({{"sales", sales}});
}

// The number of rows the overview table shows when the given filters are set on the session.
std::int64_t visible_rows(const std::vector<bi::Filter>& filters) {
  const auto nexus = make_nexus();
  bi::Studio studio("sales_studio");
  studio.source(nexus);
  studio.board("overview").grid(1, 1);
  studio.board("overview").view(bi::table("rows").query(bi::from("sales")).place(0, 0, 1, 1));
  for (const auto& filter : filters) studio.set_filter(filter);
  return studio.render().boards.front().tiles.front().table->height();
}

template <class Fn>
bool throws(Fn fn) {
  try {
    fn();
  } catch (const std::exception&) {
    return true;
  }
  return false;
}

int main() {
  // ne keeps every row whose value differs from the number.
  std::cout << "amount not 30: " << visible_rows({bi::Filter::ne("amount", 30.0)}) << '\n';
  return 0;
}
```

Output

```text
amount not 30: 5
```

### Example 4

Example 4 excludes the row whose lead is three days, so five rows remain. A duration bound is compared with every row of a duration column, so one bound selects by length of time.

```cpp
#include <pluss/bi/bi.h>
#include <pluss/bundle/bundle.h>
#include <pluss/mic.h>

#include <cstdint>
#include <iostream>
#include <string>
#include <variant>
#include <vector>

namespace bi = pluss::bi;

// Six sales rows. Regions: north, south, north, east, south, north. Amounts: 10 to 60.
// Dates: one per month from January to June 2024. Leads: 1 to 6 days.
pluss::bundle::Nexus make_nexus() {
  using pluss::table::DataFrame;
  using pluss::table::Slate;
  const auto cfg = pluss::Config{}.with_dtype(pluss::ScalarType::Float64).with_platform(pluss::pCPU);
  const DataFrame sales({
      {"region", Slate(pluss::make_note({"north", "south", "north", "east", "south", "north"}))},
      {"amount", Slate(pluss::make_series(std::vector<double>{10, 20, 30, 40, 50, 60}, {6}, cfg))},
      {"placed", Slate(pluss::make_timeline({"2024-01-05", "2024-02-10", "2024-03-15", "2024-04-20", "2024-05-25", "2024-06-30"}))},
      {"lead", Slate(pluss::make_duration(std::vector<std::int64_t>{1, 2, 3, 4, 5, 6}, {6}, pluss::duration::Unit::Days))},
  });
  return pluss::bundle::Nexus({{"sales", sales}});
}

// The number of rows the overview table shows with the given filters on the session.
std::int64_t visible_rows(const std::vector<bi::Filter>& filters) {
  const auto nexus = make_nexus();
  bi::Studio studio("sales_studio");
  studio.source(nexus);
  studio.board("overview").grid(1, 1);
  studio.board("overview").view(bi::table("rows").query(bi::from("sales")).place(0, 0, 1, 1));
  for (const auto& filter : filters) studio.set_filter(filter);
  return studio.render().boards.front().tiles.front().table->height();
}

pluss::Duration days(std::int64_t n) {
  return pluss::make_duration(std::vector<std::int64_t>{n}, {1}, pluss::duration::Unit::Days);
}

template <class Fn>
bool throws(Fn fn) {
  try {
    fn();
  } catch (const std::exception&) {
    return true;
  }
  return false;
}

int main() {
  std::cout << "lead not 3 days: " << visible_rows({bi::Filter::ne("lead", days(3))}) << '\n';
  return 0;
}
```

Output

```text
lead not 3 days: 5
```

# `pluss::bi::FilterSet`

[Back to PlussBI API Reference](../bi.md)

```cpp
#include <pluss/bi/specs.h>

using FilterSet = std::variant<std::vector<double>, std::vector<std::string>>;
```

`FilterSet` holds the members of an `In` filter. It is a variant of two vectors: numbers, for numeric
columns, and text, for text columns. The set is stored by value with the filter, so later changes to the
vector you passed do not change the filter. An empty set is refused when the studio renders, and a set
whose type does not match the column is refused too.

## Parameters

| Alternative | Used for |
|---|---|
| `std::vector<double>` | membership in numeric values |
| `std::vector<std::string>` | membership in text values |

## Returns

Not a function. `FilterSet` is a type alias for a variant of two vectors.

## Errors

An empty set, or a set whose element type does not match the column, is refused when the studio renders.

## Practical Examples

### Example 1

Example 1 builds a numeric set and reports its size. Two rows have amounts 10 or 60, so the filter keeps two rows.

```cpp
#include <pluss/bi/bi.h>
#include <pluss/bundle/bundle.h>
#include <pluss/mic.h>

#include <cstdint>
#include <iostream>
#include <string>
#include <variant>
#include <vector>

namespace bi = pluss::bi;

// Six sales rows. Regions: north, south, north, east, south, north. Amounts: 10 to 60.
// Dates: one per month from January to June 2024. Leads: 1 to 6 days.
pluss::bundle::Nexus make_nexus() {
  using pluss::table::DataFrame;
  using pluss::table::Slate;
  const auto cfg = pluss::Config{}.with_dtype(pluss::ScalarType::Float64).with_platform(pluss::pCPU);
  const DataFrame sales({
      {"region", Slate(pluss::make_note({"north", "south", "north", "east", "south", "north"}))},
      {"amount", Slate(pluss::make_series(std::vector<double>{10, 20, 30, 40, 50, 60}, {6}, cfg))},
      {"placed", Slate(pluss::make_timeline({"2024-01-05", "2024-02-10", "2024-03-15", "2024-04-20", "2024-05-25", "2024-06-30"}))},
      {"lead", Slate(pluss::make_duration(std::vector<std::int64_t>{1, 2, 3, 4, 5, 6}, {6}, pluss::duration::Unit::Days))},
  });
  return pluss::bundle::Nexus({{"sales", sales}});
}

// The number of rows the overview table shows with the given filters on the session.
std::int64_t visible_rows(const std::vector<bi::Filter>& filters) {
  const auto nexus = make_nexus();
  bi::Studio studio("sales_studio");
  studio.source(nexus);
  studio.board("overview").grid(1, 1);
  studio.board("overview").view(bi::table("rows").query(bi::from("sales")).place(0, 0, 1, 1));
  for (const auto& filter : filters) studio.set_filter(filter);
  return studio.render().boards.front().tiles.front().table->height();
}

pluss::Duration days(std::int64_t n) {
  return pluss::make_duration(std::vector<std::int64_t>{n}, {1}, pluss::duration::Unit::Days);
}

template <class Fn>
bool throws(Fn fn) {
  try {
    fn();
  } catch (const std::exception&) {
    return true;
  }
  return false;
}

int main() {
  // FilterSet holds the members of an In filter. A numeric set holds doubles.
  bi::FilterSet members = std::vector<double>{10.0, 60.0};
  std::cout << "numeric set: " << std::holds_alternative<std::vector<double>>(members) << '\n';
  std::cout << "members: " << std::get<std::vector<double>>(members).size() << '\n';
  std::cout << "rows matching the set: " << visible_rows({bi::Filter{.key = "a", .feature = "amount",
      .op = bi::FilterOp::In, .payload = members}}) << '\n';
  return 0;
}
```

Output

```text
numeric set: 1
members: 2
rows matching the set: 2
```

### Example 3

Example 3 uses a text set on the numeric amount column. The studio refuses the mismatch.

```cpp

pluss::Duration days(std::int64_t n) {

template <class Fn>
bool throws(Fn fn) {
  try {
    fn();
  } catch (const std::exception&) {
    return true;
  }
  return false;
}

int main() {
  // A text set on a numeric column is refused when the studio renders.
  bi::Filter f{.key = "a", .feature = "amount", .op = bi::FilterOp::In,
               .payload = bi::FilterSet(std::vector<std::string>{"10"})};
  std::cout << "text set on a numeric column refused: " << throws([&] { (void)visible_rows({f}); }) << '\n';
  return 0;
}
```

Output

```text
text set on a numeric column refused: 1
```

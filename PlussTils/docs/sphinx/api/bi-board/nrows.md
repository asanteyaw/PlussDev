# `pluss::bi::Board::nrows`

[Back to `Board`](../bi-board.md) · [PlussBI API Reference](../bi.md)

```cpp
#include <pluss/bi/specs.h>

std::int64_t nrows() const noexcept;
```

`nrows` returns the number of rows in the board's grid. A new board has one row. `grid` sets the row count,
and no other call changes it. A title change, a control, or a view leaves the row count alone.
The studio refuses a row count below one when it renders.

## Parameters

Not applicable. The method takes no parameters.

## Returns

The row count, as a 64-bit integer.

## Errors

This call does not throw. A non-positive row count is refused when the studio renders.

## Practical Examples

### Example 1

Example 1 shows the default of one row.

```cpp
#include <pluss/bi/bi.h>
#include <pluss/bundle/bundle.h>
#include <pluss/mic.h>

#include <cstdint>
#include <fstream>
#include <iostream>
#include <iterator>
#include <string>
#include <vector>

namespace bi = pluss::bi;

// Three sales rows: regions north, south, north; amounts 10, 20, 30.
pluss::bundle::Nexus make_nexus() {
  using pluss::table::DataFrame;
  using pluss::table::Slate;
  const auto cfg = pluss::Config{}.with_dtype(pluss::ScalarType::Float64).with_platform(pluss::pCPU);
  const DataFrame sales({
      {"region", Slate(pluss::make_note({"north", "south", "north"}))},
      {"amount", Slate(pluss::make_series(std::vector<double>{10, 20, 30}, {3}, cfg))},
  });
  return pluss::bundle::Nexus({{"sales", sales}});
}

// Renders a studio that holds one board built by the caller, and returns the render.
template <class Build>
bi::StudioRender render_with(Build build) {
  const auto nexus = make_nexus();
  bi::Studio studio("sales_studio");
  studio.source(nexus);
  build(studio);
  return studio.render();
}

template <class Fn>
bool throws(Fn fn) {
  try {
    fn();
  } catch (const std::exception&) {
    return true;
  }
  return false;
}

int main() {
  bi::Board board("overview");
  std::cout << "default rows: " << board.nrows() << '\n';
  return 0;
}
```

Output

```text
default rows: 1
```

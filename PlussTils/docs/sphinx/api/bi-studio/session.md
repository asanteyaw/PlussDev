# `pluss::bi::Studio::session`

[Back to `Studio`](../bi-studio.md) · [PlussBI API Reference](../bi.md)

```cpp
#include <pluss/bi/specs.h>

const Session& session() const noexcept;
Studio& session(const Session& value);
```

`session` reads or replaces the studio's session. Reading returns a reference to the session the studio uses for its renders. Replacing
stores a copy of the session you pass, so later changes to your own session do not change the studio.

## Overloads

| Overload | Effect |
|---|---|
| `session()` | Returns the current session as a const reference. |
| `session(value)` | Stores a copy of `value` and returns the studio. |

## Parameters

| Parameter | Meaning |
|---|---|
| `value` | A session to copy into the studio. |

## Returns

For the reader, the session. For the setter, the studio itself, so calls chain.

## Errors

These calls do not throw.

## Practical Examples

### Example 1

Example 1 reads the session of a new studio, which is empty.

```cpp
#include <pluss/bi/bi.h>
#include <pluss/bi/serve.h>
#include <pluss/bundle/bundle.h>
#include <pluss/mic.h>

#include <cstdint>
#include <filesystem>
#include <fstream>
#include <iostream>
#include <iterator>
#include <string>
#include <vector>

namespace bi = pluss::bi;
namespace fs = std::filesystem;

// Three sales rows: regions north, south, north; amounts 10, 20, 30.
pluss::bundle::Nexus make_nexus() {
  using pluss::table::DataFrame;
  using pluss::table::Slate;
  const auto cfg = pluss::Config{}.with_dtype(pluss::ScalarType::Float64).with_platform(pluss::pCPU);
  const DataFrame sales({
      {"region", Slate(pluss::make_note({"north", "south", "north"}))},
      {"amount", Slate(pluss::make_series(std::vector<double>{10, 20, 30}, {3}, cfg))},
  });
  return pluss::bundle::Nexus({{"sales", sales}});
}

// A studio with one board holding one table over the sales data.
bi::Studio overview_studio(const pluss::bundle::Nexus& nexus) {
  bi::Studio studio("sales_studio");
  studio.source(nexus);
  studio.board("overview").title("Sales overview").grid(1, 1);
  studio.board("overview").view(bi::table("rows").query(bi::from("sales")).place(0, 0));
  return studio;
}

// The number of rows the overview table shows on a studio.
std::int64_t rows_shown(const bi::Studio& studio) {
  return studio.render().boards.front().tiles.front().table->height();
}

fs::path private_dir(const std::string& name) {
  const fs::path dir = fs::temp_directory_path() / name;
  fs::remove_all(dir);
  fs::create_directories(dir);
  return dir;
}

std::string read_file(const fs::path& path) {
  std::ifstream in(path, std::ios::binary);
  return std::string((std::istreambuf_iterator<char>(in)), std::istreambuf_iterator<char>());
}

template <class Fn>
bool throws(Fn fn) {
  try {
    fn();
  } catch (const std::exception&) {
    return true;
  }
  return false;
}

int main() {
  bi::Studio studio("sales_studio");
  std::cout << "new studio session empty: " << studio.session().empty() << '\n';
  return 0;
}
```

Output

```text
new studio session empty: 1
```

### Example 2

Example 2 replaces the session with one holding a filter, then with an empty session. Each render follows the session in place.

```cpp
    fn();

  // session(value) replaces the studio's session. The next render applies the new filters.

  std::cout << "rows with the south filter: " << rows_shown(studio) << '\n';
  studio.session(bi::Session{});
  std::cout << "rows after replacing with an empty session: " << rows_shown(studio) << '\n';
  return 0;
}
```

Output

```text
rows with the south filter: 1
rows after replacing with an empty session: 3
```

### Example 3

Example 3 changes the original session after handing it over. The studio keeps its copy.

```cpp
#include <pluss/bi/bi.h>
#include <pluss/bi/serve.h>
#include <pluss/bundle/bundle.h>

template <class Fn>
bool throws(Fn fn) {
  try {
    fn();
  } catch (const std::exception&) {
    return true;
  }
  return false;
}

int main() {
  // The studio keeps a copy of the session it was given. Changing the original afterwards does not change the studio.
  const auto nexus = make_nexus();
  bi::Studio studio = overview_studio(nexus);
  bi::Session chosen;
  chosen.set_filter(bi::Filter::eq("region", std::string("south")));
  studio.session(chosen);
  chosen.clear_filters();
  std::cout << "studio still has its filter: " << !studio.session().filters().empty() << '\n';
  std::cout << "rows shown: " << rows_shown(studio) << '\n';
  return 0;
}
```

Output

```text
studio still has its filter: 1
rows shown: 1
```

# `pluss::bi::Studio::load`

[Back to `Studio`](../bi-studio.md) · [PlussBI API Reference](../bi.md)

```cpp
#include <pluss/bi/specs.h>

static Studio load(std::string_view path);
static Studio load(std::string_view path, const pluss::bundle::Nexus& nexus);
```

`load` reads a studio saved with `save`. The overload with a nexus attaches the tables so the studio can render. The overload
without one restores the boards and session only, and a studio loaded without data cannot render until you give it a source.

## Overloads

| Overload | Effect |
|---|---|
| `load(path)` | Restores boards and session. The studio has no tables until a source is set. |
| `load(path, nexus)` | Restores boards and session and attaches the nexus as the source. |

## Parameters

| Parameter | Meaning |
|---|---|
| `path` | The file written by `save`. |
| `nexus` | The tables to attach as the source. |

## Returns

The loaded studio.

## Errors

A missing file is refused. Rendering a studio loaded without data throws.

## Practical Examples

### Example 1

Example 1 loads with the same data and shows the boards and rows return.

```cpp
#include <pluss/bi/bi.h>
#include <pluss/bi/serve.h>
#include <pluss/bundle/bundle.h>
#include <pluss/mic.h>

#include <cstdint>
#include <filesystem>
#include <fstream>
#include <iostream>
#include <iterator>
#include <string>
#include <vector>

namespace bi = pluss::bi;
namespace fs = std::filesystem;

// Three sales rows: regions north, south, north; amounts 10, 20, 30.
pluss::bundle::Nexus make_nexus() {
  using pluss::table::DataFrame;
  using pluss::table::Slate;
  const auto cfg = pluss::Config{}.with_dtype(pluss::ScalarType::Float64).with_platform(pluss::pCPU);
  const DataFrame sales({
      {"region", Slate(pluss::make_note({"north", "south", "north"}))},
      {"amount", Slate(pluss::make_series(std::vector<double>{10, 20, 30}, {3}, cfg))},
  });
  return pluss::bundle::Nexus({{"sales", sales}});
}

// A studio with one board holding one table over the sales data.
bi::Studio overview_studio(const pluss::bundle::Nexus& nexus) {
  bi::Studio studio("sales_studio");
  studio.source(nexus);
  studio.board("overview").title("Sales overview").grid(1, 1);
  studio.board("overview").view(bi::table("rows").query(bi::from("sales")).place(0, 0));
  return studio;
}

// The number of rows the overview table shows on a studio.
std::int64_t rows_shown(const bi::Studio& studio) {
  return studio.render().boards.front().tiles.front().table->height();
}

fs::path private_dir(const std::string& name) {
  const fs::path dir = fs::temp_directory_path() / name;
  fs::remove_all(dir);
  fs::create_directories(dir);
  return dir;
}

std::string read_file(const fs::path& path) {
  std::ifstream in(path, std::ios::binary);
  return std::string((std::istreambuf_iterator<char>(in)), std::istreambuf_iterator<char>());
}

template <class Fn>
bool throws(Fn fn) {
  try {
    fn();
  } catch (const std::exception&) {
    return true;
  }
  return false;
}

int main() {
  const auto nexus = make_nexus();
  bi::Studio studio = overview_studio(nexus);
  const fs::path dir = private_dir("pluss_studio_load_example");
  studio.save((dir / "studio.bi").string());
  const bi::Studio loaded = bi::Studio::load((dir / "studio.bi").string(), nexus);
  std::cout << "boards loaded: " << loaded.boards().size() << '\n';
  std::cout << "rows shown: " << rows_shown(loaded) << '\n';
  fs::remove_all(dir);
  return 0;
}
```

Output

```text
boards loaded: 1
rows shown: 3
```

Example 2 loads without data. The boards come back, but rendering is refused.

```cpp
    fn();

    return true;
  }
  return false;

int main() {
  // Loading without a nexus restores the boards and the session, but not the tables. Rendering then fails.
  const auto nexus = make_nexus();
  bi::Studio studio = overview_studio(nexus);
  const fs::path dir = private_dir("pluss_studio_load_nodata_example");
  studio.save((dir / "studio.bi").string());
  const bi::Studio loaded = bi::Studio::load((dir / "studio.bi").string());
  std::cout << "boards loaded: " << loaded.boards().size() << '\n';
  std::cout << "render without data refused: " << throws([&] { (void)loaded.render(); }) << '\n';
  fs::remove_all(dir);
  return 0;
}
```

Output

```text
boards loaded: 1
render without data refused: 1
```

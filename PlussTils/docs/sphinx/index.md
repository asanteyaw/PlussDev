<h2>Choose a utility family</h2>
<p class="section-sub">Each family has its own purpose, dependencies, manual, and reference. Using one does not commit an application to the others.</p>
<div class="pluss-package-grid">

<div class="pluss-card">
<span class="card-name">Core</span>
<span class="card-model">Small conveniences</span>
<p class="card-desc">Environment access, typed conversion, output helpers, value checks, compact declarations, and callable dispatch.</p>
<a href="manual/core.html">Read the Core manual</a>
</div>

<div class="pluss-card">
<span class="card-name">Loaders</span>
<span class="card-model">Input and batching</span>
<p class="card-desc">Paths, datasets, samplers, deterministic splits, batching, shuffling, and host-to-platform transfer policy.</p>
<a href="manual/loaders.html">Read the Loader manual</a>
</div>

<div class="pluss-card">
<span class="card-name">PlussBI</span>
<span class="card-model">Analytical presentation</span>
<p class="card-desc">Declarative queries, controls, views, boards, sessions, and browser-hosted analytical experiences.</p>
<a href="manual/bi.html">Read the PlussBI manual</a>
</div>

<div class="pluss-card">
<span class="card-name">PlussView</span>
<span class="card-model">The built-in renderer</span>
<p class="card-desc">The scene, canvas, and software renderer underneath DataFrame/Atlas/plot .show() calls. If you want to show your data, call .show() on it, not this.</p>
<a href="manual/view.html">Read the PlussView manual</a>
</div>

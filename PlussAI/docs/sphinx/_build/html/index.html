PlussAI

The machine-learning and graph-computation layer of Pluss: the NodeJ differentiable-computation surface and the Lymph model layer built on top of it.

API Reference

What's in this space

PlussAI is organized around two layers: the differentiable computation graph, and the model layer built on it.

NodeJ Differentiable Computation

The differentiable-computation graph surface: nodes, operations, and automatic differentiation.

Lymph Model Layer

The model layer built on top of NodeJ, for assembling and training differentiable models.

SparseLinearMultiClassifier::infer_scores¶

API Signature¶

  • SparseLinearMultiClassifier::infer_scores(x: const SparseCsrMatrix&) -> StatusOr<Series>

  • SparseLinearMultiClassifier::infer_scores(x: const SparseTripletMatrix&) -> StatusOr<Series>

Notes¶

Computes predictions from prepared inputs using the currently learned state.

Inputs¶

  • x (const SparseCsrMatrix& | const SparseTripletMatrix&) Input feature data used by this call.

Output¶

  • Returns StatusOr<Series>. Check .ok() first; on success read .value() for the computed result.

Options¶

Option semantics used by this method:

  • SparseCsrMatrix (struct):

    • std::vector<std::int64_t> row_ptr{} Option field used by this method.

    • std::vector<std::int64_t> col_ind{} Option field used by this method.

    • std::vector<double> values{} Option field used by this method.

    • std::int64_t rows = 0 Option field used by this method.

    • std::int64_t cols = 0 Option field used by this method.

  • SparseTripletMatrix (struct):

    • Series row_indices = Series::undefined() Option field used by this method.

    • Series column_indices = Series::undefined() Controls fold/trial/count sizing.

    • Series values = Series::undefined() Option field used by this method.

    • std::int64_t rows = 0 Option field used by this method.

    • std::int64_t cols = 0 Option field used by this method.

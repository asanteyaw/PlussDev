make_flow¶

API Signature¶

  • make_flow(spec: const ModelSpec&) -> StatusOr<Flow>

Notes¶

Constructs a Flow from model spec/options; use it to chain transforms and model training.

Inputs¶

  • spec (const ModelSpec&) Method argument; see signature type for accepted form.

Output¶

  • Returns StatusOr<Flow>. Check .ok() first; on success read .value() for the computed result.

Options¶

Option semantics used by this method:

  • ModelSpec (struct):

    • TaskKind task = TaskKind::Regression Selects task type (for example classification vs regression).

    • ModelFamily family = ModelFamily::Linear Selects the model family implementation.

    • FamilyOptions options = LinearFamilyOptions{} Family-specific options payload used by the selected model/transform family.

Examples¶

Example 1 (Minimal Usage)¶

pluss::OutputEngine out;
auto res = make_flow(/* spec */);
if (!res.ok()) {
  out.error("make_flow failed", res.status().message);
} else {
  out.info("make_flow ok");
}

workflow::save¶

API Signature¶

  • workflow::save(path: const std::string&) -> void

  • workflow::save(path: const std::string&, metadata: io::FlowBundleMetadata) -> void

Notes¶

Persists the current fitted artifact so it can be loaded for inference later.

Inputs¶

  • metadata (io::FlowBundleMetadata) Input feature data used by this call.

  • path (const std::string&) Path to persisted model/data artifact.

Output¶

  • No direct return value; operation applies side effects to object state.

Options¶

No explicit option struct/enum parameters were detected for this method.

Examples¶

Example 1 (Minimal Usage)¶

pluss::OutputEngine out;
workflow::save(/* path */);
out.info("save completed");

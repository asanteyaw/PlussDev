# `prep::feature` Introduction

## What This Subfamily Owns

`prep::feature` owns the branch-aware composite transformation surface.

This is where you combine:

- several branch-local routes
- several attached stage pipelines
- one remainder policy

into one reusable `lymph::prep::FeatureTransformer`.

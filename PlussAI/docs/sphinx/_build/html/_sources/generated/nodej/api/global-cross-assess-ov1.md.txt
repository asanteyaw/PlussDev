# `cross_assess`

## Signature

```cpp
StatusOr<CrossAssessReport> cross_assess(const ModelSpec& spec, const LabeledBatch& batch, const SplitOptions& split = {}, const TrainOptions& train_options = {}, const AssessOptions& assess_options = {});
```

## Parameters

- `spec` : `const ModelSpec&`
  Method argument; see signature type for accepted form.
- `batch` : `const LabeledBatch&`
  Input feature data used by this call.
- `split` : `const SplitOptions&`, default: `{}`
  Configuration object controlling algorithm behavior and safety defaults.
- `train_options` : `const TrainOptions&`, default: `{}`
  Configuration object controlling algorithm behavior and safety defaults.
- `assess_options` : `const AssessOptions&`, default: `{}`
  Configuration object controlling algorithm behavior and safety defaults.

## Returns

Returns `StatusOr<CrossAssessReport>`. Check `.ok()` first; on success read `.value()` for the computed result.

## Notes

Evaluates model output against targets and returns metric aggregates.

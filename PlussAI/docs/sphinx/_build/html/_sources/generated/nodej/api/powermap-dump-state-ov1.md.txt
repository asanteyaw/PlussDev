# `PowerMap::dump_state`

## Signature

```cpp
[[nodiscard]] StatusOr<std::vector<Series>> PowerMap::dump_state(self) const override;
```

## Parameters

Returns `StatusOr<std::vector<Series>>`. Check `.ok()` first; on success read `.value()` for the computed result.

# `sweep`

## Signature

```cpp
StatusOr<TuneReport> sweep(const std::vector<ModelSpec>& candidates, const LabeledBatch& batch, const SplitOptions& split = {}, const TrainOptions& train_options = {}, const AssessOptions& assess_options = {}, MetricKind objective_metric = MetricKind::Accuracy, TuneObjectivePolicy objective_policy = TuneObjectivePolicy::Auto);
```

## Parameters

- `candidates` : `const std::vector<ModelSpec>&`
  List-like argument; pass values in the order expected by the signature.
- `batch` : `const LabeledBatch&`
  Input feature data used by this call.
- `split` : `const SplitOptions&`, default: `{}`
  Configuration object controlling algorithm behavior and safety defaults.
- `train_options` : `const TrainOptions&`, default: `{}`
  Configuration object controlling algorithm behavior and safety defaults.
- `assess_options` : `const AssessOptions&`, default: `{}`
  Configuration object controlling algorithm behavior and safety defaults.
- `objective_metric` : `MetricKind`, default: `MetricKind::Accuracy`
  Metric selection or score-control argument for evaluation/tuning.
- `objective_policy` : `TuneObjectivePolicy`, default: `TuneObjectivePolicy::Auto`
  Target values aligned to input observations.

## Returns

Returns `StatusOr<TuneReport>`. Check `.ok()` first; on success read `.value()` for the computed result.

## Notes

Executes hyperparameter search and reports trial-by-trial objective values.

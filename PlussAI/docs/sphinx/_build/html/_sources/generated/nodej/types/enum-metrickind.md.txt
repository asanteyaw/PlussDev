# `MetricKind`

## Signature


## Notes

Enumerated configuration choices used by NodeJ/Lymph APIs.

Known enumerators:
- `Accuracy = 0`
- `BalancedAccuracy = 1`
- `Precision = 2`
- `Recall = 3`
- `F1 = 4`
- `RocAuc = 5`
- `LogLoss = 6`
- `Mse = 7`
- `Rmse = 8`
- `Mae = 9`
- `R2 = 10`
- `QuantileLoss = 11`

## Example

```cpp
auto mode = MetricKind::Accuracy;
```

# `tree_factory::decision_tree_regressor`

## Signature

```cpp
[[nodiscard]] static WorkflowModel tree_factory::decision_tree_regressor(self, TreeFamilyOptions options = {});
```

## Parameters

- `self` : `receiver`
  Receiver object on which this method is invoked.
- `options` : `TreeFamilyOptions`, default: `{}`
  Configuration object controlling algorithm behavior and safety defaults.

## Returns

Returns `WorkflowModel`.

## Notes

Factory helper that constructs a configured model/workflow object.

## See also

- `[[nodiscard]] static WorkflowModel tree_factory::decision_tree_classifier(self, TreeFamilyOptions options = {});`

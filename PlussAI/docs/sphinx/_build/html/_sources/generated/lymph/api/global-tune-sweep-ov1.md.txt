# `tune_sweep`

## Signature

```cpp
StatusOr<nodej::TuneReport> tune_sweep( const std::vector<nodej::ModelSpec>& candidates, const nodej::LabeledBatch& batch, const nodej::SplitOptions& split = {}, const nodej::TrainOptions& train_options = {}, const nodej::AssessOptions& assess_options = {}, nodej::MetricKind objective_metric = nodej::MetricKind::Accuracy, nodej::TuneObjectivePolicy objective_policy = nodej::TuneObjectivePolicy::Auto);
```

## Parameters

- `candidates` : `const std::vector<nodej::ModelSpec>&`
  List-like argument; pass values in the order expected by the signature.
- `batch` : `const nodej::LabeledBatch&`
  Input feature data used by this call.
- `split` : `const nodej::SplitOptions&`, default: `{}`
  Configuration object controlling algorithm behavior and safety defaults.
- `train_options` : `const nodej::TrainOptions&`, default: `{}`
  Configuration object controlling algorithm behavior and safety defaults.
- `assess_options` : `const nodej::AssessOptions&`, default: `{}`
  Configuration object controlling algorithm behavior and safety defaults.
- `objective_metric` : `nodej::MetricKind`, default: `nodej::MetricKind::Accuracy`
  Metric selection or score-control argument for evaluation/tuning.
- `objective_policy` : `nodej::TuneObjectivePolicy`, default: `nodej::TuneObjectivePolicy::Auto`
  Target values aligned to input observations.

## Returns

Returns `StatusOr<nodej::TuneReport>`. Check `.ok()` first; on success read `.value()` for the computed result.

## Notes

Executes hyperparameter search and reports trial-by-trial objective values.

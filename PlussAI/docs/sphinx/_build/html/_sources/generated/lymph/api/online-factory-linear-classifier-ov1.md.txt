# `online_factory::linear_classifier`

## Signature

```cpp
[[nodiscard]] static OnlineLinearClassifier online_factory::linear_classifier(self, OnlineLinearOptions options = {});
```

## Parameters

- `self` : `receiver`
  Receiver object on which this method is invoked.
- `options` : `OnlineLinearOptions`, default: `{}`
  Configuration object controlling algorithm behavior and safety defaults.

## Returns

Returns `OnlineLinearClassifier`.

## Notes

Factory helper that constructs a configured model/workflow object.

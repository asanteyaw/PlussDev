lymph::models::Model¶

Summary¶

lymph::models::Model is the main cheap-copy trainable handle in Lymph.

Factories return it, prep stages attach to it, validation plans score it, and selection surfaces compare it.

Why This Object Exists¶

Model is the object that prevents everyday modeling work from collapsing into raw family options and one-off helper code.

You use it when one staged, trainable artifact is enough:

  • tabular classification

  • tabular regression

  • transform-style models

  • persisted classical-ML artifacts

Move upward to workflow::Workflow when the project needs stronger runtime orchestration than the trainable artifact alone.

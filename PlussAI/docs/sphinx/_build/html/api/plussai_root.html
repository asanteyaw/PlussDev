PlussAI API Reference¶

PlussAI is organized by public framework first, so you can enter through the exact namespace you are using in code.

  • classic is the public classical-ML framework over the internal nodej substrate.

  • nets is the public neural-module framework over the internal NodeK implementation.

  • nlp is the public text/NLP framework over the internal nodeb layer.

  • lymph is the high-level model/workflow framework built mostly over classic.

  • ice is the training/runtime framework built around nets.

  • procedure is the execution/persistence framework that coordinates artifacts across frameworks.

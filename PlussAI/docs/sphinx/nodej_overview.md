# NodeJ Overview

**NodeJ** is the explicit classical ML core in **PlussAI**.

Primary public modules:

- types / status / options
- dataset / data
- split
- prep transformers
- model families
- builders
- compose::Flow
- metrics / tune
- online
- io

The full method-by-method surface is documented in [NodeJ Full API Reference](nodej_full_api.md).

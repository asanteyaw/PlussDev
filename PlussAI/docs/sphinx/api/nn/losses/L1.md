# `pluss::ai::nn::losses::L1`

Mean absolute error between prediction and target.

## Signature

```cpp
Series nn::losses::L1(const Series& prediction, const Series& target,
                       const nn::losses::L1Options& options = {});
```

## What It Does

Computes `|prediction - target|` elementwise, then reduces it according
to `options.reduction` (see [`L1Options`](L1Options.md)). Grows linearly
with the error's magnitude everywhere -- unlike [`MSE`](MSE.md), which
squares it, a single large error here contributes proportionally to its
size, never disproportionately. This makes `L1` the most outlier-robust
of the regression losses in this family, at the cost of a gradient that
never shrinks as the error approaches zero (a constant `+1`/`-1`
magnitude, discontinuous exactly at zero error), unlike `MSE`'s gradient
which vanishes smoothly there.

## Parameters

`const Series& prediction`
: The model's output. Any shape; must match `target`'s shape exactly.

`const Series& target`
: The ground-truth value. Same shape as `prediction`.

`const L1Options& options`
: See [`L1Options`](L1Options.md).

## Returns

A scalar `Series` when `options.reduction` is `Mean` or `Sum`; a `Series`
the same shape as `prediction` when `None`.

## Errors

- `prediction`/`target` undefined, mismatched shapes, a non-float dtype,
  or different platforms -- throws.

## Practical Examples

Three examples: a hand-verified per-element result, a direct comparison
against `MSE` on a batch with one severe outlier, and confirming
[`SmoothL1`](SmoothL1.md) with `beta=0` reduces to exactly this loss.

### Example 1

Three predictions against three targets -- `Mean` averages the three
absolute errors directly, no squaring involved.

```cpp
#include <pluss/pluss.h>
#include <pluss/ai.h>

#include <iostream>

int main() {
  namespace nn = pluss::ai::nn;

  const pluss::Series prediction = pluss::make_series({1.0, 5.0, -2.0});
  const pluss::Series target = pluss::make_series({1.5, 2.0, -2.0});

  const pluss::Series loss_mean = nn::losses::L1(prediction, target);
  std::cout << "L1 (mean, default): " << loss_mean.item<double>() << "\n";

  nn::losses::L1Options none_opts{};
  none_opts.reduction = nn::LossReduction::None;
  const pluss::Series per_element = nn::losses::L1(prediction, target, none_opts);
  std::cout << "per-element |pred-target|: " << per_element << "\n";

  return 0;
}
```

Output

```text
L1 (mean, default): 1.16667
per-element |pred-target|: pluss::Series(shape=[3], strides=[1], dtype=float64, platform=cpu, numel=3, contiguous=true)
data=[0.5, 3, 0]
```

### Example 2

The same outlier-laden batch used to demonstrate
[`Huber`](Huber.md#example-3): `L1`'s ratio against `MSE` here is even
closer to the raw error magnitude than `Huber`'s was, since `L1` never
switches to a quadratic regime at all, not even for small errors.

```cpp
#include <pluss/pluss.h>
#include <pluss/ai.h>

#include <iostream>

int main() {
  namespace nn = pluss::ai::nn;

  const pluss::Series prediction = pluss::make_series({1.0, 2.0, 3.0, 4.0, 100.0});
  const pluss::Series target = pluss::make_series({1.1, 2.1, 3.1, 4.1, 0.0});

  const pluss::Series mse = nn::losses::MSE(prediction, target);
  const pluss::Series l1 = nn::losses::L1(prediction, target);

  std::cout << "MSE (squares the 100-unit outlier error):    " << mse.item<double>() << "\n";
  std::cout << "L1  (grows only linearly, everywhere):       " << l1.item<double>() << "\n";
  std::cout << "MSE / L1 ratio: " << (mse.item<double>() / l1.item<double>()) << "x\n";

  return 0;
}
```

Output

```text
MSE (squares the 100-unit outlier error):    2000.01
L1  (grows only linearly, everywhere):       20.08
MSE / L1 ratio: 99.602x
```

### Example 3

[`SmoothL1`](SmoothL1.md)'s source explicitly delegates to this function
when `beta=0` -- confirmed here to produce a bit-for-bit identical
result, not merely a mathematically equivalent one.

```cpp
#include <pluss/pluss.h>
#include <pluss/ai.h>

#include <iostream>

int main() {
  namespace nn = pluss::ai::nn;

  const pluss::Series prediction = pluss::make_series({1.0, 5.0, -2.0});
  const pluss::Series target = pluss::make_series({1.5, 2.0, -2.0});

  const pluss::Series l1 = nn::losses::L1(prediction, target);

  nn::losses::SmoothL1Options beta_zero{};
  beta_zero.beta = 0.0;
  const pluss::Series smooth_l1_at_zero = nn::losses::SmoothL1(prediction, target, beta_zero);

  std::cout << "L1:                  " << l1.item<double>() << "\n";
  std::cout << "SmoothL1(beta=0):    " << smooth_l1_at_zero.item<double>() << "\n";
  std::cout << "identical: " << std::boolalpha << l1.allclose(smooth_l1_at_zero) << "\n";

  return 0;
}
```

Output

```text
L1:                  1.16667
SmoothL1(beta=0):    1.16667
identical: true
```

# `lymph::prep::StandardScaler`

`StandardScaler` is the reusable learned numeric scaler in the `prep::scaling`
subfamily.

Use it when numeric centering and scaling should live as a standalone object
that can be fit, inspected, reused, and mapped outside a model-bound stage
graph.

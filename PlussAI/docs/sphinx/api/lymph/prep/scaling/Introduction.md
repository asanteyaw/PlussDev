# `prep::scaling` Introduction

## What This Subfamily Owns

`prep::scaling` owns reusable numeric scaling transformers.

These are the objects you fit on a frame or thread when you want learned
centering and scaling state to persist as a standalone transformer, not only as
an attached stage inside a model.

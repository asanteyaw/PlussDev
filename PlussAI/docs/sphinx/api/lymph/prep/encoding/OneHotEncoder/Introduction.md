# `lymph::prep::OneHotEncoder` Introduction

## What This Type Represents

`OneHotEncoder` is the object form of learned categorical expansion.

It remembers which indicator layout was learned from the training data and can
apply that same layout later to new inputs.

That persistence of category layout is the central value of the type.

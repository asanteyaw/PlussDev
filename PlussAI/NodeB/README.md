# NodeB

NodeB is the planned spaCy-like NLP space in `PlussAI`.

- Namespace: `pluss::ai::nodeb`
- Opt-in include: `<pluss/nlp.h>`
- Design target: production NLP pipelines with pluss-native naming and behavior
- Backend strategy: classical NLP + NodeJ integration for ML baselines, NodeK integration for deep models

See [NODEB_BLUEPRINT.md](./NODEB_BLUEPRINT.md) for the full architecture and roadmap.
